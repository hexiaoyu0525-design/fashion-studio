# 提交与商业落地：作品集 · Line Sheet · 标识包装 · 甘特 · AI 成片（17–21）

设计定稿后的最后一段：把作品**排成能评/能卖/能合规/能上架**的交付物。板面尺寸/字体/网格/命名统一见 `design-boards.md` 全局板面底座；工程文件（Tech Pack/BOM/3D）见 `technical-production-spec.md`；出图与出片提示词见 `image-garment.md`/`image-editorial.md`/`image-detail-fabric.md` 与 `video-brief.md`，本篇不重复。

## 17 ｜ 作品集 / 成品展示板 Portfolio Board　【语境：赛事/院校核心】

把 concept→research→development→final 串成一条叙事链。赛事语境表达优先，企业订货页保真优先（版型/面料成分克重/尺码/成本）。

### 规格

- **A3 297×420mm 横版、300dpi（3508×4961px，横版 4961×3508）是行业最主流**；提案/终期综合板用 A2。
- **大浪杯、新人奖用 27×40cm 横版**（非 A3/A4，单独模板）；海外多要求 A3 装订（每套至少正背双视图）。
- 汉帛奖：A3 建议横版、**总页数 ≤4 页装订邮寄**；首页彩色效果图+主题，其余页款式图+主题说明+面料小样，**稿面不得出现姓名/院校**。
- 视觉作品集常 **12–20 页**（LCF 上限 25 页）；图 60–75%、文 25–40%；横版为行业标准。
- **三件套（传统成衣赛通用）**：彩色效果图 + 款式/结构图 + 面料实物小样（小样尺寸各赛不同，见末尾速查）。

### 页序与排版

封面 → 概念/灵感 → 调研 → 色彩/面料 → 廓形/草图发展 → 款式图与技术规格 → 成品大片精选 → 系列 Line-up → 品牌/联系信息页。走 2–3 栏或 12 列网格、全册统一栅格与跨页；标题栏每页统一位置（系列名+页码）；图注 8–9pt、统一 Figure 前缀；一板至多 2 级标题、1 主视觉+2–4 辅助图+≤120 字说明；文本安全区 ≥5mm；PDF/X-1a 或 X-4、嵌入字体、单页 10–20MB【经验值】。

### AI 边界

AI 出氛围概念/情绪板/插画/大片/材质/风格迁移；**图内文字一律后期排，不进 AI**——实测短文本（1–3 词）约 75% 可读、长文本显著劣化，计数（纽扣/多件）在 2–3 个物体时成功率骤降；精确 hex 仍人工赋值，款式图约束后 AI 直出可用（07.5），严格对称靠提示 + 镜像后处理锁死。工作流：AI 出母图 6–12 张 → 人工筛选 PS 修图统一色调 → 线稿类走 Illustrator → InDesign 排网格/标题栏/图注/页码 → 打印 PDF/X（CMYK 300dpi+3mm 出血）或电子 PDF（RGB）。

验收门：尺寸/出血/dpi/色彩模式正确；全册栅格一致；层级 ≤3；图注齐；赛事稿匿名无身份越界；电子稿不滥用 CMYK 致偏色；页数不超标；企业稿不把 AI 图当实物图。

## 18 ｜ 订货目录 / Line Sheet　【语境：企业】

品牌发给零售买手的 B2B 订货文件（1–4 页），让买手直接从表上订货。与 Lookbook（卖生活方式、无价无规格）严格区分；与 Tech Pack 互补（线表=卖，技术包=做）。原则：**宁可朴素但完整，不可漂亮但缺项**。

### 字段（每 SKU 一行/一格）

产品图（正背/着装、干净底）｜**款号/SKU**｜产品名｜**面料成分**｜**颜色/色号**（旁附色块）｜**码段**（列全 XS–XXL，不得只写 S/M/L）｜尺码配比（每箱/每手）｜**批发价/出厂价**｜**建议零售价 MSRP/RRP**｜**MOQ**（每款/每色/总额）｜包装配比/装箱数｜**交期 Lead Time**｜条码。

- 封面：品牌 logo、季节/系列名、订货会信息、业务联系人、**下单截止日**。
- 条款页：MOQ（总额+每款都写）、付款（Net 30/60、COD、首单预付）、运输、交付窗口、cancellation date、翻单政策、退换、区域限制；附订货网格。
- 版式：A4/Letter、**PDF 为母版**（数据与版式分离，Excel 数据源合并），一页 ≤9 款，列头一致、缩略图比例统一。

### 定价数值（行业通识，非强制）

- keystone 模型：批发价 = 成本 ×2.0–2.5；零售价 = 批发价 ×2.0–2.5。
- **中国常用口径：零售 ≈ 出厂（FOB）的 2.5–4 倍**。
- 成本最常被漏算：物流/关税/损耗（新手常低估 COGS 20–40%）；成衣成本结构中面料占 40–60%、加工 CMT 20–35%、损耗 3–8%【通识】。
- 常见每款 MOQ 约 $150–500/款（品牌差异大，仅参考）；交期写"下单后 __ 天出货"，不写"尽快"。

### AI 边界

款号/价格/码段/MOQ/交期是商业数据，AI 不生成；订货产品图必须实拍或保真成片，**生成图不可当订货实拍图**；AI 出系列超真实展示图。排板用 InDesign/Illustrator，数据用 Excel，PDF 交付。

验收门：封面四要素齐；每款含图/款号/成分/色/全码段/双价/MOQ/交期；MOQ 总额与每款都写；条款页覆盖付款/运输/交付/截止/翻单/退换/区域；币种与含税口径明确；≤9 款/页。

## 19 ｜ 吊牌 / 洗唛 / 包装规范　【语境：企业落地合规】

合规重点。以下标准号与强制/推荐属性已逐条核实，**国标可能更新，落地前再查现行有效版本；合规判定必须由人工完成，AI 不能代判**。

### 中国市场使用说明 7 项（必备）

①制造者名称地址（中文）②规范品名 ③号型规格（如 160/84A）④纤维成分及含量（规范纤维名，"聚酯纤维"不写"涤纶"）⑤维护方法（符号或文字）⑥执行的产品标准 ⑦**安全类别 GB 18401 的 A/B/C 类**。耐久性标签（洗水唛）必含 3 项：号型、成分、维护方法。

### 现行标准（嵌编号，不展开来源）

| 标准 | 属性 | 要点 |
|---|---|---|
| **GB 18401-2010** | 强制 | 基本安全技术规范；**A 类=婴幼儿（≤36 个月）甲醛≤20mg/kg、pH 4.0–7.5；B 类=直接接触皮肤 甲醛≤75、pH 4.0–8.5；C 类=非直接接触 甲醛≤300、pH 4.0–9.0** |
| **GB 31701-2015** | 强制 | 婴幼儿及儿童（0–14 岁）纺织品，额外管绳带/小零件/重金属/邻苯；贴身标签不得直接接触皮肤 |
| **GB/T 29862-2013** | 推荐 | 现行有效；新版 **GB/T 29862-2026《纺织品 纤维含量标识技术规范》2026-07-02 发布、2027-08-01 实施后全部代替本版** |
| **GB/T 5296.4-2012** | 推荐 | 原强制性 GB 5296.4 已于 2017-03-23 转推荐性，正在修订；但《产品质量法》仍强制要求使用说明齐全 |
| **GB/T 8685-2008** | 推荐 | 维护符号法（MOD ISO 3758:2005）；符号顺序 **洗涤→漂白→干燥→熨烫→专业维护**；一横=缓和、两横=非常缓和、×=不允许 |
| GB/T 1335 系列 | 推荐 | 服装号型（基码见 `technical-production-spec.md` 15） |
| 出口 | 强制 | 欧盟 **EU 1007/2011**（纺织品纤维成分标签）；美国 **16 CFR 303**（纤维含量标识） |

**熨烫温度中西差异（出口标与内销标不可混用）**：GB/T 8685-2008 为 1 点 **110℃**/2 点 **150℃**/3 点 **200℃**；ISO 3758/GINETEX 为 120/160/210℃。初始水洗温度数字 95/70/60/50/40/30℃，手洗最高 40℃。
文字以中文为主、**外文字号不得大于中文、字高 ≥2mm**；安全类别必须明确写 A/B/C；执行标准写现行有效号（作废号判不合格）。
位置：上装洗水唛缝左摆缝中下部内侧，下装缝腰头里子下沿或左侧缝；吊牌经吊粒挂领口挂袢/裤腰袢。包装：一件一袋（OPP/PE）、吊牌朝向一致、按码分箱、加防潮剂、随箱装箱单、箱唛含款号/品名/色/码/数/毛净重/产地。

### AI 边界

AI 只做吊牌/包装视觉样式与图案参考；**标准号、安全类别、成分百分比、温度符号必须人工按现行标准核对，AI 不能生成或判断合规内容**；洗唛符号须用标准符号库（GB/T 8685 / ISO 3758）。

验收门：7 项齐；洗唛 3 项；安全类别与产品匹配；标准号现行有效；维护符号顺序与温度体系正确（内销/出口分体系）；中文为主、字高 ≥2mm；婴童标签不接触皮肤；吊牌与洗唛信息一致；一件一袋、按码分箱、装箱单齐。

## 20 ｜ 设计开发日程 / 甘特表　【语境：企业，轻量，可并入企划】

字段：阶段/任务｜负责人｜计划起止｜实际起止｜工期｜前置依赖｜里程碑（设计冻结/样衣确认/大货下单）｜状态｜交付物｜风险。Excel 横表，一条任务一行，可加按周条形甘特视图。

### 典型周期（行业通识区间，不可直接当承诺）

| 阶段 | 周 |
|---|---|
| 概念/研究/设计方向 | 1–3 |
| Tech Pack 开发（4–8 款） | 1–4（常与面料采购并行） |
| 面料/辅料采购（定制辅料 3–6 周易成瓶颈） | 2–6+ |
| 打板 + 首样 proto（国内 2–4，海外 4–6） | 2–6 |
| 试衣样 + 修改（**最被低估**，2–3 轮、每轮 1–3 周+物流） | 4–9 |
| 产前样 PP + 封样 | 1–3 |
| 大货生产 | 4–12 |
| QC 验货 | 几天–2 |
| 物流（海运 4–8） | 几天–8 |

- 印图贴牌（print-on-blank）6–10 周；**定制裁剪缝制（cut & sew）2–4 个月**；**完整开发周期 7–14 个月**；**国内品牌季度开发约 3–6 个月**，快反更短。
- **中国春节工厂停工 2–4 周（1–2 月），前后订单积压，须提前排期**。
- 延期逐段压缩中间环节（cascade），前端就要留缓冲；里程碑须可判定（如"设计冻结=所有款 Tech Pack Rev.A 下发"）。

### AI 边界

排期是数据与逻辑非视觉，AI 几乎无贡献（至多画流程示意图），周期须结合工厂产能/物料交期/节假日人工核定。
验收门：覆盖企划→设计→打板→样衣→试衣→订货→大货→入库全链路；每条含负责人/起止/依赖；试衣按 2–3 轮预留；大货物流含缓冲；标注春节/旺季。

## 21 ｜ AI 成片衔接（电商 / Lookbook / Editorial）　【语境：企业/商业】

只做衔接规范，不重做拍摄/灯光教程。

### 人体比例统一口径（写实与插画档不混用）

写实/照片向成片无母版直出统一 **1:9 头身、裆到脚底占身高 55%**；有 Muse 继承母版（详见 `image-editorial.md`）；9–10 头身只用于时装画（`fashion-illustration-spec.md`）。平铺/挂拍/人台走 `image-garment.md`，细节微距走 `image-detail-fabric.md`，走秀/短片走 `video-brief.md`/`video-film-types.md`，本篇不重复其提示词。

### 平台规格（平台规则以官方页为准）

- 淘宝/天猫：主图 1:1、800×800 经典、1000×1000+ 高清、≤3MB；第一张须实物图，禁拼接/边框/水印/促销文字，logo 左上宽度 ≤4/10；详情页宽天猫 790/淘宝 750px。
- 抖音小店：主图 ≥5 张、≥600×600、建议 1:1；3:4 主图 750×1000 最佳；白底 800×800、72dpi、≤3M。
- **Amazon 服装主图**：纯白 RGB 255,255,255；产品占画面 **85%**、完整不裁切、仅展示一次；**禁任何人台**（透明/实色/肤色/骨架/衣架均禁）；成人装真人站立；最长边 500–10000px（建议 1000+ 开缩放）；JPEG；主图禁文字/logo/水印/道具；命名 `产品ID.MAIN.jpg`。
- **AI 合成真人披露（2026 起硬规则）**：主图若含纯 AI 生成真人，须在图片 XMP 的 `dc:subject` 写入关键词 **`contains-synthetic-performer`**。
- Lookbook：A4（210×297）或 210×280/210×285，8–24 页（12–16 为佳），按跨页设计、1–2 look/跨页；印刷 300dpi CMYK+3mm 出血。Editorial 杂志 US Letter 8.5×11in；社媒 2:3/4:5/9:16。
- 视频衔接：Seedance 2.0 支持 4–15s、2.5 支持 4–30s（1080p、MP4/MOV）；走秀/360°/Lookbook 短视频 5–10s 一个镜头最稳。

验收门：电商主图纯白底/85% 占幅/无人台/无文字道具；AI 真人已加 `contains-synthetic-performer`；平铺对称、褶皱可控、细节齐；Lookbook 跨页栅格统一、单品信息全、印前规格对；写实比例 1:9（无母版直出）核验通过。

## 赛事提交速查（一页）

> 逐年微调，以下为 2025–2026 届实测；**正式报名以当年官方章程原文为准**。完整选赛、读题 9 项、三层分类、评分维度与获奖案例见 `aigc-competition.md`，本篇只做一页速查与"实物 vs 数字"分野。

### 两条赛道的本质差异

| 维度 | 传统成衣赛道 | 数字 / AIGC 赛道 |
|---|---|---|
