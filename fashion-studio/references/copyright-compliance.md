# AI 素材版权合规（企业与赛事共用）

企业里"无版权自查报告不提交"，赛事里"无 AI 创作说明 / 原创承诺书不受理"。两者底层是同一套东西：**素材来源、工具、提示词、风险、授权、原创证明**。

铁律：**每生成一批素材就同步登记**，不要等项目结束再补——后补等于没有证据链。

## 核心原则：参考全绿，交付分级

参考别人的作品是设计行业的正常工作方式，不需要把库清空。关键是把**参考**和**交付**分开：

- **参考（看、学、拆、垫、发散）**：**一切图皆可参考，无红线**——秀场/品牌/高定/获奖/真人脸都是素材，随便看、随便学、随便拆（学廓形/手法/质感/氛围/构图）。
- **交付（最终交付，尤其企业商用、公开发表、比赛评审）**：按用途分级——**练习/个人/内部：全 🟢**；**参赛/商用/公开发布**：只用 🟢 作锚点，🟡 必须已实质转化，🔴 一律不复现。

四级投喂权限的**完整定义**（各级细则、典型内容、法律依据、入库规则）只在 `asset-library-schema.md` 第 2 节；此处只给合规判定用的一句速览：**🟢 可投喂**＝自有 / 可商用 / AI 自建（Muse、数字样衣、自建创意面料）、过版权期历史/传统、通用材质工艺，参考交付全可用；**🟡 参考全开·交付按用途转化**＝真人脸、当代品牌/在世设计师/高定/当代获奖的整件或原创面料，**参考层随便看学垫、交付层仅参赛/商用/公开发布须转化**（真人脸→成片实质改到不可指认原真人即可用；设计师款→并置不可识别同源），练习/内部全 🟢；**🔴 慎喂·交付不复现**＝品牌 Logo/老花/经典格纹/注册印花，**可看可学可提炼（配色/构图/手法）、慎喂垫图、交付不复现**；**⚪ 仅知识**＝布光/镜头/廓形/风格等定义理论，不入库。

> 合规判定只看**交付**：参考层看过、垫过任何图都不违规（参考无红线）；违规的是**交付**（参赛/商用/公开发布）仍可识别为某真人、某品牌标志，或与某设计师款雷同。因此公开交付须留"参考 → 如何转化"的痕迹（见第五节）。

## 一、四类核心风险（每款素材都要能回答）

1. **训练数据风险**：模型可能学过受版权保护的作品、品牌、艺术家风格；AI 出图可能与在先作品构成实质性相似。
2. **商用授权风险**：所用工具的免费版 / 订阅版条款是否允许商用；生成图的版权归属与可商用范围；字体、图标、贴图的授权。
3. **肖像权 / 人格权风险**：垫图、参考图里出现真实人物、明星脸；AI 生成了"像某个真人"的脸。**过程里可把真人当"类型"参考（🟡），但终稿不得可识别为某真人**；正确做法是据此生成新的 AI Muse 并锁定身份。
4. **商标 / 相似度 / 抄袭风险**：品牌 Logo、老花、经典格纹、注册印花（🔴 不得复现）；与某品牌标志款、某设计师签名风格、某非遗纹样的特定表达高度雷同。通用材质/工艺/过版权期元素不属此类。

## 二、 提示词纪律（底线，直接照做）

- **终稿提示词不得出现**：品牌名、设计师名、艺术家名、明星名、受版权保护的角色 / IP、品牌老花/Logo 名。
  - 不写 `in the style of XX`、`XX 风`、`某某同款`、`XX 联名`。
  - 过程里可参考这些品牌，但落到**终稿提示词**时改写成可描述的视觉语言：不写"某大牌风"，写"哑光金属扣、宽肩茧型、低饱和大地色、明线辑边"。
- 垫图 / 参考图：**参考层随便垫（无红线）**；**公开交付**确认级别：🟢 可进终稿；🟡 已实质转化并留转化记录；**🔴 标志图慎喂垫图**（模型会复现标志、难剥离），公开交付不复现。
- 图标、字体、贴图单独查授权，不用 AI 生成近似 logo。
- 传统纹样：**文化母题可借鉴，避开他人对该纹样的特定独创性表达**——学"公共文化元素"（如通用云雷纹、海水江崖纹），不抄"某个人画的那版具体设计"。

## 三、逐图版权标注表（L1 随件，每款素材一行）

| 字段 | 内容 |
|---|---|
| 素材编号 | 组别_素材类型_编号_v版本（命名规则见下） |
| 素材名称 | 如：面料-月白暗纹-01 |
| 生成工具 / 模型 | 即梦 Seedream / Seedance / 所用云平台或模型名 |
| 关键提示词摘要 | 正向 + 负面提示词的核心句（终稿无品牌/明星名） |
| 终稿锚点来源 | 🟢 自有 / 可商用图库（附授权）/ 无 |
| 过程参考（🟡） | 用了哪些真人/品牌/设计师参考，以及如何转化（无则填"无"） |
| 用途 | 企划 / 电商 / 赛事 / 内部 |
| 风险等级（按终稿） | 高 / 中 / 低 |
| 规避措施 | 改了什么、避开了什么、转化了什么 |
| 生成时间 | 年月日时分（原创证明用） |
| 责任人 | 谁生成、谁审核 |

**命名规则**：`组别_素材类型_编号_v版本号`，如 `高定_面料_01_v3`；终版标 `v最终版`。

## 四、风险评级（按终稿处理）

- **高**：终稿含可识别的真人脸/明星相、品牌 logo/老花/注册印花/IP、与知名设计师款雷同、来源不明网图直接进终稿、客户指定商标。
  → 必须重做（改到不可指认原真人 / 换 🟢 锚点 / 重画标志元素）或取得书面授权，否则不上稿。
- **中**：终稿与某品牌款风格相近但已显著改动、由 🟡 过程参考转化而来、热门模型常见画面、无明确授权的图库图。
  → 留迭代与转化过程 + 与源作并置自查不可识别同源 + 合规/法务确认。
- **低**：🟢 自有素材、AI 自建 Muse 与样衣、过版权期历史/传统元素、通用面料肌理、无主体的纹理/材质、抽象背景。
  → 登记即可。

> 过程参考（🟡）本身不按高风险登记——它只在"没有转化、被带进终稿"时才升级为高/中风险。

## 五、原创性证明（证据链，企业与赛事都要留）

每款保留：**生成工具 + 关键提示词摘要 + 生成时间 + 迭代版本**（垫图前后对比、废稿）。凡用过 🟡 过程参考，**额外保留"参考了什么 → 怎么转化"的对照**（源链接、过程稿、最终稿，说明改了廓形/配色/材质/身份）。这是"自主设计 + AI 辅助"、同时也是"已实质转化"的证据。

- 核心判断（也是金奖设计师的共识）：AI 生成的前提是先有人做出过类似的东西；**要做有风格的东西，造型、结构、版式判断必须由人主导**，AI 是加速器，不是作者。
- 刻意保留"人做了什么"的痕迹：选题、母题提取、解构规则、配色决策、筛选与迭代。

## 六、版权自查报告（横切交付物，四板块）

1. **风险识别清单**：按四类风险逐项列，每款素材 / 每个风险点，附依据（法条、判例、平台条款）。
2. **规避措施**：每个风险点对应做了什么（改提示词、换来源、重绘、转化、取得授权）。
3. **合规声明**：本项目所用工具、素材来源、授权范围、是否可商用；原创承诺；肖像与商标处理情况。
4. **原创性证明**：工具链 + 提示词摘要 + 生成时间 + 版本过程 + 🟡 参考转化记录；责任人签字 / 日期。

## 七、企业 vs 赛事差异

- **企业**：交版权自查报告，重点是"可商用、可追责、可生产"；进电商上架 / 投放 / 订货会前必须过；法务和运营要能据此追责。
- **赛事**：按赛题交"AI 创作说明 / 原创承诺书"，披露工具、流程、关键提示词、自主与 AI 分界；常需作者签字；限定平台赛只能用指定平台。
- **禁 AI 的赛**：如部分传统赛、Louis Vuitton 配饰赛（规定 AI 不得用于交付物、文字与视觉渲染），不投，或按其规则手绘 / 3D 辅助。

## 八、提交前自查（过程 / 终稿分开，不通过不交）

**过程（可做）**
- [ ] 🟡 参考已登记来源链接，仅用于发散，未当作终稿锚点
- [ ] 真人脸垫图成片已实质改到不可指认原真人（或已建新 Muse 复用）；品牌老花/Logo 未进图生图

**终稿（必查）**
- [ ] 提示词无品牌 / 设计师 / 艺术家 / 明星名，无受保护 IP、无老花/Logo
- [ ] 画面无"可识别为某真人"的脸；无品牌 logo / 老花 / 经典格纹 / 注册印花
- [ ] 用 🟡 参考的款式已实质转化，与源作并置不可识别同源，并留有转化记录
- [ ] 每款素材有来源、工具、提示词、时间、责任人
- [ ] 高风险素材已重做或持有授权；字体 / 图标 / 贴图授权齐全
- [ ] 报告四板块完整、有签字日期（赛事则原创承诺 / AI 说明齐全）
