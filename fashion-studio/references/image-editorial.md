# 生图 · 模特大片与 Lookbook

## 通用要求（两个场景都要遵守）

### 1. 服装锚点校验
每次生成前，必须先读取对应的纯白底服装图，按 `consistency-lock.md` 锚点清单（结构 / 版型廓形 / 颜色及色位 / 长度 / 闭合件 / 图案·纹样·印花 / 配饰鞋履 / 面料质地）**逐项回读成锚点清单给你确认（"对"再往下）**，再写进提示词，**禁止仅凭文件夹名称臆测服装细节**。

### 2. 人物身份明确
多人图必须在prompt开头明确指定：
- 几男几女
- 各自发型、长相差异
- 不重复的角色定位

**禁止默认生成同性别同脸模特**。

### 3. 比例与透视（统一口径）

- **比例口径**：无母版直出写实/照片向 = 头身比 **1:9**、裆到脚底 **55%**（提示词写死）；有 Muse 以母版继承、不写数字（见「通用要求 5」）；插画/时装画档 9–10 头。
- 低角度广角/仰拍：**不另写头身比数字**，靠机位/构图/透视组合控制（低角度显气场但会拉长腿；全身多图用同一机位高度比例才可比）；透视下腿部自然拉长属正常，禁"头大身短畸变"。
- 出现比例畸变时，**禁止在旧图上局部微调**，必须以参考原图为核心重新生成，避免模型被错误结构锚定

### 4. 用户意图快速对齐规则
- 群像图默认做错落高低站位，**禁止用对称十字规整站位**
- 出现方向偏差时，直接以用户最新指定的参考图为唯一锚点，放弃之前的自行脑补设定

### 5. 成片人体锚 = Muse 写实母版（效果图禁作人体锚）★母版锚定法

写实成片（氛围大片、lookbook 实景、场景片）的**人体比例与身份，一律以 Muse 写实母版为唯一锚点**（用与目标机位同向的那张：正面全身 / 侧面全身 / 背面全身；身份细节用面部母版核验）。规则：

- **效果图/时装画是 9–10 头身体系，禁止当作写实大片的人体锚垫图**——直接把效果图当图1 垫图生成大片，成片会继承时装画比例、回弹成插画式拉长比例（实测翻车，勿重复踩）。
- 效果图在成片中的角色只有一个：**服装结构参考**（锁结构/版型/长度/闭合件/纹样/面料），与 Muse 母版一起双图垫入。
- 垫图组合：**图1 = Muse 写实母版（比例+姿态唯一基准）**、**图2 = 效果图（只供服装）**、**图3 = 面部特写/四宫格（身份锚）**；Prompt 结构见下方「场景3」。
- **成片提示词默认不写头身比数字**（"1:8 / 1:9 / 几头身"一律不写）——母版已把比例像素级锁住，数字约束只会触发模型粗暴执行（拉长腿/缩头），约束越多错越多（实测：写死数字的两版均翻车，去掉数字靠母版继承一次通过）；**仅在出图明显矮挫/比例异常时**才补"身形偏修长、腿部自然拉长"这类无数字的区间提示。
- **禁止对成片做自动头身划线测量**（远景/氛围/雾景场景的肤色轮廓自动检测不可靠，多次实测失败）；比例验收 = **母版继承 + 用户目测拍板**（用户确认后直接采用，不重复测量）。
- 无 Muse 母版时先按 `ai-model-muse.md` 建（标准 6 件模卡资产包），不要拿效果图硬顶。

### 6. 大片人脸双锁协议（有 Muse 必走）★人脸防漂移

有 Muse、甚至各角度面部母版齐全时，大片加入场景光线后人物长相仍漂移的根因：**全身母版人脸信息量不足、参考图注意力被场景稀释、只有图片锚没文字锚、机位角度错位**。杜绝打法（按优先级执行）：

1. **脸单独用特写母版垫**：垫图组合 **图1 = Muse 着装定妆图**（锁服装结构/版型/色位/闭合件/面料），**图2 = 面部特写母版（母版_04）或面部四宫格整张（母版_02）**——四宫格一次给模型"这个人多角度长什么样"；**全身母版不负责锁脸**（人脸像素太小 = 等于没锁）。**没有着装定妆图（只有母版+效果图、衣服未上人身）→ 走场景3（先出对应角度着装图再成片）；已有着装图 → 本协议。**
2. **图片锚 + 文字锚双锁**：提示词把身份卡原文写进去——"五官（眼型/鼻梁/下颌线）、发型、发色、肤色、标志特征与 @图片2 完全一致，不得改动，不随光影改变五官结构"。**图片管"像"，文字管"不许改"，两样都上才稳**；只图不字 = 模型当风格参考自由发挥。
3. **角度对齐**：大片什么机位就垫什么角度的脸——侧机位用侧面/微侧面部图，正面机位用正面特写；四宫格天然覆盖多角度。
4. **参考图优先级（重要）**：**服装图与脸部图必须准确、绝对保住**；**场景图可舍弃、用文字描述、或允许虚化模糊**——镜头聚焦人物、场景虚化是正常摄影语言；场景参考图与服装/脸部图抢名额时，**牺牲场景，不牺牲服装和脸**；参考图越少每张权重越高。
5. **两段式出图（最稳保险）**：第一步 脸部特写 + 场景（或文字），先出**中近景大片**确认"这个人在这个光线下长这样"；第二步以这张已确认图为图1，扩展全景/换机位。**脸先定，再谈场面**。
6. **大片默认 Seedream 5.0 Pro**（编辑一致性更强、防漂移，见 `tool-adapter.md` 默认档）；成组图固定同一机位高度与光位（机位错位是身份漂移常见诱因）。

### 7. 场景三情况路由（大片出图前先选）★场景怎么给

核心不变：**服装与脸是硬锚，场景是变量**。场景按下面三情况定路径：

| 情况 | 怎么走 | 参考图组合 |
|---|---|---|
| **① 无场景图** | 纯文字场景描述（地点/空间/光线/氛围一句话写清），走默认人脸双锁 | 图1=着装定妆 · 图2=面部特写/四宫格（场景不入参考图） |
| **② 有纯环境场景参考图** | 三图全保：场景图必须是**纯环境图**（无人、无强视觉主体），只提供空间/光线/色调；提示词逐图声明职责 | 图1=着装定妆 · 图2=面部特写/四宫格 · 图3=纯环境场景 |
| **③ 要替换人的场景图** | 底图编辑换人协议（见下）：场景图是编辑对象本体，把其中人物替换为 Muse | 图1=场景原图(壳) · 图2=Muse 面部 · 图3=着装定妆 |

**情况②注意**：场景图有人/有强主体 = 不能用，裁剪成纯背景或退回①；三图全保后服装/脸开始漂 → 确认已用 Seedream 5.0 Pro（默认档），仍漂则退回①两段式。

**情况③ 换人协议（底图编辑，走 `image_edit` 主体替换，不用文生图）**：

- 编辑指令逐图声明职责（示例）：
  "保留画面中的背景环境、空间构图与光线氛围不变；将画面中<指定人物>整体替换为 @图片2 所示的模特——五官、发型、肤色与 @图片2 完全一致，不得改动；为其换上 @图片3 所示的服装——结构、版型、颜色位置、闭合件、面料与 @图片3 完全一致；保持人物原有姿势与站位；人物光影与场景光线方向一致、融入画面，镜头聚焦人物，背景允许浅景深虚化。"
- 出指令前先定 **4 个决策**：
  1. **替换范围**：整人替换（脸+身材+服装全换）vs 只换脸+只换衣——整人替换对身份继承最彻底；只换脸保留原人物身材/姿态。
  2. **姿势站位**：保留原姿势替换最稳（模型不用重构图）；重摆姿漂移概率上升。
  3. **多人场景指名对象**：必须指名（"画面中左侧穿黑西装的男人"/"最右侧的女性"），否则模型随机换人。
  4. **体型差异**：原人物与 Muse 体型差异大（壮汉 vs 瘦高女模）会串体型，补"体型与 @图片2 一致"。
- **3 个坑**：
  1. **光线延续**：补"人物光影与场景光线方向一致"，否则人物像贴纸。
  2. **真人转化义务**：他人真人照片替换后成片仍可能残留原人特征，公开交付前按 `copyright-compliance.md` 实质转化；自己拍的场景无此约束。
  3. **脸漂保险**：第一版直接整图替换；脸漂 → 局部圈选脸部替换为 Muse 脸，确认后再换衣；仍不稳确认已用 Seedream 5.0 Pro（默认档），再按 `consistency-lock.md` 一致性 SOP 排查。

## 场景1：从零创作（纯文字，无参考图）

**什么时候用**：没有任何参考图，完全靠文字描述从零创作。**有 Muse / Muse 着装图不算"无参考"**——垫图走「通用要求 6」人脸双锁（图1 着装定妆 + 图2 面部特写/四宫格），场景纯文字描述即可；**真正一张图都没有**才纯文字直出（无母版 1:9+裆 55%，见「通用要求 5」）。

### 步骤

1. **定风格档**：从20种风格里选一个（见下方风格字典）
2. **定场景**：从20种场景里选一个（见下方场景字典）
3. **定模特**：几男几女、姿态、妆造
4. **定光线**：硬光/柔光/逆光/胶片
5. **写prompt**：把服装锚点写进去
6. **生成 + 验收**

### 提示词模板

```
[风格档] + [场景] + [模特姿态] + [光线/胶片]
服装：[从纯白底图读取的服装描述：廓形+结构+颜色+面料+特殊设计]
比例：无母版直出统一写"头身比 1:9、裆到脚底占身高 55%"；有 Muse 以母版为准、不写数字（见「通用要求 5」）
负面：不要插画、不要塑料CG、不要多余手指、不要比例失真、不要擅自加配饰、不要改变服装颜色与结构
```

### 两种图的区别

| | 极简影棚 Lookbook | 编辑大片 Editorial |
|---|---|---|
| 目的 | 看清衣服，商业、干净 | 传达调性、氛围、气场 |
| 背景 | 无缝背景 cyclorama | 实景或艺术化布景 |
| 布光 | 两个大柔光箱，均匀无影 | 单一硬主光 + 轮廓光 |
| 光圈 | f/8 全件清晰 | 浅景深、有情绪 |
| 姿势 | 站姿正面，结构完整 | 保持住的姿势，可坐可动 |

### 影棚 Lookbook 公式

```
模特穿着[描述服装]，站直正对镜头，纯白无缝背景；
两个大柔光箱均匀棚光，无硬阴影；
f/8 让整件衣服从头到脚清晰，每条接缝、翻领、口袋都可见；
中性、专业、商业 lookbook 摄影；[比例]。
```

### 焦段与镜头

- **50mm**：全身、环境宽景，透视自然
- **85mm**：三分之四肖像，自然压缩、浅景深
- **120mm 微距**：面料与配饰特写

### 胶片质感（治塑料感）

给 AI 默认的"数字塑料感"最有效的办法是指定胶片：

- **Kodak Portra 400**：暖、柔和、肤色好、色彩饱和
- **Fujifilm 400H**：冷、干净、清淡

### 模特身形硬标准（统一口径）

```
无母版直出（写实/照片向）：头身比 1:9，裆到脚底占身高 55%——提示词统一写死这两组数字；
有 Muse：以母版继承（不写数字）；插画/时装画档：9–10 头。
```

**执行口径**：**成片垫 Muse 母版时，提示词不写头身比数字**（母版已锁比例，数字只会触发模型粗暴拉长/缩头，约束越多错越多，见「通用要求 5」）；**纯文字无母版**（场景1）统一写 **1:9 + 裆 55%**，并按机位/构图/姿势/裁切透视组合校准（低角度显气场但会拉长腿，全身多图同一机位高度比例才可比，见下）；**9–10 头属插画/效果图体系，禁用于写实大片**；比例差先调组合参数，仍差按锚点重出。

每张模特图都要锁五官、发型、肤色、妆容（比例由母版继承时，这条不重复写数字）。

### 表演锚点（大片表情/情绪写法）

大片模特的表情不是"高级脸/清冷/松弛"这种词能写出来的——模型渲染不了情绪名词。写表演 = 感受词打头 + **一个可执行物理锚点**；禁习语（"目光如刀"），禁纯肌肉列表（"嘴角下压"会读成噘嘴）。与视频表演锚点（`video-brief.md`）同一套写法，静态图只定格在"瞬间"。

| 感受 | 物理锚点（可执行） |
|---|---|
| 清冷/疏离 | 眼神不追镜头，嘴角无弧度，下颌微抬 |
| 松弛/高级 | 肩线放平，重心单腿，视线自然游移 |
| 克制/紧绷 | 喉结微动，指尖轻按面料，呼吸可见 |
| 沉浸/享受 | 闭眼微仰，裙摆被风吹起时匀速转身 |
| 惊讶/被吸引 | 视线先到、头后到；眨眼后目光停在目标上 |
| 不舍/收束 | 手在面料上滑到边停住，不看镜头 |

微表情物理锚（单镜内最多 2 个）：一次眨眼、喉结动、嘴角上挑并保持半秒、指尖轻压。群像/多人时：每个出场人物各挂一个表情锚点，与身份卡（`ai-model-muse.md`）绑定，不共用同一张脸。

> 下表与 `video-brief.md` 表演锚点表**同源**（感受词 + 物理锚点，同一套写法），改动须同步两处。

### 服装锚点（大片里最容易丢）

- 结构、版型、颜色及颜色位置、长度、闭合件、图案/纹样位置、配饰鞋履、面料质地（完整清单见 `consistency-lock.md`）
- 变化只允许：姿势、场景、光线
- 风格、动作越大，越要把服装锚点写成禁令
- 低角度显气场但会拉长腿；全身多图要用同一机位高度，比例才可比

### 大片布光

- 起手：大面积柔光前侧，对侧反光板，让脸、领口、下摆都可读
- 分离背景：加轮廓光
- 面料决定光位：见 `image-detail-fabric.md` 的面料-光位表
- 在模特的完整姿势/运动路径上判断布光，不只看一个站位

### 光即情绪五杠杆（布光前先定"光在说什么"）

布光方案确定前，先过这五问——比堆"氛围感/电影感"三个字可靠，与视频布光（`video-brief.md`）同一套逻辑：

| 杠杆 | 怎么调 | 读出来是什么 |
|---|---|---|
| 光比 | key:fill 低比高调 | 低比=安全/开放/商业；高比=私密/威胁/戏剧 |
| 主光方向/高度 | 正面/侧面/逆光/底光/顶光 | 正面讨好、侧面揭示肌理、逆光孤立、底光不安、顶光审判 |
| 色温 | 暖/冷/冷暖并置 | 暖=亲密/记忆；冷=距离/夜；并置=内在分裂 |
| 动机 | 每个光源必须有来处（窗/灯/屏/太阳） | 无动机的"美光"=塑料感 |
| 光随转折变 | 云过、灯开、门缝光束 | 剧情翻转时光一起翻 |

大片风格档默认光位已给（如 Noir 硬主光+深影、浪漫柔光低对比），换档或换单件布光时用五问验证：光有没有动机、够不够让面料/轮廓可读、情绪对不对。

### 五·附 大片光影与真实感（布光逻辑，写实大片/视频共用）

大片"像真照片"的光，核心是**不均匀**——AI 通病是面部光影平、全脸均匀补光，均匀光最 AI。布光三原则：

| 原则 | 怎么做 | AI 提示词锚点 |
|---|---|---|
| 拒绝全脸均匀光 | 户外：树影切割打在脸上、阳光局部打亮半边脸、眼窝自然阴影、鼻底厚重阴影、下颌线阴影分层、帽子/头纱遮挡形成局部暗部 | 面部光影不均匀、树影斑驳切割、半边脸受光、鼻底下颌阴影分层 |
| 环境反光（真人皮肤反射环境色） | 绿植环境→脸颊微蓝绿反光；白墙建筑→冷白反光；傍晚→暖橘面中反光 | 皮肤带环境色反光（蓝绿/冷白/暖橘） |
| 哑光皮肤 + 局部高光 | 哑光皮肤为主，只留 T 区少量出油高光；**禁"皮肤发光、通透柔光"** | 哑光皮肤、T 区微微出油；不要皮肤发光/通透柔光 |

- **与风格档的关系**：这是写实大片的**底层光逻辑**，各风格档的"布光/胶片"列在此基础上叠加（如"黑白电影档"仍可硬光+深影，但面部仍应有明暗分层，不是平光）。
- **与锚点的关系**：光影属"光源"白名单，可随场景与情绪变；**但同一系列内光位逻辑保持一致**（如"户外树影"定调后不中途换成"棚拍均匀光"），避免系列内画面割裂。
- **与源感锁定的关系**：整体质感采集源（手机实拍/胶片/棚拍等签名瑕疵）见 `image-quality-sop.md` 五·附 1 源感锁定——两者互补：源感定"这是什么影像"，本节定"光怎么打"。
- 视频联动：同一光逻辑贯穿全片（`video-brief.md` 布光与面料节）；光源变化是白名单内允许的，服装锚点（结构/色位/版型/长度/闭合件/图案纹样/配饰鞋履/面料质地）依旧锁死。

### 面料带物理描述

静态图通过褶皱与垂坠体现物理：

- 重磅牛仔：保持硬挺折痕
- 轻薄亚麻：细密波纹、易皱
- 真丝：荡开、缓慢回落、连续褶浪
- 羊毛：整体摆荡、停步后缓缓垂下

### 系列图一致性

一个系列多张图要统一：**同一服装锚点、同一白平衡、同一布光逻辑、同一风格语言**。模特可以 1 个，也可以 **2–3 个**（品牌大片常见配置）：**每个模特跨图锁同一身份**（同一张参考图 / 同一身份卡反复挂），模特之间要有区分度（五官/气质/身形不打架）；群像同框图每个出场人物各锁一个身份。

先生成一张中性开场图定调，再在此基础上变化姿势与场景。

**长期固定同一个模特**（做身份卡、标准 6 件模卡资产包、每张图重新挂同一张图2、跨系列复用）的完整做法见 `ai-model-muse.md`。

## 场景2：复刻参考（有参考图，只换服装）

**什么时候用**：有参考图，想复刻它的模特/场景/灯光/动作，只把服装换成自己的。

**入口分流（给的是有人物的参考图时，先判意图再走）**：
- 保留原人物、**只换服装** → 本场景（场景2）；
- **场景保留、人物换成 Muse**（脸/身材/服装全换）→ 走「通用要求 7」情况③ 换人协议（`image_edit` 底图编辑），**不回本场景**；
- 场景图是**纯环境图**（无人）→ 走「通用要求 7」情况② 三图全保。

### 步骤

1. **先读参考图**，填这个表：
   - □ 景别：近景/中景/全身
   - □ 动作：站/坐/走/跑
   - □ 场景：建筑/街头/自然
   - □ 光线：硬光/柔光/逆光
   - □ 模特：几男几女、姿态、妆造
   - □ 核心道具：豹子/车/包等

2. **写prompt**：说明什么不变，什么换服装
3. **生成 + 验收**
   - □ 参考图里的动作、姿态、景别是否100%复刻
   - □ 参考图上的文字水印是否已在prompt里明确要求去除
   - □ 参考图里的核心道具是否保留
   - □ 多人物服装对应位置是否正确，没有串款

### 提示词模板

```
图1=参考整张大片（只提供构图/人物姿态/场景/光线/角度/风格语言，不提供服装）
图2=我的数字样衣/服装锚点（锁结构/版型/颜色位置/长度/闭合件/图案/面料，完整清单见 `consistency-lock.md`）
正向：保留图1的构图、人物姿态、场景、光线、拍摄角度与整体风格，
      仅将人物身上所穿服装替换为图2所示服装（结构、颜色、面料照图2不变）
负面：不要改变姿势/场景/光线/角度、不要保留图1原服装、不要改图2的服装结构与颜色
```

### 权限边界（参考全绿，交付分级）

- 🟢 自己的图 / 自己 AI 生成的模特大片：整图完全沿用，模特即本人
- 🟡 当代品牌/高定/获奖/**真人模特大片**：**参考随便用**（场景、光线、角度、构图、风格语言可沿用，学手法）；真人脸**可作垫图基底**，**公开交付**（参赛/商用/公开发布）成片须**实质改到不可指认原真人**（改五官/发型/妆容/年龄/气质等实质维度，非滤镜级微调；也可顺带生成同类型 AI Muse 替代、或只取身形姿态不取脸）；练习/内部全 🟢。**秀场参考图全绿**（🟢 可看/学/拆/垫、可作长期参考，学布光/节奏/廓形语言；**拿秀场款当改造基底是行业常态**——改结构/面料/色彩即改造）
- 🔴 品牌 Logo/老花：**看与学无限制、慎喂垫图、公开交付不复现**（规则见 `asset-library-schema.md`）
- 沿用效果好、想复用的"人"→ 按 `ai-model-muse.md` 提炼成固定 Muse 身份卡

### 场景轻微调整

只动一个变量——"保留图1一切，仅把背景改为 X"或"仅把光线改为 X"；一次只换一处，便于归因返工（`consistency-lock.md`）。

### 系列多模特（2–3 个）

一个系列可以出现 2–3 个模特（品牌大片常规配置）。规则：
- 每个模特跨图锁同一身份：同一模特的多张图挂同一张参考图2 / 同一身份卡，不漂移
- 模特之间区分度要够（五官/气质/身形不打架）；群像同框图每个出场人物各锁一个身份
- 服装锚点全程不变（结构/颜色/面料只随姿势、场景、光线变化）

### 返工

锚点 = 参考图的构图/人物/场景/光线 + 我的服装；改服装结构/颜色/身份 = 锚点级整图重出；仅调场景细节 = 轻微重出或圈选（遵循 `consistency-lock.md`）。

### 衔接四步管线

建议先有②成衣定妆（自家服装锁定）再做整图沿用；整图沿用 = 管线③的快速变体（模特来源从 Muse 换成参考图人物）；多张同款沿用挂同一张图1，跨图一致。

## 场景3：从「Muse 写实母版 + 效果图」做氛围成片（母版锚定法）

**什么时候用**：已有①固定的 Muse 写实母版（标准 6 件模卡）和②已定稿的效果图/定妆图，要做"非秀场的氛围大片/场景成片"（换场景、换光、换构图，服装与身份不变）。这是**系列成片阶段的唯一正解**——效果图只管服装，比例与身份全靠母版，出片一次到位。
> **已有着装定妆图（Muse 已穿着该款）时，优先走「通用要求 6」**（图1 着装图 + 图2 面部特写）；本场景用于**只有母版+效果图、衣服还没上人身**的组合。

**效果图人物身份判定（用效果图前先判）**：
1. 先对照 Muse 母版：五官/发型/肤色/标志特征一致**且写实比例** → 这就是 Muse 着装定妆图，直接走「通用要求 6」；
2. 对不上/拿不准 → 问一句"这张效果图里的人物是你的 Muse 本人吗"；
3. 兜底：无法确认是写实的 Muse 本人 → 一律按"只供服装"处理，走本场景合成（不冒险拿错的人体锚）。

### 步骤

1. **取锚**：
   - 图1 = Muse 写实母版，选**与目标机位同向**的那张（正面全身 / 侧面全身 / 背面全身）——**只锁比例与姿态，不负责锁脸**；
   - 图2 = 该款效果图/定妆图（只供服装结构）；
   - **图3 = 面部特写母版（母版_04）或面部四宫格整张（母版_02）——人脸锚，必挂**（"全身母版人脸像素太小=没锁"，见「通用要求 6」）。
   - **角度不足（Muse 着装图只有正面，成片要用侧面/背面等角度）**：先用 Muse 其他角度母版（侧面全身/背面全身/三视图）把该款服装"穿"上去，出一张对应角度的着装图（比例/身份继承母版、服装照效果图），再以该着装图为服装锚出该角度成片。
2. **定场景与光**：从下方风格字典选档（氛围片常用"国风东方/暗黑情绪/自然环境"等），过「光即情绪五杠杆」确定光位、色温、动机；构图（主体占比/留白/景别）写入。
3. **写 prompt**（模板见下）：锁「图1 比例/姿态不动 + 图3 身份不动 + 图2 服装不动 + 仅场景/光/构图/动作变」。
4. **生成 + 验收**：
   - □ 比例：以图1 母版继承为准，**用户目测**确认（不做自动划线）；
   - □ 身份：五官/发型/妆容/记忆点/纹身在、与图3 核验一致，未漂移；
   - □ 服装：结构/版型/长度/闭合件/纹样/面料与图2 一致；
   - □ 场景光：与方案一致，氛围优先；无文字/水印/多余人物/现代元素。

### 提示词模板

```
参考图1=Muse写实母版<对应视角>（比例/姿态唯一锚：写实人体比例与站姿以图1为准，含身形、纹身；不写头身比数字）
参考图2=效果图/定妆图（只供服装结构，不作人体锚）
参考图3=面部特写/面部四宫格（人脸锚：五官、发型、妆容、记忆点以图3为准）
正向：以参考图1为比例与姿态基准、以参考图3为身份基准——完全保持写实人体比例（以图1为准，不写头身比数字）、站姿，
      五官、发型、妆容、<记忆点>与 @图片3 完全一致、不得改动，不要拉长腿部、不要缩小头部、不要改变脸型；
      将参考图2的整套服装完整穿到该人物身上：<服装锚点逐项：结构/版型/长度/闭合件/纹样/面料质地>；
      场景与光线替换为：<场景/光位/色温/氛围/构图/主体占比/留白/动作>；
      写实摄影质感、真实皮肤肌理、<面料物理>、电影级光影、去AI塑料感；
负面：不要文字水印、不要多余人物、不要改变服装结构与颜色、不要改变人物身份与比例、
      不要现代元素、不要插画
```

### 与场景2 的区别（避免混用）

- 场景2「复刻参考」：图1 = **参考大片**（借构图/姿态/场景/光线/风格语言），图2 = 服装锚；适合"有一张想对齐的现成大片"。
- 场景3「母版锚定」：图1 = **Muse 写实母版**（锁比例+姿态）、图2 = 效果图（只供服装）、图3 = 面部特写/四宫格（锁身份）；适合"从系列自己成片，没有可复刻的参考大片"。
- 两种都禁止用**效果图/时装画**当人体比例锚（9–10 头体系，会拉垮写实比例）。

## 五、联动规则

- **默认联动**：风格档 → 场景 → 妆造 → 布光/胶片五件套一起定（上表每档已给默认套）；**换单件时只动一个变量**（如"极简高级 + 换水下场景"），一次只换一处，便于归因与返工（呼应 `consistency-lock.md`）。
- **锚点不变**：无论风格/场景怎么换，服装结构/版型/颜色位置/长度/闭合件/图案纹样/配饰鞋履/面料质地照旧锁定，只随姿势、场景、光线变化。
- **系列一致**：一个系列先定风格档写进项目画布"设计宪法"，全套图/片共用；风格不中途漂移。
- **风格互通**：大片风格 ↔ 效果图画风（`fashion-illustration-spec.md` 08-附）↔ 配饰板（`design-boards.md` 10）↔ 视频备料（`video-brief.md`）共用同一套风格语言，全链路一致。

### 风格分层法（混搭/说不清"要什么风格"时）

不要一个大标签压死整张图——风格是五个独立层，混搭时按层分配，各写一句：

| 层 | 写什么 | 例 |
|---|---|---|
| 媒介 medium | 实拍/定格/2D/3D/微缩 | 实拍摄影 |
| 表面 surface | 纸纹/粘土/拉丝金属/玻璃/面料 | 哑光棉、缎面反光 |
| 色调 palette | 粉彩/单色/高饱和/冷暖 | 暖杏色系、低饱和 |
| 镜头/渲染 camera-render | 微距/浅焦/正交/手持 | 85mm、浅景深、f/8 |
| 动作节奏 motion rhythm | 轻缓/顿挫/弹性/写实重量 | 静态保持、慢板 |

- 混合风格时每层只归一个风格：`实拍产品摄影 + 手绘 UI 叠加` 比堆五个风格词清晰。
- 每档 AI 提示词锚点 = 五层各自一句话，不够时按层补，不靠叠形容词。

## 六、无参考时怎么选风格档（与用户联动）

用户没给参考图/参考片时，风格档不空问、不硬定，走"**推荐三通道 → 对比小图 → 拍板进宪法**"：

1. **到达节点问一次**（`project-workflow.md` 3·5 必问含"大片风格档"）：先问"有没有偏好的风格/品牌感觉？"；用户说"不知道/你定" → 走下面推荐，**不反复问**。
2. **推荐三通道**（按可用信息优先级取）：
   - **主题/用途映射**：按系列主题与交付用途反推——高定/秀场氛围 → 极简高级·超现实·童话；品牌 campaign → 极简高级·魅惑·赛博；电商/订货 → 极简高级·学院·动感；个人作品/参赛 → 按主题意象（国风→国风东方、未来→赛博/蒸汽波、运动→动感）；杂志/编辑 → 黑白·浪漫·街头
   - **品牌语言反推**：用户点名品牌/设计师 → 走 `design-ideation.md` 3·8 拆锚点 → 匹配档位（Margiela → 极简高级/暗黑；Jil Sander → 极简高级；Versace → 魅惑；Balenciaga → 赛博/超现实）
   - **受众/渠道反推**：客群与渠道倾向（年轻 → 街头/Coquette/千禧；奢侈 → 极简/魅惑；户外 → 自然环境/动感）
3. **给法**（`project-workflow.md` 四·2 纪律）：给 **2–3 档**（含推荐锚定）→ 无参考时正好出 **contact sheet 对比小图**（每档 1 张）建立视觉 → 你拍板或说"你定"。
4. **摄影师语言自动带出**：档位选定后，该档标注的摄影语言（如"极简高级 → Penn 系构图"）**自动进提示词，不再单独问**；想换只动这一个变量（呼应"换单件只动一个变量"）。
5. **视频联动**：同一档位 + 补动态三件套（运镜/节奏按 `video-brief.md` 表）；无参考时同样先定档再定片，风格语言贯穿全片。
6. **锁定**：档位 + 摄影语言锚写进设计宪法，全套图/片共用；换档说"改设定"。

## 七、大片叙事单元（静态大片也有"小故事"）

大片不一定有剧情，但每张都要有一个"被定格的故事瞬间"——**Before → 可见瞬间 → 暗示的结果**，让观众脑补前后。

| 节拍 | 大片映射 |
|---|---|
| Arrival | 模特入场瞬间、门/镜框前的停顿 |
| Reveal | 转身、掀披、光扫过揭示构造 |
| Decision | 一个决定性的整理手势（扣扣子/抚平） |
| Transformation | 面料被风/水/光改变的状态 |
| Reversal | 正反切换、回眸 |
| Contact | 手与面料/闭合件的触碰点 |
| Disappearance | 出画、背身走远、倒影里的远离 |

写法：主体一个名词、瞬间一个可见动词（非情绪词）、场景一个有用细节、光有动机；静止画面靠"动态瞬间感"（裙摆定在半空、发丝悬浮）制造故事感。情绪写法见 `video-brief.md` 表演锚点（感受词+物理锚点，图片同样适用）。
