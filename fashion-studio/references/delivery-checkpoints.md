# 全流程验收速查卡（交付前 / 阶段流转时逐项打勾）

把 21 项交付物的验收门浓缩成一页：**阶段 → 产出物 → 进入条件 → 关键验收打勾 → 出口**。每过一阶段对照本卡过一遍；交付前从后往前逐项打勾（各章的完整验收门仍以对应文件为准，本卡是速查）。

## 视频补充验收（走 video 流程时加查）

- 五问定片能答（类型/开场 3 秒/节奏/服装出现形态/每镜功能）；锚点依赖链浅
- 风格档 = 大片 20 档同源；动态·运镜·节奏三件套齐；人体比例口径（无母版统一 1:9+裆 55%；有 Muse 继承；首帧锁、镜头贯穿一致）
- 四段式备料包完整（素材映射 / 一句话简报 / 镜头顺序 / 全局约束）；有参考只继承功能关系不抄秒数

## 企业 / 赛事专项

- **企业**：色卡/面料封样、PP/TOP 链路；AI 图只用于提案营销未冒充实物；预算/交期在案
- **赛事**：匿名、尺寸/页数/dpi 按当年章程；原创与 AI 流程披露；3D 边界守章程

## 打勾纪律

1. 逐项打勾，不凭印象说"全部符合"；每项验收找到对应产出物再勾。
2. 不过就修产物本身，不是绕过检查。
3. 各章完整验收门以对应 reference 文件为准（03→design-boards 03 节，07→fashion-illustration-spec 07 节……）；本卡只做速查与总检。
