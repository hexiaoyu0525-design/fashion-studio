## 趋势与企划节奏（`enterprise-proposal.md` / `design-boards.md` 01-附）

- 色彩/面料趋势比上市早 **18–24 个月**（先订料、打色封样），款式/廓形早 **12–18 个月**；再叠加打色/打样/大货周期。
- 研判四步：扫宏观驱动 → 收主题/色/料/形四方向（标机构+季别）→ 过客群/赛题筛子 → 转成形色质意。
- 分层落地：10% 前瞻款试趋势、30% 时尚款紧跟、30% 经典款趋势化微调、30% 库存款守盘。

## 色号 · 配色（`design-boards.md` 03）

- 核心 **4–7 色**（≤5 最聚焦）；色卡比例三选一并声明：**60-30-10** 通用 / **70-20-10** WGSN / 中文教材主色 70–80%。
- Pantone FHI 棉布 **TCX**、纸面 **TPG**（原 TPX 2015 更名）；每色给 hex+RGB+CMYK；容差 **±0.5ΔE**；对色 **D65**。
- **精确色 AI 不直出**：PS 吸管→校正到 TCX→矢量赋 hex/CMYK。

## 印花 · 分色 · 刺绣（`design-boards.md` 05，CY/T 249—2021）

- 线条 ≥118 像素/cm（≈300ppi）、云纹 ≥59（≈150）、制版输出 ≥142（≈360）；位图 TIFF/BMP。
- 分色最细线条 **≥0.2mm**；细茎间距 ≥0.4mm；机织复合色 ≥0.2mm、针织 ≥0.3mm；云纹外扩 5–8mm。
- 花回：四方连续 **40×60cm**、二方 75×110、独幅 60×80；丝印 **1–8 套色**（常见 1–6）。
- 无缝必须 PS Offset 检验（水平/垂直各 50%+Wrap Around）+ 3×3 平铺；分色用金昌/宏华，AI 不出可用分色稿。
- 刺绣：制版 Wilcom/田岛/富怡，机台文件 **.DST/.EMB/.PES**；针法 缎面 Satin / 他他米 Tatami / 走针 Run；AI 出刺绣**超真实效果图**，**不出针路/针数/缩料补偿/机台文件**；绣线用实物线卡（Coats/Anchor 线号）对色，非 Pantone 直印。
- 织花/提花走纹织 CAD 纹板；扎染/蜡染/压褶/钉珠/烫钻/激光等特种靠师傅/模具，AI 出超真实效果图。

## 材料实验（`material-lab.md`，"造料"非选料）

- 再造七族：加法 / 减法 / 变形 / 复合重组 / 染整 / 编织非织 / 立体科技；每小样记底料+手法+参数+过程三帧+再造后克重/可缝/可洗。
- 实物小样 **≥10×10cm**（立体再造 15×15）；单板 **4–8 个实验**；一系列主推材料亮点 **1–2 个**。
- AI 创意面料：四方连续 → Offset 半幅 + 3×3 验无缝 → 锁"材质母版"→ 入素材库 GAR_FAB（🟢）；虚拟材质另建"材质规则卡"跨镜头锁定。
- 再造改变物理性能（变厚变硬/变长/变重）：调缝份、换针、加里布或承重衬、重算用料；性能必须实物实测，AI 不替代。

## 款式图线宽（`fashion-illustration-spec.md` 07）

- 通用工业口径：外轮廓 **1pt**、内部 0.5–0.75pt、明线虚线（段长 2–3mm、间距 3–6mm）。
- 制图系列 d=0.25/0.35/0.5/0.7/1/1.4/2mm，优先 0.5 与 0.7；粗:中:细=4:2:1。
- **门襟叠压：女装右压左、男装左压右；女装牛仔例外（左压右）**。
- 生产级款式图：AI 约束后直出可用（07.5 清单：正背分开出/对称后处理/计数锁定/工艺逻辑写死/**真实比例 to-scale 无人体**）；合同级另用 Illustrator 收口矢量，输出 .AI/.EPS/.PDF。

## 白坯 · 纸样（`technical-production-spec.md` 12/13）

- 坯布：本白棉布，克重接近终面料；简单款 1–2 轮、复杂款 2–3 轮。
- 样衣链：**proto → fit → size set → SMS → PP → TOP**（PP 大货料批了才开裁；TOP 首批抽、批了才出货）。
- 缝份：常规 **1cm**、大身 **1.5cm**、需改部位 2cm+；美式侧/肩 5/8″(1.5)、袖窿/领 1/2″(1.2)。
- 下摆折边：盲缝裤裙 2–4cm、结构夹克 4cm；**单刀眼=前片、双刀眼=后片**。
- 精度：弧线 ±0.5mm、直角 ±1mm、裁片 ±1mm；CAD 输出 PLT/HPGL、**DXF-AAMA**（主流）/ **DXF-ASTM**（备选）（必须带刀眼）。

## Tech Pack · 公差 · 针距（`technical-production-spec.md` 14/15）

- 大身测量点公差 **±1.0cm**；小部位 **±0.5cm**；针织 T 恤类 ±1.5；牛仔关键位 ±0.5、次要 ±0.3。
- 针距：梭织通用 **SPI 10–12**（≈4 针/cm）、牛仔/夹克 8–10、童装 7–8；中文口径明暗线 ≥12 针/3cm、包缝 ≥9 针/3cm。
- 线迹：**301** 平缝 / **401** 双线链缝 / **504** 三线包缝 / **516** 五线包缝 / **406** 双针绷缝 / **602** 三针绷缝。
- 整烫：领口/裤腰 150–160℃、袖口/裤脚/裆 140–150℃。

## 号型 · 推档（`technical-production-spec.md` 15，GB/T 1335）

- 基码：女 **160/84A**、男 **170/88A**；体型 Y/A/B/C。
- 档差：身高 5cm、胸围女 4cm/男 5cm、腰围 2cm；衣/裙/裤长 1–2cm、袖长/肩宽 0.5–1cm；断点分段不均。

## 3D 虚拟成衣（`technical-production-spec.md` 16）

- 导 **DXF-AAMA**（ASTM 备选）、无缝份基线、带刀眼；粒子距 工作 20/交付 **5–20**（小片 3）。
- `.zprj ≤500MB`、Style3D `.sproj ≤300MB`；视频 **16:9 · MP4 · 30fps · ≤60s**；DRESSX 类 GLB **≤10MB**、贴图 ≤2048²、渲染 1440×1920。
- **3D 不能跳过 2D 纸样**；AI 出概念图/贴图/修图与**超真实 3D 渲染图（看效果）**，缝合仿真必须 CLO/Style3D。

## 视频（`video-brief.md` / `portfolio-board.md` 21）

- Seedance 2.0：4–15s；2.5：4–30s；1080p MP4/MOV；走秀/360/Lookbook 单镜 5–10s 最稳；**无负向字段**。
- 节奏密度【经验值】：15s **4–6 镜** / 30s **8–12 镜** / 60s **14–20 镜**；高定/时装电影取上限（更少更长）、campaign/社媒取下限。
- 转场 AI 适用性：硬切 ✅、叠化 ✅（0.3–0.8s）、划像/甩镜/匹配剪辑 ◐ 可后期补、动画转场 ✗ 后期做。

## 电商/成片（`portfolio-board.md` 21）

- 淘宝/天猫主图 1:1、800 或 1000+、≤3MB、第一张实物；抖音主图 ≥5 张 ≥600、白底 800×800/72dpi。
- **Amazon 服装主图**：纯白 RGB 255、占幅 **85%**、仅展示一次、**禁任何人台/衣架**、最长边 500–10000px、JPEG、命名 `ID.MAIN.jpg`。
- AI 合成真人须在 XMP `dc:subject` 写 **`contains-synthetic-performer`**。
