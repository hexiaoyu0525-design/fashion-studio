# 前期企划板（01–06 · 10）

设计动手前的七块板：调研、灵感、色彩、面料、纹样/工艺花型、廓形趋势、配饰造型。它们回答"为什么做、做什么感觉、什么色、什么料、什么花、什么形、怎么搭"。**先读下方「全局板面底座」——所有板面类交付物（含 `portfolio-board.md` 的展示板）共用，其余文件只引用不重复。**

每条交付物统一七项：用途 · 内容 · 版式 · 数值 · 文字 · 产出 · 验收；本篇浓缩为「定位/放什么/数值/语境与主路径/AI 边界/提示词/验收门」。

---

## 先懂前期：服装三要素 + 真实创作顺序（不是串行流水线）

**编号 01–21 是"交付物目录"，不是创作先后。** 前期是发散—收敛的迭代过程，硬按 01→06 一步一板是错的。

### 服装三要素（前期发散的核心骨架）

**服装三要素 = 款式（含廓形）、色彩、面料。** 廓形是款式的第一视觉，款式 = 廓形 + 结构 + 细节。三要素对应到板：色彩板 03、面料板 04、廓形板 06（款式外形）。

### 真实顺序（调研/灵感 → 三要素并行 → 纹样工艺 → 效果图 → 款式图）

```
调研（01）→ 灵感（02）
                 │
   ┌──────── 服装三要素：同步选择、反复牵动（非串行）────────┐
   │   款式·廓形（06）      色彩（03）      面料（04）      │
   └─────────────────────────────────────────────────────┘
                 │ 三要素方向定调后进入，并与三要素互相牵动
             纹样 / 工艺花型（05，附着层：长在面料上、落在款式上）
                 │ 前期发散收敛
             效果图（08）= 三要素 + 纹样工艺的综合表达
                 │ 定款
             款式图（07）= 定款后的技术翻译（无人体正背）
                 → 09 系列 / 11 细节 / 10 配饰 → 12 起工程
```

- **三要素并行、互相约束**：面料垂感/硬挺决定廓形能不能成立（真丝撑不起硬挺箱型、厚呢做不了贴身斜裁）；色彩必须依附在具体面料上看（同一色在丝和麻上是两个色）；廓形反过来限定可选面料。现实中是反复调、一起定，不是色彩定稿再碰面料。
- **05 纹样/工艺花型是附着层**：随三要素走，又会反向影响面料与款式，所以紧随三要素、但在效果图之前。
- **08 效果图在前、07 款式图在后**：效果图是设计提案（定"长什么样、什么感觉"）；款式图是**定款之后**给打版/工厂沟通结构的技术翻译。先有设计、后做技术翻译。
- **别和"四步管线"混**：`image-quality-sop.md` 的四步管线是**设计定稿之后**出商品图/上电商的渲染顺序，那时款式图已存在，所以步骤①才拿它当锁定参考。

### 前期板的图有四种"出身"，美感与标准各靠各的

别把所有板都丢给 AI 生图。先判这张图属于哪一类，再决定怎么出：

| 出身 | 哪些板/图 | 怎么来 | 美感靠什么 | 标准靠什么 |
|---|---|---|---|---|
| **策展拼贴型** | 01 调研、02 灵感/情绪 | 真实素材采集 + 人工拼贴（B）；AI 只补氛围底图/连接图 | 选图眼光、1 张锚点图、网格层级留白、遮字 3 秒能说出调性 | 来源 100% 可查、元素数、近景/全身比、版面规范 |
| **实物扫描型** | 04 面料、辅料 | 标准光源微距 + 实物小样（B 拼板）；AI 仅出肌理底图 | 真实质感、微距布光 | 8 字段、一料一卡、D65 对色、成分克重 |
| **AI 创意 + 专业软件收口型** | 05 纹样/印花/工艺花型、03 色彩情绪图 | AI 出花型/工艺效果（A）；无缝/分色/制版/纹板走专业软件（C） | 形色质意转译、变体矩阵（`design-ideation.md`） | 无缝接版、分色套色、针法制版、色卡 |
| **矢量/工程型** | 06 廓形剪影、03 精确色卡、07 款式图 | Illustrator/专业软件（C）；AI 只给底图/氛围 | 干净统一、可读 | 等比例/可缩放/对称、精确赋值、工艺符号 |

> 08 效果图是前期的**综合表达**（融合三要素+纹样），走 `fashion-illustration-spec.md` 与白模骨架自举（`design-ideation.md` 第 12 节），不属本表任一单一出身。

## 全局板面底座（唯一出处，其他文件引用本节）

### 尺寸 / 像素 / 出血（ISO 216；印刷以终尺寸计）

| 版面 | 净尺寸 mm | @300dpi 净像素（竖） | 含 3mm 出血像素 | @150dpi 屏幕 |
|---|---|---|---|---|
| A2 | 420×594 | 4961×7016 | 5032×7087 | 2480×3508 |
| A3 | 297×420 | 3508×4961 | 3579×5031 | 1754×2480 |
| A4 | 210×297 | 2480×3508 | 2551×3579 | 1240×1754 |
| 横版 A3 | 420×297 | 4961×3508 | 5032×3578 | 2480×1754 |
| 11×17in 英制作品集 | 279×432 | 3300×5100 | — | 1650×2550 |

- **DPI 三分**：印刷/评审打印/赛事提交 = **300dpi、CMYK、四边 3mm 出血**；屏幕高清/移动端 = **150dpi、RGB**；网页预览 = 72dpi。同一板导出时改的是像素，不是"用途名称"。
- 安全边距：成品边内缩 **10–15mm**（作品集 15–25mm）；关键文字不入出血区。
- 电子提交：PDF/X-1a 或 PDF/X-4、嵌入字体（单页大小上限多在 10–20MB【经验值】）。

### 字体层级（印刷 pt；全案 ≤1–2 个字族，靠字重字号拉开）

| 层级 | pt | 说明 |
|---|---|---|
| 主标题 | 36–72（封面可到 90） | 衬线或表现型 |
| 副标题 | 14–24 | 与正文反差分 |
| 小标题 | 18–24 | 同族换字重 |
| 正文 | 9–11 | 行距 120–135%，单行 45–75 字符 |
| 图注 | 7–9 | 统一前缀（Figure/Fig.）、统一位置 |
| 页码/脚标 | 7–9 | 全案统一 |

### 网格 / 图文比 / 固定区

- **2–3 栏或 12 列栅格**，栏间距（gutter）全案统一；走网格、图片比例统一、对齐。
- 图文比 **6:4 ~ 7:3**（图为主）；调研板例外地字更密（约 5:5）。
- 固定五区：**标题栏**（主题名+季节码+副标，顶部 8–12%）·**主视觉区 Hero**（1 张锚点图，30–40%）·**内容区**（45–60%）·**图注**（与图绑定）·**页脚**（logo+页码+版本+日期，4–6%）。
- 留白 15–25%，宁少勿挤；一块板至多 2 级标题、1 个主视觉 + 2–4 辅助图 + 一段 ≤120 字说明。

### 命名 / 交付 / 两语境

- 命名：`季节码_系列_板名_版本_日期`，例 `SS27_Mist_ColorBoard_v3_20261013`。
- 交付：PDF（保真）+ JPG/PNG（预览），可编辑母版留 `.indd/.psd/.ai/.fig`；印刷 CMYK 与屏幕 RGB 不在同一交件混用。
- **企业保真语境**：颜色/面料/版型以实物为准，色号可复现、面料给成分克重供应商、每图带来源；平台合规。
- **赛事表达语境**：概念完整、视觉冲击、叙事连贯，允许强风格化，但守征稿方尺寸/页数/dpi/匿名硬指标。

### 拼贴板公共形式美（01–06 拼贴类板共用，各板只列特有行）

所有"有机拼贴"类板（灵感/主题/色彩/面料/纹样/廓形）**默认满足公共四件套**：**大小对比**（1 个大视觉重心 + 中等元素 + 小点缀）、**疏密对比**（一侧密集、一侧留白）、**元素叠压**（前后遮挡有层次）、**透叠层次**（部分元素半透明）。排布不是规整网格，是"乱而有序"的有机拼贴（撕纸/撕裂边缘、穿插叠压）。各板特有手法（元素互动 / 理念表达 / 线条分割 / 手工拼贴感）见各板。

### 三条产出路径（全技能通用标记）

- **A 生图（Seedream）**：氛围/意象/材质/花型创意；短板是精确取色、图内文字、计数、矢量精度、跨图一致性。
- **B 排板拼贴（PS/InDesign/Figma）**：网格、层级、印前规格、精确赋值，是所有终稿的收口环节。
- **C 矢量线稿（Illustrator/Inkscape）**：款式图、剪影、色卡、信息图、符号库，保证可缩放可编辑。

### 版权底线（技能将公开发布）

板内只放用户自有或合法获取的素材；秀场照、品牌 lookbook、趋势机构报告图均为第三方版权，技能只给方法，不内嵌任何图片、不提供图源路径。版权判定见 `copyright-compliance.md`。

## 01 ｜ 调研板 / 概念板 Research Board　【语境：两者】

- **定位**：回答"为什么做这个主题"，用证据而非感觉。企业重竞品价格带与客群结论（可压 A4）；赛事重一手/二手调研区分与来源 100% 可查（A3，常 2–3 页）。
- **放什么**：四模块——①趋势（色彩/面料/廓形，标机构+季别）②消费者（画像/场景/痛点/UGC）③竞品（品牌×价位×品类×风格象限、价格定位矩阵、可加 SWOT）④文化历史（年代/地域/工艺/纹样，附年份出处）；加主题叙事（关键词 5–8、概念 80–200 字）与数据信息图。
- **关键数值**：图 50–60% : 字 40–50%；正文 8–10pt、图注 6.5–8pt；每页 4–8 模块；关键词 5–8 个；关键信息 **100% 有出处**（编号+机构/作者+年份）。
- **语境/主路径**：两者；主路径 **B（排板）+ C（信息图）**。
- **AI 边界**：AI 只出"占位式版式示意/氛围底图"；**真实数据、竞品 logo、含数字的成品信息图一律人工**（AI 会幻觉数字、有版权风险）。
- **提示词**：
```
专业时装调研板版式示意（research board layout），编辑式排版，克制米白灰底，
信息密集但留白清晰，横向 A3 比例。左栏：文化/历史参考图拼贴（4–6 张【经验值】，带图注占位）；
中栏：消费者人物插图 + 关键词标签；右栏：柱状/象限信息图占位。
参考图1=版式骨架网格；参考图2=配色与字体气质；参考图3=图表视觉样式。
平视正投影，模块对齐，无透视畸变。只出占位版式，文字与数据后期填入。
不要文字乱码、不要伪造数字、不要真实品牌 logo、不要水印、不要可识别正脸。
```
- **验收门**：每条关键信息有出处；一手/二手有区分；主题→客群→竞品→机会推导闭环；竞品矩阵含价格带；网格/色调/页码齐；印刷导出 CMYK 300dpi。

### 01-附 · 自主趋势研判方法（别只会搬机构报告）

调研板里的①趋势不是把 WGSN/Pantone 截图贴上，而是**自己研判后收出方向**。色彩/面料趋势比上市早约 **18–24 个月**、款式约 **12–18 个月**；SS 春夏与 AW 秋冬的国际时装周、机构预测（WGSN/Coloro/Pantone/POP）再提前半年到一年。**机构工具怎么用**：WGSN+Coloro 用 STEPIC 框架（社会/科技/环境/政治/产业/创意）出关键色、Coloro Toolbox 含 3500+ 色卡并做跨底材与光源可行性验证、Pantone 年度色=宏观趋势研究的代表色——机构的"结论"当参考，自己按四步收方向。四步：

1. **扫宏观驱动**：社会 / 技术 / 经济 / 环境 / 文化的变化（AI、户外生活、可持续、在地文化、健康、老龄化等），判断它会改变人"什么场景、什么心理、要什么衣服"。
2. **收四个方向**：宏观 → 主题关键词 / 色彩 / 面料材料 / 廓形单品，每条**标注机构 + 季别 + 来源**，并区分"机构预测"与"我自己的客群证据"。
3. **过本品牌 / 本赛题的筛子**：客群画像、价格带、品牌 DNA（企业）或赛题主题（赛事）来筛——不适合客群的趋势再热不上、不扣题的趋势再新不进。
4. **转成自己的设计语言**：把趋势词翻成形 / 色 / 质 / 意（`design-language-dictionary.md`、`design-ideation.md`），落到具体廓形、面料、工艺，进 03/04/06 板。每个趋势点必须能回答"它变成了我系列里的哪一个具体东西"。

**落地三问**：① 这趋势对我的客群/赛题成立吗？② 我是第一批、跟随还是收尾（对应企业 `enterprise-proposal.md` 30/30/30/10：10% 前瞻款试趋势，30% 经典款做流行色/面料/细节的再设计，别整季押单一趋势）？③ 它具体落在哪个款、哪块料、哪个色？

## 02 ｜ 灵感板 / 情绪板 Mood Board　【语境：两者，赛事更重】

- **定位**：一张图回答"这一季什么感觉、给谁穿"。先立概念句再选图，不做漂亮图堆砌。
- **与主题版的区别**：
  | 维度 | 灵感板（Mood Board） | 主题版/系列推导（Thematic Board） |
  |---|---|---|
  | 核心目的 | 确立氛围、情绪和故事 | 展示设计从概念到成衣的推导过程 |
  | 内容构成 | 情绪图片、氛围参考、抽象概念 | 色彩、面料、廓形、图案、配饰等具体设计元素 |
  | 设计阶段 | 设计流程的起点（最开始） | 设计思路的展开与深化（灵感版之后） |
  | 最终呈现 | 一个充满想象力的"视觉故事" | 一套完整、有逻辑的设计方案 |
  > **重要原则**：灵感板阶段不出现具体设计元素（色卡、面料样本、廓形图），这些是后面主题版的事；灵感板不出现本系列成品服装，人物只能局部特写（手、肩、侧脸），不能是完整穿着本系列设计的模特。

- **放什么**：
  - **核心原则**：围绕主题感觉发散元素，不限定具体类型，只要能体现这个系列的感觉和氛围就行
  - **元素来源发散**：至少覆盖3个以上不同领域（可以是任何领域：艺术作品、器物、自然肌理、工业产品、摄影、雕塑、光影、文字、地理、建筑、人物局部等），不要只局限在某几类
  - **不能放**：❌ 服装效果图（那是效果图的内容）；❌ 款式图（那是款式图的内容）；❌ 色卡表格（那是色彩板的内容）；❌ 面料特写（那是面料版的内容）；❌ 完整模特全身图

- **版面结构**：
  ```
  ┌─────────────────────────────────────────┐
  │ 【左上角】                               │
  │  ■ 灵感版（大标题）                     │
  │  ■ 一段概念说明文字（灵感来源、核心表达）│
  ├─────────────────────────────────────────┤
  │ 【中部主体】                             │
  │  ■ 碎片拼贴效果（撕纸边缘、元素叠压）    │
  │  ■ 元素来源发散，围绕主题感觉            │
  ├─────────────────────────────────────────┤
  │ 【边缘】                                 │
  │  ■ 色卡色块（如果需要，小面积）          │
  ├─────────────────────────────────────────┤
  │ 【底部】                                 │
  │  ■ 一行灵感关键词（如果需要）            │
  └─────────────────────────────────────────┘
  ```

- **形式美要求**（公共四件套见「全局板面底座」；此处只列灵感板特有手法）：
  | 设计手法 | 怎么体现 | 判断标准 |
  |---|---|---|
  | **元素互动** | 元素之间有呼应，不是孤立的 | 能看出元素之间的关系，不是各管各的 |

- **关键数值**：元素 **12–20 个**（深研可至 20–30、客户提案 10–18）；图 60–70%、留白 30–40%（有呼吸感，不是塞满）；大中小三级层次：1个大主体 + 3-5个中等元素 + N个小点缀；标题 28–48 / 副标 16–24 / 图注 8–11pt；概念句 20–40 字（情绪+观点+场景，不写"复古/高级"）。

- **语境/主路径**：赛事表达优先；主路径 **A 出素材 + B 拼贴**（B 收口）。

- **AI 边界**：A 强于氛围底图/材质意象/成组风格延展；不能出精确 hex、实物面料、可编辑网格、可靠图内文字（图内文字一律后期人工排版，见全局底座）。

- **提示词**：
  ```
  生成一张时装概念情绪板拼贴，A3 横版，主题是"XX感觉"。
  风格：有机拼贴，撕纸碎片边缘效果，元素互相叠压穿插，乱而有序。
  元素：围绕主题感觉，来源发散，至少3个不同领域（建筑/自然肌理/艺术作品/器物/工业产品/光影等）。
  形式美：一个大视觉重心（占画面1/3面积），中等元素3-5个，小碎片点缀，大小对比强烈；
  元素集中在一侧，另一侧留白，有呼吸感；元素互相遮挡叠压，有前后层次关系。
  参考图1 提取材质肌理；参考图2 提取色彩氛围；参考图3 提取光线与情绪；其余新生成。
  保持参考图1 材质不变；画面留出约30%空白供后期排版；不生成文字与水印。
  不要规整网格排列、不要元素平铺、不要大小差不多、不要太满太挤、不要完整服装人物、不要成衣。
  ```

- **验收门**：
  - 遮字给别人看 3 秒能说出调性；
  - 有 1–2 主导想法非平铺等权；
  - 元素数达标；
  - 元素来源发散，至少3个不同领域；
  - 有大小对比、疏密对比、元素叠压、透叠层次；
  - 主体是情绪参考，不是服装效果图；
  - 无跑题图、无重复图、无"剪贴簿感"；
  - 尺寸/dpi 与征稿一致。

## 02-附 ｜ 主题板 / 概念板 Thematic Board　【语境：两者，赛事更重】

- **定位**：为这个系列定"灵魂"——起名字、定核心理念，用视觉方式表达这个思想。
- **与灵感板的区别**：
  | 维度 | 灵感板（Mood） | 主题板（Thematic） |
  |---|---|---|
  | 核心问题 | "这个系列看起来是什么感觉？" | "这个系列到底想说什么？为什么要做？" |
  | 回答的问题 | 感觉、氛围、情绪 | 理念、思想、概念 |
  | 内容类型 | 视觉氛围、材质、建筑、光影 | 象征、对比、隐喻、符号 |
  | 目的 | 定方向 | 定灵魂 |
  > **判断方法**：这张图是在说"感觉"，还是在说"思想"？是在展示"看起来像什么"，还是在表达"为什么做这个"？

- **放什么**：
  - **核心原则**：围绕核心理念发散元素，不限定具体类型，用象征、对比、隐喻的手法表达这个思想
  - **元素围绕理念展开**：每个元素都在为表达这个理念服务，不是随便放的
  - **不能放**：❌ 色彩提取（那是色彩板的内容）；❌ 面料转化（那是面料版的内容）；❌ 廓形发展（那是廓形版的内容）；❌ 细节工艺（那是细节版的内容）；❌ 服装成衣（主题版尽量不出现服装）；❌ 真实人物（主题版尽量不出现人物）

- **版面结构**：
  ```
  ┌─────────────────────────────────────────┐
  │ 【左上角】                               │
  │  ■ 系列名称（大标题）                   │
  │  ■ 核心理念说明文字（这个系列想说什么）  │
  ├─────────────────────────────────────────┤
  │ 【中部主体】                             │
  │  ■ 象征/对比/隐喻元素拼贴               │
  │  ■ 元素围绕理念展开，有视觉冲击力        │
  ├─────────────────────────────────────────┤
  │ 【底部】                                 │
  │  ■ 一行关键词（理念关键词）             │
  └─────────────────────────────────────────┘
  ```

- **形式美要求**（公共四件套见「全局板面底座」；此处只列主题板特有手法）：
  | 设计手法 | 怎么体现 | 判断标准 |
  |---|---|---|
  | **理念表达** | 所有元素都在为表达理念服务 | 每个元素都有意义，不是随便放的 |

- **关键数值**：元素 **8–15 个**（比灵感板少，更聚焦理念）；图 60–70%、留白 30–40%；大中小三级层次：1个大主体（核心象征元素） + 2-4个中等元素 + N个小点缀；系列名 28–48 / 理念说明 16–24 / 关键词 8–11pt；理念句 20–40 字（具体思想，不写"复古/高级"）。

- **语境/主路径**：赛事表达优先；主路径 **A 出素材 + B 拼贴**（B 收口）。

- **AI 边界**：A 强于氛围底图/象征意象/成组风格延展；不能出可靠图内文字（AI生成的文字都是乱码，所有文字后期人工排版）。

- **提示词**：
  ```
  生成一张时装主题概念板拼贴，A3 横版，主题是"XX理念"。
  风格：有机拼贴，撕纸碎片边缘效果，元素互相叠压穿插，乱而有序。
  元素：围绕"XX理念"，用象征、对比、隐喻的视觉元素表达这个思想。
  形式美：一个大视觉重心（核心象征元素，占画面1/3面积），中等元素2-4个，小点缀碎片，大小对比强烈；
  元素集中在一侧，另一侧留白，有呼吸感；元素互相遮挡叠压，有前后层次关系。
  参考图1 提取象征元素风格；参考图2 提取对比关系；其余新生成。
  画面留出约30%空白供后期排版；不生成文字与水印。
  不要规整网格排列、不要元素平铺、不要大小差不多、不要太满太挤、不要服装成衣、不要真实人物。
  ```

- **验收门**：
  - 遮字给别人看 3 秒能说出这个系列想表达什么思想；
  - 有明确的核心理念，不是模糊的感觉；
  - 元素都在为理念服务，不是随便放的；
  - 和灵感板有区别：不是氛围，是概念；
  - 有大小对比、疏密对比、元素叠压、透叠层次；
  - 无跑题图、无重复图、无"剪贴簿感"；
  - 尺寸/dpi 与征稿一致。

## 03 ｜ 色彩板 Color Story　【语境：两者】

- **定位**：用视觉元素来表达这个系列的色彩感觉和氛围，不是列出有哪些颜色。
  - **概念色彩版**（赛事/设计提案）：主体是情绪参考图，色卡是提取结果
  - **企业生产色卡**（大货比对）：精确色号、可复现，交染厂对色

- **概念色彩版 vs 企业色卡的区别**：
  | 维度 | 概念色彩版（设计阶段） | 企业生产色卡（大货阶段） |
  |---|---|---|
  | 核心目的 | 展示这个色彩体系是什么感觉、什么情绪 | 可复现，交染厂对色 |
  | 主体内容 | 情绪参考图（占70%以上面积） | 精确色卡（占大面积） |
  | 色卡位置 | 顶部/边缘，小面积点缀 | 主体，占大面积 |
  | 呈现形式 | 艺术拼贴、杂志版面 | 表格、列表 |

- **放什么（概念色彩版）**：
  - **核心原则**：围绕色彩情绪发散元素，不限定具体类型，只要能体现这个色彩的感觉和氛围就行
  - **元素来源发散**：至少覆盖3个以上不同领域（可以是任何领域：建筑、自然、艺术、器物、工业产品、摄影、雕塑、光影、文字、地理、人物等），不要只局限在某几类
  - **不能放**：❌ 面料特写（那是面料版的内容）；❌ 规整的服装/站立模特（那是效果图的内容）；❌ 色卡表格（那是企业生产用的，不是概念色彩版）；❌ 太多文字说明（文字是点缀，不是主体）
  - **元素类型丰富**：不是单一类型，多种元素围绕色彩主题展开

- **版面结构（概念色彩版）**：
  ```
  ┌─────────────────────────────────────────┐
  │ 【顶部/边缘】                           │
  │  ■ 色卡色块（小面积点缀，提取结果）      │
  ├─────────────────────────────────────────┤
  │ 【中部主体】                             │
  │  ■ 情绪参考图拼贴（景观、场景、材质）    │
  │  ■ 元素互相叠压，撕纸边缘，大小对比      │
  ├─────────────────────────────────────────┤
  │ 【底部】                                 │
  │  ■ 一行色彩关键词（如果需要）            │
  └─────────────────────────────────────────┘
  ```

- **形式美要求（概念色彩版）**：= 公共四件套（大小对比/疏密对比/元素叠压/透叠层次，见「全局板面底座」），无特有手法。

- **关键数值**：
  - **概念色彩版**：情绪参考图占 70–85%、色卡点缀占 15–30%；元素 **8–15 个**；大中小三级层次：1个大主体 + 3-5个中等元素 + N个小点缀；留白 30–40%
  - **企业生产色卡**：核心 **4–7 色**（≤5 最聚焦）；比例三套口径并列，显式声明选用哪套——
    - **60-30-10**（通用配色/穿搭）；
    - **70-20-10**（WGSN 商业色盘：中性基色 70/支持色 20/点缀 10）；
    - 中文教材：主色 70–80% + 辅点缀合计 15–25% + 点缀约 5%。

- **色号体系（企业生产用）**：服装用 **Pantone FHI**（约 2800 色）；棉布色卡 **TCX**、纸面 **TPG**（原 TPX 于 2015 年更名）；每色同时给 hex/RGB/CMYK；色样容差 **±0.5ΔE**；D65 标准光源对色。

- **语境/主路径**：
  - **概念色彩版**：赛事表达优先；主路径 **A 出素材 + B 拼贴**（B 收口）
  - **企业生产色卡**：企业保真；主路径 **C/B 精确赋值**（AI 仅氛围）

- **AI 边界（硬）**：
  - **精确色不能由文生图直出**——同一色号 hex 随测量条件变化，模型只给"看起来像"的像素。
  - 流程：PS 吸管取 AI 底图→手动校正到目标 TCX→矢量矩形精确赋 hex/CMYK→CMYK 校样。

- **提示词（概念色彩版）**：
  ```
  生成一张时装概念色彩情绪板拼贴，A3 横版，主题是"XX色彩感觉"。
  风格：有机拼贴，撕纸碎片边缘效果，元素互相叠压穿插，乱而有序。
  元素：围绕"XX色彩感觉"，用景观、建筑、材质、光影等视觉元素表达这个色彩情绪。
  形式美：一个大视觉重心（占画面1/3面积），中等元素3-5个，小碎片点缀，大小对比强烈；
  元素集中在一侧，另一侧留白，有呼吸感；元素互相遮挡叠压，有前后层次关系。
  参考图1 提取色调；参考图2 提取材质色彩；参考图3 提取光影氛围；其余新生成。
  顶部/边缘留出小面积位置放色卡；画面留出约30%空白供后期排版；不生成文字与水印。
  不要规整网格排列、不要元素平铺、不要大小差不多、不要太满太挤、不要色卡表格、不要面料特写。
  ```

- **验收门**：
  - **概念色彩版**：遮字给别人看 3 秒能说出这个系列的色彩是什么感觉；主体是情绪参考图，色卡是小面积点缀；有大小对比、疏密对比、元素叠压、透叠层次；无"剪贴簿感"
  - **企业生产色卡**：主辅点缀三档明确、比例口径显式；4–7 色非等权；每色 TCX/TPG+hex+RGB+CMYK 齐全；面积权重可见；企业板含染色/色牢度注记；无"只有 hex 无 Pantone"。

## 04 ｜ 面料板 / 材料板 Fabric Board（含辅料）　【语境：两者】

### 04-附 辅料知识字典（辅料怎么选：分类 × 视觉 × 注意）

  | 维度 | 概念纹样版（设计阶段） | 企业生产工艺方案（大货阶段） |

  | 核心目的 | 展示这个系列的装饰语言和工艺特色 | 把创意翻译成可下单的工艺方案 |

- **放什么（概念纹样版）**：
  - **核心原则**：围绕这个系列的装饰语言和工艺特色发散元素，不限定具体类型，展示这个系列有什么装饰特色、用了什么工艺
  - **纹样手法选择**：根据主题风格判断应该选什么纹样手法，不是随便选好看的。常见类型：印花类、刺绣类、褶皱/压褶类、拼接/拼布类、外露缝线/明线、钉珠/亮片类、科技/未来感等

  - **点缀**：少量人物展示效果（1-2个，是点缀不是主体）、工艺细节、装饰线条
  - **不能放**：❌ 色卡表格（那是色彩版的内容）；❌ 设计元素推导（那是廓形版的内容）；❌ 太多人物（堆一堆人像时装秀海报）；❌ 重复人物（同一个人出现好几次）；❌ 只有平面图案（像图案集，没有氛围和效果）

### 企业生产工艺方案详细内容

把"表面装饰"创意翻译成**可下单**的工艺方案。纹样（图案母题）是设计层；**印花、刺绣、织花、印染、特种工艺**是实现层——同一纹样可以印花、可以绣花、可以织出来，工艺不同，生产文件、成本、AI 边界完全不同。本板创意（花型/色彩/位置）与工艺（方式/套色或针数/底布/成本）同板呈现。

### ⓪ 先选工艺类型（不同工艺，生产文件与 AI 边界不同）

| 工艺大类 | 代表 | 图案怎么实现 | 生产文件/软件 | AI 能做 | AI 不能做（必须专业/人工） |
|---|---|---|---|---|---|
| **数码印花** | 喷墨直喷、热转印/热升华、DTG | 高分辨率图直接喷/转印，无套色限制，短版友好 | TIFF/PNG 高分辨率，RGB/CMYK 色彩管理 | 花型创意、**超真实效果图** | 无缝/接版仍须人工 Offset 验；色牢度/色差以打样为准 |
| **丝网印花** | 胶浆/水浆/厚板/烫画 | 1–8 套色，每色一块网版，色块线条无真渐变 | **分色稿**：金昌 EX9000/宏华等 | 花型创意、**超真实效果图** | **不出可用分色稿**；套色/线宽/叠印必须专业 |
| **刺绣** | 电脑平绣、毛巾绣、贴布绣、绳绣 | 绣线在面料上按针路走线 | **绣花制版：Wilcom/田岛 Tajima/富怡绣花 → .DST/.EMB/.PES**（见下专项） | **刺绣超真实效果图**（针脚立体/珠光）、花型 | **不出针路/针法/针数/缩料补偿/机台文件**；对色以实物绣线卡为准 |
| **织花/提花** | 提花、织锦、牛仔提花、领带 | 织出来的（经纬纱组织成花），不是印 | **纹织 CAD 做纹板/组织** | 图案风格、**超真实效果意象** | 不出纹板/组织文件；需织机与打样 |
| **印染/手工** | 扎染、蜡染、蓝染、拓印、植物染 | 手工/染料晕染，冰纹、扎结不可完全复制 | 无固定机台文件，靠工艺师傅 | **超真实效果意象**、图案灵感 | 实物靠手工，做不出可控的手工肌理 |
| **特种工艺** | 钉珠/亮片/烫钻、盘带、绗缝、压褶/抽褶、激光切割、植绒/发泡/滴塑、**烂花/烧花（Burnout）** | 模具/特种机/手工/排布；烂花=酸蚀溶解部分纤维露出透纱底 | 激光切割矢量路径、压褶模具、特种机文件；烂花蚀刻位置/强度靠样布 | **超真实效果渲染**、排布创意 | 模具/针路/排布/工时靠人工与专业软件；烂花花位/酸蚀深度以打样为准 |

> 选型：数码印花门槛低、表现自由；丝印适合大色块、大货成本低但受套色限；刺绣显高级、有立体肌理但按针数计费、周期长；提花做高档针织/梭织；扎染/特种做差异化卖点。**同一图先定用哪种工艺，才谈花型规格与提示词。**

### 花型类型 × 工艺 选择逻辑（先定构图，再定工艺）

| 决策维度 | 选项 | 怎么选 |
|---|---|---|
| 纹样母题 → 构图 | **连续纹样**（满花/四方连续） | 母题有叙事性、要覆盖大面（衬衫/连衣裙/家居服） |
| | **定位花 placement** | 单点/局部装饰焦点（胸前/后背/裙摆），强调单一母题 |
| | **边条/二方连续** | 领口/袖口/下摆/门襟的装饰带 |
| | **散点** | 小母题均匀散布、克制留白 |
| 构图 → 工艺 | 连续纹样 | 数码印花（快速/无套色限）或提花（高档织出来） |
| | 定位花 | 数码 / 丝网（大色块）或刺绣（立体高级） |
| | 边条 | 织带提花 / 刺绣条 / 印花条 |
| | 散点 | 数码印花 / 钉珠亮片 |
| 工艺 → 成本周期 | 数码印花 | 门槛低、短版友好、无套色限；无缝接版须人工验 |
| | 丝网 | 大色块大货便宜、1–8 套色；分色人工 |
| | 刺绣 | 高级立体、按针数计费、周期长 |
| | 提花 | 高档、需纹织 CAD 打纹板 |
| | 特种 | 差异化卖点、模具/工时贵 |

> 三者联动示例："碎花母题 → 满花连续 → 数码印花（成本低）/ 提花（高档）；同一碎花 → 定位到胸前 → 刺绣（立体卖点）。"先回答"图案长在哪、铺多大"，工艺自然收敛。

- **放什么**：花型主题与元素；**先标工艺类型**（印花/刺绣/织花/印染/特种，见上表）；花型类型（满花/散点/定位花 placement/二方边条）；印花循环方式（平接 1/1、1/2 半跳、1/3 跳、菱形/阶梯）；**花回原图 + cm + 像素 + dpi**；3×3 铺版接版示意；工艺与套色（印花每色 Pantone；刺绣标绣线色号/针数）；底布/面料；企业页加单耗/MOQ/成本。
- **关键数值**：
  - 分辨率 **CY/T 249—2021**：线条图案 ≥118 像素/cm（≈300ppi）、云纹 ≥59 像素/cm（≈150ppi）、制版输出 ≥142 像素/cm（≈360ppi），位图 **TIFF/BMP**；数码稿终尺寸 150–300dpi（300 为生产基线）。
  - 分色硬指标（CY/T 249—2021）：分色后最细线条 **≥0.2mm**；细茎/撇丝间距 **≥0.4mm**；复合色宽度机织 **≥0.2mm**、针织 **≥0.3mm**；云纹外扩 5–8mm；深色块面收缩 0.2–0.4mm。
  - 花回尺寸（瓦栏平台口径）：服装四方连续 **40×60cm**、二方 75×110cm、独幅 60×80cm；数码方形花回 **30/45/60/90cm**。
  - 丝网印花 **1–8 套色**（商业常见 1–6，每色一块网版，色块/线条、无真渐变）；数码印花无套色限制、短版友好。

### 05-1 ｜ 刺绣专项（工艺与印花根本不同）

刺绣是**绣线在面料上走针**，不是印颜色。AI 能渲染"看起来绣出来的效果"，但绣花机不认图，只认**制版文件**。

- **制版（digitizing）软件**：Wilcom（威尔克姆）、Tajima 田岛（DG/ML）、富怡绣花、Pulse 等；由制版师把图案翻译成针法路径。
- **机台文件**：**.DST**（田岛通用，最常用）、**.EMB**（Wilcom 源文件）、**.PES**（Brother 家用）、**.EXP/.JEF** 等；要给制版师/绣花厂，不能只给一张 AI 图。
- **针法（基础几类）**：**平包针/缎面针 Satin**（窄小填充，光泽强）、**他他米/榻榻米 Tatami**（大面积填充）、**走针/平针 Run**（轮廓、勾边）、十字针；另有毛巾绣（chenille）、链目绣、贴布绣、绳绣（cording）。
- **制版关键参数**：针距/密度（针脚间距，决定饱满度与软硬）、底针 underlay（防皱、定型）、锁针（线头不散）、**缩料补偿（pull compensation，刺绣会把布料拉短，制版要预先放长）**、换色次数、**总针数**（直接决定工时与成本）。
- **辅料**：绣线（人造丝/涤纶/棉线，**用绣线色卡对色，如 Coats/Anchor 线号或 Pantone 转绣线**，不能直接把 Pantone 当线号）、衬料（纸衬/水溶衬/热熔衬，按面料选）、绣线股数。
- **AI 边界**：AI 出刺绣**超真实效果图**（针脚立体、珠光、绣线光泽尽量真实，可直接作交付展示）与花型/布局创意；**针路制版数据**（针法、针距密度、针数、缩料补偿、机台文件）与真实绣线色差/绣作工时仍须制版师 Wilcom 打版（.DST）→ 绣花厂打样 → 实物对色、看针脚平整度。AI 超真实图只作展示与提案，不冒充实物与制版。
- **提示词（刺绣超真实效果，非制版）**：
```
刺绣工艺效果图，<平绣/缎面针/毛巾绣/贴布绣>，图案为<花卉/几何/母题>，绣线配色<主+辅+点缀>。
```

- **语境/主路径**：
  - **概念廓形版**：赛事表达优先；主路径 **素材采集（浏览器搜索品牌秀场图）+ B 拼贴**（B 收口）
  - **企业廓形分析**：企业保真；主路径 **C 矢量剪影 + B 排板**（AI 仅氛围意象）

- **AI 边界**：
  - AI 出不了等比例剪影矩阵（比例与对齐不可控）；**剪影必须在 Illustrator 统一描边等距排布**，同一板内不混用不同比例人体。

- **提示词（概念廓形版）**：
  ```
  生成一张时装概念廓形灵感板拼贴，A3 横版，主题是"XX风格廓形"。
  风格：手工剪报拼贴，不规则剪裁边缘效果，元素互相叠压穿插，大小不一，角度各异，乱而有序。
  元素：符合"XX风格"的全身着装廓形图，抠图后拼贴，展示不同的廓形和比例。
  形式美：一个大视觉重心（占画面1/3面积），中等元素3-5个，小点缀碎片，大小对比强烈；
  元素集中在一侧，另一侧留白，有呼吸感；元素互相遮挡叠压，有前后层次关系。
  参考图1 提取廓形风格；参考图2 提取比例感觉；其余新生成。
  画面留出约30%空白供后期排版；不生成文字与水印。
  不要规整网格排列、不要元素平铺、不要大小差不多、不要太满太挤、不要矢量剪影矩阵、不要只有局部细节。
  ```

- **验收门**：
  - **概念廓形版**：遮字给别人看 3 秒能说出这个系列的廓形风格；主体是符合风格的全身着装廓形图；有大小对比、疏密对比、元素叠压；有手工拼贴感；无"剪贴簿感"
  - **企业廓形分析**：板内必有可读剪影（非仅情绪图）；剪影等比例、脚线对齐、有比例注记；6 层顺序正确；色彩/面料与其他板一致；趋势点标机构+季别（WGSN/Coloro/Pantone/POP 等）；300dpi 矢量不失真。

## 10 ｜ 配饰造型板 Accessories & Styling Board　【语境：两者，选做】

- **定位**：为每套 look 定义"穿什么衣、配什么件、怎么搭"，既是造型说明也是商业连带的可视化清单。**选做环节，不是必须做的。**
- **阶段位置**：在款式图之后、摄影大片之前做——先定服装和技术图纸，再定搭配什么配饰，最后拍完整造型；也可以放在前期企划阶段先定方向。
- **两种方式**：
  - **方式A：自己设计配饰**（参考效果图流程）：配饰为本系列专门设计，走设计流程，从灵感→效果图→定稿
  - **方式B：直接选用参考图中的配饰**：直接用已有配饰/参考图里的配饰搭配，不需要重新设计
- 企业给每 look 采购清单与组套；赛事作造型/整体搭配页，重完成度与原创性。

### ⓪ 先判定：这板是"选品搭配"还是"原创配饰"

两条路交付物完全不同，动手前必须先分叉。

**A · 选品搭配（采购/调用现有配饰）**：配饰不新做，只做搭配。主路径 = AI 出造型/flat-lay 氛围 + B 拼贴采购清单 + 商品级配饰实拍/矢量；AI 图只标氛围示意，不生成真实品牌配饰（见下方 AI 边界）。下面"放什么/关键数值/提示词"主要服务这条路。

**B · 原创配饰设计（为本系列专门设计的配饰）**：配饰是**新设计的单品**，走 `design-ideation.md` 全套，不是 flat-lay 能解决的：
- 先做**设计简报**（与服装共用一个系列母题），把配饰当"系列设计语言的延伸"，再做形色质意转译（见 `design-ideation.md` 第 5 节配饰小节）。
- 走**参考分寸尺**：配饰的经典款辨识度比服装更高，**参考分寸比服装更严**（见下方黑名单），只学结构逻辑、不抄标志性外形与五金。
- 出**变体矩阵**（包形/鞋楦/首饰体量 × 材质 × 五金）→ 四角色评审圈（买手视角尤重：这配饰好不好卖、能不能量产）。
- 出图走 C 路径：包/鞋/首饰的**技术线稿与结构工程图**必须 Illustrator/专业软件；**超真实效果展示图 AI 可出**（金属反光、材质质感渲染）；鞋楦、出格、镶嵌的**工程精度**仍专业。

**配饰专属设计维度（原创时逐项定满）**：

| 品类 | 必须定的变量 |
|---|---|
| 包袋 | 廓形（托特/腋下/水桶/马鞍/手拿/双肩）、结构（硬挺/软塌）、开合（拉链/磁扣/翻盖/敞口）、五金（锁扣/链条/铆钉）、背法（手拎/单肩/斜挎/腰包）、容量与隔层 |
| 鞋履 | 鞋楦（宽窄/圆尖头）、头型（圆/方/尖/方头）、跟型（平/粗/细/猫/坡）、帮面（深口/浅口/靴筒）、鞋底材质与厚度、扣件 |
| 首饰 | 材质（金/银/珠/宝石/树脂）、工艺（铸造/镶嵌/编织/珐琅）、体量（点/线/面）、佩戴点、是否成套 |
| 帽/围巾/腰带/眼镜 | 帽型与帽围、围巾尺寸与系法、腰带宽度与扣、眼镜框型与镜片色 |

**配饰参考黑名单（🔴 商标 + 外观专利 + 商业外观重灾区；可看结构原理，不喂图、不进成品）**：
- 经典包款：Birkin/Kelly/Constance、Chanel CF/2.55/Le Boy、Dior Saddle/戴妃、LV Speedy/Neverfull、Goyard 箱型。
- 鞋：红底鞋（Louboutin 红底）、Roger Vivier 方扣、黄边明线靴、Maison Margiela 分趾 Tabi、Gucci 乐福马衔扣。

- **放什么**：按 look 分栏（每栏 LOOK 01/02…），覆盖头部（帽/发饰/眼镜）、颈部（围巾/丝巾/颈链）、躯干（腰带/胸针/背带）、手部（手套/手链/戒指）、足部（鞋/袜）、包袋六区；加整体造型（妆面/发型/叠穿/色彩材质呼应）。每 look 一张上身造型图 + 配饰小图阵列 + 清单表（选品）；原创配饰额外加设计线稿/结构图/五金与材质说明。
- **关键数值**：**每 look 3–5 件配饰**（1 主件 + 3 配饰经典组合）【经验值】；配饰与服装取 ≤3 个主色、至少 1 件与主色严格呼应；每件配饰小图 ≥30mm、造型图 ≥120mm 高；每页 2–4 个 look；图 65–75%；正文 8–10pt、图注 6.5–8pt、LOOK 标 14–20pt。整套搭配（Complete Look）对客单价的提升约 15–25%【通识，非承诺】。
- **语境/主路径**：两者；主路径 **A 造型氛围图 + B 拼贴清单 + C 配饰技术线稿**。
- **AI 边界**：AI 出造型/flat-lay 展示图与配色呼应，也可出原创配饰的概念展示图；**精确还原指定产品的五金/结构/logo 不可靠，不生成真实品牌配饰（版权+失实），商品级配饰必须实拍或矢量线稿**，AI 图可作**超真实展示图**（不冒充商品实拍与品牌货）。原创配饰：**鞋楦/鞋底工程、包袋出格（纸格）、五金结构、宝石镶嵌、logo 与标准件**须鞋包/首饰专业软件或版师；**金属反光等质感渲染与造型方向 AI 可出超真实展示图**。
- **提示词**：
```
时尚配饰造型板，flat-lay 平铺俯视，<帽/墨镜/项链/手袋/鞋/袜/腰带> 与一件主体服装组合。
参考图1=主体服装廓形与色彩（配饰须呼应）；参考图2=配饰造型与材质风格；参考图3=整体配色明度。
同色系呼应 + 1 处撞色点缀，材质对比（皮/金属/针织/织物），
干净米色/浅灰/纯白背景，柔和顶光，整齐排列不重叠；正投影俯视，构图均衡。
不要品牌 logo、不要水印、不要可识别真人正脸、不要堆叠遮挡、不要杂乱背景、不要多余手指。
```
- **验收门**：每 look 清单完整（品类+色彩/材质+呼应点）且与 lineup 的 LOOK 编号一一对应；色彩呼应明确；覆盖 ≥3 个配饰品类；妆发/叠穿说明齐备；图 ≥30mm/件；无 logo、无未授权图、无黑名单标志性元素的近似照搬；AI 图已标注为氛围示意。**走 B 原创路的另加**：配饰共用系列母题、过参考分寸尺与三问、专属设计变量定满、技术线稿由矢量/专业软件产出、五金鞋楦出格不靠 AI 直出。

**④ 配饰设计流程四步（AI 能做/须专业分界）**

1. **概念**（与服装共用系列母题）：AI 出概念氛围图、材质意向、造型方向。
2. **原型验证**：实物原型手作或 3D 建模验证（AI 只出效果意象；结构强度/佩戴舒适须实测）。
3. **结构细节**：五金（扣/链/锁）、闭合方式、背法/佩戴部位、尺寸规格——AI 出展示图，工程细节由专业软件。
4. **技术文件**：包袋出格（纸格）、鞋楦工程、首饰 CAD/镶嵌图、金属模具——全部专业软件/版师，AI 不代出。
