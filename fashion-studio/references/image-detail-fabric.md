# 生图 · 细节 / 工艺 / 面料微距

这类图用来证明"值这个价"：在详情页、卖点海报、大片里支撑高级感和工艺可信度。

> 每种面料本身是什么（成分、手感、克重、垂感、光泽、布光与动态、AI 翻车点）查 `fabric-guide.md`；本文件管"怎么拍/怎么生成微距与特写"。

## 材质四要素（提示词里"材质"这一格就填这四个）

描述面料时写全，模型才不会给你"塑料感"：

1. **纹理 pattern**：织纹/肌理/纹路（斜纹、罗纹、提花、绒面、绗缝、暗纹刻花）。
2. **光泽 light**：反光方式（哑光、柔光、缎面高光、金属冷光、光追反射）。
3. **厚度 thickness**：克重与厚薄感（薄透/中等/重磅，如 380g 双面呢）。
4. **垂感 drape**：悬垂与动态（硬挺、随动褶皱、连续褶浪、停步后缓慢垂下）。

例：`纹理=暗纹刻花，光泽=柔光低反光，厚度=中等偏薄，垂感=随步幅自然荡开`。

## 微距公式

```
微距特写（extreme macro）：[具体部位] 的 [细节]，[让光扫过显露出织纹的光]；
浅景深，焦外柔和；100mm/120mm 微距，f/8 让细节清晰；
细节摄影，强调做工与材质；[比例]。
```

## 聚焦什么

| 部位 | 要显出的细节 |
|---|---|
| 拉链 | 拉链带哑光质感、金属拉头、拉链齿 |
| 口袋 | 口袋边缘缝线、加固套结 |
| 缝线 | 针距、双缝线、明线 |
| 纽扣 | 纽扣材质、扣眼、绕线 |
| 袖口 / 下摆 | 罗纹、松紧、折边 |
| 面料 | 织纹、纱线、绒面、单根纤维 |
| 拼接 / 印花 | 图案对花、拼接位置 |

## 不露脸、不强调身体

工艺图要写清："不出现脸、不强调身体，纯粹聚焦材质与做工"（no face, no body emphasis, pure focus on material character and build quality）。

## 面料微距公式

```
面料微距：[羊毛/针织] 织纹特写，100mm 微距 f/8，柔和漫射光避免硬阴影，
清晰显露出针织图案与纱线质感，单根纤维可见，[颜色]，铺满画面；
纺织品质感摄影，超高分辨率。
```

## 面料 - 光位表（质感是"打"出来的）

| 面料 | 光位 | 效果 |
|---|---|---|
| 粗花呢 / 针织 / 羊绒 | 主灯侧移，减少补光 | 织纹与毛流方向才看得见 |
| 真丝 / 缎面 / 皮革 | 调光源角度、尺寸、旗板 | 控制高光走向 |
| 亚麻 / 棉 | 侧逆光 | 经纬线出浮雕感 |
| 金属扣件 | 窄条柔光箱 + 格栅 | 冷调高光，控制溢光 |
| 深色面料 | 保留暗部细节 | 不为"够黑"丢结构 |

## 背景与道具

- 深色/中性桌面背景，让材质跳出
- 方向性侧柔光（directional side softbox）显织纹
- 可加入手工工具（针线、剪刀、面料样）暗示工艺，但不抢主体

## 技术工艺视频化

把工艺"动起来"（手划过缝线、拉链拉合、面料垂坠、水泼在面料上）就是 techfilm，见 `video-film-types.md`。

## 负面

不要塑料感、不要错误的针距、不要虚构的缝线结构、不要过度锐化、不要把面料织成不存在的花纹。
