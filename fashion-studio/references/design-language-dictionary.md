# 风格语言字典：把感性词翻译成设计变量（纯文字入口）

`design-ideation.md` 解决"怎么想、怎么转译、怎么评审"；本文件解决纯文字入口的第一个动作：**客户/你嘴里那些模糊词，到底对应哪些能画出来、能下单的设计变量。**

核心动作一句话：**把"评价词"翻译成"设计词"。** "显瘦""高级""复古"是看完以后的**结论**，不是设计动作；模型收到"高级感"只会自由发挥。必须把它拆成廓形、比例、色、面料、结构、细节这些**看得见的变量**，再进 `design-ideation.md` 的简报与白模流程。

用法：
1. 听到感性词 → 查本字典，逐项落到设计变量（拿不准就给客户 2–3 个变量组合选项，不替他猜）。
2. 变量填满设计简报 → 走"白模骨架先行→自举"（见 `design-ideation.md` 第 12 节）。
3. 年代/流派/历史款是**公共财富**，可大胆取形转译（分寸仍按 `design-ideation.md` 第 3 节 L2–L4）；当代设计师/品牌过程可参考（🟡）学语言、终稿须转化，品牌名不进终稿提示词，Logo/老花属 🔴。

## 一、高频感性词 → 设计变量（最常用）

| 客户说的词 | 翻译成设计变量（择 2–4 项落地） |
|---|---|
| 显瘦 | 高腰线+上短下长；V 领/纵向分割；同色系顺色拉长；H 或微 A 廓形不贴身；硬挺面料不贴肉；袖长盖上臂最粗处；竖条纹/明线引导视线 |
| 显高 | 高腰+短上衣；同色下装与鞋；小面积头部/肩部视觉；纵向线、开衩；提高视觉重心；避免中长上衣压个 |
| 遮肉/藏肚子 | 不贴身的 A 字/箱型/斗篷；胸前或肩部做焦点转移视线；硬质不贴身面料；落肩、叠穿；避免薄软针织贴身+腰位收紧 |
| 高级/有质感 | 降低饱和度、控制配色≤3；哑光或真丝等"真"材质、去塑料光泽；加大留白与素面；精细做工细节（明线/包边/好五金）；合身度+挺括；少即是多 |
| 氛围感 | 明确是哪种氛围（慵懒/清冷/暧昧/书卷气）→ 转成色调（暖/冷、明/暗）+ 面料（绒/纱/麻）+ 光线（逆光/柔雾）+ 廓形（松弛/包裹） |
| 松弛感/慵懒 | 落肩、微廓形、长款；针织/亚麻/棉等软垂面料；低对比大地色；自然褶皱、不刻意；微拖地、袖口卷起 |
| 清冷/疏离 | 冷调、低饱和、冷白/雾蓝/灰；利落直筒 H 廓形；硬挺或垂坠两极面料；极简、金属冷光；去可爱元素（圆/碎褶/蝴蝶结） |
| 温柔/甜 | 柔和暖粉/奶色/杏；圆领、V 浅领；针织/雪纺/真丝；碎花/小褶/收腰；曲线、软质、中短款 |
| 甜酷/娘 man | 甜的单品（吊带/碎花/裙）+ 酷的单品（皮衣/工装/马丁靴/金属）；配色黑+粉、硬+软材质对冲；一个造型只留一个主调 |
| 通勤/职场 | 西装/衬衫/直筒裤/及膝裙；中性色+一个点缀；挺括抗皱面料；结构清晰、无夸张装饰；可叠穿、好打理 |
| 老钱风/静奢 quiet luxury | 中性低饱和（米/驼/藏青/奶白）；天然好面料（羊绒/真丝/精纺羊毛）；无 logo；合身经典廓形；珍珠/皮质/金属克制点缀 |
| 街头/潮 | 廓形 oversized、落肩、阔腿；牛仔/卫衣/工装布；高饱和或撞色；印花/徽章/机能扣件；分层、外大内窄 |
| 机能/山系 | 多口袋/拉链/魔术贴/抽绳；尼龙/软壳/压胶；防水防风属性；模块化；暗色系+荧光点缀 |
| 少女/减龄 | 短款、A 字、泡泡袖/娃娃领；马卡龙色；轻薄面料；小体量、圆线条；控制元素数量避免幼稚 |
| 复古 | **年代不明=废词，必须先追问年代**：50s New Look/60s 迷你/70s 波西米亚/80s 垫肩/90s 极简/Y2K，查第二节年代字典 |
| 设计感 | 明确"哪里有设计"：解构分割/非常规闭合/不对称/面料改造/特殊廓形；且只设一个视觉焦点，其余克制 |
| 小众/不撞款 | 独立设计师语言、结构创新、材质实验、非常规穿着方式；越商业越要守分寸（见参考分寸尺） |
| 挺括/有型 | 硬质、克重高、有骨架的面料（西装料/牛仔/厚针织/涂层）；省道/衬/分割做结构；避免软垂贴身 |
| 垂坠/飘逸 | 真丝/雪纺/粘胶/薄针织；斜裁、放量；荡领/裹身/大摆；走路有动态；光位侧逆显垂 |
| 极简 | 少分割、少配色、少细节；靠版型、面料与比例取胜；隐藏闭合件；结构线即装饰 |
| 性感 | 明确方式：露肤（背/肩/侧/腿哪一处，只露一处）/贴身（针织）/透视（薄纱）/开衩/剪裁；一处为限 |

> 翻译时不要只改一个变量。同一感性词至少落 2–4 个变量，并在简报里写"为了达到 X，我用了廓形 A + 色 B + 面料 C"。

## 二、年代风格字典（"复古"必须落到年代）

每个年代给：主导廓形 / 关键单品 / 标志细节（色与面料已精简，由 Agent 按年代常识补齐 3–5 项并在简报中声明口径）。取用时按 L2–L4 转译，不做整年代复刻。

| 年代 | 廓形 / 关键单品 | 标志细节 |
|---|---|---|
| 1920s 爵士 Flapper | 直筒低腰 H、及膝直裙、boyish 扁平 | 流苏、串珠、羽毛、头巾、cloche 钟形帽、 dropped waist |
| 1930s | 斜裁修长、贴身、长裙摆 | bias 斜裁、荡领、荷叶边、宽肩将起 |
| 1940s 战时 | 垫肩、收腰、及膝实用廓形 | 厚垫肩、A 字裙、衬衫裙、头巾、节约用料 |
| 1950s | **New Look 蜂腰大摆、X 型**、铅笔裙 | 收腰、伞裙、波点、格纹、猫眼镜、丝巾 |
| 1960s | 迷你 A 型、直筒、未来感 | 迷你裙、A 字、几何、波普、go-go 靴、娃娃裙 |
| 1970s | 波西米亚长裙、阔腿、嬉皮 | 喇叭裤、流苏、麂皮马甲、披肩、高腰、麂皮靴 |
| 1980s | 权力套装、宽肩、oversized | 厚垫肩、power suit、蓬袖、金属、紧身裤、logo 腰带 |
| 1990s | 极简 slip dress、低腰、grunge | 吊带裙、直筒、马丁靴、choker、mom jeans、做旧 |
| 2000s Y2K | 低腰、短款、紧、闪亮 | 低腰裤、露脐、蝴蝶/铆钉、迷你包、工装、反光材质 |
| 当代/无年代 | 见 六·5 品牌语言字典（仅学手法） | 按当季趋势机构 + 品牌客群定 |

**取法**：历史年代（约 20 世纪中叶及更早）版权安全，可大胆取廓形/结构；**做当代设计时把年代元素当"一种语言"，至少改 3–4 个设计层**（如 50s 廓形 + 宋锦面料 + 当代比例 + 新母题 = 新中式 New Look，见 `design-ideation.md` 3.6）。

### 三·附 1 廓形字母字典（Silhouette Alphabet）

字母廓形是"主导轮廓语言"，不与具体款式绑定（H 型可以是衬衫裙，也可以是长裤套装）。**一个系列定 1–2 个主导字母**（06 板"主导轮廓 2–4 个"里的核心 1–2），其余款在其上变形。

| 字母/廓形 | 控制点（肩·腰·摆） | 气质语义 | 面料适配 | AI 提示词锚点 |
|---|---|---|---|---|
| H 型（箱型/直筒） | 肩腰摆基本同宽、不收腰、直线方型 | 修长、简约、庄重、中性 | 中厚垂坠料（精纺羊毛/粗花呢/棉府绸）；硬挺料撑箱型 | 箱型直筒、不收腰、肩腰摆等宽、直线条 |
| X 型（沙漏 hourglass） | 阔肩、收腰、下摆外扩 | 女性化、曲线、华丽 | 有骨料撑肩摆（毛料/塔夫绸）+ 收腰余量；垂料显腰线 | 收腰外扩、肩摆宽、腰位收紧、沙漏曲线 |
| A 型（正三角） | 肩自然窄、下摆外扩 | 活泼、优雅、流动 | 垂坠料（雪纺/真丝）显飘逸；硬料显体积 | 上窄下宽、A 字外扩、肩自然、下摆放开 |
| O 型（茧型/椭圆） | 上下收、中段鼓 | 圆润、包裹、慵懒 | 厚软料（针织/羊毛/夹棉）能鼓起 | 茧型椭圆、中段膨胀、下摆收拢 |
| T 型（倒三角） | 肩夸张、下摆收紧 | 力量、男性化 | 硬挺料+垫肩结构（毛料/皮革） | 宽肩窄摆、垫肩、下摆收 |
| Y 型 | 肩宽、下摆更收（比 T 更剧） | 强势、戏剧化 | 同 T，可加硬纱 | 宽肩、下摆收窄、倒三角 |
| S 型（贴身曲线） | 贴合胸·腰·臀曲线 | 性感、修长 | 弹性/斜裁料（弹力针织/真丝斜裁） | 贴合曲线、S 形侧影、腰臀分明 |
| 鱼尾 mermaid | 膝上贴身、膝下外扩 | 舞台、华丽 | 弹力底+挺括外摆（弹力缎+硬纱） | 膝上贴合、膝下鱼尾外摆 |
| 斗篷 cape | 肩连身、无袖笼线 | 潇洒、仪式感 | 垂坠硬挺兼具（羊毛/毡） | 斗篷式、无袖笼、肩部展开 |

### 三·附 2 结构变量字典（省道 · 分割线 · 褶裥）

用户说结构词时，本表把"术语"翻成"可写进提示词的设计语言"；与 13 纸样（省/分割制图）、12 立裁（转省实操）、07.5 款式图（省道 BP 约束）衔接——本表管"说什么、翻成什么"。

| 变量 | 是什么 / 设计作用 | 常见位置 | AI 提示词锚点 |
|---|---|---|---|
| 省道 dart | 收多余量、平面转立体的核心技术；省尖指向凸点（女装胸省指 BP） | 胸省/腰省/胁下省/袖窿省/肩省/肚省 | 省道收量、省尖指向胸点 |
| 省道转移（转省） | 省量可移位、量不变：挪到分割线/褶裥/其他省位，改造型线 | 肩省→腰省、腰省→公主线 | 转省处理、省量并入分割线 |
| 公主线 princess seam | 纵向连续曲缝，把胸省腰省藏进缝里；外观无省道、雕塑感合体 | 肩/袖窿/胸省延伸至下摆 | 公主线分割、纵向曲线缝、无省道外观 |
| 刀背缝（袖窿公主线） | 袖窿侧起的分割线，比公主线更贴侧身曲线 | 前后衣身以刀背弧线分割 | 刀背缝分割、袖窿弧线延伸 |
| 分割线（功能/装饰） | 功能性：贴合人体曲面（公主线/育克）；装饰性：造型分割、褶根固定 | 纵向修饰比例、横向/斜向造型、育克 | 纵向分割线拉长比例、育克分割、斜向分割造型 |
| 褶裥 pleat（功能/装饰） | 功能性：满足运动量（裙摆/袖肘）；装饰性：肌理节奏 | 裙摆、袖口、门襟、领口 | 工字褶/顺褶/对褶/百褶/碎褶；功能褶量 vs 装饰褶 |
| 塔克 tuck | 细窄明褶、针迹固定，装饰性 | 前襟、肩部、领口 | 塔克细褶、针迹固定 |
| 打揽 smocking | 抽褶成蜂窝状弹性格纹，装饰+弹性 | 胸省位、裙腰、袖口 | 打揽蜂巢褶、弹性抽褶 |

### 五·附 配色法则字典（为什么这么配好看）

色彩板管"定哪些色 + 精确落值"（`design-boards.md` 03），本表管"这些色**按什么关系**放一起才成立"。用户说配色需求时先查这里，翻成可执行的搭配关系。

**① 色相环配色方案六法（配色关系总表）**

| 方案 | 色环关系 | 效果 | 服装用法 | AI 提示词锚点 |
|---|---|---|---|---|
| 同类色 monochromatic | 同一色相，靠明度/纯度变化 | 最稳、高级、同色系叠穿 | 同色系深浅叠穿显高显贵；通勤/静奢常用 | 同色系深浅叠搭、单一色相明度层次 |
| 邻近色 analogous | 色环相邻 2–3 色 | 自然和谐、温和 | 橄榄+芥末+卡其这类暖邻近；日常安全 | 邻近色和谐搭配（橄榄芥末卡其） |
| 互补色 complementary | 色环相对 180°（红绿/蓝橙/黄紫） | 最强冲击、醒目 | 撞色点缀（控制面积 1–2 成），多巴胺/赛博常用 | 互补撞色（蓝橙/红绿），点缀面积控制 |
| 分裂互补 split-complementary | 基色 + 其互补色两侧的邻色 | 强对比但比纯互补柔和 | 想撞色又怕太冲时的进阶 | 分裂互补（如蓝 + 黄橙/红橙） |
| 三角 triadic | 色环均分 120° 三色 | 平衡有活力、热闹 | 三色齐用注意面积主次；艺术感/时尚感 | 三角配色（红黄蓝均分），主辅点缀 |
| 四角/矩形 tetradic | 两组互补（矩形） | 丰富但难控制 | 高手向，须大面积中性压底 | 四角配色（两组互补），中性色压底 |

**② 对比体系（伊登七对比：三要素 + 冷暖/互补/同时/面积）**

| 对比类型 | 是什么 | 用法 | 提示词锚点 |
|---|---|---|---|
| 色相对比 | 不同色相放一起（弱=邻近、强=互补） | 决定"配不配"的主轴 | 色相对比强弱按方案选 |
| 明度对比 | 深浅差异（黑/白/灰关系） | **明度拉开显高级、显干净**；明度拉不开再美也糊 | 明度层次拉开（深底浅点缀） |
| 纯度对比 | 鲜艳与灰浊差异 | 灰调底 + 一色高饱和点题（莫兰迪+亮色） | 低饱和底 + 高饱和点睛 |
| 冷暖对比 | 暖色系 vs 冷色系的对抗 | 暖橘+冷蓝、红+蓝绿；张力与活力 | 冷暖对抗、暖冷撞色 |
| 互补对比 | 色环 180° 成对（红绿/蓝橙/黄紫） | 最强刺激，点缀使用（见六法互补） | 互补撞色、点缀面积 |
| 同时对比 | 相邻色互相影响（同一灰在两色旁观感不同） | 背景色会改变服装观感；定底衬色时注意 | 中性底、避免邻色干扰 |
| 面积对比 | 色量比例（60-30-10） | 面积定主次；小面积高纯色点睛 | 主色大面积、点缀小面积 |

**③ 三色原则与成套搭配（给"穿什么 / 怎么配"）**

- 全身 **≤3 色**（含鞋包）；三色角色：**主色**（面积最大，定调）/ **辅色**（第 2 大，支撑）/ **点缀**（小面积，点睛）。
- **同色系叠穿**（同一色相深浅层叠）= 最省力且最高级；**无彩色 + 一色点缀**（黑白灰底 + 一个亮色）= 最不容易翻车；黑白大地色系当底、加一种彩色即稳。
- 鞋包等小配件与服装**呼应同色**（顺色），比跳色更显整体。
- 赛事/高定可破三色（多色艺术表达），但**必须有主次与中性压底**；企业通勤保守执行三色。

**④ 色彩心理与场合（给谁穿、什么场合）**

| 维度 | 说明 | 应用 |
|---|---|---|
| 冷暖情绪 | 暖（红橙黄）=活力/亲和/食欲；冷（蓝绿紫）=冷静/疏离/高级 | 品牌调性、场合氛围定冷暖 |
| 膨胀/收缩 | 高明度/高饱和显膨胀，低明度显收缩 | 显瘦方案：深色 + 纵向呼应；体态修饰 |
| 肤色适配 | 冷皮宜冷调（蓝/粉/紫），暖皮宜暖调（金/橙/驼） | 模特/客群画像细化 |
| 场合四档 | 通勤（黑白灰大地低饱和）/ 休闲（邻近色+一点点缀）/ 礼服（同色系+光泽料+小面积撞色）/ 秀场（可破三色、强对比艺术表达） | 每档直接给配色上限 |

## 七、人话 ⇄ 术语对照（零术语用户用：学生/初学者/说不出术语）

**用法**：学生说什么都行——感受、比喻、大白话、甚至"就要好看的"。查下面四张对照表，把他的话翻成专业词，再落提示词；翻不出来的就发图（图代词）或出向导选择题（`project-workflow.md`「零术语适配」）。**交付时附"你说的 → 我用的"对照小条**，学生边用边积累，几次之后自己就会说专业词了。

## 八、字典使用验收（纯文字转译完，自检）

- [ ] 每个感性词都被翻成了至少 2 个看得见的设计变量（廓形/色/面料/结构/细节）。
- [ ] "复古"已追问到具体年代，并按 L2–L4 改了 ≥3–4 层。
- [ ] 色彩给了方向词，且知道精确色要进色彩板人工落 hex/Pantone（AI 不直出）。
- [ ] 面料写了四要素（纹理/光泽/厚度/垂感），不是只写"高级面料"。
- [ ] 品牌名/设计师名只用于理解语言，**没进喂图、没进提示词**。
- [ ] 变量已填满 `design-ideation.md` 简报，准备走白模骨架，而不是一把文生图。
