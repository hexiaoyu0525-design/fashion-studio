# 企业企划：从任务到完整方案

目录：接活拆 brief → 三企划三层结构 → 设计企划五环节 → 产品设计方案 → 分波段 → 30/30/30/10 → 时间计划 → 视觉交付物矩阵 → 系列概念方案五板（含五要素/排版）→ 商品出图装配 → 数字稿→实物保真（封样/对色/产前样）→ 方案交付形态 → 模拟企业评审会。

## 第 1 步 · 接活：把企业一句话拆成 brief

企业来的任务常是一句话（"帮我们做秋冬新品"）。先补齐六件事，缺什么用选项问：

1. **目标**：上新、招代理、参展、融资、品牌升级
2. **季节与波段**：春夏 / 秋冬 / 胶囊，第几波
3. **受众**：年龄、场景、价格带、客群画像
4. **渠道**：线下门店、电商、抖音/小红书、订货会、发布会
5. **交付物**：要多少图、几条片、什么形式
6. **预算与时间**：拍摄/生成预算、上线 deadline

## 第 2 步 · 认清完整企划的三层结构

完整企划 = **商品需求企划 + 设计企划 + 营销企划**。

- 商品需求企划在先：多少款、什么品类、什么价位、多少数量
- 设计企划基于它开展：主题、色彩、面料、系列、款式
- 营销企划同步：主题与产品策略构思时，就同步做视觉与传播

本技能主要交付**设计企划 + 营销企划里的视觉物料**，但方案要能接得住商品需求。

## 第 3 步 · 设计企划的五个环节

1. 流行趋势研究与调研分析
2. 企业原有情况分析（现在有什么、缺什么）
3. 本季设计重点与调整方向
4. 产品设计方案
5. 时间计划与执行安排

### 趋势信息的九个渠道

卖场实地、网络热卖、街头采集、批发市场、面料公司与面料市场、流行预测机构（Pantone）、国际杂志/网站/秀场、跨品类（化妆品/家居/饰品）、影视作品。

原则：**所有外部信息都要按本品牌客群筛选；秀场是人为推动流行的，成衣市场接受度永远有选择。** 最了解客群的是品牌自己。

### 趋势研究报告写三块

- 国际流行：色彩、廓形、款式、面料、饰品
- 成衣市场：同类与目标品牌的畅销款、面料、色彩、细节、工艺、品类
- 面料辅料：提前洞察面料方向，辅料是流行的装饰手段

### 趋势研判的时间节奏与落地（采集之后，还要"过筛子、转语言"）

- **提前量**：色彩/面料趋势比上市早约 **18–24 个月**（要先订面料、打色封样），款式/廓形约 **12–18 个月**；再叠加打色、打样、大货周期（见 `technical-production-spec.md` 甘特与封样链路）。
- 九个渠道 + 三块报告只解决"采集与整理"；真正决定卖不卖的是**过本品牌客群筛子、转成自己的设计语言**。自主研判四步（宏观驱动 → 收四个方向 → 客群筛选 → 落到形色质意）见 `design-boards.md` 01-附。
- **趋势分层落地**（接第 6 步 30/30/30/10）：10% 前瞻款承担试新趋势（敢试、量小）；30% 时尚款紧跟趋势；30% 经典款做"趋势化微调"（换流行色/面料/肌理）；30% 库存款守基本盘。不要整季押在一个未验证的趋势上。
- 报告三句话必须落到产品：①这个趋势具体是**哪个色/哪块料/哪个廓形**；②落在**哪个波段、哪些款**；③和上一季相比**改了什么**（给改款依据，接第 4 步）。落不到产品的趋势只算谈资，不进企划。

## 第 4 步 · 产品设计方案

1. **设计主题、灵感来源与趋势提案**：每一季分若干系列主题，每主题给灵感来源、关键词与概述
2. **产品色系**：用色卡或面料分系列给出主色
3. **主面料与关键面料**：材质、薄厚、对应哪一波上新
4. **产品设计图**：按主题分出系列与推出时间
5. **品类、数量与搭配计划**：考虑内外、上下的可搭配，以"套"的形式提高连带；毛衫、衬衣等搭配款可自制或外购贴牌

### 品牌调研七项（对标时用）

①主要品类 ②主要色系 ③主打款式 ④主打面料/里料/主配料 ⑤装饰细节与特殊工艺 ⑥定位与客群 ⑦价格区间。

对标品牌的语言拆解叠用 `design-ideation.md` 3·7 七维框架（定位/廓形/色盘/面料/装饰造型/态度 → 提炼可学锚点，不点名），拆出的锚点进企划设计与设计宪法。

卖场陈列再看：橱窗、入口、装修风格、陈列形式、色彩分布、道具、试衣间、导购着装。

## 第 5 步 · 分波段上市

- 每季分若干波段，常见每半月一波（如秋冬五波，每波再分 A/B 两小批）
- 每波段要结合销售网络的地域、气候、节日
- 往年销售数据是依据

## 第 6 步 · 产品结构 30/30/30/10

每季产品由四部分组成：

- **30%** 时尚产品
- **30%** 经典畅销产品
- **30%** 库存产品
- **10%** 新概念/新品类前瞻产品

经典款不能原样投放，要做小幅度再设计：换面料、换流行色、细节加装饰、面料做肌理。

## 第 7 步 · 时间计划（细化到人）

设计初稿数量与时间 → 新款式数量比例 → 每波段推出时间与数量 → 调整款/补充款 → 集体定款 → 选面料大样 → 打板与样衣 → 定面料大货与到货 → 外加工/外购 → **视觉物料（拍摄/生成）** → 上线。

定款人员主要来自销售部（以销定产），设计部负责讲解企划。

## 第 8 步 · 视觉交付物矩阵（接进图与视频）

给每个波段配一套：

| 交付物 | 用途 | 进入模块 |
|---|---|---|
| 款式/平铺/挂拍图 | 电商详情、订货会、款式建档 | image-garment |
| Lookbook 系列图 | 订货会画册、整季基调 | image-editorial |
| 服装大片/模特图 | 主视觉、社媒、电商主图 | image-editorial |
| 细节/工艺/面料微距 | 详情页卖点、高价感支撑 | image-detail-fabric |
| 品牌宣传片 | 品牌价值、官网/发布会 | video-film-types |
| 系列宣发片 campaign | 每波段上新主片 | video-film-types |
| Moodfilm / 时装电影 | 调性传播、社媒 | video-film-types |
| Techfilm | 面料/工艺/功能性卖点 | video-film-types |
| BTS 幕后 | 社媒日常、真实感 | video-film-types |
| 秀场/活动片 | 发布会、订货会 | video-film-types |

一次拍摄/生成可以"一套素材出多件"：**主片 + 若干社媒切片 + 一条 BTS**，这是行业标准做法。

## 系列概念方案：五板整合（设计前期的核心交付）

一个系列的 AI 素材最终整合成一份**系列概念方案 PDF**，固定五板，板板有图、有说明：

1. **主题灵感板**：母题、关键词、8–12 张参考图【经验值】、约 100 字主题定位。
2. **配色方案板**：≤3 主色 + 1 点缀色，色卡 + 搭配说明。
3. **面料板**：每款面料高清图 + 材质四要素（纹理/光泽/厚度/垂感）+ 生成参数记录。
4. **图案板**：纹样/印花高清图 + 文化说明（名称/寓意/重构思路）+ 无缝循环。
5. **AI 效果图板**：系列每套正/背/侧完整着装效果图，系列一致。

每板配 L2 板块说明（写法见 `text-content.md`）；每张图标注来源/工具/授权（见 `copyright-compliance.md`）。

### 系列化五要素（判断是不是"一个系列"）

- **主题统一**：同一母题、同一概念；
- **配色呼应**：≤3 主色 + 1 点缀，跨套呼应；
- **面料关联**：各套面料有共同肌理或材质逻辑；
- **图案延续**：同一纹样体系在不同款式上延展；
- **款式递进**：外套/上衣/下装/连身层层递进，能成套搭配。

保系列一致性靠：固定风格词 + 固定模特 + 固定场景 + 垫图控制（见 `consistency-lock.md`）。

### 排版规范（概念方案 PDF / 企划演示）

- 视觉层级清晰（标题 → 图 → 说明），一屏一个重点；
- 留白充足，不堆满；
- 字体统一：标题与正文各一种，全篇不超过两种；
- 图文对齐、走网格，图片比例统一；
- 图标、字体、贴图来源工具授权齐全；
- 赛事 A3 拼版另按赛题 dpi/尺寸（见 `aigc-competition.md`）。

## 商品出图装配清单（电商落地）

概念方案通过后进入商品图，按 SKU 装配：

| 图种 | 数量/规格 | 用途 |
|---|---|---|
| 白底主图 | 每 SKU 1 张，1:1 或 3:4 | 商品列表/搜索主图 |
| 平铺/挂拍/人台 | 正/背/侧 | 版型展示、建档 |
| 模特上身图 | 每款 3–5 张 | 场景化转化 |
| 详情页套图 | 每款 6–10 张 | 卖点、面料、工艺、尺码、场景 |
| 细节微距 | 每款 1–3 张 | 高价感支撑 |
| 视频/切片 | 主片 + 竖屏切片 | 主图视频、社媒 |

全部按波段、SKU 归档，版权标注逐图随件，**无版权自查报告不上架**。

## 数字稿 → 实物保真（AI 图不能替代封样）

企业语境的最终标准是**大货**，不是 AI 图。AI 数字稿只用在提案、选款沟通、营销氛围；它**不能对色、不能当面料样、不能当工艺依据、不能冒充实物**。数字到实物必须走下面这条"封样—对色—产前样"链路，否则"屏幕上好看、做出来不一样"是必然。

**① 打色对色（颜色一致的唯一办法）**
- 染厂按目标 Pantone TCX 打 **lab dip 色样**（通常 2–3 个批次选 1），不用 AI 图取色。
- 在标准**灯箱 D65** 下对色，并换光源（A 光 / TL84 / CWF）查**跳灯（同色异谱）**——店里和户外看不能两个色。
- 容差 **±0.5ΔE**（见 `design-boards.md` 03）；确认后做**色卡封样**（纸卡/布卡/手刮样），染厂、采购、质检各持一份。
- 大货布到后比对封样色卡，偏色超差退回。

**② 面料封样（一料一卡）**
- 大货面料按 `design-boards.md` 04 八字段确认：成分、克重 GSM、门幅、组织、后整理、色号、供应商、价格/MOQ。
- 留**大货封样（approved bulk fabric）**，与面料板、lab dip 一并归档；克重/手感/色差对不上封样的批次拒收。

**③ 样衣链（逐级验证到能出货）**
- `proto 头版 → fit 试身样 → size set 齐码样 → SMS 销售样 → PP 产前样 → TOP 船头样`（各轮定义与 fit 五要素见 `technical-production-spec.md` 12）。
- **PP 产前样**：必须用大货料、大货线、大货工艺做，封样批了才开裁。
- **TOP 船头样**：从大货首批随机抽，批了才允许出货。

**④ 数字与实物的边界（写进项目约定）**
- AI 图/效果图不作为染厂对色、面料验收、工艺检验的依据；对色只认封样，工艺只认 Tech Pack。
- 电商/平台**第一张主图必须是实物图**，AI 成片不得冒充实货（Amazon 等平台规则见 `portfolio-board.md` 21；AI 合成真人须做 XMP 披露）。
- 营销用 AI 图可与实物存在风格化差异，但涉及颜色/款式的关键承诺（详情页、吊牌）以实物与封样为准。

**验收门**：色卡（lab dip）封样 ✓、大货面料封样 ✓、PP 批准并签字 ✓、TOP 抽检与封样一致（色/面料/工艺/尺寸在 `technical-production-spec.md` 14 公差内）✓，才算"数字→实物"保真闭环；任一缺失，不允许开裁或出货。

## 方案交付形态

企业里以**图文演示**传达，分析报告文字简明，直接写关键词：

**视觉：**
- 关键词 + 灵感图（趋势/主题）
- 色卡 / 面料色卡
- 款式图 + 系列归纳表
- 波段上市表（时间、品类、数量、占比）
- 视觉交付物清单（图多少、片几条、什么比例）
- 系列概念方案五板 PDF

**文字（同样是交付物，不能漏）：**
- 品牌故事、本季概念陈述（一句话主题 + 约 200 字主题故事）
- 每个系列主题命名与概念
- 每款产品的设计说明与卖点（廓形/面料/工艺/场景）
- 三级随件说明（每图 / 每板 / 项目）+ 汇报发言稿，见 `text-content.md`
- 版权自查报告，见 `copyright-compliance.md`
- 营销文案（上新、详情页、社媒、海报短句）、视频旁白/字幕

## 模拟企业评审会：最终验收

- 形式：**5 分钟汇报 + 3 分钟答辩**，分角色（设计总监讲整体 / 企划讲主题 / AI 讲技术 / 合规讲版权）。
- 评审对照四项：提示词与素材、面料纹样、系列概念方案、版权报告。
- 三级结论：**通过（≥80 分）/ 有条件通过（60–79，列修改项）/ 不通过（<60）**。
- 答辩四类：设计理念、技术实现、版权原创、市场与生产；结论落到"可生产、可商用、可追责"。

文字的具体写法见 `text-content.md`。
