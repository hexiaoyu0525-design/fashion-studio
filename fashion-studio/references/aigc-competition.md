## 1. 先按"最终交付物"分三层（最重要）

3D 工程文件**不是** AIGC 服装赛的普遍门槛，而是"AI+3D / 数字资产"赛道的特定要求。先判定你要交哪一层，再决定用不用学 3D。

| 层 | 最终交付 | 要不要 3D 软件 | 现有技能 |
|---|---|---|---|
| **A 纯图** | 效果图 / A3 拼版（含灵感、色卡、款式、面料、效果、细节） | 不要 | 全包 |
| **B 图+视频** | 上述图 + AI 走秀 / 营销片（MP4） | 不要 | 全包（视频走 Seedance） |
| **C 图+3D** | 图 + 走秀视频 + **3D 工程文件**（.zprj/.sproj/.fbx/.glb/.clo3d） | 要 Style3D/CLO 等 | 只卡在 3D 工程，其余全包 |

两个关键事实：
- **赛道制**：很多省级赛（如浙江"Style3D 杯"）里传统成衣 / AI 效果图 / AI+3D 赛道并列，选非 3D 赛道即可。
- **C 层初赛也只要图**：初赛交 A3 效果图（含 3D 渲染图），进了决赛才要 3D 工程文件，且常给免费软件培训。

- 浙江 / 宁波 / 湖州"Style3D 杯"AI+3D 数智时尚赛道（决赛 .sproj/.zprj 工程 + 60 秒视频）
- FIGA Fashion in Gaming（.fbx/.glb 3D 模型 + 高清渲染）

- 汉服 AI+3D 赛道（图稿 + 3D 工程 + 纹样/款式源文件）

- 部分传统赛明确要手绘稿——读题先确认"是否允许 AI、允许到什么程度"。

## 3. 三个真实获奖案例拆解（2025–2026）

### 案例 A · 纯图：米兰设计周 AI+纹饰——《裕固以何》《维纳斯之泪》

只交图，评委在一张 A3 上看"文化讲没讲清、纹样有没有当代感"。获奖作品的设计说明高度一致地遵循公式：

> **具体母题 → 可量化提取 → 算法/AI 解构 → 命名配色 → 落地应用**

- 《维纳斯之泪》（广州美院）：取帕特农神庙**黄金比例**，把"立柱凹槽数量、柱身收分比例"做成可调算法模块，庄严多立克柱式变成流动曲线镂空。
- 《裕固以何》（太原理工）：取裕固族波浪/三角/矩形几何 + 花草蝴蝶做二次设计，配色直接给出火红、耀眼蓝、蒲公英黄、岛屿绿、陨石黑。
- 评分点：**"从母题到算法的转化逻辑"**——你能不能说出"纹样从哪来、用什么规则改了它"。

### 案例 B · 图+视频：沙河杯（模板，2026 首届尚未出最终成绩）+ 真实标杆

- **沙河杯模板**：A3 九项企划（标题/灵感/色彩/面料/款式图/效果图正背侧/细节/理念/AI 说明）+ 4K 走秀 MP4；提交清单无 3D 工程。
- **真实标杆**：伦敦 Africa Fashion Week 2025《Transcendence》（Meta × 尼日利亚设计师 Ifeanyi Nwune），AI 提示词→草图→面料/图案/视觉叙事→落地成衣走秀，演示了"AI 出图→动态走秀"的完整链路。
- **2026 首届深圳 AI+Fashion 金鹭奖**：伦敦时装学院团队《共生寄生边界》（意大利、中国台湾作品分获银鹭奖）；报道未逐一列明格式，**以当年赛题为准**。

### 案例 C · 图+3D：Style3D 第一届金奖《溟荇虚镜》——苗圣爱（中国美院）

金奖本人的真实分工，把"AI 和 3D 怎么接力"说得最透：

1. **AI 管灵感、图案、模特、背景**（软件可拖图自动生成版片、AI 换模特脸/背景）；
2. **造型和版片坚持自己做**——Style3D 打版片、面料分区、配料选料、模拟缝线位置方式、光追渲染；
3. 虚拟服装可 P 到真人照片（迪丽热巴、林允等艺人造型），数字版片可直接打印、半天做成衣（传统白胚改胚要 1–3 天）；
4. 决赛交 3D 工程文件 + 60 秒动态视频 + 3D 渲染图，另有现场改款建模考核。

她的原创观（写进版权模块）：**"AI 生成图像的前提，永远是先有人做出过类似的东西……想做有风格的东西，还是得自己做。"**

## 4. 六板图种：共用 + 标准分叉

六板（灵感 / 色彩 / 面料 / 款式 / 效果 / 细节）是服装设计通用语言，企业和赛事都要，**出图方法全部复用 `image-*` 模块**；分叉的是"标准、组合、独占图种"。

| 图种 | 企业侧重（对物·能卖能产） | 赛事侧重（对人·系列概念） |
|---|---|---|
| 灵感板 | 内部趋势参考，给设计团队定方向 | 正式评分项，A3 大版面，要文化叙事 |
| 色卡 | Pantone 色号、染厂可对、可生产 | 主/辅/对比 + 搭配说明，版面美观 |
| 面料 | 真实材质、无缝循环、可打版、克重 | 可用数字/虚拟材质（金属、发光、粒子） |
| 款式图 | 工艺单级，工厂照着能打版 | 结构图 + 结构可行性一眼看懂（producibility） |
| 效果图 | 商业还原、单品/SKU、可上架、与实物一致 | 系列概念（正/背/侧）、氛围叙事、3–5 套 cohesion |
| 细节图 | 电商卖点 / 工艺说明 | 装饰/纹理/创新点，服务设计叙事 |

- **企业独占**：白底平铺/挂拍/幽灵模特、商品主图、详情页套图、陈列、无缝循环印花、波段 SKU。
- **赛事独占**：数字成衣 3D 渲染、3D 工程文件、虚拟模特/数字走秀、非现实数字材质、A3 多板拼版。
- **共用基本原则**：系列一致性（五要素、固定风格词 + 固定模特 + 固定场景、垫图控制）。
- 同一张图用**用途开关**切标准：同一套提示词，企业端加"可生产/真实/电商规格"，赛事端加"系列概念/氛围/前瞻"。

## 5. 赛事出图装配清单（按层取）

### A 层装一包（纯图）

- 灵感板（8–12 张参考【经验值】+ 文化母题说明）
- 色彩方案（主/辅/点缀色，色卡）
- 面料/纹样板（材质四要素 + 文化说明 + 无缝循环）
- 款式图（每套正/背，标注廓形、门襟、开衩、缝位）
- 效果图（3–5 套完整着装，系列一致）
- 细节图（纹样、工艺、辅料特写）
- 文字：设计说明（逐套）+ AI 创作说明 + 原创承诺
- 排版成 A3/A1 PDF，去标识

### B 层加一段片

- 上述图全部 + **AI 虚拟走秀/营销片**（走 `video-brief.md` 四段式，喂 Seedance）
- 走秀片必须清楚呈现：**廓形、面料垂坠感、动态褶皱**（评分点）
- 数字材质规则全片统一（金属/发光/粒子不跳），配乐贴合，无标识

### C 层再加 3D 工程

- 上述图 + 片 + **3D 工程文件**（外部软件）
- 交 3D 前的图与视频技能全包；工程文件见第 10 节交接清单

## 6. 读题必确认 9 项

1. **套数**：系列 3–5 套，常见 4 套。
2. **图稿**：A3(297×420)/A1(58×84)、横/竖、dpi（300/400）、JPG/PDF、CMYK/RGB。
3. **视频**：时长（30–90s）、分辨率（1080p/4K）、帧率（30/60fps）、比例（16:9/9:16）、MP4、大小上限。
4. 要不要 **3D 工程文件 / 纹样/款式源文件**（决定是不是 C 层）。
5. 要不要**实物成衣**。
6. **文字**：设计说明字数、语言（中英）、是否要 AI 工具与提示词披露。
7. 是否**限定平台**（如 Fabricant 只能用其平台，允许轻量 PS 裁剪调色）。
8. **去标识**：不得出现姓名、院校、团队标识。
9. 报名表、原创承诺书、文件命名、截稿时间。

## 7. 完整创作链路（按层裁剪）

| 步 | 交付物 | 模块 |
|---|---|---|
| 1 定题立意 | 主题、文化切入点（200 字） | text-content |
| 2 灵感板 | 母题、参考风格、文化元素 mood board | 本文 + image-editorial |
| 3 色彩方案 | 主/辅/对比色 + 色卡 + 搭配说明 | 本文 |
| 4 面料/材质 | 真实或虚拟面料质感、肌理、功能 | image-detail-fabric |
| 5 款式设计 | 款式图/结构图（正背、工艺） | image-garment |
| 6 效果图 | AI 完整着装（正/背/侧）系列整套 | image-editorial |
| 7 细节图 | 纹理、装饰、工艺特写 | image-detail-fabric |
| 8 数字成衣 | B 层走视频；C 层走 Style3D/CLO 工程 | video-brief / 本文第 10 节 |
| 9 虚拟走秀视频 | 4 套依次展示廓形/垂坠/动态褶皱 | video-film-types + video-brief |
| 10 文字排版 | 设计说明/AI 创作说明 + A3 排版 PDF | text-content |

A 层停在 7→10；B 层加 8（视频）、9；C 层加 8（3D）、9。

## 8. 评审维度

- **国内 Style3D**：设计灵感、创意、制版、动态产品呈现、软件操作熟练度、流程执行。
- **行业 AI 赛（如渠县户外纺织 AI 赛）**：服装设计、材料应用、功能服用、前瞻创意、市场潜力、技术深度；手稿阶段必须用 AI。
- **国际 Fabricant（按权重）**：
  1. **可生产性 Producibility（最重）**——廓形、结构、材料必须现实可制造；结构逻辑要在图里可见或陈述里讲清。
  2. **系列一致性 Cohesion**——3 look 是一个胶囊系列，廓形/色彩/情绪/造型统一。
  3. **平台深度**——多工具结合。
  4. **原创性**——不直接模仿某设计师签名风格。
  5. **市场契合**——statement 款 + 可穿款搭配。

## 9. 关键规格速查（实测自赛题）

- **沙河杯**：企划 JPG/PNG，A3，≥400dpi，九项内容；走秀 MP4，4K 3840×2160，16:9，60fps，60–90 秒，4 套；PDF 打包 + 报名表 + 原创承诺，无个人标识。
- **Style3D 数智未来**：初赛 A3 横版 300dpi JPG（作品名 + 说明 + 系列效果图 + 每套结构图/面料材质图/3D 渲染图，≥3 套）；决赛 60 秒内 16:9 MP4（30fps，≤300MB）+ 3D 渲染图 + 3D 工程文件 + 现场改款建模，**不做实物**；主办方提供机器人 FBX 模型与基础走秀动画。
- **Fabricant**：3 套全身 look（catwalk/editorial/studio）+ 3 张细节；200 词 statement；图 9:16 或 1:1（PNG/JPG），视频 9:16 或 16:9（MP4）。
- **AI Fashion Week**：5 张初选 → 20 张走秀 + 5 配饰特写 + 5 张 BTS/街拍/前排。
- **传统赛（中国服装设计师协会）**：首页彩色效果图 + 主题；其余页每套款式图 + 主题说明 + 面料实物小样（5×5cm）；A3 297×420 横版；入选后做实物。

## 10. C 层 3D 边界与交接清单（AI 出渲染图看效果，工程文件交专业软件）

**诚实边界**：即梦 / 图生图 / Seedance 能做款式图、效果图、面料纹样、虚拟走秀视频、交给 3D 前的全部图，以及**超真实 3D 渲染图（可交付看效果：提案 / 初赛 / 数字走秀）**；**可编辑的 `.zprj/.sproj/.clo3d/.fbx/.glb` 工程文件必须用 Style3D / CLO / Marvelous Designer 等专业软件**，本技能不生成可编辑工程文件，AI 渲染图不冒充 3D 工程。

**AI → Style3D 交接清单**（把 AI 出的图交给 3D 环节）：

1. 每套正/背/侧效果图（锁廓形、配色、闭合件位置）。
2. 标准款式图/结构图（标注缝位、分割线、结构）。
3. 面料材质图 + 材质四要素（纹理/光泽/厚度/垂感），数字面料参数。
4. 纹样/图案源文件（高清、无缝循环、可贴图）。
5. 配色色号与分区。
6. 走秀参考（动态/场景/情绪），供 3D 动画与 60 秒视频参考。
7. 3D 渲染图与 60 秒视频由 3D 软件输出；物理模拟（垂坠/褶皱/碰撞）以 3D 为准。

提示：进决赛通常有官方免费培训；零基础约一个月可上手基础打版（参照金奖案例）。

## 11. AI 披露、禁 AI 与提交自查

- 多数 AIGC 赛要求 AI 创作说明：工具、流程、技术路径、关键提示词；明确自主与 AI 分界。别隐瞒，评审会查工具链。
- 限定平台赛（Fabricant）只能用其平台；允许轻量 PS 裁剪调色。
- 数字衣也要"像这件衣服"：结构、配色、版型锚点一致（见 `consistency-lock.md`）。
- **提交前自查**：套数/尺寸/dpi/时长/帧率/比例逐项符合；C 层 3D 工程是否随附；AI 说明是否诚实披露；是否去标识；原创承诺书/报名表/命名齐全；版权自查（见 `copyright-compliance.md`）。
