# 品类指南：全品类 · 全风格（结构 · 工艺 · AI 翻车点）

出图前对不上品类先查本表：它只回答"这个品类**结构长什么样、靠什么工艺成立、AI 最容易翻哪几处车、提示词该锚在哪**"。纯风格词/年代/流派 → `design-language-dictionary.md`；面料参数与渲染 → `fabric-guide.md`；面料微距公式与光位表 → `image-detail-fabric.md`；配饰黑名单与造型板 → `design-boards.md` 第 10 节。

【语境】企业保真看结构与工艺能否核对；赛事与秀场语境看高级感、完成度与画面处理。**主力场景是国际品牌秀场级高级时装与高定比赛级服装，故本文件把高定 / 繁复 / 高级时装写得最细（见 2.10 与第三节）。**

## 〇、使用说明

- **先定四件事**：管线哪一步、走哪条路径（A 生图 / B 排板 / C 矢量·专业）、用哪套人体、什么语境——见 `image-quality-sop.md` 第七节；本文件只给该品类的**主路径**。
- **人体比例统一口径（严禁混用）**：无母版直出写实/照片向 = **1:9**（裆到脚底 55%）；有 Muse 继承母版；插画/时装画档 **9–10 头身**。落位与流程见 `fashion-illustration-spec.md` 6A，本文件只写"该品类用哪套、差在哪"。
- **本文件不负责**：风格词与年代定义、面料参数、微距光位、配饰黑名单、工程文件、运镜与四段式。锚点禁令与返工分流见 `consistency-lock.md`。

## 一、总览：品类 × 主路径 × 人体 × AI 翻车点

| 品类 | 主路径 | 人体 | AI 最高频翻车点（一句话） |
|---|---|---|---|
| 女装梭织（衬衫/连衣裙/半裙/裤装） | A + C 收款式图 | 写实/照片向 1:9 / 时装画 9 | 门襟方向写反、胸省不成逻辑、纽扣计数不守恒 |
| 女装外套/西装/大衣（tailoring） | A + C（结构最重） | 写实/照片向 1:9 | 驳头与领座关系错、垫肩过头、开衩扣位漂移、吃势无从自证 |
| 针织/毛衣（含针织成衣） | A 生图强 | 时装画 9 / 写实/照片向 1:9 | 织法被画成另一种花、罗纹方向乱、毛流起球不均 |
| 牛仔 denim | A + C | 写实/照片向 1:9 | 明线宽色不对、洗水层次假、五金计数错、斜纹方向错 |
| 男装 | A + C | 时装画 9（–9.5）/ 写实/照片向 1:9 | 门襟左右相反、肩腰比按女装画、袋型串位 |
| 童装 | A + C | 童装头身 4–7.5（随年龄） | 头身按成人画、五官位置错、安全细节胡编 |
| 内衣/家居/泳装 | A | 写实/照片向 1:9 | 弹力贴身画成梭织硬挺、模杯结构错、拉伸后织纹漂移 |
| 羽绒/棉服/户外/机能 | A + C | 写实/照片向 1:9 | 绗缝格距不均、充绒像气球、压胶条画成装饰线 |
| 运动/瑜伽/运动休闲 | A | 写实/照片向 1:9 | 弹力针织画成梭织、支撑结构错、拼接走线漂移、塑料光泽 |
| 婚纱/晚礼服/高级定制 | A + C（高定最重） | 时装画 9–10 / 写实/照片向 1:9 | 珠绣针路不可控、蕾丝每张都变、大裙摆垮塌、骨架外露 |
| 皮革/皮草/麂皮 | A | 写实/照片向 1:9 | 皮草毛向不一致、皮革塑料感、皮革上画错缝线 |
| 配饰/鞋包 | A 超真实展示 + C 技术线稿 | 无人体 flat-lay | 五金/鞋楦/出格工程不可靠、还原指定产品必失真 |

**路径速记**：超真实展示/材质渲染走 A；终稿排版印前赋值走 B；款式图、剪影、色卡、纸样、分色制版走 C。生产文件永远 C；AI 超真实展示图可直接交付提案（`image-quality-sop.md` 第四节路由表）。

## 二、逐品类指南

每节统一：结构要点 → 代表面料 → 标志工艺 → AI 翻车点 → 人体 → 提示词锚点 + 负面 → AI 边界。

### 2.1 女装梭织（衬衫 · 连衣裙 · 半裙 · 裤装）

**廓形**：衬衫 H/落肩/oversized；连衣裙 A 型、直筒、裹身、衬衫裙、鱼尾；半裙 A 字/直筒/百褶/包臀；裤装直筒/阔腿/锥形/微喇。
**结构**：领型（标准领/立领/八字/温莎）、克夫单双、门襟叠压、公主线、腰省与腰头、裆位与浪、下摆折边。
**代表面料**：高支府绸、真丝缎、亚麻、雪纺、粘胶（`fabric-guide.md`）。**标志工艺**：门襟明线、锁眼、包边、斜裁 bias、抽褶/活褶/对褶、来去缝。

**AI 翻车点**：① 门襟叠压写反（**女装右压左**；女装牛仔是例外，见 2.4）② 胸省不指向胸高点 ③ 纽扣/扣眼计数漂移 ④ 斜裁画成直裁、无弧形荡摆 ⑤ 下摆折边画成明线（正装/晚装用盲缝，休闲款才画虚线）。

```
【主体】女装梭织衬衫，H 型直筒，落肩长袖，方领，前门襟单排五粒扣
【结构】领型/克夫/下摆清晰；门襟右压左；明线沿门襟与袖窿
【颜色】主色 <雾霾蓝>；领里 <同色略深>；纽扣 <哑光树脂本色>
【材质】纹理=高支府绸细平纹，光泽=哑光，厚度=中薄，垂感=微垂有骨
【构图】正背平铺，白底无阴影，正投影，无模特；图1=版型 图2=面料 图3=配色
```
```
不要人体/模特/五官/褶皱光影/透视/背景/文字/水印/logo/纽扣数错/门襟方向相反/袖长不一
```

**边界**：AI 能做正背平铺、人台、配色与材质氛围；做不了款式图的对称与计数、纱向与刀眼、精确色号、真实手感——须 Illustrator 描摹成矢量（`fashion-illustration-spec.md` 07）。

### 2.2 女装外套 · 西装 · 大衣（tailoring）

**廓形**：单/双排扣西装、H 型大衣、茧型、浴袍式、斗篷、风衣（翻领/肩章/枪挡/风暴片/束腰）。
**结构**：领型（平驳/戗驳/青果领）、驳头宽、领座与领面、肩线（自然肩/薄垫肩/厚垫肩）、开衩（单/双/无）、里布、衬、扣位、袖山吃势。
**代表面料**：精纺羊毛、双面呢、粗花呢、羊绒、华达呢（`fabric-guide.md`）。**标志工艺**：手工驳头、马尾衬/粘合衬、绱袖对位、明线辑边、撬边（盲缝）。

**AI 翻车点**：① 驳头与领座关系错（驳头是翻折面，不是贴上去的片）② 垫肩过头 → 肩部盔甲感 ③ 开衩位置与双排扣扣位不成对称 ④ 袖山吃势自证不了——AI 永远给不出"缝合边等长"（`technical-production-spec.md` 13）⑤ 手工撬边下摆被画成明线压线。

```
【主体】女装双排扣戗驳领大衣，H 型直身，单开衩，双嵌线口袋，宽驳头
【结构】驳头翻折面与领座层次分明；肩线自然微垫；袖山圆顺；门襟右压左
【颜色】主色 <深驼>；扣 <同色包扣>；里布 <暗棕同色系>
【材质】纹理=精纺斜纹细密，光泽=哑光微润，厚度=中厚，垂感=利落挺括
【构图】幽灵模特正背，中灰底，柔和侧光显挺括；图1=版型 图2=挺括度 图3=配色
```
```
不要模特脸/多余配饰（帽围巾包腰带）/插兜手/驳头贴片感/夸张垫肩/扣位不对称/改变长度/水印文字
```

**边界**：AI 出人台成衣与材质氛围；结构能否做出来、衬与里布工程、吃势对位必须打版师 + 立裁验证（`technical-production-spec.md` 12）。

### 2.3 针织 / 毛衣（含针织成衣）

**廓形**：圆领/高领/V 领毛衫、开衫、绞花毛衣、针织连衣裙、针织外套。
**结构**：织法（平针/罗纹/坑条/绞花 cable/提花）、针距（GG 机号）、领口罗纹宽度、袖窿与袖山收针、下摆罗纹。
**代表面料**：羊毛、羊绒、美利奴、羊驼、马海毛（`fabric-guide.md`）。**标志工艺**：罗纹收口、套口缝合、局部提花、撞色段染、起绒拉毛。

**AI 翻车点**：① 织法被画成另一种花（要 1×1 罗纹给出坑条或提花）② 罗纹方向错位（领口横向、袖口环向必须一致）③ 线圈尺度失控、纱线与针距不匹配 ④ 毛流与起球不均 ⑤ 立体款拉伸后织纹漂移。

```
【主体】女装圆领绞花毛衣，落肩宽松，长袖，领口袖口下摆 1×1 罗纹收口
【结构】绞花沿前身中央纵向走；罗纹方向：领口横向、袖口环向、下摆横向
【颜色】主色 <燕麦米白>；罗纹 <同色>
【材质】纹理=粗针绞花凸起 + 罗纹竖纹，光泽=哑光，厚度=厚，垂感=松软微坠
【构图】平铺俯视 + 背面，浅灰底，柔和均匀光显线圈；图1=织法 图2=毛线 图3=配色
```
```
不要梭织布感/印花/织法错乱/罗纹方向相反/塑料光泽/假起球/人体/水印文字
```

**边界**：AI 出织纹、纱线质感、撞色；针距 GG、收针路径、套口工艺、起球与缩率必须织造打样与工艺单（`technical-production-spec.md` 14）。

### 2.4 牛仔 denim

**廓形**：直筒/阔腿/紧身/微喇/高腰 mom/工装牛仔；牛仔夹克、背带裤。
**结构**：腰头与腰耳、后育克、五袋、裆位；**女装牛仔门襟例外：左压右**（与女装常规右压左相反）。
**代表面料**：斜纹丹宁 10–14oz、赤耳 selvedge、弹力牛仔（`fabric-guide.md`）。**标志工艺**：明线（橙/黄棕双线，**SPI 8–10**）、套结加固、撞钉、五金、水洗（石磨/酸洗/猫须/做旧）。

**AI 翻车点**：① 明线宽度、色号、走向不一致 ② 洗水层次假、猫须随机 ③ 撞钉/铆钉/扣件计数漂移、门襟排扣数错 ④ 斜纹方向与部位不匹配 ⑤ 口袋对花错位 ⑥ 女装牛仔门襟画反。

```
【主体】女装高腰直筒牛仔裤，五袋式，后育克，腰头带腰耳
【结构】门襟左压右（牛仔例外）；明线沿侧缝/裆缝/袋口双线；袋角套结加固
【颜色】主色 <中洗复古蓝>；明线 <黄棕>；五金 <做旧铜>
【材质】纹理=3/1 右斜丹宁，光泽=哑光，厚度=中厚 12oz，垂感=硬挺带折痕
【构图】正背平铺，浅灰底，硬光显斜纹起伏；图1=版型五金 图2=洗水斜纹 图3=配色
```
```
不要真皮替代/平纹布感/明线颜色错/洗水过假/拉链齿乱/门襟方向反/水印文字/模特
```

**边界**：AI 出洗水效果、明线五金氛围、大片动态；洗水配方、色牢度、五金规格与明线 SPI 必须水洗打样与工艺单。

### 2.5 男装

**廓形**：西装套装、衬衫、大衣、夹克、工装；版型偏直、肩线方正。
**结构**：**门襟左压右**（与女装相反）；领型（平驳/戗驳）、袋型（贴袋/开线袋/双开线）、肩线（自然/罗马肩）、下摆开衩；男装腰线偏低、收腰弱。
**代表面料**：精纺羊毛、法兰绒、牛津纺、卡其、粗花呢（`fabric-guide.md`）。**标志工艺**：手工驳头、手缝扣眼、明线辑边、附衬、里袋。

**AI 翻车点**：① 门襟左右画反 ② 肩腰臀比按女装画（男肩接近 **2 头宽**、臀≈肩或略窄、腰平）③ 袋型串位 ④ 误加领带/胸口手巾 ⑤ 收腰过度、女装化。

```
【主体】男装双排扣西装外套，自然肩，平驳领，双开线口袋，单开衩
【结构】门襟左压右；肩线方正不外扩；腰线偏低、收腰弱；袖山圆顺
【颜色】主色 <炭灰>；扣 <深色四眼扣>
【材质】纹理=精纺细斜纹，光泽=哑光微润，厚度=中薄，垂感=利落
【构图】幽灵模特正背，中灰底，柔和侧光；图1=版型结构 图2=面料 图3=配色
```
```
不要女装肩腰比/收腰夸张/门襟方向反/多余配饰（领带胸针包）/垫肩夸张/模特脸/水印文字
```

**人体差异**：插画档男装取 **9（–9.5）头身**，肩近 2 头宽，裆 4.5、膝 6.5（`fashion-illustration-spec.md` 6A.2）；写实/照片向统一 1:9。
**边界**：AI 出版型氛围与面料；结构化版型（肩斜、胸省、驳头角度）与合身度必须打版 + 立裁 + 试身。

### 2.6 童装

**廓形**：连体爬服、卫衣、连衣裙、背带裤、外套；宽松、易穿脱。
**结构**：开口位置（肩开/侧开/前开）、拉链/魔术贴/按扣、领口大小（防勒）、无尖锐五金、下摆与袖口收口。
**代表面料**：针织棉、汗布、摇粒绒、棉府绸（`fabric-guide.md`）。**标志工艺**：**针距 SPI 7–8**（比成人稀，防针孔）、包缝、平缝、无痕标签。

**安全硬口径（必须写进方案，AI 不能代替判定）**：**GB 31701-2015** 婴幼儿及儿童（**0–14 岁**），管绳带、小零件、重金属、邻苯，贴身标签不得接触皮肤；**GB 18401-2010** **A 类 = 婴幼儿（≤36 个月）**甲醛 ≤20mg/kg、pH 4.0–7.5，B 类直接接触皮肤甲醛 ≤75、pH 4.0–8.5。
**人体（专用口径，别套成人）**：0–1 岁约 **4 头** → 4–6 岁 **5–5.5** → 6–12 岁 5.5–6.5 → 13–15 岁 7–7.5 → 16–17 岁约 7.5；**8 岁前男女童几乎无差异**；童体特征 = 头大、颈短、腹部前凸、3 岁以下小腿外弯；儿童五官集中在头部 1/2 以下。

**AI 翻车点**：① 头身按成人比例画 ② 五官位置偏高 ③ 忽略腹部前凸与小腿外弯 ④ 加了绳带/小零件（安全隐患）⑤ 五金锐利化 ⑥ 婴儿款画成成人版缩小。

```
【主体】4–6 岁女童连衣裙，A 字，泡泡短袖，领口按扣开合，**5–5.5 头身**
【结构】圆领无绳带；袖口宽松不勒；下摆 A 形放量；无尖锐五金
【颜色】主色 <奶油白>；点缀 <浅豆绿>
【材质】纹理=细密棉布平纹，光泽=哑光，厚度=中薄，垂感=柔软
【构图】正背平铺，白底，柔和均匀光，无真人童模；图1=童装版型 图2=面料 图3=配色
```
```
不要成人头身比/绳带与可脱落小零件/锐利五金/成人化妆容造型/真人童模脸部/水印文字
```

**边界**：AI 出童装版型氛围、配色、面料、扁平淡彩款式预览；安全合规判定、A/B/C 类归属、绳带与附件检测全部人工（`portfolio-board.md` 19）。

### 2.7 内衣 / 家居 / 泳装

**廓形**：文胸/内裤/塑身衣、家居服（针织套装/睡袍）、泳装（连体/分体/比基尼）。
**结构**：罩杯（模杯 moulded cup/拼接杯）、钢圈与下扒、侧比与背扣、肩带调节；**弹力贴身合体逻辑**，不用梭织松量逻辑。
**代表面料**：弹性针织、莱卡/氨纶混纺、蕾丝花边、网眼（`fabric-guide.md`）。**标志工艺**：包缝/绷缝、无痕压胶、蕾丝拼接、模压定型、扣件。

**AI 翻车点**：① 把弹力贴身画成梭织硬挺（关键错误）② 模杯结构与胸型关系错 ③ 拉伸后织纹漂移、网眼变形 ④ 身体穿模 ⑤ 蕾丝每张都变 ⑥ 泳装正身出现明线（泳装多用包缝/压胶）。

```
【主体】女性连体泳衣，高衩，细肩带，后背交叉，四面弹贴身

### 2.8 羽绒 / 棉服 / 户外 / 机能

**廓形**：长款羽绒、短款面包服、棉服、冲锋衣（硬壳/软壳）、机能夹克、马甲。
**结构**：**绗缝格**（横/竖/菱形/洋葱格）、充绒分仓、压胶**接缝密封 seam sealing**、防水拉链与挡风片、帽口与下摆抽绳、防风裙、多口袋模块。
**代表面料**：尼龙/锦纶塔丝隆、防水透湿膜、软壳/硬壳（`fabric-guide.md`）。**标志工艺**：绗缝、压胶贴条、防水拉链、魔术贴、气眼与绳扣。

**关键属性（可核口径）**：绒子含量（旧称"含绒量"，如 90/10）、充绒量（g）、**蓬松度 fill power 常见 550–800+【经验值】**；羽绒服装产品标准 **GB/T 14272（现行版本以官方为准）**；防水以静水压 mmH₂O、透湿 g/m²·24h 表述。

**AI 翻车点**：① 绗缝格距不均、格数与分仓不成逻辑 ② 充绒蓬松画成气球或塌陷 ③ 压胶条被画成装饰线条 ④ 拉链头/气眼/绳扣乱长 ⑤ 口袋位置漂移、模块化不成系统 ⑥ 冲锋衣画成普通夹克。

```
```

```

### 2.10 婚纱 / 晚礼服 / 高级定制（最详写）

高定不是"更好的成衣"，而是独立的结构—工艺—工时体系：**由单人尺寸立裁成形，靠内置结构撑住廓形，由手工工艺堆出完成度。**

**(1) 廓形与支撑**

| 廓形 | 结构特征 | 支撑方式 |
|---|---|---|
| A 字 A-line | 腰线以下线性放大 | 衬裙 petticoat 或单层硬网纱 |
| 球裙 ballgown | 腰线骤放，体积最大 | **裙撑 crinoline / 网纱衬裙**，多层薄纱叠加 |
| 鱼尾 mermaid | 膝上贴身、膝下外放 | 内置鱼骨 + 局部衬撑，膝位断点 |
| 鞘式 sheath | 顺体直落 | 斜裁 bias 或弹力里布 |
| 帝国式 empire | 高腰线（胸下） | 高腰分割 + 长直摆 |
| 拖尾 train | 后摆延长 | 分层薄纱 + 内衬撑幅 |

**(2) 内置结构（看不见，但决定成败）**：**立裁 draping**——礼服、斜裁、披挂缠绕、非对称、体积褶皱必须走立裁（`technical-production-spec.md` 12）；**胸衣 corset / 马甲**以鱼骨 **boning** 提供纵向支撑与定型，衬布定形；**裙撑 crinoline / 衬裙**撑出球裙与 A 字体积。**AI 可出**内置结构的**超真实效果展示图**（视觉表达：骨架位置、体积支撑的"看起来的样子"）；**结构强度、承重与人体适配、鱼骨位置数量**必须立裁 + 人体试穿，或 3D 物理验证（CLO / Style3D，`technical-production-spec.md` 16）——AI 展示图不冒充结构验证。

**(3) 面料与装饰**

| 类别 | 常见 | 作用 |
|---|---|---|
| 薄纱 tulle | 硬网纱 / 软网纱 | 叠体积、撑裙摆、做罩层 |
| 蕾丝 lace | 尚蒂伊 / 重绣 / 水溶蕾丝 | 面层图案，通透与立体 |
| 缎 satin | 真丝缎 / 重缎 | 高光泽主体、鱼尾贴身成型 |
| 欧根纱 organza | 硬挺透明 | 造型罩层、撑轮廓 |
| 塔夫绸 taffeta | 细密平纹、脆响 | 撑开成体积，蓬裙/礼服 |
| 雪纺 chiffon | 极薄软透 | 飘逸层、叠层 |
| 天鹅绒 velvet | 短绒 | 复古高级感，随角度哑光 |

装饰工艺：**钉珠、亮片、珠绣、立体花 appliqué、羽毛、压褶、刺绣**。
**AI 出超真实效果展示图**：精确珠绣/钉珠/蕾丝的**视觉效果图**（珠子密度、针脚立体、珠光尽量真实，可直接交付提案/作品集）。**生产/实测边界**：**精确珠绣针路与针数**——绣花机只认制版文件（Wilcom / 田岛 → **.DST / .EMB / .PES**），AI 给不出针法、针距密度、缩料补偿与总针数（`design-boards.md` 05-1）；**蕾丝花型无缝循环**必须人工 Offset 检验；**手工工时【经验值】** AI 无从估算。

**(4) AI 翻车点（高定专属）**：① 珠绣像"贴纸"——珠子大小不一、排布随机、无针法逻辑，放大即穿帮 ② 蕾丝每张都变——效果图/细节图/大片图案不一致，必须逐张挂同一张蕾丝参考图（`consistency-lock.md`）③ 纱层透视层次乱 ④ 大裙摆无支撑垮塌（AI 默认画成垂坠布料）⑤ 内置骨架外露 ⑥ 长拖尾上下重复同一段蕾丝、接缝可见 ⑦ 靠堆砌充高级——满屏亮片 + 塑料高光 = 廉价（`design-ideation.md` 第 10 节）。

**(5) 提示词锚点**

## 三、全风格落地：把风格落到品类上

风格词定义、年代、流派、品类语言归 `design-language-dictionary.md`。本节只讲**同一风格落到不同品类时，结构与工艺差在哪**。

### 3.1 精致度四档：同一品类，四个完成度

同一件连衣裙，做成高定、高级成衣、商业成衣还是快时尚，**结构—面料—工艺—装饰—画面**全不同。先定档位，再定提示词。

| 维度 | 高级定制 Haute Couture | 高级成衣 RTW | 商业成衣 | 快时尚 |
|---|---|---|---|---|
| 结构松量 | 单人尺寸立裁，合体到毫米；内置结构（corset/boning/衬布/裙撑） | 多码放量，版型考究，结构线清楚 | 按基码（女 160/84A、男 170/88A）放量，服务成本 | 简化结构，减少分割与省道 |
| 面料 | 定制/稀缺真丝、蕾丝、提花，可独家 | 优质（精纺羊毛、真丝、羊绒比例高） | 混纺为主，性价比优先 | 化纤比例高，轻量化 |
| 工艺繁复度 | 数百小时手工【通识】；钉珠/珠绣/立体花/羽毛/刺绣 | 讲究缝制，局部手工 | 标准化流水 | 极致简化、少工序 |
| 装饰 | 满身手工，讲究**繁复而不脏** | 一两个记忆点 | 局部点缀 | 印花/贴标为主 |
| 配饰 | 定制配饰、鞋履成套 | 品牌配饰体系 | 通用配饰 | 极少或外购 |
| 完成度 | 内外皆精（里布/衬/收口全手工） | 内外兼顾 | 外观优先 | 外观达标 |
| 画面处理 | 秀场级质感优先、克制背景、面料光泽可读 | 干净商业棚拍调 | 明亮实拍感 | 高饱和快销感 |

**高定"繁复而不脏"五条**：① 一个视觉焦点，其余让位（处处重点 = 没有重点，`design-ideation.md` 第 6 节）② 装饰服从结构，珠饰沿分割线走 ③ 颜色收敛，多同色系深浅 + 一个金属点缀 ④ 光泽对比克制，全亮面即廉价 ⑤ 留白，大面积素面衬托一处极致工艺。

### 3.2 风格族 × 品类落地（只讲结构—面料—工艺差异）

| 风格族 | 结构差异 | 面料/工艺差异 | 该品类高发问题 |
|---|---|---|---|
| 极简 Minimal | 少分割、隐藏闭合件，靠版型与比例取胜 | 高支、哑光、精确缉线、无装饰 | 没装饰遮丑，**版型必须准** |
| 先锋解构 Deconstruct | 外露结构、移位省道、非对称、未完成感 | 混纺、拼料、生边毛边、错位缝 | 赛事可激进，企业款必须能缝 |
| 复古 Retro | 按年代取廓形（50s 收腰大摆、80s 垫肩等） | 对应年代面料与工艺，至少改 3–4 层 | 缺年代 = 废词；要落到具体年代 |
| 新中式国风 | 立领、盘扣、襟型（大襟/对襟）、开衩、现代廓形 | 宋锦、暗纹肌理、丝麻、提花 | 印花/提花与工艺错配；纹样须无缝 |
| 街头 Street | oversized、落肩、阔腿、分层外大内窄 | 牛仔、卫衣布、工装布、印花徽章机能扣件 | 元素堆砌；与机能要区分 |
| 户外机能 Tech | 模块化、多口袋、压胶、抽绳、防风襟 | 尼龙、防水透湿膜、软壳/硬壳 | 把压胶画成装饰线；忽略功能结构 |
| 老钱/学院 Old Money | 经典合身廓形、格纹、徽章、针织 | 羊绒、精纺羊毛、真丝，无 logo | 面料档次决定成败，化纤毁掉质感 |
| 浪漫 Romantic | 收腰、伞摆、荷叶边、泡泡袖、蝴蝶结 | 雪纺、欧根纱、蕾丝、缎 | 元素过度叠加，从浪漫变廉价 |
| 哥特 Gothic | 暗调、立领、收腰、皮革与蕾丝拼接 | 黑、皮革、蕾丝、金属 | 光泽失控；蕾丝图案不一致 |
| Y2K | 低腰、短款、紧、闪亮 | 亮面、网眼、人造革、反光材质 | 亮面在高定语境是败笔，按档位用 |

## 四、出图自检与验收门

### 4.1 出图前五问

- [ ] **品类结构写全了吗**：领型、肩线、闭合件、下摆、分割线是否合该品类常识（西装看驳头、牛仔看门襟左右）？
- [ ] **风格落到结构上了吗**：不是"高级/复古"这种评价词，而是到廓形、面料、工艺、装饰（`design-language-dictionary.md`）。
- [ ] **档位定了吗**：高定 / RTW / 商业 / 快时尚——决定装饰密度与画面处理。
- [ ] **人体选对了吗**：写实/照片向 1:9（无母版直出统一值）还是插画档 9–10，两张不混。
- [ ] **参考图分工写了吗**：图1 结构、图2 面料或模特、图3 配色或场景，逐张点名（`consistency-lock.md`）。

### 4.2 图出来后六查

- [ ] **结构自洽 + 工艺可信**：门襟方向、闭合件计数、分割线合常识；明线宽/色/走向统一；绗缝、压胶、包缝按品类正确出现，不当作装饰乱入。
- [ ] **弹力与体积正确**：弹力面料不画成梭织硬挺；球裙不画成垂坠垮塌。
- [ ] **装饰不脏**：有焦点、有留白、颜色收敛、光泽对比克制。
- [ ] **人体正确**：写实/照片向 1:9 不反弹性；时装画 9–10 头身不回弹写实（`fashion-illustration-spec.md`）。
- [ ] **跨图一致**：蕾丝/珠饰/印花系列内一致；细节图与主体图不矛盾。
- [ ] **合规与版权**：无未授权真人肖像、无品牌 logo、无 IP 角色；每图有来源与授权标注。

### 4.3 验收门（缺一不可）

1. 每个品类都写出了**"AI 能做（超真实展示）/ 须专业（生产·实测·合规）"**，且须专业的部分有替代路径（专业软件 / 立裁 / 打版 / 检测）。
2. 高定/婚纱类必须明确：**AI 出超真实展示，生产文件/实测/合规靠专业**。
3. 至少有一条符合档位的结构—面料—工艺描述。
4. 所有提示词都配负面词，所有跨文件引用都是裸文件名。
