# 锚点锁定与返工（图与视频共用）

## 锚点清单

每次都要把这两组锚点写成显式禁令。**没写成禁令的，就是模型自由发挥的地方。**

### 服装锚点

- 结构：领型、肩线、袖长、门襟、下摆形状
- 版型：廓形、松量、腰线位置
- 颜色：主色**及颜色位置**（拼接、滚边、内衬各自的位置）
- 长度：衣长、裙长、袖长、裤长
- 闭合件：纽扣数量与位置、拉链、腰带、扣件
- 图案：印花或格纹的**位置**与尺度
- 配饰与鞋履
- 面料质地与反光程度

### 模特锚点

- 五官：脸型、眼睛、鼻、唇、肤色
- 发型：长度、分缝、发色、蓬松度
- 身形比例：**无母版直出写实/照片向 1:9、裆到脚底 55%**；有 Muse 以母版继承（执行口径：有母版提示词不写数字，约束越多错越多；无母版统一写 1:9+55%；插画档 9–10 头禁用于写实；比例差先调组合参数，仍差按锚点重出）
- 妆容与标志性特征

## 变化白名单

只有三项允许变化：**动作、场景、光源。**

## 禁区句式库

### 服装（中文）

```
服装的结构、版型、配色、长度与闭合件位置始终与 @图片1 一致，
不随镜头变形、不改色、不改变长度、不增减任何配饰，
不加任何未经指定的新配件（不加帽子、外套、珠宝、包、logo、腰带）。
保持服装的颜色、材质、形状与位置贯穿全片。
```

### 服装（英文）

```
Keep the exact same outfit from the reference image. Do not add hats, coats, jewelry, bags,
logos, belts, or new accessories unless specified. Preserve the outfit color, material,
shape, and placement throughout the entire clip.
```

### 模特

```
人物的五官、发型与身形比例始终与 @图片2 一致；
不得互换人物与服装的外观、服装、动作。
```

### 风格

```
不要黑白、插画、故事板线稿、玩具感渲染或塑料 CG。
不要生成运动路径、坐标轴或摄影机辅助线。
```

### 声音

```
无字幕、无 BGM，只保留风声、布料声与环境底噪。
```

## 失败诊断表

定位到**唯一一处**该改的地方，再按下面的返工规则分流：**锚点级问题整图/整段重出，非锚点小瑕疵才局部圈选。**

| 症状 | 根因 | 改哪一句 |
|---|---|---|
| 服装颜色变了 / 出现不该有的拼接 | 只有正面图，或没写颜色位置 | 补背面 + 逐处写明颜色位置 |
| 服装形状、长度变了 | 禁区没写长度与廓形 | 加"不改变长度、不改廓形" |
| 服装形状/长度反复漂（换装/实穿场景） | 参考图不是全身图（角度/裁切/遮挡使长度信息不全） | 换全身图作参考（效果图规则见 `fashion-illustration-spec.md` 08） |
| 多了帽子、腰带、包 | 缺"不加新配件" | 补禁区句式 |
| 模特脸变了 | 面部参考不清，或一图同时管脸和服装 | 拆成独立脸部参考与服装参考；大片按人脸双锁协议重垫（特写母版垫脸 + 身份卡文字锚，见 `image-editorial.md` 通用要求 6） |
| 模特比例不对 | 没写身形比例，或机位让比例失真 | 无母版补 1:9+裆 55%（写死）、有母版以母版重出、插画档补 9–10 + 查机位高度 |
| 多指/手部畸形 | 手入镜且姿势复杂 | 简化手部动作、让手自然垂下/出画；已生成的成片可圈选手部局部重绘（非锚点） |
| 动作被省略 / 剪辑慌乱 | 时间轴密度过高 | 减每段动作或拉长时长 |
| 模型自己加了东西 | 时间轴密度过低 | 补足每拍动作与状态 |
| 风格变成插画 / 塑料感 | 缺负面清单 | 补"不要插画/塑料 CG"，指定胶片 |
| 背景抢主体 | 场景元素太多 | 换更简场景或加浅景深 |
| 反光不对、看不出质感 | 光位与面料不匹配 | 按面料-光位表改光 |
| 运镜漂移、边缘拉伸 | 运镜太复杂 | 简化成稳定机位 |
| 织纹/缝线糊成一片 | 没显式要求织纹，或光圈太大 | 加"可见织纹与缝线"，f/8 |
| 视频里辅助线漏进画面 | 白模没加负面 | 补"不要运动路径/坐标轴/辅助线" |
| I2V 漂移（图生视频人物/产品变） | prose 重复描述了参考已承载的静态细节，或动作过载 | 加 `preserve @图片1 subject exactly; only motion, light, and camera change`（增量原则见 `video-brief.md`） |
| 泛化外观（假、塑料、千篇一律） | 空泛风格词堆砌，无物理细节 | 换成物理光源 + 材质行为 + 具体机位终点（替词表见 `image-quality-sop.md`） |
| 计划结尾不符（续段接不上） | 按计划状态续写，没用实际尾帧 | 从实际成片/尾帧的可见状态开场（多段续拍交接见 `video-brief.md`） |

## 返工规则

先判断问题在不在锚点上，再决定"整图重出"还是"局部圈选"。图片、视频都适用。

### 第〇步 · 返修六判定（看到结果先定性，不急着重出）

每次拿到结果，**先区分"不像"还是"不好看"**——这是两条完全不同的返工通道，先问用户一句"是像不像的问题，还是好不好看的问题"，或自己按下面两条判定后给结论：

- **不像**（与锚点/参考不一致：结构、色位、闭合件、身份、比例、光调偏了）→ 走**锚点通道**：整图重出或圈选（本文件第一、二步）。
- **不好看**（锚点都对，但设计感/审美平庸、构图或光影欠佳）→ 走**审美通道**：`design-ideation.md` 6·5 高级感升维清单 + 方向对比小图，不重出锚点。

> 别把审美问题当锚点问题改（越改越远），也别把锚点问题当审美问题磨（白烧额度）。

再归入一档，动手——不是所有失败都要重新生成：

| 判定 | 含义 | 怎么做 |
|---|---|---|
| **Keep** | 可用，或瑕疵可接受 | 保留，不返工 |
| **Fix-in-post** | 缺陷适合后期修（文字水印/杂物/小杂音） | 走后期，不进生成 |
| **Edit** | 该层可单独重生成（局部圈选/时间戳+框选） | 局部编辑，保其余层 |
| **Re-roll** | 同一提示词重跑（偶发模型波动） | 原词重跑一次，不改词 |
| **Rewrite** | 提示词/素材本身有问题 | 一次只改一个变量后重出 |
| **Stop** | 方向错了，继续烧钱无意义 | 停下来回锚点/回需求 |

- **预算/授权纪律**：每轮返工先确认剩余额度与已授权范围；零额度/额度耗尽时**不提交**新生成，只给诊断与建议；一次只改一个变量，改完记入版本日志。
- 重复失败 ≠ 提示词必然错：先按 `失败诊断表` 定位唯一根因，再选判定，不盲目重出。

### 第一步 · 分流

- **整图 / 整段重生成（默认，锚点优先）**：凡动了服装结构/版型/廓形/长度/闭合件、颜色位置/整体配色、图案/纹样/印花、配饰鞋履、面料质地反光、模特身份/整张脸/比例、大动作姿势、光调/镜头/场景氛围，以及视频里的运镜、整体动作、服装随动垂坠——一律整图/整段重出，不做局部补丁。
- **局部圈选 / 蒙版重绘（仅限非锚点小瑕疵）**：手部多手指/手姿势、面部小瑕疵/表情、背景杂物/路人、文字水印（消除笔）、单颗纽扣/拉链头/一个小配饰、小范围颜色或材质（hex 级替换）、局部光影、印花局部文字。
- **视频**：Seedance 2.5 支持"时间戳 + 框选区域"只改单时段单区域，保留其余画面、光影、音频、动作与时间轴；但运镜、整体动作、服装随动垂坠仍要整段重出。

### 第二步 · 局部编辑纪律

1. 选区略大于瑕疵、留羽化过渡，**不贴着褶皱或身体边缘**，否则接缝和光影穿帮。
2. 提示词写清"改什么 + 其余保持不变"；改颜色给 hex，改材质给材质四要素。
3. 改完检查接缝、光影、褶皱、织纹、颜色连续；视频还要检查动态与时间轴连贯。
4. **画布圈选 SOP（即梦 Canvas 工作台）**——画布是精确选区的权威界面，Agent 指令编辑只作辅助：
   1. 在 Canvas 集中查看本批全部图/视频；
   2. 圈选问题区：略大于瑕疵、留羽化过渡，不贴着褶皱或身体边缘；
   3. 把选区 + 一句话"哪里不对、要什么"回传给我 → 我给局部改写句（改什么 + 其余保持不变，规则见第 2 条）；
   4. 改完在画布复核接缝/光影/褶皱/织纹/颜色连续；视频另查动态与时间轴连贯。
   分工：选区/手动微调在画布，备料/诊断/改写句归 Agent（`tool-adapter.md` 二·5）。
5. **同一处局部改 2 次仍不自然，立刻改回整图重出**，不硬抹。

### 通用规则

1. **一次只改一处。** 同时改两句，无法判断哪句起作用。
2. 锚点级问题直接整图/整段重生成，不做局部补丁。
3. 同一处连改两次仍不对，就**改素材**（补背面图 / 换更清晰的模特图 / 加姿态参考），而不是继续磨措辞。
4. 记下每次改动的变量，攒几次就能看出这件衣服的"敏感点"。

## 出图版本管理（返工/迭代留档）

版本管理让"几十张图分不清哪版是哪版"不再发生：

- **命名**：`<系列>_<图名>_V<版本号>_<日期>`（V1 → V2 → V3…）；定稿版加 `_FINAL`。同一图多版本**并列存在，不覆盖旧版**。
- **每轮改版记一行**（项目画布"提示词与版权日志"）：版本号 / 改了哪句提示词或哪张参考 / 为什么改 / 结果如何。攒几轮就能定位这件衣服的"敏感点"。
- **保留策略**：锚点级整图重出 → 保留上一版作对照（出对比图用）；非锚点局部小修 → 不留中间版；每阶段定稿版 + 项目终版必留。
- **与返工规则挂钩**：整图/整段重出 → 开新版本号；局部圈选微调 → 同一版本内改动，不占版本号。
- 交付时终版走 `delivery-checkpoints.md` 总检，母版（可编辑源）与成品（PDF/成片）分开留存。
