# 文字交付物（企业与赛事共用）

核心心法：**一份客观事实底稿，两种出口。**

- 先把作品的客观事实（母题、色号、面料、廓形、工艺、参数、来源）记成一份不带形容词的"事实底稿"；
- **企业出口对物说话**——随件说明书，让客户 / 买手 / 工厂 / 运营看得懂、能决策、能生产；
- **赛事出口对人说话**——作品自述，说服评委，且本身就是评分项。

## 目录

- 第一步：写事实底稿（先客观）
- 企业出口（L1 单素材 / L2 板块 / L3 项目 / 横切版权 / 汇报答辩）

- 品牌与营销文案（企业长期）

---

## 第一步：写事实底稿（先客观，不做修辞）

每件 / 每系列先记全这张表，企业和赛事文字都从它长出来：

| 维度 | 记什么（客观、可核对） |
|---|---|
| 母题 | 具体文化 / 自然 / 建筑来源（不写"中国风"，写"裕固族波浪几何纹""帕特农柱式收分比例"） |
| 解构规则 | 提取了什么元素、用什么规则改（比例、几何、对称、重组） |
| 色彩 | 主色 / 辅色 / 点缀色，尽量给色号或可命名色 |
| 面料 | 材质、肌理、克重、垂坠、光泽 |
| 廓形 | H / X / O / A 型、收腰、长度、肩线 |
| 工艺 / 细节 | 闭合件、缝线、提花、拼接、辅料 |
| 穿着场景 | 季节、场合、人群 |
| 来源 / 工具 | 素材来源、AI 工具、提示词摘要、生成时间（见 `copyright-compliance.md`） |

## 企业出口：图随文走的三级随件说明

企业交付是"**每张图、每组图、每个阶段后面都跟着说明**"，验收标准和评审会质询都对着这些文字来。

### L1 · 单素材说明（贴在每一张图后面）

每张面料 / 纹样 / 效果图后面配三行：

1. **生成记录**：完整提示词 + 参数 + 工具 + 效果评分（可复现）。
2. **文化说明**（涉及传统元素时）：纹样名称、寓意、重构思路（如"团窠纹：原寓意团圆，重构为四方连续现代印花"）。
3. **版权标注**：来源、生成工具、授权、风险等级（高 / 中 / 低），表格见 `copyright-compliance.md`。

### L2 · 板块说明（贴在每一组图 / 每个板后面）

概念方案五大板（灵感 / 配色 / 面料 / 图案 / 效果图），每板一段说明，并用**系列化五要素**串场：
主题统一 · 配色呼应（≤3 主色 + 1 点缀）· 面料关联 · 图案延续 · 款式递进。

### L3 · 项目说明（整套方案）

- 主题定位（约 100 字）+ 概念阐述；
- 系列概念方案 PDF（排版规范见 `enterprise-proposal.md`）；
- 评审会**汇报发言稿 + 答辩**（见下）。

### 横切：版权自查报告

无报告不提交，结构见 `copyright-compliance.md`。

### 汇报发言稿与答辩（模拟企业评审会，分角色）

5 分钟汇报 + 3 分钟答辩，建议分四个角色各写一段：

- **设计总监（整体）**：系列定位、系列化逻辑、与品牌客群的关系。
- **企划专员（主题 / 灵感）**：文化母题、色彩、故事、主题文案。
- **AI 设计师（技术实现）**：工具链、提示词与参数、怎么保证系列一致性、出图效率。
- **合规专员（版权）**：素材来源、风险评级、规避措施、可商用结论。

**答辩四类高频问题**：设计理念 / 技术实现 / 版权与原创 / 市场与生产。每类提前准备 2–3 句，结论必须落在"可生产、可商用、可追责"。
验收三级结论（写进汇报末页）：通过（≥80 分）/ 有条件通过（60–79，列出修改项）/ 不通过（<60）。

### 企业随件文字的单款产品文案

每件：产品名 + 设计说明 + 核心卖点。

- 设计说明：廓形 / 面料 / 工艺 / 穿着场景。
- 卖点 = 功能 + 情绪 + 证据：
  - 证据："重磅双面呢、门襟没有一颗纽扣"
  - 功能："一件过冬不显臃肿"
  - 情绪："通勤到饭局都撑得住"

## 赛事出口：作品自述（说服评委，是评分项）

### 1. 参赛概念（200 词 / 200 字门槛）

国际赛常用（Fabricant 用 200 词 concept 报名）。结构：
主题 → 灵感来源 → 核心廓形 / 材料 → 为谁设计 → 差异点。

### 2. 设计理念（国内赛企划）

三段：创作思路 + 文化内涵 + 商业价值。

### 3. 设计说明（逐套写，固定结构）

灵感 → 色彩 → 面料 → 廓形 → 工艺 → 穿着场景。**图里有的设计，文字里必须有解释。**

### 4. AI 创作说明（AIGC 赛特有，独立交付物）

- 用了哪些 AI 工具（生图 / 视频 / 3D）、创作流程与技术路径；
- 关键提示词（可附）；
- 明确标注：**哪部分自主设计、哪部分 AI 辅助**；
- 诚实，评审会查工具链；详见 `copyright-compliance.md` 第七节。

### 5. Designer statement（英文，国际，约 200 词）

collection concept → construction logic → material → the wearer → why now。
国际评审看重"可生产性 Producibility"，要在陈述里讲清结构逻辑。

### 获奖作品的文字规律（从真实获奖作品反推）

A 层纯图赛的设计说明几乎都遵循：**具体母题 → 可量化提取（比例 / 几何 / 符号）→ 算法 / AI 解构 → 命名配色 → 落地应用**。
评委会看你能不能说清"这个纹样从哪来、你用什么规则改了它"，而不是泛泛的"国潮 / 高级"。

## 品牌与营销文案（企业长期，非随件）

### 1. 品牌故事

讲清：品牌从哪来、为谁存在、承诺什么。不堆形容词，用具体的人和场景。

### 2. 本季概念陈述

- 一句话主题（系列名 + 核心概念）；
- 主题故事约 200 字：用一个意象 / 一个画面讲清"这季在讲什么"；
- 关键词 3–5 个。

### 3. 系列主题命名

每系列一个主题名 + 一句概念 + 灵感来源。

### 4. 营销文案

- 上新标题、详情页、小红书 / 抖音图文、海报短句；
- 视频旁白 / 字幕（与 `video-brief.md` 配合）。

## 一页纸交付摘要（给领导 / 买手 / 评委）

交付时常要一张"一眼看懂"的单页（评审初筛、汇报封面、订货会手卡都用）。图占 60–70%，文字只留决策点，模板见 `assets/project-template.md` 第八节。

- **1 张核心主视觉**（全系列最强一张，不是拼图）+ 系列名/作品名。
- **一句话主题**（不超过 15 字）。
- **三要素一行**：色（色块/色号）｜ 面料（1–2 个关键词）｜ 廓形（H/X/A…）。
- **3–4 款/系列缩略图**，每款一个短名。
- **概念 ≤100 字**：母题 + 为谁 + 一个记忆点；企业落在"可生产、可商用"，赛事落在"为什么这样设计"。
- **3 条卖点 / 工艺亮点**：每条"一个画面 + 一个证据"（如"无一颗纽扣的双面呢手缝"）。
- **语境行**：企业=客群/波段/上市时间/价格带；赛事=作品名/套数/AI 披露一句话。
- 版式：一页 A4/A3，单一网格、两种字以内；图内文字后期排，规格/出血走 `design-boards.md` 底座。

## 通用写作原则

- **一个画面胜过一串形容词**：写"手缝双面呢，门襟没有一颗纽扣"，不写"匠心高级"。
- 主题故事用意象和动词，不写空话。
- 色彩 / 面料 / 工艺具体到可核对："Pantone 18-1142 驼色""380g 双面羊毛"。
- 赛事 / 企业文字都与画面一一对应；文字随图走，不出现"图里没有、文字里硬说"的点。
- **去标识要求**：赛事作品正文不出现姓名、院校、团队信息（企业方案则按品牌要求放署名）。
- 企业文字默认客观、可复现、能追责；赛事文字允许概念和意象，但也要能落地。
