# 设计灵感与品质（让设计本身好看、原创）

素材库（`asset-library-schema.md`）解决的是"**对不对、像不像**"；本文件解决"**好不好看、是不是你自己的设计**"。

核心判断：**模型只是渲染器，不产出审美。** 好看由上游的"设计决策"和下游的"筛选"决定，不由提示词华丽程度决定。案例喂得再多，只可能得到"高级的模仿"，甚至越喂越撞脸。本文件提供一套可复用的"创意发动机"：**设计简报 → 参考分寸 → 灵感转译 → 系列语言 → 发散评审 → 沉淀风格 DNA**。

设计原则、比例、评审圈由我前置和执行；最终"美不美"的一票是你的（你是艺术总监，我是创意总监 + 渲染）。

---

## 1. 两种入口

| 入口 | 特征 | 起点 |
|---|---|---|
| 纯文字 | 只有一句话/主题，没有任何图 | **先说清"意象"再填简报**（意象挖掘三问，见下）→ 分阶段生成（廓形→色/面料→细节），**不一把出** |
| 有参考图 | 给了一件衣服/一个廓形/一张氛围图 | 先做"参考拆解"（它好在廓形/色/细节/氛围），定保留什么、改掉什么，再走分寸尺 |

**意象挖掘三问**（纯文字入口、且方向说不清时必走——先共鸣后翻译，避免"高级/好看"这类空词直接翻错方向）：问这三件事，从答案提炼意象再进简报——
1. **想表达什么情绪**？〔清冷疏离 / 克制内敛 / 柔韧流动 / 戏剧张力 / 希望新生…〕——情绪决定色调与光影叙事；
2. **给谁看 / 什么场合**？〔赛事评委 / 企业订货 / 秀场观众 / 日常穿着…〕——决定克制度与表达强度；
3. **背后有什么故事**？〔一个比喻 / 一个意象：如"被规则束缚又渴望挣脱""东方庭院的一场晨雾"〕——故事里藏母题与记忆点。
> 答不出就发图（图代词）或走意象底库选项（`project-workflow.md` 二·5 感觉五步收拢）；答案出来后按第 4 节形/色/质/意四维拆解落简报。

没有想法、也没有参考时，先走本文件把"设计"做出来；设计定稿后，出图严格走 `image-quality-sop.md` 的四步管线。

### 1·5 参考使用五问（拿到任何参考先过五问，不直接喂图）

有参考图/参考片时，**先定"怎么参考"再动手**；无参考时跳过，走"字典优先 + 对比小图"（总路由见 `project-workflow.md` 〇·5）。

1. **参考还是交付**：参考层**一切皆可、无红线**（看/学/拆随便，不标权限）；分级只作用于**交付**——练习全 🟢；参赛/商用/公开发布：当代品牌/真人/高定 → 🟡 须转化、老花/Logo → 🔴 不复现（`asset-library-schema.md`）。
2. **角色分工**：它作 图1（服装结构）/图2（模特身份）/图3（场景光位）哪个角色？**一张图只管一个变量**（`image-quality-sop.md` 六）。
3. **学什么**：形/色/质/意四维取哪几维？（廓形 / 色彩 / 面料质感 / 意境叙事——见本文件第 4 节灵感转译）。
4. **参考强度**：垫图锚点（锁结构）／只取语言（学手法不抄形）／只作氛围（情绪方向）——强度越高、转化要求越高。
5. **不写什么 / 不复现什么**：提示词与公开交付不复现——品牌名/logo/老花/签名款整衣（**看与学无限制**：可看可拆可提炼配色/构图/手法，但模型会复现标志，故慎喂垫图、交付不复现；**真人脸不在禁用之列**：可作垫图基底，成片实质改到不可指认原真人即可用）；学到的每一点都要能说清"**怎么转译**"（分寸尺 L2–L4）。

## 3. 参考分寸尺（核心）

### 3.1 先立立场

服装是几千年发展高度成熟的学科——中外服饰史、设计大师、各品牌已把廓形、结构、剪裁、审美探索得非常充分。**必须系统参考已有服装，绕开它反而是闭门造车、容易做出"外行的原创"。** 问题不是"参考不参考"，而是"**参考到什么分寸**"。**先说清：参考本身无红线**——一切图皆可看、可学、可拆（这是行业正常方式）；下面的分寸尺管的是**交付**像不像（参赛/商用/公开发布时），不是限制你参考。

### 3.2 五级分寸

| 级别 | 做法 | 判定 |
|---|---|---|
| L0 直接复制 | 垫图照生成一模一样的款，logo/印花/标志廓形都在 | ❌ 抄袭/侵权 |
| L1 元素照搬 | 直接搬某品牌最有辨识度的单品元素（某经典领、某签名廓形、某老花） | ❌ 撞脸、高危 |
| L2 解构转译 | 拆出它"为什么成立"（廓形逻辑、比例、剪裁手法），用自己的面料/色/母题重做 | ✅ 可接受 |
| L3 多源杂交 | 2–3 个不相干来源各取 1–2 个要素 + 自己的母题，组合到无法指认 | ✅ 好 |
| L4 提炼原理 | 只学"为什么好"（比例、节奏、剪裁哲学），完全用自己的语言重写 | ✅ 最高级 |

目标：**交付层**（参赛/商用/公开发布）最终成品落到 L2–L4，且无法被一眼指认到任何一件具体作品；**练习/个人/内部参考不要求转化，全 🟢**。

### 3.3 参考素材三分类（按版权安全度取用）

| 类别 | 代表 | 取用分寸 | 库权限 |
|---|---|---|---|
| 历史/传统服饰 | 古希腊、巴洛克、维多利亚、唐/宋/明、民国、New Look 廓形、传统纹样 | 版权安全，可大胆取**形、结构、元素**，仍建议转译 | 历史/文物归 🟢 可投喂元素 |
| 当代品牌/在世设计师 | 各品牌成衣、高定、获奖新作、设计师签名手法；**秀场图全绿** | **参考全开**：可垫图、可发散，学**设计语言/手法**（Margiela 的解构、三宅一生的褶、Vionnet 的斜裁、Mugler 的身体结构）；**秀场图 🟢 全绿**——可看/学/拆/垫、可作长期参考，不标 🟡；**交付**（参赛/商用/公开发布）转译到不可指认（L2–L4），不抄具体某季款；练习/内部全 🟢 | 🟡 参考全开·交付按用途转化（**秀场图除外，全绿**） |
| 跨域素材 | 建筑、艺术流派、自然、陶瓷、雕塑、植物微距、光影 | 做**材质、氛围、印花**的原创增量，版权风险低 | 🟢 可投喂 |

> 这也是素材库"文化案例"要细分的原因：**历史文物/传统服饰** 可作 🟢 元素转译；**当代品牌/设计师/高定/获奖新作** 归 🟡（**参考层随便用**、交付层仅公开场合转化）；其中的 Logo/老花/注册印花单独归 🔴（**看与学无限制**、慎喂垫图、交付不复现）。**参考层全绿——分级只作用于交付。**

### 3.4 七条硬规则

1. **取逻辑，不取外形**：不问"这件长什么样"，问"它靠什么成立"——什么廓形、什么结构、什么比例、什么对比。把逻辑抽走，结果自己长。
2. **至少改动 3–4 个设计层**：廓形、色彩、面料、细节、结构、比例、穿着方式。只换色叫"贴标"，不叫设计。
3. **单一来源不主导**：任一参考只贡献 1–2 个要素；至少 2–3 个来源 + 自己的母题。
4. **标志性元素（交付层底线）**：logo、品牌老花/格纹、注册印花、艺术家印花属 🔴——**看与学无限制**（提炼配色/构图/手法）；**慎喂垫图**（模型会复现标志、难剥离）；**交付不复现**；设计师高识别度签名款整衣作 🟡——参考全开，交付（参赛/商用/公开发布）转译到不可指认。
5. **民族/非遗有挪用底线**：做"意"的转译，不做"形"的猎奇搬运；尊重语境、能对应文化内涵，必要时标注来源（合规判定见 `copyright-compliance.md`）。
6. **历史取形、当代取法、跨域取质**：形与结构从历史/传统来，剪裁语言从大师来，材质氛围从跨域来。
7. **越接近商业，越要保守**：企业订单里的复刻/联名必须有授权；个人探索和参赛概念可以更激进。

### 3.5 交付前三问（每次必答）

1. 看图能不能指认到某一件/某品牌？能 → 继续转译。
2. 我改了哪几层？写得出 3 层以上吗？写不出 → 没到原创。
3. 拿掉参考来源，这件还成立吗？不成立 → 是寄生，不是设计。

### 3.6 例子：参考 New Look

- 没分寸：垫图生成一模一样的 Dior Bar jacket = L0。
- 有分寸：只学"收腰 + A 字摆 + 量感裙"的**廓形逻辑**（廓形是公共财富），换成宋锦、月白、冰裂纹结构线、当代比例 → 你的"新中式 New Look"，指认不到哪件。

### 3.7 怎么读一个品牌 / 一场秀（品牌语言拆解框架）

拿到任何品牌、设计师或秀场参考，按 **7 维度**拆解，转译成可学语言——再进设计宪法或提示词（**提示词只写锚点，不点名**）：

| 维度 | 拆什么 | 提炼成 |
|---|---|---|
| ① 定位 | 客群、价位、态度 | 品牌调性一句话 |
| ② 廓形 | 每季主导廓形（H/A/X/茧形/斗篷…） | 廓形族（查 06-附 廓形字典） |
| ③ 色盘 | 惯用色系、每季主色+点缀 | 色板方向（查 03-附 色彩字典） |
| ④ 面料 | 惯用材质（粗花呢/真丝/牛仔/机能…） | 面料语言（查 fabric-guide） |
| ⑤ 装饰造型 | 工艺/印花/配饰/发型妆面 | 装饰母题（查 05 花型决策 + 配饰映射） |
| ⑥ 态度 | 气场/情绪（冷感/浪漫/叛逆/静奢…） | 风格 DNA（查六·5/六·6 大师语言） |
| ⑦ 提炼 | 可学的语言 → 锚点词（不点名） | 进设计宪法，跨图复用 |

> 取法梯度：**历史取形**（年代/流派公共财富）、**已故大师取法**（六·6 可大胆学）、**当代学语言**（六·5 仅学手法、终稿转化）。拆完过参考分寸尺 L2–L4（见本节 3.2）。拆解结果可存成**品牌语言卡**（品牌名仅内部、锚点语言入库复用，见 `asset-library-schema.md` 文化案例库）。

### 3.8 用户点名品牌/设计师做参照（入口流程）

用户没说方向、只给几个品牌/设计师名当参照/灵感时，走 **先翻译 → 后确认 → 再出图**，品牌名不进提示词：

1. **确认清单**：把用户给的品牌/设计师逐个圈出；"类似这种感觉" vs "就这几个"先确认；不确定的圈出来问。
2. **逐个拆语言**：六·5/六·6 字典有的直接查可学语言；**字典没有（或想更贴近当季）自己搜集**——联网查该品牌/设计师的设计理念、秀场、作品，按 3·7 七维拆解成锚点语言；用户明确要求"就要那个感觉"时**直接采用其风格语言为基准**（公开交付仍按版权口径转化）。
3. **提炼共同 DNA + 差异带**：多个参照合成**一个区间**而非并列两个点（如 Margiela × Jil Sander = 解构破坏 × 静奢纯净）。
4. **先翻译后确认**：品牌名翻成**锚点语言（不点名）**列给用户对："你要的是 XX + XX，主语言偏 A、辅语言偏 B——对吗？"对完才进提示词。
5. **contact sheet 拍板**：用锚点出 2–3 个方向对比小图（偏 A / 偏 B / 平衡融合），看图指或说"你定"。
6. **进宪法**：拍板方向写进设计宪法，之后自动取锚点不再重复问。

**多品牌融合规则**：
- 定**主导 + 辅助**（1 个品牌做主语言，其余只点缀 1–2 个元素），避免拼贴感；
- 冲突元素先自查：破坏感 × 精致感、量感 × 修身不同时做主语言；
- 融合结果是"你的语言"而非某品牌仿款——终稿过参考分寸尺 L2–L4。

**红线**：品牌名/设计师名只用于内部理解，**不进喂图、不进提示词、不进成片**（锚点写法见六·5/六·6 + 版权分级）；当代品牌仅学手法、已故大师可大胆取形。

## 4. 灵感转译（形 · 色 · 质 · 意 → 设计要素）

拿到任何灵感（一个主题、一件文物、一张图、一段自然），先做四维拆解，再翻译成四个设计要素。**不直接抄衣服。**

| 维度 | 提取什么 | 翻译成设计要素 |
|---|---|---|
| 形 | 轮廓、比例、线条、结构 | 廓形（H/X/A/O/T、茧型、斗篷）、分割线、省道 |
| 色 | 主色、辅助色、点缀色、色彩关系 | 色板（主60/辅30/点缀10，落 hex 与色位） |
| 质 | 肌理、光泽、厚薄、垂感 | 面料四要素（纹理/光泽/厚薄/垂感）+ 工艺 |
| 意 | 气质、情绪、文化语境 | 系列调性、穿着方式、配饰与造型 |

例："宋韵" → 形：宋器收放比例→利落 H 廓形；色：天青/月白/牙白；质：冰裂→暗纹肌理、宋锦；意：留白→克制的结构取舍与大面积素面。

## 5. 系列设计语言（一个系列必须是一套话）

一个系列至少锁死四条，每个款都要能回应：

1. **一个核心母题**：反复出现的形/纹/结构（如：同一道分割线、同一枚盘扣、同一褶皱逻辑）。
2. **一个材料动作**：全系列在面料上做同一件事（如：都做撞色滚边、都用同一种压褶）。
3. **一个比例故事**：统一的廓形与比例关系（如：高腰线 + 上短下长）。
4. **一个记忆点**：每个款至少一个"让人记住"的点，且全系列不重复打架。

系列化五要素（主题、色彩、面料、廓形、细节）的落地方法见 `enterprise-proposal.md`。

### 5.1 配饰是系列设计语言的延伸（不是另起炉灶）

做原创配饰时，它必须复述同一个系列的那套话：包的廓形、鞋的线条、首饰的形与五金，都应来自本系列的**母题、比例故事和材料动作**，而不是另选一套好看的配件。例：系列母题是"冰裂纹分割线"，包身的拼接、金属扣件的造型、鞋头的分割都呼应同一道裂纹，而不是另外配一个老花包。

- 配饰板先分叉"选品搭配 / 原创设计"，原创路走本文件全套，详见 `design-boards.md` 第 10 节。
- **配饰参考分寸比服装更严**：经典包款、红底鞋、老花、经典五金、名首饰是商标 + 外观专利 + 商业外观重灾区，属 🔴——过程可看其结构原理，不喂图生图、不照生成、不近似到可指认；黑名单与取用边界、配饰专属设计变量、五金/鞋楦/出格的 AI 边界见 `design-boards.md` 第 10 节。
- 评审时多加一问：拿掉这些配饰、换成任意一件，会不会破坏系列？会破坏说明配饰真正长在系列里；无所谓则说明配饰是凑数。

## 6. 设计原则硬约束（客观、可前置）

- **一件一个视觉焦点**，其余让位；禁止平均用力、处处重点。
- **节奏与对比**：紧松、长短、繁简、亮哑、透实，至少一组强对比。
- **配色 60-30-10**；全系列主色不超过 1–2 个，点缀色克制。
- **结构可制造**：概念再先锋，也要有可落地的结构逻辑（参赛概念款除外，企业款必须）。
- **用约束逼创意**：限定一种面料 / 零废弃 / 一个接缝 / 固定 3–5 套，常常出更好的设计。

### 6·5 高级感升维清单（把普通设计拉高设计感的正杠杆，与第 10 节负面词库配对使用）

负面词库防"变廉价"，本清单管"变高级"——**设计不丑 ≠ 高级**，高级需要主动升维。出图前/评审时逐项自检，至少命中 2–3 个杠杆：

| 杠杆 | 是什么 | 可执行锚点（写进提示词） |
|---|---|---|
| ① 明暗层次 | 拉开明度差，拒绝平光平铺；深底浅点缀或强侧光 | 明度层次拉开、深底浅点缀、侧光塑形 |
| ② 比例节奏 | 紧松/长短/繁简/宽窄至少一组强对比，制造呼吸 | 上紧下松、长衣阔腿、一处繁一处简 |
| ③ 留白与密度 | 大面积空 + 一处高密度焦点，焦点之外全部让位 | 大面积留白、单点高密度细节、其余克制 |
| ④ 材质冲突 | 两种对立材质并置（硬×软、哑×亮、挺×垂） | 皮革×真丝、哑光×金属、粗花呢×缎面 |
| ⑤ 光影叙事 | 光的方向/切割/阴影讲故事，不止照明 | 逆光轮廓、树影切割、一束顶光、暗部藏细节 |
| ⑥ 结构戏剧 | 一个结构上的"意外"或"不可能"，成为记忆点 | 错位门襟、非常规闭合、悬垂结构、一体成型 |
| ⑦ 细节密度 | 单点高密度工艺细节（刺绣/珠绣/分割），其余素净 | 一处繁复刺绣、其余素面、工艺焦点 |
| ⑧ 氛围统一 | 全系列同一光逻辑/同一色调/同一情绪，不中途变调 | 全程同一光位逻辑、色调一致、情绪贯穿 |

> 用法：任何一次出图/评审前过一遍此表。**评审视角**：说不清"这个设计靠哪个杠杆立住"，判平庸；**出图视角**：从 2–3 个杠杆写提示词锚点（如"明度拉开 + 材质冲突 + 单点密度"），比堆形容词有效。

## 7. 参考金字塔（喂图分层，一张图管一个变量）

不要让一张图同时管脸、衣服和面料。喂图按变量分层，与 `image-quality-sop.md` 图1/图2/图3 一致：

| 喂图 | 管什么 | 来源 |
|---|---|---|
| 图1 | 款式/廓形/结构 | 历史款（🟢）或自己定稿的款式图 |
| 图2 | 人物脸/比例 | 自有模特库 |
| 图3 | 材质/场景/氛围 | 面料纹理、跨域素材（🟢） |

- 大师/年代只当**语言**写进提示词（"90 年代极简结构 + 宋器比例"），不垫它的图、不出现品牌名。
- 写"**设计语言 prompt**"，不写"画面 prompt"：描述廓形线、省道、结构、分割、比例关系，不写"高级感""质感拉满"。

## 8. 发散 → 收敛（不赌第一张）

1. **概念阶段要量**：先出一批廓形/概念变体（同一简报，多方向），不要在第一张上反复改。
2. **变体矩阵**：把 **廓形 × 色彩 × 面料** 单维度系统变化，扫一遍设计空间，找最强组合，而不是随机一次次抽。
3. **收敛后深化**：选定 1–2 个方向，再进入 `image-quality-sop.md` 精修。
4. **杂交取优**：最佳结果常是 A 的廓形 + B 的领 + C 的色——把不同变体的优点合成新的一张。
5. **方向选择默认出对比小图（contact sheet）**：3–6 个方向拼一版、各标 1–2 个关键词，看图选方向，不用干巴巴的文字选项；一次只变一个维度（协作协议见 `project-workflow.md`）。

## 9. 多角色评审圈（我同时用四个视角挑刺）

每个方案我用四个视角打分，**说不出"母题是什么、记忆点是什么"的，判平庸**。

| 视角 | 主要看什么 |
|---|---|
| 设计总监 | 概念是否成立、系列是否统一、母题是否贯穿、有没有记忆点 |
| 买手 | 好不好卖、可穿性、价格带、品类搭配、有没有明显滞销款 |
| 赛事评委 | 创新性、完成度、设计说明与图是否一致、是否经得起"为什么这样设计" |
| 版师 | 结构是否成立、能不能做出来、有没有违背面料与工艺常识 |

评分建议五项各 1–5 分：设计逻辑 / 系列感 / 惊喜点 / 可穿性 / 原创度。任一项 ≤2 分的方案退回，不进入精修。

## 12. 白模骨架先行 → 自举图生图（纯文字落地第一张的核心技术）

纯文字最容易翻车的原因：第一张图就让模型同时决定**结构 + 色 + 材质 + 光 + 配饰**，变量太多，结果全随机。正确做法是**一次只让它决定一个变量，用一张图把前一个变量锁死，再喂回去加下一个**。

### 12.1 第一张出"白模骨架"，只锁结构

- 不要第一张就出彩色成片。先出**黑白 / 素灰 / 无材质 / 无色彩**的结构骨架图：白模、灰模、素体人台或纯线稿，只有廓形、分割线、省道、闭合件位置、比例、长度。
- 这一步唯一要确认的是"**形对不对、结构成不成立**"，色彩面料一律不碰。结构不过，不进下一步。
- 白模阶段一次出多版（对应第 8 节变体矩阵），选定 1 个结构最强的方向。
- 提示词骨架：
```
时装设计白模/素体骨架图，黑白或极浅灰，无任何色彩与花纹、无面料材质、无配饰，
中性白色/浅灰背景，只呈现服装的廓形、结构线、分割线、省道、领型、肩线、门襟、
闭合件位置与长度落点；<正面 + 3/4 侧>，轮廓干净，比例准确，结构清晰可读。
不要颜色、不要花纹、不要面料光泽、不要配饰、不要文字水印、不要真实品牌、不要多余装饰。
```
（时装画人物态的白模 = 先出 9–10 头身 croquis 人体模板，再图生图着衣，见 `fashion-illustration-spec.md` 6A.4。）

### 12.2 自举（bootstrap）：第一张之后全是图生图

1. **锁结构**：白模骨架（无彩色）。
2. **加色**：把上一张白模作为图1，图生图，只加色板（主/辅/点缀与位置），结构不动。
3. **加材质**：把上一张作为图1，再图生图，只加面料四要素（纹理/光泽/厚度/垂感），结构与色不动。
4. **加细节**：补闭合件、局部结构、工艺。
5. **上模特/场景**：此时进入 `image-quality-sop.md` 步骤③（图1成衣、图2模特、图3场景）。

每一步都**点名图1/图2/图3各管什么、锁什么、不许动什么**，上一张就是下一张的图1（这就是"自举"）。每步只加一个变量，结构从第一张起就不再漂移。

### 12.3 与四步管线的关系

- 白模骨架属于**设计阶段**，用来从无到有把设计"长"出来；四步管线（`image-quality-sop.md`）属于**定稿后**，用来稳定出图、保证多图一致。
- 白模骨架走完上色上材质，产物就是四步管线的步骤①"锁数字样衣"，可直接喂进去，不必重头再来。
- 任何一步结构崩了，**回退到上一张白模重出**，不要在崩掉的彩图上继续叠加（越叠越乱）。

## 13. 两条路的最小流程

**纯文字**：感性词查 `design-language-dictionary.md` 翻成设计变量 → 设计简报 → 灵感转译（形色质意）→ 变体矩阵出廓形 → **白模骨架锁结构（第 12 节）→ 自举依次加色/材质/细节** → 评审圈选定 → 进入四步管线。

**有参考图**：参考拆解（好在廓形/色/细节/氛围）→ 过参考分寸尺（历史取形/当代取法/跨域取质）→ 定保留项与改动项（≥3 层）→ 补自己的母题与跨域材质 → 变体矩阵 → 评审圈 → 进入四步管线。

## 13.5 你的草图 / 线稿接入（手上有稿，别从零重画）

> 你自己画的稿子是技能**最欢迎的输入**：自有产出、投喂权限 🟢，可直接垫图当锚点、不必转化（权限见 `asset-library-schema.md`）。三类草稿走三条线：

| 你给的稿 | 是什么 | 怎么接 | 落到哪 |
|---|---|---|---|
| **款式/结构草图** | 画了一件衣服的结构、分割线、省道、闭合件位置（可无色彩） | 当"白模骨架"直接用：作为图1 图生图 → 加色/材质/细节（见第 12 节自举），或直接作四步管线步骤①"锁数字样衣"的参考图1 | `image-quality-sop.md` 步骤① · 第 12 节 |
| **人体线稿 / croquis** | 手绘 9–10 头身人形（时装画比例），未画衣服 | 作**参考图1** 图生图着衣（图2=服装款型、图3=面料配色），锁比例与姿态；系列内复用同一张保持一致 | `fashion-illustration-spec.md` 6A.4 |
| **纹样/图案草稿** | 花型、印花、刺绣布局草稿 | 作**参考图1=花型图案与布局**，垫图去规范化/补配色/做四方连续 | `design-boards.md` 05 纹样板 |

**草图专属硬边界（别踩）**：

- 草图 / AI 出的 flat 线稿**可直接发展成技术款式图**：垫图 + 07.5 约束清单（正背分开/对称后处理/计数锁定/**真实比例 to-scale 无人体**）直出款式图；合同级另用 Illustrator 描摹成矢量（对称、缝线/纽扣计数、纱向、公差以标注为准，见 `fashion-illustration-spec.md` 07/07.5）。
- 纹样草图做印花：无缝四方连续须人工 PS Offset 检验、丝印分色走金昌、刺绣制版走 Wilcom（.DST）——AI 出超真实效果图（`design-boards.md` 05）。
- 交稿时说一句"这是款式结构草图 / 人体比例稿 / 纹样草稿"，我按对应线接入；不说就按图面判断，拿不准先问。
