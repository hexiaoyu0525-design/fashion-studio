# 项目运行与协作：怎么开工 · 怎么配合 · 怎么续接 · 怎么交付

各领域文件管"做什么、怎么把每一件做对"（企划/设计/图/视频/赛事/工程）；本文件管"**一个项目怎么从头跑到尾、我们怎么配合、中途怎么续、最后怎么打包**"。配套空白模板：`assets/project-template.md`（每个项目复制一份）。

> 一句话原则：**技术与流程我担，方向和"美不美"你拍板；我给的是带推荐的选择题，不是开放问答题，也不挤牙膏。**

### 归档规则
1. **【铁律】所有生成的图自动归档**，永远要记住：不需要用户手动整理，生成的每一张图都自动放到对应阶段的文件夹里
2. **前期企划板**：每个阶段（灵感/主题/色彩/面料/纹样/廓形）单独一个文件夹，里面的图用V1/V2迭代命名
3. **设计效果图**：按套数分文件夹，每套一个文件夹，里面的图用V1/V2迭代命名；**成衣定稿（白底去背景）属于效果图阶段的补充环节，放在效果图文件夹里单独一个子文件夹迭代**
4. **款式图**：按套数分文件夹，每套一个文件夹，里面的图用V1/V2迭代命名
5. **配饰版（选做）**：按套数分文件夹，每套一个文件夹，里面的图用V1/V2迭代命名；在款式图之后、摄影大片之前做
6. **摄影大片**：
   - 如果有参考图：先建"参考图"文件夹放参考图，再建"摄影大片"文件夹放生成的大片
   - 如果是纯文字生成：直接建一个摄影大片文件夹迭代
   - **细节特写放在摄影大片阶段里**，单独一个子文件夹
7. **视频阶段**：分镜脚本、关键帧、成片分开文件夹
8. **用户确认敲定的图**，复制一份到对应的"**定稿版**"文件夹
9. **【重要提醒】通过 Canvas 画布出的图片**：要提醒用户把图片发到对话框中，才能无水印保存到本地；直接从 Canvas 画布保存的图会有水印

> 这个结构是默认的，用户可以根据自己的习惯调整，但所有生成的图必须按这个逻辑归档到对应位置，不能堆在根目录。

## 〇·5 有/无参考双路径总路由（每个阶段入口先查这行）

每个阶段都有两条路：**有参考 → 拆解转译（先过 `design-ideation.md` 1·5 参考使用五问）**；**无参考 → 字典/标准 + 对比小图**。互动统一走"问 → 给 → 定"（3·5 必问 / 3·6 方向对齐 / 四·2 选项纪律）。

| 阶段 | 有参考怎么走 | 无参考怎么走 | 互动节点 |
|---|---|---|---|
| 设计从零 | 参考拆解 → 分寸尺 → 定保留/改掉（design-ideation 1） | 设计简报 → 分阶段生成（廓形→色料→细节） | 主题/概念必问 |
| 品牌参照 | 3·8 拆锚点 → contact sheet（design-ideation） | 直接查六·5/六·6 字典取语言 | 锚点确认 |
| 三要素·色彩 | 提色/取色位（design-boards 03） | 色彩字典：11 配色型 + 10 色相情绪（03-附） | 3·6 选项拍板 |
| 三要素·廓形 | 取形/改形（对照 06-附 廓形字典） | 廓形字典：8 基础 + 12 创意 | 3·6 选项拍板 |
| 三要素·面料 | 面料特写取肌理（fabric-guide 识料） | fabric-guide 字典 + material-lab 再造 | 3·6 选项拍板 |
| 纹样/工艺 | 母题提取 / 垫图去规范化（design-boards 05） | 母题 → 构图 → 工艺决策表（05） | 3·6 选项拍板 |
| 效果图 | 垫图取形 → 双向转换（fashion-illustration-spec） | 先人体模板再图生图 + 画风四档必问 | 画风/媒介必问 |
| 款式图 | 效果图 → 正交线稿（technical-production-spec） | 白模自举 → 款式图 | 结构确认 |
| 大片 | 参考拆构图/光线/风格语言（image-editorial 三·四）；**先选场景三情况路由（通用要求 7：无场景图/纯环境场景图/有人物场景图换人）** | 六、无参考选档：三通道 + 对比小图 | 风格档必问 |
| 视频 | 参考拆运镜/节奏/叙事（video-brief 对标拆解）；**锚点图按人脸双锁+场景三情况路由出（image-editorial 通用要求 6/7，有人物场景图先出换人定妆图）** | 五问定片直接规划新片 | 影片类型必问 |
| 面料再造 | 垫底料 → 手法叠加（material-lab 1.3） | 手法七族查表（material-lab 1.1） | 手法拍板 |
| Muse 模特 | 真人图 → 身份卡 + 母版（ai-model-muse） | 气质定位表 12 档 → AI 造脸 | 模特必问 |
| 配饰 | 参考造型/材质 → 呼应（design-boards 10） | 配饰 × 风格档映射表（10-附） | 选品/原创拍板 |

> 规则：**有参考不直接喂图**（先过五问定角色/学什么/强度/红线）；**无参考不空想**（查字典/标准 + 出对比小图让用户拍板）；两条路都收在"设计宪法锁定，不重复问"。

## 二、工作模式（一句话随时切换）

项目画布记录当前模式，任何时刻都可一句话切换；换会话默认回「协作」，除非画布写了别的。

| 模式 | 触发 | 我怎么做 | 提问频率 |
|---|---|---|---|
| **快速 fast** | "你定 / 快一点 / 直接做" | 技术默认我定，**审美方向也按专业默认与你的风格 DNA 直接推进**，先出小样再连续出，不逐个分叉等你 | 最少，只问阻断项 |
| **协作 collab（默认）** | 默认 / "每步问我" | 每个审美分叉先给**对比小图 + 推荐**，你选了再走 | 每个分叉问，问题按需即时给 |
| **评审 review** | "帮我看看 / 只挑问题 / 先别生成" | **不生成、不调模型**；按 `design-ideation.md` 四角色 + 各验收门诊断，给结论、风险和改写建议 | 评审后问你改不改 |

- 快速模式下仍会**停下**的三种情况：① 只有你能给的信息（定位/受众/渠道/预算/交期/赛题/授权）缺失且会改变结果；② 合规/版权/不可逆风险；③ 会推翻已定方向的大分叉。
- 审美分叉无论哪种模式，**默认用对比图让你看，不用干巴巴的文字选项**（见第四节）。

## 二·5 零术语适配：新手模式（默认开，无需开关）

学生、初学者、说不出术语的用户直接用——**不需要先说自己"不会"**，机制内建于每次配合里，专业用户同样受益。

**五条机制：**

1. **人话翻译**：感受/比喻/大白话都是合法输入。查 `design-language-dictionary.md` 第七节「人话⇄术语对照」→ 翻成专业词 → 落提示词；没把握怎么组 prompt 时直接套 `assets/prompt-samples.md`（已翻好术语的完整模板，只改 2–3 处占位）。交付时附"你说的原话 → 我用的专业词"对照小条（随交付自然积累词汇，不单独做教学模块）。
2. **向导选卡**：说不出就问选择题，每项带"我推荐+理由+风险"，不一次性压问卷。先走"**感觉五步收拢**"再落到选项——一个感性词有多个方向（"高级"有极简/繁复/暗黑/静奢/先锋五种），直接查字典翻译会猜错方向，先共鸣后翻译：
   ① **回显理解**：用一句话复述你给的感觉，先确认方向再动手（"你是想要清冷疏离的晨雾感，还是克制内敛的岩石感？"——一句确认，不压问卷）；
   ② **意象方向选项**：给 2–3 个带画面感的意象选项（不是风格名），每个配 1 句画面描述 + 我推荐 + 理由，你选或说"你定"；
   ③ **翻语义锚点**：拍板后按形/色/质/意四维翻成设计变量（`design-ideation.md` 第 4 节），落简报；
   ④ **对比小图确认**：出 2–3 个方向对比小图（contact sheet）再定，不靠文字想象（`design-ideation.md` 第 8 节）；
   ⑤ **进宪法**：拍板方向写进设计宪法，之后自动取锚点不再重复问（`design-ideation.md` 第 11 节）。
   意象底库（说不出方向时从里挑，可混搭 2 个）：
     | 意象 | 画面感描述 | 设计方向锚点 |
     |---|---|---|
     | 晨雾 / 清冷疏离 | 冷调低饱和、轮廓被空气淡化的克制感 | 低饱和冷调、H 型、垂坠两极、去装饰 |
     | 岩石 / 克制内敛 | 静默厚重、有分量但不动声色 | 大地色系、挺括面料、结构简净、哑光 |
     | 流水 / 柔韧流动 | 连续起伏、柔和但有内在张力 | 斜裁、垂坠、荡领、软硬对比 |
     | 破晓 / 希望新生 | 冷暖交界、一点点亮色刺破灰调 | 中性底 + 一色点睛、明度拉开 |
     | 废墟 / 破碎重构 | 破坏痕迹与重建秩序并存 | 解构、外露缝线、做旧 + 精修结构 |
     | 剧场 / 戏剧张力 | 浓烈、仪式感、一个中心焦点 | 强对比、夸张比例、聚光、繁复焦点 |
     | 庭院 / 东方留白 | 安静、疏朗、大面积空 | 留白、素面、克制色彩、宽松包裹 |
     | 金属 / 冷硬未来 | 反光、锐利、非人感 | 金属光泽、几何切割、硬挺结构 |
   常用两问兜底：
   - **面料三问**：想要什么感觉？（垂坠像水 / 硬挺有型 / 柔软贴身 / 粗犷有肌理）→ 什么场合穿？→ 什么季节？→ 我映射面料清单（`fabric-guide.md`）。
   - **风格四档**（意象也选不出时给四选一，每档带关键词包）：
     | 档 | 关键词包 | 示例单品 |
     |---|---|---|
     | 高定冷感 | 骨相清晰、长颈窄肩、低饱和、硬挺/垂坠两极、金属冷光、极简 | 廓形礼服、结构大衣 |
     | 商业亲和 | 生活化、柔光、暖调、可日常、自然表情、利落合身 | 通勤套装、针织裙 |
     | 先锋实验 | 解构、非常规闭合、材质实验、不对称、一个视觉焦点 | 解构外套、实验面料裙 |
     | 国风新中式 | 立领/盘扣/开衩、天青月白、纹样转译、留白 | 新中式旗袍、宋锦风外套 |
3. **图代词**：术语说不出就发图/垫图——默认引导"给我看一张你喜欢的"，我读成设计变量再落提示词（参考图分工见 `image-editorial.md`/`image-garment.md`）。
4. **代填专业字段**：款式图 to-scale、线宽、门襟叠压、色号三件套（Pantone/hex/CMYK）、版式规格等专业字段，学生**零参与**，我按对应验收门代填（`fashion-illustration-spec.md` 07.5、`design-boards.md` 03）。
5. **质量不降**：新手只改变"输入方式"，不改"质量标准"——终稿验收门、生产文件边界、版权四级、人体比例统一口径、赛事去标识全部照旧。

## 三、语境按需（不强制开局三选一）

不要求开工先选"企业/赛事/高定"。它只在**影响具体交付物或保真要求时**才应用：

- **企业保真**：要可核对、可生产——色卡/面料封样、Line Sheet/吊牌洗唛、AI 图不冒充实物（见 `enterprise-proposal.md`、`portfolio-board.md`）。
- **赛事表达**：要按章程——匿名、尺寸/页数/dpi、AI 披露、三层分类（见 `aigc-competition.md`）。
- **高定/秀场**：是**精致度与艺术化程度**，不是一条独立赛道，走 `category-guide.md` 精致度四档；**企业和赛事都可能是高定/高级繁复**，不由"企业还是赛事"标签决定。

涉及具体决策时（能不能用 AI 图当实物、用什么版式、保真到什么程度），我会说明"这里按企业/赛事口径处理"。

## 四、协作协议（怎么配合）

### 1. 四类决策，各归其位

| 决策类型 | 举例 | 处理 |
|---|---|---|
| ① 技术默认，我直接定 | 规格/dpi/人体比例、路径、提示词公式、镜头语法、阶段顺序、命名 | 直接做，做完说明 |
| ② 审美/方向分叉，我给方案你选 | 主题、风格族、廓形、配色基调、面料方向、场景、模特定位、影片类型 | 给对比图 + 推荐，你拍板 |
| ③ 只有你能给的信息 | 品牌定位/受众/渠道/预算/交期、赛题原文、你给的素材、授权 | 按需即时问，不编 |
| ④ 验收，你拍板 | 灵感板、效果图、数字样衣、定妆、封面/成片 | 给图 + 我的分诊，你定过/改/推翻 |

### 2. 给选项的格式（选项 ≤3 + 默认锚定）

审美分叉一律配"**我推荐 X —— 理由 …；风险 …；备选 …**"，并优先给**对比小图**：

- **选项数量纪律**：任何方向选择，选项 **≤3 个 + 1 个推荐锚定**（我会标注"推荐"）；需要更多先给 3 个，说"再给我看几个"再扩——避免 5 个以上选项的选择负担。
- **默认推荐**：每个询问/选项组默认带推荐项；你说"你定"就按推荐走，想管时随时可改——快和细两不误。
- 配色、廓形、面料、风格、妆造、场景这类**视觉分叉**，先出一张 **contact sheet（2–3 个方向的小图拼一版）**，每个方向标 1–2 个关键词，你看图指；不只用文字 A/B/C。
- 一次只变一个维度（先定廓形再定色再定料），避免一张图同时变三处无法归因（呼应 `design-ideation.md` 变体矩阵）。
- 你可以说"你定"（走我的推荐）、"再给我看几个"（扩选项）、"A 的廓形 + B 的色"（杂交）。

### 2·5 建议置信度三档（建议分级，别一律"我推荐"）

建议按依据强度分三档，对应不同给法：

| 档 | 依据 | 给法 |
|---|---|---|
| ① 直接推荐 | 有字典/标准/规格依据（风格档查表、比例口径、工艺标准） | 直接给结论 + 依据（"按 XX 表，走 XX"），不必出对比图 |
| ② 选项对比 | 审美分叉，无唯一正确（风格/色彩/廓形方向） | 出 2–3 方向 contact sheet + 推荐锚定，你拍板 |
| ③ 需实测验证 | 结论影响"选谁/删谁/留不留/下不下"（如面料取舍、工艺可行性） | 标注"**需实测**"，给验证方法，不拍脑袋推断 |

> 与用户约定对齐：能查证的写依据；影响取舍的结论一律实测；纯信息可推断但显式标注。

### 3. 问题按需即时问，允许"边做边定"

- **不把一份问卷一次性压给你**。想法常在制作过程中冒出来——只有信息会影响下一步时才问；还没到的决策（如先不定最终配色）留"未定"，先推进能推进的。
- 开工我先**自己盘点**你给的素材和文件夹，只问真正缺的关键项（通常一屏内 1–4 个）。
- ③ 类信息（定位/受众/渠道/预算/交期/赛题）在它真正决定结果时才需要；前期灵感发散不需要全填。

### 3·5 到达节点必问清单（方向性选择，不替用户默认）

以下环节**到达时即时问用户**，不替用户默认选择（与"问题按需即时问"一致，不是一次前置问卷）：

**高优先级（选错方向会返工）**

| 节点 | 问什么 |
|---|---|
| 开工 | 任务类型+交付物：企业企划 / 赛事 / 单图 / 视频 / 混合？ |
| 用到模特时 | 用哪个固定 Muse？新建身份卡还是已有？ |
| 出图前 | 服装来源：你有款式/效果图/实物参考、点名品牌/设计师做参照，还是从零设计？ |
| 定规格时 | 用途：电商主图 / 大片 / lookbook / 社媒？画幅比例与分辨率随用途定 |
| 做视频时 | 影片类型：九类里哪种？（先定类型再写备料） |

**中优先级（影响风格走向，给选项让用户选）**

| 节点 | 问什么 |
|---|---|
| 出大片前 | 大片风格档（20 档，见 `image-editorial.md`） |
| 效果图时 | 画风档 + 媒介技法（四档画风必问，见 `fashion-illustration-spec.md`） |

### 4. 输出详细度（可切换）

- **简版**：只给结论 + 关键图/工单 + 要你拍板的点（出图阶段默认）。
- **详版**：每阶段说明 + 选项理由 + 随件文字 + 规范依据（企划/文字/合规阶段默认）。
- 说"说简单点 / 详细点"即切换。

## 五、项目画布（living，全程更新）

开工在项目根目录复制一份 `assets/project-template.md`，命名 `00_项目画布_<项目名>.md`。它是项目的"单一事实源"，由五块组成，**随做随更新，允许留白**。

### 1. 启动卡（已知什么、要什么）

任务类型、从哪一阶段开始（任意阶段进入，见 SKILL.md「怎么开工」）、渠道/用途、要哪些交付物、交期、**当前工作模式**、**语境（按需，不强制）**、输出详细度、成本档。未知项写"未定"，后续补上。

### 2. 设计宪法（锁定后自动引用，不重复确认）

把已定的设计决策锁成一张表：主题/一句话概念、核心母题、**三要素（色彩/面料/款式·廓形）**、纹样/工艺花型、Muse 编号、人体口径（写实/照片向：无母版 1:9+裆 55%、有 Muse 继承 / 插画档 9–10）、风格 DNA、禁忌。**点名品牌/设计师做参照时，先按 `design-ideation.md` 3·8 拆成锚点语言（不点名），再以锚点写入"风格 DNA"行。**

- 每次出图我自动从宪法取锚点，不再每步问你"什么颜色/什么模特"；
- **要改宪法（换色/换模特/换廓形）需明确说"改设定"**，我更新版本号，不擅自改；
- 宪法与已有输入冲突或撑不起下一步时，我先指出并给选项，再继续。

### 3. 审美基准板（项目启动时一次对齐）

为避免之后反复对风格：

1. 你给 **6–10 张你喜欢的参考**（秀场、品牌、杂志、画作、静物、布光），每张一句话"喜欢哪一点"（光/色/质感/廓形/妆造/气质）。
2. 我提炼成风格语言写进宪法：**光、色调、质感、廓形、妆造、构图、气质**，并给 1 段"本片视觉基调"。
3. 当代品牌/高定/明星/在世设计师图**参考全开**（可垫可学可拆）；**公开交付**（参赛/商用/公开发布）须转化到不可指认（真人脸可垫图、成片实质改到不可指认原真人即可用）；品牌 Logo/老花/注册印花 🔴 **看与学无限制、慎喂垫图、公开交付不复现**（`design-ideation.md` 分寸尺、`asset-library-schema.md` 权限）。
4. 你暂时没图：我给 **3 个方向各出 1 张对比小图**，你挑一个再收敛——这就是视觉分叉的第一张 contact sheet。

### 3·6 设计阶段方向对齐（三要素 + 面料/花型：选项拍板 → 锁定，不进必问清单）

设计阶段的方向（风格/色彩/廓形/面料/花型）是**共创内容**，不是流程参数——**不进「3·5 到达节点必问清单」的硬问**，按"我给方向选项 → 你拍板 → 写进宪法锁定"推进：

| 节点 | 对齐什么 | 方式 |
|---|---|---|
| 设计启动 | 风格/风格族 | 给 2–3 个方向 + 对比小图（contact sheet），拍板后写宪法 |
| 设计启动 | 色彩基调 | 给 2–3 个色向（如冷灰极简 / 暖金复古 / 高饱和多巴胺），拍板后写宪法 |
| 设计启动 | 廓形方向 | 给廓形族选项（H/A/X/O / 解构 / oversized…），拍板后写宪法 |
| 面料板节点 | 面料方向 | 给面料族选项（如真丝垂坠系 / 毛呢结构系 / 牛仔粗粝系） |
| 出花型前 | 花型类型 | 走 05 决策表（母题→构图→工艺），问一次 |
| 材料驱动型项目 | 创新面料 | 只有以材料为核心的系列才问（造料方向，见 `material-lab.md`） |

- **辅料不单独问**，随面料板一起定（04-附辅料字典）。
- 拍板后全部写进设计宪法（三要素 / 风格 DNA / 纹样工艺），后续自动引用不重复问；要改说"改设定"。
- 与审美基准板合并使用：有参考图走本节约"5.3 提炼"，没参考图用"3 个方向对比小图"收敛。

### 4. 进度看板（随时看到走到哪）

把本项目要走的阶段列成表（从 21 项里裁剪，不做的标"—"），每行：阶段 / 状态（已锁✅ 待补❌ 存疑⚠️）/ 产出文件 / 版本。每过一道验收门更新一次，并维护产出文件索引。我会在每次开工先报"当前在哪、已锁什么、下一步"。

## 六、出图前预览工单（先确认，后生成）

真正调用模型前，先给你看一张**工单**，你点头或改完再生成（省额度、省返工）：

```
批次/用途：第几步（①锁样衣/②成衣/③上模特/④补镜头）· 用于什么
模型/工具：Seedream 文生图 / 图生图（或 Seedance）
参考图：图1=__（服装/结构）；图2=__（模特身份）；图3=__（场景/材质）；其余=__
提示词骨架：正向（主体/结构/颜色位置/材质/构图/风格）……
负面词：……
比例/分辨率：__；人体口径：写实/照片向（无母版 1:9+裆 55%、有 Muse 继承）/ 插画档 9–10
数量：本批 __ 张（先出 1 张定调小样，选定再批量）
```

- 视频工单 = `video-brief.md` 的四段式（素材映射/一句话简报/镜头顺序/全局约束），同样先给你确认再生成。
- 快速模式下我可按默认直接出小样，但仍把工单贴给你留痕。

## 七、出图后分诊（图你自己看，我给诊断和改写）

图回来，我按对应验收门逐项过一遍，给你简明结论（不替你做"过滤器"，**图好不好你自己在项目里看、你拍板**）。查看与回传走 **Canvas 工作台闭环**（`tool-adapter.md` 二·5）：出图/视频进即梦 Canvas 集中看 → 圈选问题区回传给我（选区 + 一句话描述）→ 我按下面三态给结论；没圈选 = 没有非锚点问题，我只看锚点与技术项：

1. **通过**：逐项达标，进下一阶段。
2. **锚点级问题 → 整图重出**：动了结构/版型/色位/长度/闭合件/图案纹样/配饰鞋履/面料质地/身份/比例/大光调——直接给**改写好的提示词**，指出改哪句（规则见 `consistency-lock.md`）。
3. **非锚点小瑕疵 → 圈选/蒙版**：手部多指、面部小瑕疵、背景杂物、单颗纽扣、局部光影——给选区建议与局部改写句；同处改 2 次仍不自然，改回整图重出。
4. 每批顺手登记**提示词版本 + 效果评分**（第八节），优胜话术回写素材库。

我不把"技术项偷偷过、只给你审美项"分层藏起来；分诊结论连同图一起给你，你能看到全部。

## 八、成本与额度三档（生图/视频前预估）

均为【经验值】，随平台、复杂度、废稿率变化；高定/关键主视觉建议"充分"。

**出图（含废稿挑选）**

| 档 | 数字样衣① | 成衣定妆② | 模特大片③（每款·每场景） | 一个 4–6 套系列总量 |
|---|---|---|---|---|
| 最省 | 4–6 张 | 2–3 张 | 3–5 张 | 约 30–50 张 |
| 标准 | 8–12 张 | 4–6 张 | 6–10 张 | 约 60–100 张 |
| 充分 | 15–20 张 | 8+ 张 | 12–16 张 | 150 张以上 |

- 挑选系数通常 **3–5 张选 1**；高定/复杂结构常 5–8 选 1。

**视频（一条 15–30s 成片）**

| 档 | 每个镜头候选 | 一条片总生成片段（含废） |
|---|---|---|
| 最省 | 1 条 | 3–6 条 |
| 标准 | 2–3 条 | 8–15 条 |
| 充分 | 4–6 条 | 20 条以上 |

生图/视频前我给"本批按标准档约 __ 张/条、预计废稿 __"的预估，你可在工单上改档。

## 十、交付打包与一页纸摘要

交付前按语境逐项打勾（总检见 SKILL.md 末尾；企业/赛事各自清单见 `enterprise-proposal.md` / `aigc-competition.md` / `portfolio-board.md`）：

- 交付物齐不齐（图/片/工程/文字/报告）；
- 版权随件齐不齐——**每出一批图就登记**（`copyright-compliance.md` 字段），交付前**一键汇总成版权自查报告**，企业无报告不上架、赛事无 AI 披露不受理；
- 规格/匿名/披露/可核对按语境；
- **一页纸摘要**：给领导/买手/评委看的单页（骨架见 `assets/project-template.md`，写法见 `text-content.md`）——1 张核心主视觉 + 一句话主题 + 三要素 + 3–4 款缩略 + ≤100 字概念 + 3 条卖点/工艺，图占 60–70%。
