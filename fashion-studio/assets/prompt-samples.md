# 示例锚点包：已翻好术语的完整提示词模板

> **给零术语用户的快速起手**：不知道"该怎么说专业词"时，选一档贴合的模板，**只改 2–3 处占位**（`<颜色>`、`<款式细节>`、`<面料>`）就能用。每档模板已含：主体/结构/颜色位置/材质/构图/风格/负面词 + 参考图分工——全部是专业口径，可直接照抄进即梦/Seedream。
>
> 模板只覆盖最常见任务；每个模板的具体验收门与返工规则见各对应文件（模板末尾标注）。**改占位时保持句式结构，只替换内容，别删负面词。**

## 1. 连衣裙 / 礼服（高定繁复档）

**用途**：秀场/赛事/高级繁复礼服——结构、工艺、图案都要"高级繁复"。**改两处**：`<主色>`、`<款式细节>`（如"立体刺绣花朵""珠绣腰封""不对称斜裁"）。

```
【主体】女性礼服长裙，<款式细节>，高定廓形
【结构】收腰立裁，内置结构撑住廓形，<主色>与同色系辅色分层；闭合件隐形
【颜色】主色 <主色>；辅色 <同色系浅一档>；点缀 <金属色/深色 1 处>；颜色位置写死（上身X色/裙摆Y色）
【材质】纹理=<缎面/蕾丝/欧根纱 选一>，光泽=<柔光高光/哑光 二选一>，厚度=中，垂感=垂坠有体积
【构图】全身正面，纯白/深灰无缝背景，单一方向柔光箱，f/8 全身清晰，3:4 竖构图
【风格】高级定制秀场质感，克制配色，一处视觉焦点
【参考】图1=面料与配色；图2=廓形/结构参考（若有）
【禁止】不要塑料感、不要过度磨皮、不要多余配饰、不要改变廓形、不要水印文字、不要多个人物
```

**负面词**：`塑料反光, 过度磨皮, 多余配饰, 廉价质感, 色彩浑浊, 比例失真, 水印文字, 多个人物`
验收门见 `image-editorial.md`；品类结构见 `category-guide.md` 2.10 高定。

## 使用要点

1. **只改占位、不动句式**：替换 `<颜色>` `<款式细节>` 时保持结构完整，负面词别删。
2. **参考图优先**：模板默认无参考图直接文生图；你有图就按模板「参考」行分工挂图1/图2/图3，更可控。
3. **先出 1 张定调小样**：批量前先出 1 张确认方向（`project-workflow.md` 第六节工单）。
4. **比例两套别混**：写实/照片向直出统一 1:9，效果图插画档 9–10 头身，款式图无人体 to-scale。
5. **模板不覆盖的品类**：去 `category-guide.md` 查品类结构/工艺/翻车点，按本文件句式自组。
