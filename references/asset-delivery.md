# AI 资产交付规范（asset-delivery）

> **本文件包含两类内容**：
> - **交付底线**（不可破）：产物必须直接展示给用户——没在对话里展示 = 未交付。
> - **可调整项**：画布是否留份、要不要归档、存哪里、怎么命名——按用户的明确要求来，不强制。

> 归属：fashion-studio · 作用域：**fs 全部 AI 生成/编辑产物，无例外**——款式图、效果图、大片、lookbook、面料、平铺、挂拍、细节、工艺、模特/人台、系列图等一切图片产物，以及视频/音频；不限于 Muse/模特资产。
> 前置：建模特与标准资产包走 `ai-model-muse.md`；资产库运营走 `muse-asset-library.md`；版权合规走 `copyright-compliance.md`；素材库字段走 `asset-library-schema.md`。
> 版本：1.4 · 许可 CC BY 4.0

## 一、核心原则：两份即可，不自动保存

**默认规则（用户偏好）：fs 的每一张 AI 生成或编辑产物，只出现在两个地方——**

1. **对话展示一份**：在对话框用媒体卡片直接展示给用户（可见交付，必须做）。
2. **画布留一份**：由图像工具在生成时自动写入画布（若当前环境支持自动写入），Agent 不手动建条目。

**除此之外，Agent 不主动做任何保存动作**：不手动建画布条目、不做本地项目文件夹归档、不复制另存、不下载重传、不整理目录。用户觉得哪张好，自己保存；需要 Agent 额外归档时，用户会明确说。

> 判定：产物没在对话里直接展示，视为"未交付"；只给路径或文字描述不算交付。是否归档、存几份，不是交付的前置条件。

## 二、豆包办公默认实现（画布自动写入 + 对话框展示）

> 豆包办公的实现 = **一条原始产物短链，两处可见**：① 图像工具按 Workspace ID 自动写入画布（画布一份）→ ② 对话框媒体卡片展示（对话一份）。共用同一条工具返回值，不下载、不重传、不换链。

### 1. 画布自动写入（不手动建条目）
- 调用 `image_gen`／`image_edit` 时把当前对话的有效 `canvas_workspace_id` 作为参数传入；工具成功返回后，产物已自动写入画布（通常为 `gen-v2-*` 条目、`path="/"`），这就是"画布一份"。
- **禁止写入类动作**：再为该产物执行 `design-cli design-workspace +create`／`+create-batch`、`+update` 改 path、`FileBatchUpload`、下载、复制或另建 IMAGE Item——工具返回值里没有"已写入画布"的提示，容易误判为尚未落位而重复建条目，结果同一张图在画布出现两份。
- **只读核对不属禁止范围**：`+get`／`+tree`／`+ls` 只读不写、不产生任何条目，用于确认落位或排障时可以用；宿主强制要求写入后核对时，按宿主规则执行一次。
- 判断画布中两条记录是否同一文件：比对条目 asset 的 `uri` 字段，`uri` 相同即同一份文件的两个条目。
- 定向 `+get` 可能因索引延迟返回空 items，此时用 `+tree`／`+ls` 或创建回执确认对象是否真实存在，不要据此判定写入失败而重复提交。

### 2. 对话展示（必须做）
- 主 Agent 把生成工具返回的**原始短链**通过媒体卡片（RichMediaCard；环境用 `present_files` 时同效）逐项展示，逐字使用工具返回值，不下载、不重传、不换链。
- 一次返回多张时按稳定顺序逐项展示，可分组（≤6 张/组）。用户"看到图"以此为准，不得只给路径或文字描述代替。

### 3. 不做本地归档
- 不主动把产物复制/另存到项目文件夹或本地素材库；这是用户自己的动作。用户明确要求本地存档时再做。

### 4. 绑定画布（仅初始化，不属于产物归档）
- 当前对话已有唯一有效 `canvas_workspace_id` 时直接复用；没有时调用 `design-cli design-workspace +workspace-create --title "<标题>"` 建一张，从响应 XML 读唯一 ID，并由主 Agent 用 `present_files(<workspace_id>)` 交付画布卡片（**不得**创建 workspace-id.txt 等中间文件）；画布卡片交付成功前不得生成/编辑媒体。
- `+get-workspace` 只用于显式查询、恢复或排障，不代替"对话无 ID 时必须创建"的初始化规则。

## 三、其他环境降级（工具中立）

- **无自动画布写入 / 无 design-cli 环境**：对话媒体卡片展示不变；是否需要手动写入画布或归档，按用户的明确要求执行，不擅自增加步骤。
- 换 Agent / 平台时按 `tool-adapter.md` 做能力映射；任何环境下"对话直接展示"都是底线，自动归档不是。

## 四、Muse 人物资产包（引用，不重复）

Muse/固定模特的标准资产包定义见 `ai-model-muse.md`，本文件不重复；其产物同样按本规范交付：对话展示＋画布自动留一份，不手动建条目、不自动归档，用户自行保存。
