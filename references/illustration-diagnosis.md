# 效果图翻车诊断手册（太简单 / 太乱 / 比例不对 / 不和谐）

> **本文件以设计建议为主，“症状/翻车”均按你的风格目标判断，可按你的需求调整；仅以下为硬约束（不可破）**：物理事实不分风格——软料撑不起硬廓形，想要硬廓形必须换有骨的料。

> 这是一份**急诊手册**。效果图画完了，自己看着不满意，但说不清哪里不对——翻这里。
>
> 它不是教你怎么设计，是**当你的设计已经长歪了，怎么定位病灶、怎么对症下药**。
> 方法论在 `garment-transformation.md`（整体怎么判断）和 `composition-garment.md`（局部怎么摆）；这里是**看病流程**。

## 什么时候用我

- 效果图画完了，**说不上哪里不对，但就是"不好看/不高级/不像样"**；
- 每个单品单独看都行，**拼在一起就是别扭**；
- 加了一堆细节反而更乱、减了一堆东西反而更空；
- 上下身比例怪、模特像偷穿别人衣服；
- 明明按教程配色了，出来还是像淘宝款/睡衣裙/舞台装。

## 二、翻车点①：效果图太简单（怎么加细节，有章法地加）

**什么时候是问题**：当你想要有设计感、有细节看点的风格，但做成了一个光板基础款。

**什么时候不是问题**：如果你就是想要极简、静奢、Jil Sander、无印良品那种素净路线，那"光板"就是对的——这种风格本来就要靠面料和剪裁说话，不靠装饰。

### 翻车点① · 现象描述
一件衣服画出来就是个光板——H 型直筒、单色、没有口袋没有褶没有扣，远看是优衣库基础款。客户说"不够"、评委说"太素"。

### 翻车点① · 为什么会犯
- 直接从廓形跳到成品，中间没有做"局部设计"这一步；
- 怕乱所以什么都不加，结果变成空；
- 只在"装饰层"想细节（绣花/印花），没在"结构层"动刀。

### 诊断步骤（先查什么再查什么）

**第 1 步：先眯眼成灰影**
- 灰影里有没有一个"最重/最亮"的块？
- 没有 = 缺主焦点。这是第一优先级，先解决它。

**第 2 步：问自己——这件衣服"靠什么说话"？**
- 靠廓形说话（那廓形得够特别，不能是最普通的 H）；
- 靠面料说话（那面料得有质感）；
- 靠细节说话（那细节得有一个主角）。
- 三样都没有 = 三无产品，一般建议补一样（但极简素净路线本来就三样都淡，靠面料质感说话，不算问题）。

**第 3 步：定位"可以加的地方"**
- 看肩线、领口、袖口、腰线、下摆——这五个位置，哪个现在是空的？
- 五个全空 = 一般建议至少加两个（经验参考，不是硬标准）。

### 修改动作（按优先级从上往下加，一次加一个）

| 加法顺序 | 动作 | 例子 | 加完看一眼 |
|---|---|---|---|
| ① | 改廓形：把 H 微调成 A/X/或加不对称 | 光板直筒裙→前面开衩/裙摆斜裁 | 远看影子变了吗？变了就停 |
| ② | 加一个主焦点：一颗异色大扣、一个大口袋、一条腰带、一个胸针位 | 胸口加一个大贴袋 + 袋盖 | 有落点了吗？有了就停 |
| ③ | 加材质对比：同一件衣服拼两块不同性格的料 | 上衣袖子用亮缎、衣身用哑光羊毛 | 有质感层次了吗？ |
| ④ | 加分割线：1–2 条纵向或斜向分割 | 前片加两条公主线 | 有骨架了吗？ |
| ⑤ | 加层次叠穿：内层露一条边（领/袖/下摆） | 外套里露一截衬衫领 | 有层次了吗？ |
| ⑥ | 最后才加装饰：局部印花/明线/滚边 | 袖口加一道对比色滚边 | 够了就停 |

**一般来说比较稳妥的做法**（不是硬规矩，极繁/巴洛克/波普风可以不同）：
- 一次只加一个，加完看一眼，不够再加。
- **装饰一般放在最后一步**。先动结构和材质，最后才绣花印花——但波普、民族风本来就满身印花，不受这条约束。
- 加完一般建议留一块空的地方。全件都加满=从"太简单"跳到"太乱"——但极繁主义/巴洛克本来就要堆满，不在此列。

## 三、翻车点②：效果图太乱（怎么做减法）

**什么时候是问题**：当你想要有主次、统一调性的设计，但各种元素堆得像杂货铺、没有主角。

**什么时候不是问题**：如果你就是想要波普满印、民族风满身花、复古拼贴、Y2K 堆满、巴洛克极繁，那"满"和"花"就是对的——这种风格本来就要多元素堆出来。

### 翻车点② · 现象描述
一件衣服上有：泡泡袖 + 荷叶边领 + 满身口袋 + 满身明线 + 撞色拼接 + 大印花 + 金属扣——每个单看都不错，放一起像服装展会。

### 翻车点② · 为什么会犯
- 怕"不够"，把所有想到的好东西全加上了；
- 没有主角意识，每个元素都想当焦点；
- 从别人秀场图里东抄一块西抄一块，没有自己的母题。

### 翻车点② · 诊断步骤

**第 1 步：数焦点**
- 在效果图上圈出所有"强对比点"（亮色块、大口袋、显眼装饰、印花中心）。
- 超过 2 个 = 多焦点（经验参考，不是硬标准；极繁/巴洛克风格可以多焦点）。这是第一病因。

**第 2 步：数元素种类**
- 这件衣服用了几种面料？几个颜色？几种装饰手法（褶/边/扣/贴袋）？
- 面料 >2、颜色 >3、装饰手法 >3 = 过载（经验参考，不是硬标准；波普/民族风本来就要多色多料）。

**第 3 步：找出"主角"**
- 问自己：这个系列最想让人记住的是什么？（是廓形？是印花？是褶皱？是解构？）
- 那个主角留下，其余全部让位。

### 修改动作（从最明显的冗余开始减）

| 减法顺序 | 动作 | 判断标准 |
|---|---|---|
| ① | 减第二焦点：所有强对比点里只留一个，其余弱化/去掉 | 眯眼看灰影，只应看到一个最重块 |
| ② | 减重复：一样的口袋/褶/扣超过 3 个，减到 1–2 个 | 阵列感保留，但不要超过两排 |
| ③ | 减颜色：超过 3 个色，合并成 1–2 个主色 | 参考 color-theory 配色法 |
| ④ | 减面料：超过 2 种拼接，减到 1–2 种 | 材质对比留一处就够 |
| ⑤ | 减装饰手法：褶+荷叶+明线+滚边同时存在，留一个 | 一次设计主打一种工艺语言 |
| ⑥ | 减分割线：主结构线超过 4 条，藏掉不重要的 | 线越多越碎 |
| ⑦ | 减印花：满印改局部印 | 局部印花在极简/静奢路线里更耐看——但波普满印本来就要满身花，这条不适用 |

**一般来说比较稳妥的做法**（极简/静奢路线适用；极繁/巴洛克/波普风格相反）：
- 减完觉得空是正常的——在极简路线里，**空是高级感的来源**，不要立刻补新的。但极繁主义本来就要堆满，"空"对你不成立。
- Jil Sander 原话："你只有在确信能量完整保留时，才能删掉一些东西。"（来源：Jil Sander 自述——删到核心信息反而更突出；这是极简派的方法论，不代表所有风格）
- 留下的一般建议是**这个系列的母题**，其余全部让位。

## 四、翻车点③：上下身比例不对（怎么修）

**什么时候是问题**：当你想要显高修长、合身利落的风格，但五五分、头重脚轻、显腿短。

**什么时候不是问题**：如果你就是想要工装风、街头宽松廓形、Oversize、慵懒垂坠、日式 oversize，那五五分、不强调腰线就是对的——这种风格本来就不掐腰线。

### 翻车点③ · 现象描述
- 五五分：上衣和裙子一样长，看起来像偷穿了别人的衣服；
- 头重脚轻：上半身蓬大，下半身窄细，像要倒；
- 压个子：横分割正好卡在腰/大腿最粗处，视觉切短；
- 上长下短：衣服盖到大腿中部，下半身没了。

### 翻车点③ · 为什么会犯
- 没定腰线位置，按"常规长度"画；
- 上下都想做大廓形，结果变方桶；
- 横分割线切在了视觉不该切的位置。

### 翻车点③ · 诊断步骤

**第 1 步：画一条腰线**
- 这件衣服的腰线（实际或视觉）在哪？肚脐上 3cm（高）/ 肚脐（正）/ 肚脐下 3cm（低）？（3cm 是经验参考，不是硬标准）
- 想显高→腰线一般建议提高；想慵懒→腰线可以低；五五分在显高路线里会显矮，但工装/街头/慵懒风本来就不强调腰线。

**第 2 步：看上下身量感比**
- 上半身视觉重量 vs 下半身：
  - 上重下也重 = 方桶（一般建议改一个；但工装/廓形街头风本来就要方桶感）。
  - 上重下轻 = 戏剧款（需要功力压，新手慎用）。
  - 上轻下重 = 比较稳、容易出修长感（经验参考；如果你要的就是 Oversize 方桶，不适用）。

**第 3 步：找横切割线**
- 身上有几条横向色带/横分割？
- 横切割在腰部最宽处 / 大腿最粗处 = 在显高修长路线里会显矮显胖；但如果你要的就是横条纹街头/运动风，横带本身就是设计语言。
- 超过 2 条横切割 = 容易切碎（经验参考，不是硬标准）。

### 翻车点② · 修改动作

| 问题 | 怎么修 |
|---|---|
| 五五分（上下一样长） | 想显高的话，一般建议提高腰线 2–3cm（经验参考，不是硬标准），或上衣塞一半裙子；或外套短款+下装长——但如果你要的就是街头/Oversize 五五分，不用改 |
| 头重脚轻（上身蓬下身窄） | 要么上身收窄（改贴身），要么下身加宽（A 摆/阔腿） |
| 上长下短（衣服盖大腿） | 改短上衣到腰下，或下装加长到脚踝（纵向延伸） |
| 横切割切在最粗处 | 把横分割线上移到胸下或下移到胯上，避开腰臀最宽 |
| 全身多横带 | 合并成 1 条；其余改纵向贯通（同色上下） |

> 三分法原则（来源：服装比例教学——1:2 优于 1:1；经验参考，不是硬标准）：在追求修长显高的路线里，一般不要把身体对半切，视觉上 1/3 + 2/3 的比例往往比 1/2 + 1/2 更生动、显长。但如果你要的就是工装/街头/慵懒的五五分廓形，这条不适用。

## 五、翻车点④：各要素拼一起不和谐（怎么调和）

**什么时候是问题**：当你想要风格统一、调性一致，但硬料软料、冷色暖色、精致浪漫各唱各的调，像两个人拼的。

**什么时候不是问题**：如果你就是想要解构拼接、故意混搭、赛博拼贴、Y2K 撞色，那"不和谐"本身就是风格——这种设计就是要打破统一感。

### 翻车点④ · 现象描述
- 颜色配得挺对，面料一搭就廉价；
- 廓形是设计款，细节却像基础款；
- 上衣是硬挺西装料，下裙是软纱，像两个人拼的；
- 整体说不上哪里错，但风格"串了"。

### 翻车点④ · 为什么会犯
- 每个要素单独选的时候都"对"，但没问它们是不是"一家人"；
- 元素之间没有统一的调性锚点；
- 硬×软、亮×哑、厚×薄的对比用得太随意，不是沿结构拼。

### 翻车点④ · 诊断步骤

**第 1 步：列出整件衣服的所有要素**
- 廓形是直的还是弧的？
- 面料是硬挺还是柔软？亮还是哑？厚还是薄？
- 颜色是冷还是暖？明度高还是低？
- 细节是利落精致还是浪漫繁复？

**第 2 步：找"性格打架"的要素**
- 廓形是硬朗直线，面料却是软塌垂坠——打架。
- 配色是冷调高级，印花却是暖调童趣——打架。
- 整体是极简利落，细节却满身荷叶——打架。

**第 3 步：定一个主调性**
- 这件衣服到底想干嘛？（硬朗高级？柔软浪漫？街头年轻？）
- 所有要素向这个调性对齐。

### 翻车点③ · 修改动作

| 不和谐类型 | 怎么调和 |
|---|---|
| 廓形硬+面料软 | 要么换硬料撑住廓形，要么放弃廓形做软垂（二选一） |
| 颜色冷+细节暖 | 把暖色细节降纯度，或挪到远离脸的位置 |
| 上半高级+下半休闲 | 把休闲单品升级面料质感，或把上半简化 |
| 多种材质随机拼 | 材质对比只留一处，沿结构线拼，不要随机分布 |
| 风格串台（极简+洛丽塔） | 砍一头，保留一个主调性；另一个做小面积点缀 |

**核心原则（调和法，适用于追求统一调性的路线）**：所有元素共享一种语言——同一种线条（都直或都弧）、同一种质感（都哑或都有光泽）、同一种工艺密度（都简或都繁）。**在统一路线里，调和不是"什么都搭一点"，是"全部服从一个性格"。** 但如果你走的是解构/混搭/故意撞色路线，"不服从一个性格"就是你要的，不用调和。

## 六、翻车点⑤：像睡衣裙 / 像浴袍 / 没骨架

**什么时候是问题**：当你想要有肩线、有结构、能撑起廓形的成衣，但做成了一片软布直接挂身上。

**什么时候不是问题**：如果你就是想要日式禅意、波西米亚、解构软裁、慵懒垂坠、无结构罩衫，那"没肩线、不收腰、一片垂坠"就是对的——这种风格本来就要无结构感。

### 翻车点⑤ · 现象描述
画出来一条宽松长连衣裙，软塌塌、没腰线、没肩线、一片直筒到底，看着像睡衣/家居服/浴袍。

### 翻车点⑤ · 为什么会犯
- 全软料 + 无结构 = 布直接挂在身上；
- 没有肩线，没有收腰，没有任何"剪裁点"；
- 软料垂坠变成"垂成一条布袋"，而不是"垂出形状"。

### 翻车点④ · 修改动作

| 救法 | 怎么做 |
|---|---|
| 加肩线 | 加垫肩/连肩袖/落肩结构，让衣服在肩点站住 |
| 加腰线 | 用腰带/腰头/抽绳明确收腰，哪怕只收 3cm |
| 换更有骨的料 | 雪纺/真丝太软→换中垂羊毛/厚棉混纺 |
| 加结构线 | 前后片加公主线/分割线，让布"有地方去" |
| 加一层内衬 | 内衬撑出廓形，外层软垂叠在外面 |
| 加一个硬结构件 | 领子立起来、袖口收紧、下摆加硬衬——任一处硬点 |

**判断**：在追求成衣骨架的路线里，一件衣服一般至少要有一个"硬"的地方（肩/腰/领/袖/摆），全软容易显家居服。但如果你要的就是禅意软裁/波西米亚垂坠风，全软本来就是对的，这条不适用。（注：软料撑不起硬廓形这种物理事实不分风格——想要硬廓形就得换有骨的料，这是物理问题。）

---

## 七、翻车点⑥：说不出哪里不对但就是不好看

### 排查顺序（按这个顺序查，不要乱跳）

**第 1 步：眯眼成灰影，看剪影**
- 把效果图眯起来，只看大块黑白灰。
- 剪影清楚吗？重心稳吗？是想要的那个廓形吗？
- 剪影散/重心歪/看不出大形 = 全局问题，去 §1.1 视觉重心和 §1.2 量感平衡。

**第 2 步：找主焦点**
- 第一眼停在哪？找得到吗？
- 找不到 = 缺主焦点，去加一个。
- 找到 3 个以上 = 焦点太多，做减法。

**第 3 步：看疏密**
- 有疏有密吗？还是全密/全疏？
- 全密 = 做减法（§3）；全疏 = 加细节（§2）。

**第 4 步：看比例**
- 腰线位置对吗？上下身量感平衡吗？
- 五五分/头重脚轻 = 去 §4。

**第 5 步：看风格统一**
- 所有要素是一个性格吗？
- 性格打架 = 去 §5。

**第 6 步：看面料和廓形配不配**
- 想要的廓形，这个面料撑得住吗？
- 软料画硬廓形 = 必塌（这是物理事实，不分风格）。换料或改廓形。

**第 7 步：看背面**
- 背面长什么样？背面空不空？
- 正面精彩背面一片光 = 一般建议补背面细节（后领/后腰/后背中缝/后开衩）——这是完成度问题，不分风格；除非你刻意设计背面就是净版。

> 7 步走完还找不出问题，大概率是**模特姿势/妆容/背景/打光**在拖后腿——那不是衣服的问题，是 presentation 的问题。

## 八、翻车点⑦：廉价感怎么破

**什么时候是问题**：当你想要高级感、静奢、质感路线，但颜色艳、面料薄、满身 logo、明线滚边粗糙。

**什么时候不是问题**：如果你就是想要快时尚、街头潮牌、亮色运动、Y2K 辣妹、淘宝风，那"艳""薄""满身 logo"就是这种风格本来的样子，不是翻车——只是和"高级感"不是一回事。

### 典型表现
- 颜色对，但就是"淘宝感"；
- 版型对，但看起来"几十块"；
- 满身印花但很俗。

### 病因和药方

| 廉价感来源 | 药方 |
|---|---|
| 面料太薄太透 | 换高克重面料（>180g/m² 厚料一般会出大褶而不是细波纹；经验参考，不是硬标准）——这是静奢路线的核心：在追求利落大褶的风格里，薄料容易显轻飘，不是因为颜色，是因为它起的是细碎涟漪而不是利落大褶（来源：MioLook 静奢面料分析；雪纺/真丝垂坠风本来就要薄料，不适用） |
| 颜色太艳太纯 | 把主色纯度降两档（参考 color-theory 1.3） |
| 满身印花/满身 logo | 改局部印/定位印，或干脆去掉 logo |
| 明线滚边太抢眼 | 换同色明线，或去掉装饰线 |
| 褶皱太碎太密 | 换重料出大褶浪，不要碎褶 |
| 装饰太多太杂 | 做减法（§3），留一个主角 |
| 剪裁不贴合 | 加省道/调整分割线，让衣服"长在身上" |

**一句话**：在静奢/高级感路线里，高级感一般不是加出来的，是**把所有"喊价格"的元素全部去掉**，让面料和剪裁自己说话（来源：The Row / Loro Piana 品牌分析——价值通过织物光泽和剪裁精度传递，不靠 logo）。但这是静奢派的方法论，波普/潮牌/Y2K 风格本来就要 logo 和视觉冲击，不用走这条路。

## 九、出效果图前的 60 秒自检清单

打勾式，出图前过一遍——**每条先问自己：我要的风格是不是就是这个？** 下面括号里写了"想显高/想极简才要查"的，如果你要的是相反风格（街头/慵懒/波普），这条自动跳过，不用打勾。

**全局（10 秒）**
- [ ] 眯眼看灰影，有清晰的主焦点吗？（想要有视觉重心→查；想要散点/侘寂/波西米亚→多个散点也对）
- [ ] 远看 3 米能说出这是什么廓形吗？（想要廓形鲜明→查；想要模糊氛围/解构软裁→不强求）
- [ ] 上下身量感平衡吗（不是五五开）？（想要显高修长→查；想要街头宽松/工装/慵懒→五五分也没问题）
- [ ] 有疏有密吗（不是全密/全疏）？（想要疏密节奏→查；想要极繁堆满或极简素净→全密/全疏本身就是风格）

**比例（10 秒）**
- [ ] 腰线位置对吗（不是五五分）？（想要显高→查；想要街头/Oversize/慵懒→低腰线或无腰线都行）
- [ ] 横切割线没卡在腰/臀最宽处吗？（想要显高修长→查；想要横条纹运动/街头→横带就是设计语言）
- [ ] 上下身长度比是 1:2 而不是 1:1 吗？（想要显高修长→查；想要工装/慵懒 oversize→1:1 也没问题；经验参考不是硬标准）

**和谐（10 秒）**
- [ ] 整件衣服只有 1–2 个主色吗？（想要和谐统一→查；想要波普/民族/混搭→多色本来就要；1–2 色是经验参考）
- [ ] 面料性格统一吗（不是随机拼三种料）？（想要统一调性→查；想要解构拼接/赛博拼贴→混搭就是风格）
- [ ] 所有元素是同一个性格吗（不串台）？（想要统一→查；想要故意撞色/解构→串台就是你要的）
- [ ] 主焦点只有一个吗？（想要有重心→查；想要极繁/巴洛克→多焦点本来就要）

**完成度（10 秒）**
- [ ] 近看 30cm 有一个"有意思"的细节吗？（想要耐看细节→查；想要极简远观型→近看素净也对）
- [ ] 背面有呼应吗（不是一片空）？（这是完成度问题，不分风格；除非你刻意设计背面就是净版）
- [ ] 剪影单独描出来好看吗？（想要剪影设计感→查；想要氛围/面料主导→不强求剪影）

**立体预判（10 秒）——这几条是物理事实，不分风格**
- [ ] 这个廓形用这面料撑得住吗？
- [ ] 哪里会塌？有支撑吗（肩/腰/内衬）？
- [ ] 软料画的硬体积，现实中会不会垮？

**质感（10 秒）**
- [ ] 面料看起来够克重吗（不是薄薄一片）？（想要静奢/利落大褶→查；想要雪纺/真丝垂坠/飘逸→薄料本来就要）
- [ ] 颜色纯度降到位了吗（不是玩具色）？（想要低饱和高级感→查；想要波普/亮色运动/民族风→高饱和本来就要）
- [ ] 装饰手法只主打了一种吗？（想要统一工艺语言→查；想要复古拼贴/极繁→多种工艺叠加就是风格）

**按你想要的风格，该打的勾都打上 = 这版效果图可以交付。任何一个该打没打上 = 回去翻对应章节。**
