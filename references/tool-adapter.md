# 工具与平台适配：换生图 / 视频模型、换 Agent 怎么用

本技能是一套**方法论**，不是某个生成平台的插件。**即梦 / Seedream / Seedance 是作者实测的默认实现**，写在各文件里的操作步骤都以它为蓝本；但流程、提示词骨架、锚点、验收门、品类与面料知识、21 项交付规范本身**工具中立**。换平台、换 Agent 时，按本文件把薄薄一层"工具操作"替换掉即可，方法论整层不动。

---

## 一、先分清两层：方法论层（不变）与工具适配层（随平台变）

| 层 | 内容 | 换平台/换 Agent 时 |
|---|---|---|
| **方法论层**（本技能主体） | 创作顺序与服装三要素、四步管线、锚点、图1/图2/图3 分工、四段式结构、验收门、人体比例统一口径、参考分寸、品类/面料/服饰史、21 项交付规范、工艺分流、国标数值、版权与文字、项目画布 | **完全不变** |
| **工具适配层**（很薄） | 平台入口名、素材槽位数量、参考图/视频上限、负面词字段有无、首尾帧/局部编辑能力、时长/画幅/分辨率、素材编号写法、模型/Agent 自己的连接器 | **换成目标平台的等价能力** |

一句话：**换的是"按哪个按钮、能挂几张图、有没有负向栏"，不是"先做什么、怎么验收、怎么保证不变形"。**

---

## 二、本技能的默认平台（作者实测）

- **生图**：Seedream **5.0 Pro**（即梦；**大片/高定/campaign 等成品档统一默认 Pro**，编辑一致性更强、防漂移；Pro 不可用时降级 5.0 Flash/标准版），文生图 / 图生图 / 多图参考。
- **视频**：Seedance（即梦）**2.5**（统一默认 2.5；2.0 仅在不支持 2.5 的环境降级），图生视频，入口为「全能参考」「首尾帧」。
- 本技能**不绑定本地节点工作流、不依赖本地算力**；批量提效交给云平台的批量能力。
- **连接器不是必需**：Agent 负责把料备齐、把提示词写准；**最终"生成"由你在平台上按下**。Agent 没有图像/视频连接器时，流程照走，你手动把素材与提示词粘进平台即可。

## 二·5 即梦 Canvas 画布在流程中的角色（默认平台工作台）

即梦 Canvas（Dreamina 画布）是默认平台配套的**工作台**：集中查看、图片描述、圈选编辑、素材编排都在这里做。它管"用户侧操作"，Agent 管"提示词侧"，分工写死：

| 用途 | 画布做什么（用户侧） | Agent 做什么（提示词侧） |
|---|---|---|
| ① 集中查看台 | 出图/出视频后所有结果在画布汇总看（含视频预览） | 按验收门给诊断：通过 / 整图重出 / 圈选 |
| ② 图片描述 | 看图时用自己的话描述"哪里不对、想要什么" | 把描述翻译成局部改写句，或判定是否锚点级问题 |
| ③ 精确编辑台 | 圈选 / 蒙版 / 时间戳+框选，只改单区域（选区精度以画布为准） | 给"改什么 + 其余保持不变"的改写句；同一处改 2 次不自然 → 改判整图重出 |
| ④ 素材编排台 | 多图参考、首尾帧挂图、多段视频编排与预览 | 给四段式 / 素材映射与挂图顺序（`video-brief.md`） |

- **分工边界**：精确选区、手动微调、在画布上直接改 → 用户/画布；备料、写词、诊断、局部改写句、整图重出判定 → Agent。**选区精确性以画布界面为准，Agent 指令编辑只作辅助**。
- **闭环**：画布圈选 → 回传"选区 + 问题描述" → Agent 给局部改写句 → 回画布执行 → 复核接缝/光影/织纹/颜色连续（SOP 见 `consistency-lock.md` 第二步）。
- **无画布时降级**：没有画布 → 局部瑕疵只能整图重出 / 用 Agent 指令定向编辑（精确度下降）；批量查看用平台图库或本地文件夹替代。

## 三、使用前：平台能力自查清单

换平台先逐项确认，缺哪项就按"降级做法"走，不要假装它有：

| 能力 | 本技能用它做什么 | 没有时的降级 |
|---|---|---|
| 文生图 text-to-image | 白模骨架、从零起稿 | 必备，无此能力无法做 |
| 图生图（单图参考） | 自举、锁结构、风格统一 | 必备 |
| **多图参考（≥3，且能分别控制）** | 四步管线图1衣/图2人/图3场 | 只支持单图：分步做（先锁衣→再锁人），或把参考合成一张；一致性下降，多废稿 |
| 角色/人脸一致性参考 | 固定 Muse 跨图同人 | 无该功能：每次重挂同一张定妆、身份描述逐字复用，成功率降低 |
| 局部重绘 inpaint（圈选/蒙版） | 非锚点小瑕疵修复 | 没有：**一律整图重出**（不做局部） |
| 负面词 / 负向提示栏 | 排除俗套与缺陷 | 没有：全部写成正向否定句（"不要…"改"保持…锐利/干净"） |
| 参考图数量上限 | 一次挂多张素材 | 按上限分批，最关键的衣/人优先 |
| 图生视频 image-to-video | 成衣走秀、时装短片 | 没有则只能文生视频，锚点不稳，不建议做服装视频 |
| 多素材到视频 | 四段式（衣/人/场景/参考视频同喂） | 只收单图：先用生图把关键帧做齐，逐镜图生视频再剪辑 |
| 首尾帧 first-last frame | 锁定起止造型、收动作 | 没有：用单图 + 明确动作描述/分镜，控制变弱 |
| 视频局部编辑（时间戳+区域） | 只改单时段单区域 | 没有：整段重出（运镜/整体动作本就该整段重出） |
| 时长 / 画幅 / 分辨率 | 成片规格 | 按目标平台实际规格，分段拍摄再接 |
| 商用授权与条款 | 版权合规 | 查不清授权的平台不用于商用（见 `copyright-compliance.md`） |

## 四、术语映射表（技能叫法 → 通用能力 → 在新平台找什么）

| 本技能叫法 | 本质能力 | 常见通用/英文叫法 | 找不到时 |
|---|---|---|---|
| 图1 / 图2 / 图3 | 多图参考，各图管一个变量 | reference images / image prompts / subject·character·style reference | 单图参考分步走 |
| @图片N / @视频N / @音频N | 按编号引用上传素材 | media references / attachments | 改为"第 N 张"文字说明或逐段喂 |
| 四段式 | 图生视频提示词结构（素材映射/简报/镜头/约束） | image-to-video prompt / shot script | 结构通用，直接改写 |
| 全能参考 | 多素材图生视频入口 | multi-reference / video reference mode | 逐镜图生视频 |
| 首尾帧 | 起止帧插值 | first-last frame / start-end frame | 单图+动作描述 |
| 圈选 / 蒙版 / 框选 | 局部重绘 | inpaint / mask / region edit / brush | 整图重出 |
| 时间戳+框选 | 视频局部编辑 | video inpaint / segment edit | 整段重出 |
| 负面词 | 负向提示 | negative prompt | 正向否定句 |
| 定妆 / 多角度自举 | 角色一致性 bootstrap | character reference / character sheet / identity lock | 反复挂同图+固定描述 |
| 1:9+55%（无母版直出）、继承母版（有 Muse）、9–10（插画档） | 人体比例口径 | body proportions | 无母版写死、有母版不写、插画档前置 |
| 画幅 16:9 / 9:16 | 宽高比 | aspect ratio | 平台尺寸选择器 |
| 素材数量/时长上限 | 平台约束 | limits / max references / duration | 见第七节，按平台改 |

> 提示词语言：本技能默认中文提示词，多数现代模型中英文都吃；英文模型可整段翻译，**但结构/色号/材质/比例/闭合件等锚点关键词必须保留**，不要只翻"高级感"这类形容词。

## 五、把生图方法迁到其他平台

1. **槽位对应**：把"图1=衣、图2=人、图3=场景"分别放进平台的服装/角色/风格参考槽；平台若只有一个"参考图"，就分步（先图生图锁衣，再以成图为底加人），不要一次喂三张让模型自由串。
2. **一次只加一个变量**：白模骨架锁结构 → 自举加色 → 加材质 → 加细节 → 上模特（见 `design-ideation.md` 第 12 节）。这是跨平台最稳的出图法，与用哪个模型无关。
3. **角色一致性**：有角色/人脸参考功能就绑定 Muse 定妆；没有就每张重挂同一张母版 + 身份描述逐字复用（见 `ai-model-muse.md`）。
4. **局部修复**：平台有 inpaint 才走圈选；没有就整图重出，别用重绘幅度硬调（规则见 `consistency-lock.md`）。
5. **负面词**：有负向栏填清单；没有就改正向否定句。
6. **提示词骨架通用**：品类/面料/布光/人体的具体写法（`category-guide.md`、`fabric-guide.md`、`image-detail-fabric.md`）直接可用；换模型主要调"参考图上限、风格化程度、对中文的理解"，不调设计逻辑。

常见生图平台类型（能力以各家官方为准）：多图参考云生图、Midjourney（角色/风格参考）、Flux/Stable Diffusion 系（云端或本地，含 inpaint/control 能力）、GPT 类出图、Google Whisk/图系等；本技能不指定、不背书任一。

## 六、把视频方法迁到其他平台

1. **四段式通用**：素材映射 / 一句话简报 / 镜头顺序 / 全局约束，任何 image-to-video 模型都能吃，只是素材槽位与命名不同（见 `video-brief.md`）。
2. **多素材入口缺失**：先用生图把每个镜头的关键帧做齐（含造型、布光、构图），再逐镜图生视频，剪辑拼接；首尾帧能锁起止就用。
3. **无负向字段**：视频模型普遍无负向，全部改正向句（"保持锐利、结构稳定、不添加配饰"），不要堆"不要"。
4. **时长/主体上限**：以目标平台为准，超时长分段、超主体拆分（群像最稳仍是 3 人内，见 `ai-model-muse.md` 第七节）。
5. **声音与后期不变**：配乐、音效、旁白、字幕、花字、封面本就后期做，与视频模型无关（见 `video-brief.md` 声音与后期包装）。

常见视频平台类型（能力以各家官方为准）：可灵/Kling、Runway、Pika、MiniMax H3、Sora、Veo、Hailuo 等图生视频；选谁看"多素材参考、首尾帧、时长、服装保持度、商用授权"，本技能不绑定。

## 七、默认平台专属数值（换平台时务必以目标平台为准）

下列是**即梦/Seedream/Seedance 的口径【经验值】**，不是通用常数；换平台时替换，方法论不变：

| 项 | 默认平台口径 |
|---|---|
| 生图参考图上限 | Seedream 约 10–14 张（不同入口 10/14） |
| 视频素材数量 | 图片 ≤30；主体 1–8 个最可靠；视频 ≤10 段共 30s；音频 ≤10 段共 30s |
| 视频时长 | Seedance 2.0：4–15s；2.5：4–30s |
| 成片规格 | 1080p MP4/MOV；画幅 16:9 / 9:16 |
| 负向字段 | Seedance 无负向字段；Seedream 各入口不一致，以官方界面为准 |
| 局部编辑 | Seedance 2.5 支持"时间戳+框选"；图片局部靠圈选/蒙版画布 |
| 视频入口 | 「全能参考」「首尾帧」命中 Seedance 2.0/2.5 |

> 与平台无关的**真常数**（不要改）：人体比例统一口径（写实/照片向 1:9+裆 55%、有 Muse 继承 / 插画档 9–10）、锚点分工、服装三要素、国标号与公差（GB/FZ、Pantone、CY/T 249 等）、针距/缝份/3D 工程规格，见 `quick-reference.md`。

## 八、换 Agent（豆包之外，Codex / WorkBuddy / Claude Code 等）

- 本技能是**纯 Markdown**：`SKILL.md`（带 name/description 头）+ `references/` + `assets/`（一个 CSV 模板、一个项目画布模板）+ `LICENSE`。**无代码、无插件、无专有 API 调用、无本地路径依赖**。
- **支持 SKILL.md / Agent Skills 约定的 Agent**：把整个 `fashion-studio` 文件夹放进它的 skills 目录，重开会话即自动加载（Claude Code、Cursor、WorkBuddy、豆包等均采用该结构；Codex 按其官方 skills/配置入口放入同一份 SKILL.md）。
- **从 GitHub 安装**：在支持 skills 的 Agent 里用通用安装器 `npx skills add <仓库>`，或手动 clone 后放入 skills 目录（面向人类的安装说明见仓库 `README.md`）。
- **不支持 SKILL.md 的 Agent / 网页对话**：把 `SKILL.md` 与 `references/` 当作"手册/提示词包"——让它读取该目录，或把 SKILL.md 贴进系统提示/项目说明，让它按任务路由表引用对应文件。同样有效，只是不会自动触发。
- **连接器非必需**：本技能刻意设计为"Agent 备料写词、用户在平台按下生成"，因此即使该 Agent 没有图像工具、没有飞书，也能完整使用。
- **素材库可替换**：飞书多维表格只是蓝图；`assets/asset-library-template.csv` 可导入 Airtable / Notion / Excel 等任意表格（见 `asset-library-schema.md`）。
- **语言**：正文中文；给英文模型用时整段翻译即可，锚点词与规格数值保留。

## 九、迁移自检（换平台 / 换 Agent 后，跑通再上量）

- [ ] 能力清单逐项过（尤其多图参考、角色一致性、图生视频、局部编辑）
- [ ] 平台专属数值（参考图上限、时长、画幅、负向）已换成新平台口径
- [ ] 用一个最小样例跑通：①锁数字样衣 → ③上模特（图1衣/图2人/图3场）→ 一条 5 秒视频，验证锚点稳定
- [ ] 商用授权与 AI 披露口径确认（`copyright-compliance.md`、`portfolio-board.md` 21）
- [ ] Muse 定妆在新平台仍能跨图同人（不行就强化身份描述/换角色参考）
