# 版型工程：白坯 · 纸样 · Tech Pack · BOM/推档 · 3D 虚拟成衣（12–16）

这是全技能里 **AI 与专业分工最明确**的一篇。核心三条底层事实：
1. **纸样是带数学约束的工程图**：人体测量 + 松量 + 缝份 + 缩率 + 对称配对 + 刀眼对位 + 多码推档 + 面料方向性，文生图一项都不具备。
2. **通用生成式 AI 产出的是像素，不是结构**：它学的是"共现"不是"约束满足"，会给"看着合理但几何不可能"的结构幻觉。
3. **专业链是 2D 纸样 → 3D 缝合 → 仿真**：3D 成衣不能由 AI 一键生成可生产资产，仍必须先有 2D 纸样。

AI 能做的是**超真实展示图、渲染图、花型与效果示意**；**尺寸、缝份、刀眼、推档、用量、成本、仿真工程数据全部必须人工/专业软件**。用 AI 生成图冒充结构图或 3D 工程是诚信底线。

## 12 ｜ 版型白坯 / 立裁 Toile & Draping　【语境：两者】

用廉价坯布试做的测试衣，验证版型与合体，不投入最终面料。企业做版型验证与轮次留痕；赛事作设计过程证据；数字赛道用虚拟白坯替代部分实物试衣。**立裁适用**：礼服、斜裁（bias）、披挂缠绕、非对称、体积褶皱——凡"性格由布料在身体上怎么垂落决定"的款。

### 硬数值

- 坯布：**本白棉布/棉坯布（muslin/calico）**，克重宜接近终面料；硬挺羊毛、流体真丝等建议**另做第 2 件**用克重/悬垂相近的廉价布。
- 轮次：简单款 **1–2 轮**；复杂款 **2–3 轮甚至更多**，每轮改版后重做重评。
- 企业样衣链：**proto 头版 → fit 试身样 → size set 齐码样 → SMS 销售样 → PP 产前样 → TOP 船头样**（PP 用大货料大货线、批了才开裁；TOP 从大货首批抽、批了才出货）。
- **必须真人试身（fit model）**：人台无肩、无运动、无反馈；静态人台会漏问题，须让模特下蹲/抬臂测活动量，逐点 POM 对照技术包。
- 白坯阶段侧缝/肩缝留长以便放量；数字白坯 CLO 粒子距 5–20（见 16）。

### 合体度三档（先定档再立裁，别一上来就贴体）

| 档 | 松量/贴合 | 适用 | 立裁注意 |
|---|---|---|---|
| 贴体 fitted | 贴合曲线、松量极小 | 礼服、斜裁、针织贴身款 | 省道/分割多，试身最严格 |
| 半贴体 semi-fitted | 贴身但留活动量 | 衬衫、西装、连衣裙（企业主流） | 肩胸合体、腰臀留量 |
| 宽松 loose/oversized | 不贴身、量感廓形 | 大衣、工装、Oversized | 垂落决定形态，少省道、靠结构与面料 |

**坯布预算**：立裁坯布要比终面料宽/长——衣身片幅宽加 **20–30%**（含剪口/别针/放量）；裙摆、垂褶按 **2–3 倍用量**预估；复杂垂褶款先裁大矩形再逐步修，别一步裁到款式线。

### 浮余量处理（胸凸量 / 背凸量怎么消失）

立体的人体凸度在平面上表现为浮余量（胸凸量、背凸量），立裁时必须被处理掉，**三条出路必选其一**：

1. **收进省道**：胸省/腰省（省尖指向 BP）；
2. **并入分割线**：公主线/刀背缝，浮余量随分割走；
3. **转化为褶裥/垂褶**：抽褶、塔克，把凸量变成设计语言。

判断口诀：**浮余量去向 = 省道 / 分割 / 褶，三者必有其一**；立裁"贴不上"多半就是浮余量没分配。

### 创意立体造型制版（draping for form——造型立裁，不是合身立裁）

功能立裁回答"怎么合身"，造型立裁回答"**布料在人台上能立出什么形**"。高定、秀场、赛事的"雕塑感"全靠它。

| 手法 | 做法 | 造型结果 | AI 提示词锚点 |
|---|---|---|---|
| 垂褶 drape | 布从锚点（肩/胸/腰）自然垂落、捏出褶浪 | 流动、浪漫（希腊式/斜裁感） | 垂褶披挂、锚点褶浪 |
| 螺旋/斜裁扭曲 | 斜向缠绕、扭转固定 | 螺旋曲线、紧身流畅 | 斜裁螺旋缠绕、扭转褶 |
| 几何块面折叠 | 布料折叠成块面（折纸感）叠压固定 | 建筑感、立体几何（Issey / Viktor & Rolf 语境） | 折纸块面、折叠立体几何 |
| 立体填充/支撑 | 充棉、鱼骨、裙撑、硬纱撑起内部结构 | 雕塑体积（球裙/O 型/立体廓形） | 内部支撑、充棉膨起、鱼骨定型 |
| 解构重组 | 裁片错位拼接、内里外翻、非常规省位 | 未完成感、实验感（McQueen / Margiela 语境） | 错位拼接、内里外露 |
| 局部造型实验 | 单部位（领/肩/腰/袖）先做造型小样再连成衣 | 局部亮点、可复制系列语言 | 局部立体造型、肩部/领部雕塑 |

- 造型立裁同样走"小样→验证→成衣"：先在布料上试造型（垂褶方向/褶皱密度/支撑够不够），确认能缝能穿再进款式。
- 造型用坯布/代用料与终面料性格必须接近（垂感/挺括/厚度），否则造型不成立。
- **AI 分界**：AI 出造型立裁**效果意象**（垂褶/折纸/雕塑感氛围图）可以；受力点、支撑结构、造型是否站得住**必须人台/实物验证**——AI 画得再好看，缝出来塌了就废。

### 照片与记录（正/侧/背/动态/别针贴线一个不能少）

正面全幅判平衡（左右偏、前短后长）；侧面判松量、前后领深、起吊（hiking）、腰位；背面判后领深、后腰省、背长；局部拍领口/袖窿/袖山吃势/省尖/分割线；动态拍抬臂/屈膝/转身；特写别针位置与 line tape 走向。立裁人台贴线：黑带=人体基准（CF/CB、胸围/腰围/臀围、侧缝、肩线、领围），红带=公主线/造型线；转印时先画净缝线→加放缝份→转印纸样，未确认前不用最终面料直接立裁。

### Fit comments 五要素（含糊意见无效，打版师不必猜就能改）

| 要素 | 反例 | 正例 |
|---|---|---|
| 定位 | "胸口太紧" | "前胸在胸尖点两侧各绷紧 1/2 英寸"（点/照片标注） |
| 量 | 无 | "胸围合计放松 1 英寸" |
| 过渡 | 无 | "沿腋下顺滑过渡到现有腰围尺寸" |
| 证据 | 无 | "多角度照片 3 张" |
| 优先级 | 无 | "关键必改 / 锦上添花" |

常用词：拖拽线 drag line（斜纹指向受拉部位→减松量/调省道）；横褶=长度过量；纵褶=该段宽度过量；tight/loose 写明部位程度；balance（领口后拉=肩斜不对）；hiking 起吊。

### AI 分界与提示词

AI 可把效果图转成"白坯布风格"效果图、出立裁工作台氛围图、出斜裁/抽褶悬垂**示意（仅比选，不作版型依据）**；真实悬垂/松量/平衡必须真人/人台或 3D 验证。
```
参考图1=服装款式设计效果图；参考图2=白坯人台姿态；参考图3=坯布质感。
将服装改为本白棉坯布（muslin/calico）质感，保留款式结构与分割线；
可见别针固定与黑色贴线（前中、胸围、腰围线）；中灰背景，柔和顶光，正面全身，
摄影棚质感，高细节，无水印无文字。
负面：文字、水印、标签、网格线、软件 UI、别针穿模、多余手指、肢体畸变、
比例失真、改变原廓形、改变拉链/省道位置、非坯布质感（缎面反光）、人台写实人脸。
```
验收门：本白棉布克重接近终面料；完整可穿（领/袖/门襟）；正侧背+细节+动态齐；别针贴线可辨；逐条 fit comments 含五要素；轮次日期可追溯；复杂款有第 2 件；AI 白坯图不得当版型依据。

## 13 ｜ 纸样 / 结构图 Pattern　【语境：企业；赛事实物间接考核】

纸样是分片后可裁的部件（结构图是制图，二者不同）。赛事多数不直接交纸样，但**入围做成衣实物即间接考核版型**；数字赛以 3D 工程内含的 2D 纸样为考核载体。

### 必含内容

净样线（成品线）+毛样线（含缝份/折边）；**每片必标布纹线**（直丝/横丝/斜丝）；刀眼（所有主缝、袖窿/袖山、长弧缝配 balance 刀眼）；省道/褶位/褶深/倒向；扣位/扣眼/钻孔/拉链位；贴边、里布版、衬版、净版；**缩率预放量**（打版前先测缩水率）；片名/款号/尺码/裁片数/正反片数量。

### 硬数值

| 项 | 数值 |
|---|---|
| 缝份（英式） | 常规 **1cm**；大身缝 **1.5cm**；需改部位 **2cm+** |
| 缝份（美式） | 侧缝/肩缝 **5/8″(1.5cm)**；袖窿/领口 **1/2″(1.2cm)**；袖口/领 1/4″–1/2″；商业纸样 70%+ 用 1.5cm |
| 缝份（按面料） | 牛仔等厚重料 ≤2cm；雪纺等轻薄料 0.6–1cm；通用 0.6–1.5cm |
| 下摆折边 | 盲缝裤/裙 2–4cm；结构夹克 4cm（装衬）；整条裙摆 1–2cm；一般双折边 1.5cm |
| 刀眼约定 | **单刀眼=前片/前段；双刀眼=后片/后段** |
| 精度 | 纸面弧线 ±0.5mm；直角 ±1mm；裁片 ±1mm |
| 净/毛样 | net（不含缝份）/ net-plus（含），**必须书面约定** |
| 推档（欧美） | 胸/臀每码 +1.5″、腰 +1″；部分体系每码 2.5cm |
| 基础码 | 用中间号型做基础样板，两端推板误差最小 |

纸样标注：布纹线上方写款号/尺码，下方写裁片名/面料类型/裁片数量；大片写缩水率；纸样挂单写片数与实样片数；挂板孔打下摆/袖口/脚口离毛边 3–5cm。CAD：富怡/ET/博克/Gerber/Lectra/Optitex；输出 **PLT/HPGL**（绘图仪 1:1）、**DXF-AAMA**（主流）/ **DXF-ASTM**（备选）（跨 CAD）。

### AI 八不具备（生产级纸样为什么出不了）

| 约束 | 生产要求 | 文生图 |
|---|---|---|
| 尺寸闭合 | 袖山弧=袖窿弧+吃势，缝合边等长/差量可控 | ❌ 无尺寸概念 |
| 缝份一致 | 全片等宽或按部位设定 | ❌ |
| 刀眼对位 | 两片刀眼一一对应 | ❌ |
| 对称配对 | 左右片、面里衬配套 | ❌ |
| 多码推档 | 档差规则、两端码不失真 | ❌（自动放码两端不可信） |
| 面料方向 | 布纹线、毛向、条格对位 | ❌ |
| 可制造 | 可裁可缝可开袋装拉链 | ❌ |
| 输出格式 | DXF-AAMA（主流）/ DXF-ASTM（备选）、PLT | ❌（导不出 DXF） |

AI 可做：正背 flat 线稿作技术沟通（仍须打板师按人体数据重画）、分割线/省道转位灵感（仅灵感）、花型印花、CAD 导 PDF 后的整版美化。正式打版/推板/排料/出图全走 CAD+人工。
```
参考图1=服装效果图。输出正面与背面正交款式线稿（technical flat drawing），
纯黑细线、白底、无阴影无透视；清晰表达领型、省道、分割线、门襟、口袋、袖型与下摆，
工艺制图风。不要人物、模特、阴影、文字、标注数字、色彩、纹理、夸张比例。
```
验收门：每片布纹线正确；主缝/袖窿袖山刀眼对应、长弧缝有 balance；缝份一致并注明 net/net-plus；折边合品类；缩率已测已放；片名款号份数齐；缝合边长度校验过；全码齐套且两端码校验；唛架可 1:1 输出。漏布纹线/刀眼不对应/未测缩水/AI 图冒充结构图均为致命。

## 14 ｜ 工艺单 / 制单 Tech Pack　【语境：企业】

工厂报价、打样、量产、验货的单一技术指令文件。一句话原则：**凡是工厂会自行假设（assume）的地方，都必须写进文件。** 简化款 **6–15 页**（外套/多色多印花更多）；页数不是质量指标。

### 10 个模块（按工厂阅读顺序）

| # | 模块 | 关键内容 |
|---|---|---|
| 1 | 封面 | 款名、款号、季节、系列、日期、版本（Rev.A/B/C）、设计师/版师/制单人/工厂 |
| 2 | 技术款式图 | 正/背/侧 + 细节放大，黑白线稿 to-scale，每道缝/口袋/门襟/辅料/标位引线 |
| 3 | 色卡 | 每配色：色名、Pantone TCX、对应面料/辅料 |
| 4 | BOM | 见 15 |
| 5 | 尺寸规格表 | POM 编号+测量方法+基码值+全码档差+公差，配测量点图 |
| 6 | 工艺/缝制 | 缝型、线迹代号、SPI/针距、缝份、工序顺序、锁钉、特殊工艺 |
| 7 | 印花/绣花 | 图案尺寸、位置坐标（距领口/侧缝 cm）、颜色、工艺 |
| 8 | 洗水/整烫/包装 | 水洗工艺、整烫温度、折叠规格、一件一袋、装箱 |
| 9 | 标识规格 | 主标/尺码标/洗水唛/吊牌的内容、材质、位置、固定方式（见 `portfolio-board.md` 19） |
| 10 | 修订记录 + fit comments | 版本/日期/变更/变更人；每轮意见与处理结论 |

表头：BOM 列 `序号|类别|名称|规格参数|颜色|单位|单件用量|损耗率|供应商|单价|位置/用途|备注`；尺寸表列 `POM编号|测量点|测量方法|基码值|XS…XXL|公差(±)`。**POM 必须在款式图上编号并与表一一对应**，每点含"编号+大白话测量方法+基码值+档差+公差"；超 3 页加页眉（款号+版本+页码）。

### 公差（pass/fail 线，超差判不合格）

| 类别 | 公差 |
|---|---|
| 大身测量点（衣长/胸围/腰围/下摆围） | **±1.0cm**（约 ±1/2″） |
| 小部位（袖口/门襟宽/带子/口袋） | **±0.5cm**（约 ±1/4″） |
| 针织大身（T 恤类） | ±1.5cm |
| 机织围度（国标实例） | ±2.0cm |
| 牛仔（洗水后）关键位 ±0.5cm、次要位 ±0.3cm | — |

> cm 与 inch 两套口径**同一份文件内必须统一**，不混排。

### 针距 / 线迹（写工艺单必须用代号）

- 梭织通用 **SPI 10–12**（约 4 针/cm）；牛仔/夹克 8–10；童装 7–8；暗缝 3–5；针织 T 恤 10–12（针距过高易针孔/断纱），弹性缝需更高 SPI 防缝线开裂。
- 中文口径（针/3cm）：**明暗线 ≥12 针/3cm、包缝 ≥9 针/3cm**、手工 ≥7（肩缝/袖窿/领 ≥9）；T 恤实例 3cm 内 14 针。
- 线迹代号（参照 ASTM D6193 / ISO 4915，与工厂确认用哪套）：**301** 单针平缝（锁式）；**401** 双线链缝（受力弹性缝）；**504** 三线包缝（锁边）；**516** 五线包缝（safety stitch，针织侧缝）；**406** 双针绷缝（T 恤下摆/领口）；**602** 三针绷缝（厚料下摆/装饰压线）。
- 整烫温度：领口/裤腰 150–160℃；袖口/裤脚/裆部 140–150℃。
- 版本流程：设计师/版师→工艺师→工厂回签→批准；下发后任何改动必须升版重发，禁止口头改单。

### AI 分界

尺寸表、POM、档差、公差、BOM 用量/损耗、成本**都是数据不是图像，全部人工在 Excel/PLM 完成，AI 不能生成**。**工艺单插图 AI 可直接出**：用 `fashion-illustration-spec.md` 07.5 约束清单出超真实款式/工艺图作插图（默认路径），callout 与数据由人工/排板补标注（同一数字与款式图、细节图三处一致）。Seedream 给款式方向参考图、面料色感/肌理示意。
验收门：封面版本与修订一致；正背侧+细节线稿 callout 与 POM 编号对应；每 POM 五要素；公差分级单位统一；BOM 覆盖面料/里/衬/线/五金/商标/吊牌/包装含用量损耗；工艺含缝型/代号/SPI/缝份/工序；印花有坐标；标识内容位置明确；色卡与 BOM 一致；fit 意见有处理结论并升版。

## 15 ｜ BOM + 尺寸规格表 / 推档 Size Spec　【语境：企业】

组织方式：单款开发并入 Tech Pack（每款自洽）；系列开发独立成册（BOM 总表+码型总表，多款共享，需版本联动）。实务两者都维护，以"款号+版本"互引。

### BOM 字段

面料（编号/名称/成分/幅宽/克重/组织后整理/色号）、里料、衬/垫料（粘合衬/无纺衬/垫肩）、缝线（规格如 40/2、20/3、成分、颜色、单件耗线）、五金（拉链型号长度齿型、纽扣直径材质色、四合扣、气眼、绳带、松紧）、商标（主标/尺码标/洗水唛/吊牌/吊粒）、包装（OPP 袋/纸箱/防潮剂/装箱单）；数据列：单件用量、损耗率、单价、供应商、位置用途。

- 用量：`面料用量(m) ≈ 单件净耗面积 ÷ 有效门幅 × (1+损耗率)`；**损耗率经验区间 3%–8%**（排版损耗实例可达 ~12%，厚料/条格对花更高）；报价按"净用量×(1+损耗率)×单价"。

### 尺寸表与号型

- 必须区分**净体尺寸（人体）vs 成衣尺寸（含松量）**，工厂按成衣尺寸做；列名写"成衣胸围/净体胸围"。
- 基码（GB/T 1335 系列口径，需按品牌确认）：**女 160/84A、男 170/88A**；企业常以 M 码或销量中位码为基码。
- 号型标注：上装 `身高/胸围+体型`（160/84A），下装 `身高/腰围+体型`（160/68A）；体型 **Y 偏瘦/A 正常/B 偏胖/C 肥胖**；身高 5cm 分档、胸围 4cm、腰围 2cm。
- **档差**：身高 **5cm/档**；胸围女 **4cm/档**、男/大码 **5cm/档**；腰围 **2cm/档**；衣/裙/裤长 1–2cm；袖长/肩宽 0.5–1cm。
- **断点（breakpoint）分段**：档差非全程均匀（如成熟女装 6–18 码围度每档 4cm，18–24 码跳到 6cm，符合 BS EN 13402-3），不能全码一个档差。
- 关键 POM：上装=衣长/胸围/肩宽/领围/袖长/袖口/下摆围/门襟宽；裤=裤长/腰围/臀围/前后浪/大腿围/脚口/裆长；半裙=裙长/腰围/臀围/裙摆围；连衣裙=衣长/三围/肩宽/袖长/领围。

### AI 分界

BOM 用量、损耗、尺寸值、档差、公差**全部人工完成**，任何"AI 自动生成尺寸表/BOM"都不成立；Seedream 仅贡献面料示意与款式氛围（见 `design-boards.md` 04 面料板）。
验收门：BOM 无缺项；用量按门幅换算、损耗 3–8%（特殊另注）；尺寸表区分净体/成衣、单位统一；每 POM 有测量方法与公差；基码明确、档差按断点分段；推档表与尺寸表逐码一致；供应商/单价等商业敏感列按对象裁剪。

## 16 ｜ 3D 虚拟成衣　【语境：数字赛道为主，企业渐用】

用于数字订货会、虚拟走秀、数字服装赛事、数字藏品、虚拟白坯先于实物筛款。只写边界与规格，不展开操作。

### 文件格式与硬规格

| 项 | 规格 |
|---|---|
| 导入 2D 纸样 | **DXF-AAMA 推荐**（ASTM 备选）；**无缝份基线、必须带刀眼**；每片布纹线正确 |
| 粒子距 particle distance | 工作 20，交付 **5–20**（小片 3） |
| CLO 资产 | `.zprj`（含 avatar）/ `.zpac`（仅服装）/ `.zfab` 面料 / `.trm` 辅料 / `.btn` 纽扣 / `.avt` |
| 工程大小 | **.zprj ≤500MB**；Style3D `.sproj` 每款 **≤300MB**；Goshop `.gproj` ≤3G |
| 通用交换 | OBJ / FBX / GLB（饰品多 FBX、网页/AR 用 GLB） |
| 视频 | **16:9、MP4、30fps、≤60s** |
| 数字资产（DRESSX 类） | T-pose 双码（S/XL）；渲染 **1440×1920** 正/背/侧/45° 透明底；**GLB ≤10MB**；贴图 ≤2048²（尽量 1024²） |

资产说明（Asset Description）须含：所用软件、材质与克重、尺码/适配 avatar、PBR 贴图清单（base/normal/roughness）、是否含饰品、单位（默认 mm），缺描述可能被审核拒绝。

### AI 分界（核心：3D 不能跳过 2D 纸样）

| 环节 | AI | 必须专业软件（CLO/Style3D/Marvelous/Browzwear） |
|---|---|---|
| 概念图/风格板 | ✅ | — |
| 2D 纸样 | ❌ | CAD 或 3D 内打版 |
| 缝合/仿真 | ❌（不能一键产可生产成衣） | 缝合+仿真（垂坠/褶皱/碰撞以 3D 为准） |
| 面料 | ✅ 花型/印花贴图（作 PBR 基础图） | 参数标定（克重/弹力/悬垂）、PBR 制作 |
| 渲染/背景 | ✅ 修图换背景氛围 | 引擎渲染（MetaHuman/UE 等） |
| 走秀视频 | ✅ 辅助剪辑/旁白 BGM | 3D 内动画/走姿导出 |

厂商"图生纸样"需深度集成 3D 物理引擎+人工质检才可用；其减废/提速数据为厂商口径，未见独立复现。
```
数字服装概念图：参考图1=款式设计稿；参考图2=材质。中性数字人台，T-pose，
中灰无影背景，材质为参考图2所示面料质感，正面全身，高精度渲染，无文字无 UI。
负面：文字、UI、网格、水印、logo、穿模、漂浮的衣服、无缝合感、塑料感、
改变服装形态/颜色、贴图接缝、低模多边形感。
```
验收门（**看效果 / 进生产两档**）：**看效果 / 提案 / 赛事展示档**——AI 出超真实 3D 渲染图（正背侧/45° 渲染背景统一、视频规格达标）即可交付，用于看效果与数字走秀；**进生产档**——工程格式/大小达标；含 2D 纸样+缝合线，不扭不穿模；布纹线对、刀眼齐；粒子距 5–20；面料参数+PBR 齐备；资产说明完整；只交渲染图无工程=不合格。AI 图冒充 3D 工程=诚信底线。
