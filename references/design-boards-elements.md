## 03 ｜ 色彩板 Color Story　【语境：两者】

- **定位**：用视觉元素来表达这个系列的色彩感觉和氛围，不是列出有哪些颜色。
  - **概念色彩版**（赛事/设计提案）：主体是情绪参考图，色卡是提取结果
  - **企业生产色卡**（大货比对）：精确色号、可复现，交染厂对色

- **概念色彩版 vs 企业色卡的区别**：
  | 维度 | 概念色彩版（设计阶段） | 企业生产色卡（大货阶段） |
  |---|---|---|
  | 核心目的 | 展示这个色彩体系是什么感觉、什么情绪 | 可复现，交染厂对色 |
  | 主体内容 | 情绪参考图（占70%以上面积） | 精确色卡（占大面积） |
  | 色卡位置 | 顶部/边缘，小面积点缀 | 主体，占大面积 |
  | 呈现形式 | 艺术拼贴、杂志版面 | 表格、列表 |

- **放什么（概念色彩版）**：
  - **核心原则**：围绕色彩情绪发散元素，不限定具体类型，只要能体现这个色彩的感觉和氛围就行
  - **元素来源发散**：至少覆盖3个以上不同领域（可以是任何领域：建筑、自然、艺术、器物、工业产品、摄影、雕塑、光影、文字、地理、人物等），不要只局限在某几类
  - **一般不建议放**（板间分工，有意混搭可破）：面料特写（通常归面料版）、规整的服装/站立模特（通常归效果图）、色卡表格（那是企业生产用，不是概念色彩版的主体）、太多文字说明（文字通常是点缀，不是主体；但做概念提案时加一段说明也合理）
  - **元素类型丰富**：不是单一类型，多种元素围绕色彩主题展开

- **版面结构（概念色彩版）**：
  ```
  ┌─────────────────────────────────────────┐
  │ 【顶部/边缘】                           │
  │  ■ 色卡色块（小面积点缀，提取结果）      │
  ├─────────────────────────────────────────┤
  │ 【中部主体】                             │
  │  ■ 情绪参考图拼贴（景观、场景、材质）    │
  │  ■ 元素互相叠压，撕纸边缘，大小对比      │
  ├─────────────────────────────────────────┤
  │ 【底部】                                 │
  │  ■ 一行色彩关键词（如果需要）            │
  └─────────────────────────────────────────┘
  ```

- **形式美要求（概念色彩版）**：= 公共四件套（大小对比/疏密对比/元素叠压/透叠层次，见「全局板面底座」），无特有手法。

- **关键数值**：
  - **概念色彩版**：情绪参考图占 70–85%、色卡点缀占 15–30%；元素 **8–15 个**；大中小三级层次：1个大主体 + 3-5个中等元素 + N个小点缀；留白 30–40%
  - **企业生产色卡**：核心色通常 **4–7 色**（≤5 色最聚焦，是常见稳妥做法；想要丰富印花/民族风系列时色数可以更多）；比例三套口径并列，显式声明选用哪套——
    - **60-30-10**（通用配色/穿搭）；
    - **70-20-10**（WGSN 商业色盘：中性基色 70/支持色 20/点缀 10）；
    - 中文教材：主色 70–80% + 辅点缀合计 15–25% + 点缀约 5%。

- **色号体系（企业生产用）**：服装用 **Pantone FHI**（约 2800 色）；色卡类型、色值写法、容差与对色光源口径统一见 `quick-reference.md`，本文件不重复。

- **语境/主路径**：
  - **概念色彩版**：赛事表达优先；主路径 **A 出素材 + B 拼贴**（B 收口）
  - **企业生产色卡**：企业保真；主路径 **C/B 精确赋值**（AI 仅氛围）

- **AI 边界（硬）**：
  - **精确色不能由文生图直出**——同一色号 hex 随测量条件变化，模型只给"看起来像"的像素。
  - 流程：PS 吸管取 AI 底图→手动校正到目标 TCX→矢量矩形精确赋 hex/CMYK→CMYK 校样。

- **提示词（概念色彩版）**：
  ```
  生成一张时装概念色彩情绪板拼贴，A3 横版，主题是"XX色彩感觉"。
  风格：有机拼贴，撕纸碎片边缘效果，元素互相叠压穿插，乱而有序。
  元素：围绕"XX色彩感觉"，用景观、建筑、材质、光影等视觉元素表达这个色彩情绪。
  形式美：一个大视觉重心（占画面1/3面积），中等元素3-5个，小碎片点缀，大小对比强烈；
  元素集中在一侧，另一侧留白，有呼吸感；元素互相遮挡叠压，有前后层次关系。
  参考图1 提取色调；参考图2 提取材质色彩；参考图3 提取光影氛围；其余新生成。
  顶部/边缘留出小面积位置放色卡；画面留出约30%空白供后期排版；不生成文字与水印。
  不要规整网格排列、不要元素平铺、不要大小差不多、不要太满太挤、不要色卡表格、不要面料特写。
  ```

- **验收门**：
  - **概念色彩版**：遮字给别人看 3 秒能说出这个系列的色彩是什么感觉；主体是情绪参考图，色卡是小面积点缀；有大小对比、疏密对比、元素叠压、透叠层次；无"剪贴簿感"（即无章法贴纸感）在克制专业调性下要避免；在手作拼贴风里这反而是特色
  - **企业生产色卡**：主辅点缀三档明确、比例口径显式；4–7 色非等权；每色 TCX/TPG+hex+RGB+CMYK 齐全；面积权重可见；企业板含染色/色牢度注记；无"只有 hex 无 Pantone"。

## 04 ｜ 面料板 / 材料板 Fabric Board（含辅料）　【语境：两者】

- **定位**：围绕面料主题的完整视觉拼贴——展示用什么面料、面料什么质感、面料穿在身上什么效果。
  - **概念面料版**（赛事/设计提案）：主体是面料纹理+小样，点缀是人物展示效果
  - **企业生产面料卡**（大货阶段）：精确信息、可复现，作大货比对标样

- **概念面料版 vs 企业面料卡的区别**：
  | 维度 | 概念面料版（设计阶段） | 企业生产面料卡（大货阶段） |
  |---|---|---|
  | 核心目的 | 展示系列的材质语言和面料氛围 | 可复现，作大货比对标样 |
  | 主体内容 | 面料纹理特写 + 面料小样（占70%） | 每块面料一个信息块（成分+克重+...） |
  | 点缀元素 | 少量人物展示效果 + 场景氛围 + 装饰线条 | 辅料独立分区 |
  | 呈现形式 | 艺术拼贴、杂志版面 | 表格、列表、信息块 |

- **放什么（概念面料版）**：
  - **核心原则**：围绕面料主题发散元素，不限定具体类型，展示这个系列的材质感觉和面料氛围
  - **主体**：面料纹理特写 + 面料小样
  - **点缀**：少量人物展示效果（1-2个，是点缀不是主体）、场景氛围、装饰线条、工艺细节
  - **人物使用规范**：人物适量（1-2个）、不重复、是点缀不是主体；人物的作用是展示面料穿在身上的效果
  - **一般不建议放**（板间分工，有意混搭可破）：色卡表格（通常归色彩版）、设计元素推导（通常归廓形版）；人物是点缀不是堆人像秀海报；避免同一人物重复出现；也不要只剩干面料块像色卡，留点氛围和穿着效果（除非你做的就是纯粹面料卡）。

- **版面结构（概念面料版）**：
  ```
  ┌─────────────────────────────────────────┐
  │ 【左上角】                               │
  │  ■ 面料板（大标题）                     │
  │  ■ 一段概念说明文字（材质语言）         │
  ├─────────────────────────────────────────┤
  │ 【中部主体】                             │
  │  ■ 面料纹理特写 + 面料小样拼贴          │
  │  ■ 少量人物展示效果穿插在中间           │
  │  ■ 元素互相叠压，撕纸边缘，大小对比     │
  ├─────────────────────────────────────────┤
  │ 【底部】                                 │
  │  ■ 一行材质关键词（如果需要）            │
  └─────────────────────────────────────────┘
  ```

- **形式美要求（概念面料版）**（公共四件套见「全局板面底座」；此处只列面料板特有手法）：
  | 设计手法 | 怎么体现 | 判断标准 |
  |---|---|---|
  | **线条分割** | 用线条和几何图形分割画面 | 有装饰感，不是纯照片拼贴 |

- **关键数值**：
  - **概念面料版**：面料相关元素占 70–85%、人物点缀占 15–30%；元素 **8–15 个**；大中小三级层次：1个大纹理特写 + 3-5个中等元素 + N个小点缀；留白 30–40%
  - **企业生产面料卡**：每块面料一个信息块——小样/微距图 + **成分 + 克重 GSM + 门幅 + 组织 + 后整理 + 色号 + 供应商/价格/MOQ**（8 字段）；辅料独立分区（拉链/纽扣/织带/松紧/蕾丝/五金/衬里/缝线/标签）；可加面料改造小样（打褶/刺绣/洗水/拼接/绗缝，工艺分流见 05，赛事加分）；单板 **6–12 块主面料 + 4–8 项辅料**【经验值】

### 企业生产工艺方案详细内容

把"表面装饰"创意翻译成**可下单**的工艺方案。纹样（图案母题）是设计层；**印花、刺绣、织花、印染、特种工艺**是实现层——同一纹样可以印花、可以绣花、可以织出来，工艺不同，生产文件、成本、AI 边界完全不同。本板创意（花型/色彩/位置）与工艺（方式/套色或针数/底布/成本）同板呈现。

### ⓪ 先选工艺类型（不同工艺，生产文件与 AI 边界不同）

| 工艺大类 | 代表 | 图案怎么实现 | 生产文件/软件 | AI 能做 | AI 不能做（必须专业/人工） |
|---|---|---|---|---|---|
| **数码印花** | 喷墨直喷、热转印/热升华、DTG | 高分辨率图直接喷/转印，无套色限制，短版友好 | TIFF/PNG 高分辨率，RGB/CMYK 色彩管理 | 花型创意、**超真实效果图** | 无缝/接版仍须人工 Offset 验；色牢度/色差以打样为准 |
| **丝网印花** | 胶浆/水浆/厚板/烫画 | 1–8 套色，每色一块网版，色块线条无真渐变 | **分色稿**：金昌 EX9000/宏华等 | 花型创意、**超真实效果图** | **不出可用分色稿**；套色/线宽/叠印必须专业 |
| **刺绣** | 电脑平绣、毛巾绣、贴布绣、绳绣 | 绣线在面料上按针路走线 | **绣花制版：Wilcom/田岛 Tajima/富怡绣花 → .DST/.EMB/.PES**（见下专项） | **刺绣超真实效果图**（针脚立体/珠光）、花型 | **不出针路/针法/针数/缩料补偿/机台文件**；对色以实物绣线卡为准 |
| **织花/提花** | 提花、织锦、牛仔提花、领带 | 织出来的（经纬纱组织成花），不是印 | **纹织 CAD 做纹板/组织** | 图案风格、**超真实效果意象** | 不出纹板/组织文件；需织机与打样 |
| **印染/手工** | 扎染、蜡染、蓝染、拓印、植物染 | 手工/染料晕染，冰纹、扎结不可完全复制 | 无固定机台文件，靠工艺师傅 | **超真实效果意象**、图案灵感 | 实物靠手工，做不出可控的手工肌理 |
| **特种工艺** | 钉珠/亮片/烫钻、盘带、绗缝、压褶/抽褶、激光切割、植绒/发泡/滴塑、**烂花/烧花（Burnout）** | 模具/特种机/手工/排布；烂花=酸蚀溶解部分纤维露出透纱底 | 激光切割矢量路径、压褶模具、特种机文件；烂花蚀刻位置/强度靠样布 | **超真实效果渲染**、排布创意 | 模具/针路/排布/工时靠人工与专业软件；烂花花位/酸蚀深度以打样为准 |

> 选型：数码印花门槛低、表现自由；丝印适合大色块、大货成本低但受套色限；刺绣显高级、有立体肌理但按针数计费、周期长；提花做高档针织/梭织；扎染/特种做差异化卖点。**同一图先定用哪种工艺，才谈花型规格与提示词。**

### 花型类型 × 工艺 选择逻辑（先定构图，再定工艺）

| 决策维度 | 选项 | 怎么选 |
|---|---|---|
| 纹样母题 → 构图 | **连续纹样**（满花/四方连续） | 母题有叙事性、要覆盖大面（衬衫/连衣裙/家居服） |
| | **定位花 placement** | 单点/局部装饰焦点（胸前/后背/裙摆），强调单一母题 |
| | **边条/二方连续** | 领口/袖口/下摆/门襟的装饰带 |
| | **散点** | 小母题均匀散布、克制留白 |
| 构图 → 工艺 | 连续纹样 | 数码印花（快速/无套色限）或提花（高档织出来） |
| | 定位花 | 数码 / 丝网（大色块）或刺绣（立体高级） |
| | 边条 | 织带提花 / 刺绣条 / 印花条 |
| | 散点 | 数码印花 / 钉珠亮片 |
| 工艺 → 成本周期 | 数码印花 | 门槛低、短版友好、无套色限；无缝接版须人工验 |
| | 丝网 | 大色块大货便宜、1–8 套色；分色人工 |
| | 刺绣 | 高级立体、按针数计费、周期长 |
| | 提花 | 高档、需纹织 CAD 打纹板 |
| | 特种 | 差异化卖点、模具/工时贵 |

> 三者联动示例："碎花母题 → 满花连续 → 数码印花（成本低）/ 提花（高档）；同一碎花 → 定位到胸前 → 刺绣（立体卖点）。"先回答"图案长在哪、铺多大"，工艺自然收敛。

- **放什么**：花型主题与元素；**先标工艺类型**（印花/刺绣/织花/印染/特种，见上表）；花型类型（满花/散点/定位花 placement/二方边条）；印花循环方式（平接 1/1、1/2 半跳、1/3 跳、菱形/阶梯）；**花回原图 + cm + 像素 + dpi**；3×3 铺版接版示意；工艺与套色（印花每色 Pantone；刺绣标绣线色号/针数）；底布/面料；企业页加单耗/MOQ/成本。
- **关键数值**：
  - 分辨率 **CY/T 249—2021**：线条图案 ≥118 像素/cm（≈300ppi）、云纹 ≥59 像素/cm（≈150ppi）、制版输出 ≥142 像素/cm（≈360ppi），位图 **TIFF/BMP**；数码稿终尺寸 150–300dpi（300 为生产基线）。
  - 分色硬指标（CY/T 249—2021）：分色后最细线条 **≥0.2mm**；细茎/撇丝间距 **≥0.4mm**；复合色宽度机织 **≥0.2mm**、针织 **≥0.3mm**；云纹外扩 5–8mm；深色块面收缩 0.2–0.4mm。
  - 花回尺寸（瓦栏平台口径）：服装四方连续 **40×60cm**、二方 75×110cm、独幅 60×80cm；数码方形花回 **30/45/60/90cm**。
  - 丝网印花 **1–8 套色**（商业常见 1–6，每色一块网版，色块/线条、无真渐变）；数码印花无套色限制、短版友好。

### 05-1 ｜ 刺绣专项（工艺与印花根本不同）

刺绣是**绣线在面料上走针**，不是印颜色。AI 能渲染"看起来绣出来的效果"，但绣花机不认图，只认**制版文件**。

- **制版（digitizing）软件**：Wilcom（威尔克姆）、Tajima 田岛（DG/ML）、富怡绣花、Pulse 等；由制版师把图案翻译成针法路径。
- **机台文件**：**.DST**（田岛通用，最常用）、**.EMB**（Wilcom 源文件）、**.PES**（Brother 家用）、**.EXP/.JEF** 等；要给制版师/绣花厂，不能只给一张 AI 图。
- **针法（基础几类）**：**平包针/缎面针 Satin**（窄小填充，光泽强）、**他他米/榻榻米 Tatami**（大面积填充）、**走针/平针 Run**（轮廓、勾边）、十字针；另有毛巾绣（chenille）、链目绣、贴布绣、绳绣（cording）。
- **制版关键参数**：针距/密度（针脚间距，决定饱满度与软硬）、底针 underlay（防皱、定型）、锁针（线头不散）、**缩料补偿（pull compensation，刺绣会把布料拉短，制版要预先放长）**、换色次数、**总针数**（直接决定工时与成本）。
- **辅料**：绣线（人造丝/涤纶/棉线，**用绣线色卡对色，如 Coats/Anchor 线号或 Pantone 转绣线**，不能直接把 Pantone 当线号）、衬料（纸衬/水溶衬/热熔衬，按面料选）、绣线股数。
- **AI 边界**：AI 出刺绣**超真实效果图**（针脚立体、珠光、绣线光泽尽量真实，可直接作交付展示）与花型/布局创意；**针路制版数据**（针法、针距密度、针数、缩料补偿、机台文件）与真实绣线色差/绣作工时仍须制版师 Wilcom 打版（.DST）→ 绣花厂打样 → 实物对色、看针脚平整度。AI 超真实图只作展示与提案，不冒充实物与制版。
- **提示词（刺绣超真实效果，非制版）**：
```
刺绣工艺效果图，<平绣/缎面针/毛巾绣/贴布绣>，图案为<花卉/几何/母题>，绣线配色<主+辅+点缀>。
参考图1=花型图案与布局；参考图2=绣线色彩；参考图3=底布面料质感。
绣线立体感清晰、针脚饱满有光泽，边缘有平包针勾边，底布<亚麻/真丝/牛仔>，
柔光侧光突出绣线浮雕，微距特写，正投影平整。不要印刷感、不要水印文字 logo、不要多余手指。
```

> 织花/提花、扎染蜡染、钉珠烫钻/压褶/激光等特种工艺，生产文件与 AI 边界见上方 ⓪ 分流表；共同原则——**AI 出"超真实效果图"（可交付展示），专业软件/师傅出"生产文件"**。

- **语境/主路径**：企业保真；主路径 **A 出花型/工艺超真实效果图 → B 拼板 → 专业软件收口（印花走金昌分色、刺绣走 Wilcom 制版、织花走纹织 CAD）**。
- **AI 边界**：AI 出花型/工艺**超真实效果图**（花型、刺绣针脚立体、珠光、织纹细节尽量真实，可作交付展示）；**生产文件仍须专业路径**——无缝四方连续人工在 PS 检验（Offset 半幅+折回，平铺 3×3 验接）、**丝印分色用金昌 EX9000/宏华等（AI 不出可用分色稿）**、**刺绣制版 Wilcom/田岛打版（针法/针数/缩料/.DST）**、织花纹板/特种工艺模具同理；精确色号（Pantone/绣线色号）人工对实物。
- **提示词**：
```
无缝四方连续花型，<复古植物/热带花叶/几何植物纹>，满花平铺，元素密度均匀、边缘到边缘。
四方连续，<平接/1/2 跳接>，无明显花回方向，可无限平铺。
风格：<手绘水彩/复古丝网/线描/扁平矢量>，配色<主+辅+点缀>，底色<白/米/深绿>。
参考图1=元素造型与画风；参考图2=配色明度；参考图3=密度与留白节奏。
正方形画布，元素不贴边切断。不要可见接缝、不要元素被裁切、不要文字水印 logo、不要边框。
```
- **提示词（概念纹样版）**：
  ```
  生成一张时装概念纹样工艺板拼贴，A3 横版，主题是"XX装饰语言"。
  风格：有机拼贴，撕纸碎片边缘效果，元素互相叠压穿插，乱而有序。
  元素：围绕"XX装饰语言"，用纹样/工艺特写、工艺样本、人物穿着效果、工艺细节等视觉元素表达。
  形式美：一个大视觉重心（大纹样特写，占画面1/3面积），中等元素3-5个（工艺样本、人物），小点缀碎片，大小对比强烈；
  元素集中在一侧，另一侧留白，有呼吸感；元素互相遮挡叠压，有前后层次关系。
  参考图1 提取纹样/工艺质感；参考图2 提取细节特写；参考图3 提取光线与氛围；其余新生成。
  画面留出约30%空白供后期排版；不生成文字与水印。
  不要规整网格排列、不要元素平铺、不要大小差不多、不要太满太挤、不要只有平面图案、不要太多人物。
  ```

- **验收门**：
  - **概念纹样版**：遮字给别人看 3 秒能说出这个系列有什么装饰特色、用了什么工艺；主体是纹样/工艺相关元素，人物是适量点缀；纹样手法和主题匹配；有大小对比、疏密对比、元素叠压、透叠层次；无"剪贴簿感"（即无章法贴纸感）在克制专业调性下要避免；在手作拼贴风里这反而是特色
  - **企业生产工艺方案**：**工艺类型已选定（印花/刺绣/织花/印染/特种）**；印花：花回 cm/像素/dpi 三者自洽、Offset 半幅 + 3×3 无缝、循环方式标注正确、丝印分色最细线 ≥0.2mm、复合色 ≥0.2/0.3mm、生产稿用 TIFF/位图不用 JPG；刺绣：花型已交制版（有 .DST/.EMB）、绣线色号以实物线卡对、针数/衬料/缩料经打样确认；每色有 Pantone 或绣线色卡条；企业页含工艺/底布/单耗/MOQ/成本；AI 图未被当作分色稿或绣花制版。

## 06 ｜ 廓形趋势板 Silhouette & Trend Board　【语境：两者】

- **定位**：收集符合本系列风格的已有服装廓形，作为设计参考和灵感来源，把抽象的"风格"落地成具体的服装轮廓。
  - **概念廓形版**（赛事/设计提案）：参考已有品牌的廓形，拼贴排列，作为设计灵感
  - **企业廓形分析**（大货阶段）：把"氛围"落到"形"，企业板加品类结构与目标零售价区间

- **概念廓形版 vs 企业廓形分析的区别**：
  | 维度 | 概念廓形版（设计阶段） | 企业廓形分析（大货阶段） |
  |---|---|---|
  | 核心目的 | 收集符合本系列风格的已有服装廓形，作为设计灵感 | 把"氛围"落到"形"，避免只有情绪没有形 |
  | 素材来源 | 已有品牌的秀场图、街拍图，抠图后拼贴 | 矢量剪影矩阵，等比例等间距排列 |
  | 呈现形式 | 手工拼贴，大小不一，互相叠压 | 规整矢量剪影，等比例对齐 |
  | 作用 | 为后续效果图阶段提供廓形参考 | 成买家 brief，指导生产 |

- **放什么（概念廓形版）**：
  - **核心原则**：收集符合本系列风格的已有服装廓形，抠图后拼贴排列，作为设计参考和灵感来源
  - **素材来源**：从网上下载的真实品牌秀场图、街拍图（如Balenciaga/Rick Owens/Maison Margiela等），抠图后只保留人物着装部分
  - **主体**：符合本系列风格的全身着装廓形图
  - **点缀**：主题氛围参考、关键词
  - **一般不建议放**（板间分工，有意混搭可破）：只有面部特写、只有局部细节（看不清整体轮廓）；自己设计的款式图（通常归效果图）；规整的矢量剪影矩阵（那是企业分析的形式）

- **版面结构（概念廓形版）**：
  ```
  ┌─────────────────────────────────────────┐
  │ 【左上角】                               │
  │  ■ 廓形版（大标题）                     │
  │  ■ 一段概念说明文字（廓形灵感来源）     │
  ├─────────────────────────────────────────┤
  │ 【中部主体】                             │
  │  ■ 抠图后的服装廓形拼贴                 │
  │  ■ 大小不一，角度各异，互相叠压         │
  │  ■ 有疏密节奏，不是均匀排列            │
  ├─────────────────────────────────────────┤
  │ 【底部】                                 │
  │  ■ 一行廓形关键词（如果需要）            │
  └─────────────────────────────────────────┘
  ```

- **形式美要求（概念廓形版）**（公共四件套见「全局板面底座」；此处只列廓形板特有手法）：
  | 设计手法 | 怎么体现 | 判断标准 |
  |---|---|---|
  | **手工拼贴感** | 边缘是不规则的剪裁边，有随意感 | 像设计师从杂志上剪下来贴在 sketchbook 里 |

- **关键数值**：
  - **概念廓形版**：廓形图 **6–12 个**；元素大小不一，角度各异；大中小三级层次：1个大主体 + 3-5个中等元素 + N个小点缀；留白 30–40%
  - **企业廓形分析**：推荐按 6 层顺序排（主题→廓形→关键单品→色彩→面料→细节，这个顺序是顺着"为什么→什么形→什么款→什么色→什么料→什么细节"的阅读逻辑，按你需要也可调）：①主题（一句话+氛围图 1–2）②廓形（主导轮廓 2–4 个，剪影+比例注记）③关键单品（外套/下装/连身/内搭，共 4–8）④色彩（3–5，与色彩板一致）⑤面料（2–3，与面料板一致）⑥细节（领/袖/门襟/工艺，2–4）；剪影常见 **2–4 个**、关键单品 4–8、细节 2–4；企业板里剪影建议**等比例、等间距、脚线对齐、矢量化、高度 ≥1500px**（这样买家看得清比例；概念拼贴版不需要这种规整）。

- **语境/主路径**：
  - **概念廓形版**：赛事表达优先；主路径 **素材采集（浏览器搜索品牌秀场图）+ B 拼贴**（B 收口）
  - **企业廓形分析**：企业保真；主路径 **C 矢量剪影 + B 排板**（AI 仅氛围意象）

- **AI 边界**：
  - AI 目前出不了稳定的等比例剪影矩阵（比例与对齐不可控，这是技术限制不是审美选择）；**企业分析板建议在 Illustrator 统一描边等距排布**，同一板内别混用不同比例人体（否则比例比较没意义；概念拼贴版随意）。

- **提示词（概念廓形版）**：
  ```
  生成一张时装概念廓形灵感板拼贴，A3 横版，主题是"XX风格廓形"。
  风格：手工剪报拼贴，不规则剪裁边缘效果，元素互相叠压穿插，大小不一，角度各异，乱而有序。
  ```

- **验收门**：
