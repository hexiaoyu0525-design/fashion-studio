这份文件是"素材库"的**蓝图（schema）**，不是素材本身。技能是方法论，素材库是个人实例资产，二者分离，保证技能能独立分享、上 GitHub。

## 2. 投喂权限（最重要的标签）

### 2.1 总原则：参考全绿，交付分级

- **参考层（看、学、拆、垫、发散——内部找方向/定类型/练手/图生图探索）**：**一切图皆可参考，无红线**。秀场图、品牌图、高定、获奖作品、真人脸，都是参考素材——学廓形、学手法、学质感、学氛围、学构图，随便看、随便拆。这是设计行业的正常工作方式。
- **秀场图全绿**：秀场参考图在参考层与过程全开（看/学/拆/垫、**可作长期参考**），**不标 🟡、无"须转化"标签**；**拿秀场款当改造基底是行业常态**——改结构/换面料/调色彩/改款式即完成改造（属行业常规动作，非警戒线）；真正的红线只剩 🔴 老花/Logo（慎喂垫图、公开交付不复现）与真人面容（**可垫图，成片实质改到不可指认原真人即可用**——改五官/发型/妆容/年龄/气质等实质维度，非滤镜级微调）。
- **交付层（最终交付，尤其企业商用、公开发表、比赛评审）**：按用途分级——**练习/个人/内部参考：全 🟢，随便用**；**参赛/商用/公开发布**：🟡 转化到不可指认、🔴 不复现品牌标志（保护的是你自己：比赛原创性审查、品牌法务、客户商标风险）。
- 语境越公开（企业/比赛/上架/投放）交付执行越严；纯个人练习、不发表，交付全 🟢。

每条素材必须打一个权限标，决定它"交付时能不能直接进终稿"（参考层一律可用，不用纠结）：

| 级别 | 名称 | 能否参考/垫图（过程） | 能否进终稿（交付） | 典型内容 |
|---|---|---|---|---|
| 🟢 | 可投喂·可作锚点 | ✅ | ✅ 练习/交付全可用 | 自有/可商用/平台授权/AI 自建；公共领域历史传统；通用材质工艺 |
| 🟡 | 参考全开·交付按用途转化 | ✅ 可看可学可垫可发散 | ⚠️ 仅参赛/商用/公开发布须转化；练习/内部全 🟢 | 真人/明星/网图的脸；当代品牌/在世设计师/高定季度/当代获奖的整件或原创面料（**秀场图除外——全绿，见 2.1**） |
| 🔴 | 慎喂·交付不复现 | ⚠️ 可看可学可提炼（配色/构图/手法）；**慎喂垫图**——模型会原样复现标志、画进作品后难剥离 | ❌ 交付不复现 | 品牌 Logo / Monogram / 老花 / 经典格纹 / 注册印花图案 |
| ⚪ | 仅知识 | 不入库为素材 | 不入库 | 布光/镜头/廓形/风格/材质/产出类型的定义与理论 |

### 2.2 各级细则

- **🟢 可投喂**：
  - 自有/可商用/平台授权/AI 自建产出：AI Muse 身份卡、数字样衣三视图、自拍、自绘结构草图、**自建 AI 创意面料**；
  - 公共领域：过版权期的历代服饰、文物原件与复原、传统/民族/非遗服饰（可作"元素转译"，取形取结构取元素；民族非遗须尊重语境、不猎奇，分寸见 `design-ideation.md` 第 3 节）；
  - **通用材质、肌理、织法、工艺、结构手法**：皮革、丝绸、针织、做旧、压褶、明线、省道等——材料与工艺本身不享有版权，可直接垫；
  - 通用"类型"信息：身材/比例/骨架/气质/妆发（**不指向某个具体真人**的那种）。
  - 可进图生图、可当图1/图2/图3、可做长期锚点。

- **🟡 参考全开·交付按用途转化**：
  - 当代真人/明星/网图模特的**那张具体的脸**；当代品牌、在世设计师、Haute Couture 季度系列、当代获奖作品的**整件成衣或原创面料**。
  - **参考层全开**：可看、可垫、可图生图、可发散，学"类型、设计语言、廓形比例、技术、材料、概念"——与 🟢 参考无异。
  - 交付层两条硬要求（**仅参赛/商用/公开发布时生效；练习/个人/内部全 🟢，不要求转化**）：
    1. **真人脸**：交付不指向任何真人——真人脸**可作垫图基底**，成片**实质改到不可指认原真人即可用**（改五官/发型/妆容/年龄/气质等实质维度，非滤镜/磨皮级微调；保留标志性特征如痣/伤疤/极特征面容则不算不可指认）；想跨图复用才提炼成 **AI Muse 身份卡** 🟢（非强制），此后只认新卡。
    2. **设计师整件/原创面料**：交付转译到"与源作并置时不可识别同源"；比赛有原创性/雷同审查，近抄即判抄袭。
  - 个人库可存参考图（带**来源链接**、标 🟡），不随技能/GitHub 发布、不外发协作者。

- **🔴 慎喂·交付不复现**：
  - 品牌专属 **Logo / Monogram / 老花 / 经典格纹 / 注册印花图案**（商标 + 美术作品，如 LV 老花、Dior 斜纹、Gucci 双 G、Burberry 格纹等）。
  - **参考层无限制**：可看、可学、可提炼"配色/构图/手法"——这不属于参考红线。
  - **技术提示（不是法律红线）**：不建议直接垫图喂模型——模型会**原样复现标志**、画进作品后极难剥离，复现即侵权；所以"看可以、学可以，别把标志图当垫图"。
  - **交付**：不得复现该标志；表里只存来源链接。

- **⚪ 仅知识·留技能**：布光/镜头/景别/廓形/风格/材质/产出类型的*定义与理论*。不入库为素材，方法论已在技能各文件里；库里只放"对应实例"。

> 法律依据（一般性说明，非法律意见）：真人脸受肖像权保护（《民法典》1018–1019），AI 深度合成不得"伪造"他人肖像——**垫图可、交付成片须实质改到不可指认原真人（即不构成可识别肖像）**；品牌 Logo/老花/注册印花受商标权与著作权双重保护；通用材质与工艺、过版权期历史服饰不受此限。**企业商用与公开发表的比赛**按最严执行。

> 说明：本蓝图面向**线上模型（即梦 Seedream/Seedance 等云平台）**。姿态、手部、动作、面料动态以**普通参考图或动态参考视频**提供（控制角色=姿态/动作），不是本地节点工作流的 openpose/线稿/深度/白模等控制网文件。

| 控制角色* | 多选 | 身份 / 服装结构 / 材质 / 色彩 / 姿态 / 动作 / 场景 / 光位 / 镜头 / 氛围 / 不适用 |

## 4. 六大类与子类清单

括号内为：形式 / 默认控制角色 / 默认权限。标"项目驱动"= 不预建通用图，遇到具体项目需要再补（见第 6 节）。

### 一、人物模特（MODEL）
- 模特库：AI Muse 身份卡（图/身份/🟢，自有 AI 模特，可反复垫、供群像）；**真人/明星/网图的脸 → 🟡 过程参考，仅用于生成新 Muse**；身材/比例/气质等"类型"信息 🟢
- 人体体态：站姿/坐姿/走秀/转身/抬手/面料垂坠测试（图/姿态/项目驱动，复杂姿态当场补，不预建通用图册）
- 妆造：创意彩妆、裸妆、国风妆造、各类发型（图/身份·氛围；通用妆发类型 🟢，具体真人妆发随脸走 🟡）
- 手部特写：手部姿势、触摸面料、提裙摆、佩戴饰品（图/姿态/项目驱动，需要时自拍当场补，不预建）

### 二、服装本体（GAR）
- 风格库：时装艺术/现代成衣/先锋解构/新中式（图+文/氛围；**定义 ⚪ 留技能**，当代品牌样例 🟡）
- 廓形库：H/X/A/O/T/茧/斗篷/不规则解构（图+文/结构；定义 ⚪，历史/自建实例 🟢）
- 款式库：成衣/礼服/高定/工装/户外（图/结构/自建数字样衣 🟢；设计师整件 🟡）
- 结构库：省道/褶裥/抽皱/分割线/立裁/解构撕裂/立体堆叠（**通用结构是知识 ⚪**；该设计自己的结构草图/数字样衣 🟢；复杂翻车项目驱动，不预建）
- 零部件库：领/袖/肩/门襟/口袋/开衩/纽扣/盘扣/拉链/袢带（**标准件写词即可，不预建**；该款特殊部件随样衣 🟢）
- 纹样工艺面料库：传统纹样/现代印花/刺绣/扎染/热压/棉麻丝绸皮革（图·纹理/材质·色彩；**传统纹样+通用材质肌理工艺+自建创意面料 🟢**；当代设计师原创面料 🟡；**品牌专属老花/Logo/注册印花 🔴**）
- 虚拟材质库：液态金属/透明薄膜/晶格/碎玻璃（纹理/材质；自建 🟢，他人实验材质 🟡）
- 饰品库：首饰/头饰/腰饰/鞋履/包袋（图/结构·配饰；通用款 🟢，品牌标志款 🔴）

### 三、文化案例（CUL，按时代/权利分两类，见 `design-ideation.md` 分寸尺）
- 传统服饰案例：非遗/民族服饰/国风当代再设计（图·链接/🟢 可转译，民族非遗须尊重语境、不猎奇）
- 中外服饰史文物：中国历代、西方古典（图·链接/🟢 可元素转译，文物原件+复原；过版权期的廓形与传统纹样可取形取结构）
- 全球品牌&设计师：商业成衣/独立设计师（图·链接/🟡 过程参考，学设计语言，终稿转化）；拆解出的**品牌语言卡**（品牌名仅内部、锚点语言可入库复用，见 `design-ideation.md` 3·7/3·8）
- 高级定制系列：Haute Couture 季度系列（图·链接/🟡 过程参考；其中的老花/Logo 元素 🔴）
- 往届赛事获奖作品：设计大赛/AIGC 获奖（图·链接/🟡 过程参考，当代获奖不抄）

### 四、影像视觉（VIS，图片大片 + 视频共用）
- 场景空间：影棚/秀场/古建筑/山野湖面/白棚/复古室内/未来场景（图/场景；自建/通用场景 🟢，他人大片场景 🟡，项目驱动）
- 光影布光：伦勃朗/平光/轮廓逆光/柔光/硬顶光/电影感自然光（图/光位；**定义 ⚪**，自建实例 🟢）
- 镜头语言：景别/推拉摇移/机位（图/镜头；**定义 ⚪**，项目驱动）
- 色彩色卡：季度配色/传统五色/莫兰迪/撞色，附色值（图+文/色彩/🟢，品牌专属配色组合参考 🟡）
- 面料动态：丝绸飘/薄纱摆/硬挺垂落/流苏（视频/动作/项目驱动；**做视频时当场拍真实布料，不预建通用动图**）
- 模特动作动态：走秀/转身/裙摆/慢动作（视频/动作/项目驱动，做视频阶段再补）

### 五、创作理论 & 成果（THE）
- 主题概念库：自然/考古/非遗/未来/性别/材料实验，配灵感文案与关键词（文字/🟢 提示词素材）
- 作品集排版库：作品集/展板版式（图·链接/🟡 参考版式，不抄具体设计）
- 设计理论文献：设计史/艺术流派/时尚评论（文字·链接/⚪ 只引用，不进生成）

### 六、成品归档（OUT，闭环）
- 产出品类（Editorial/Campaign/Lookbook/Fashion Film/Brand Promo/Runway/社媒/BTS/Webisode/Mood/Tech/AR）的**定义**在 `video-film-types.md`，不入库。
- 库里只放自己的**成片/成品归档**：每条记录"用了哪些素材 ID + 提示词 + 版本 + 评分 + 过程参考如何转化"，与版权报告的原创证据链闭环（见 `copyright-compliance.md`）。

## 5. 素材命名规则

`大类码_子类码_编号_v版本`，例如 `MODEL_MUSE_001_v1`、`GAR_LOOK_003_v1`、`GAR_FAB_012_v最终版`。

大类码：MODEL 人物 / GAR 服装 / CUL 文化 / VIS 影像 / THE 理论 / OUT 成品。

固定模特编号 `MODEL_MUSE_001/002…`（身份卡），数字样衣编号 `GAR_LOOK_001…`（已锁成衣）。

## 6. 养库原则（只攒锚点和项目实测，不预建通用图册）

素材库是**养**出来的，不是按清单填满的。像素参考只攒两类：

1. **可复用锚点**：AI Muse 身份卡、数字样衣三视图、自建材质/场景/固定元素。这是跨项目反复用的核心资产，优先建。
2. **项目里实测翻车、当场补的参考**：某复杂结构、某特殊材质，或某次确实需要的特定手势/姿态/布料动态。补完若可复用再归档。

**不预建的内容**（技能里有文字、写词就能画对，或属于通用知识）：

- 风格/廓形/光影/镜头/色彩**定义**、常见场景、通用妆造、标准结构与零部件（普通领型/袖型/拉链/省道等）——这些是 ⚪ 知识，写词即可。
- 通用"防崩图册"（批量的人体体态、手部、动作、面料动态）——不做通用囤图。遇到具体一张：
  - 复杂姿态：抓一张对应姿态的秀场帧 / 自拍，或直接用数字样衣定妆；
  - 手部：自拍自己的手做该动作（最准、随手可得），或裁切/藏手/手出画、多出几张挑好的；
  - 布料动态：做视频时拍这件衣服/这块布真实甩动。

积累通道：① 手机表单/扫码快速入库（发链接或图，标签与权限由 Agent 补全）；② 做项目时丢进项目文件夹/对话，Agent 判断"会复用则入库、一次性则仅留项目"；③ 项目结束回填实测好用的素材与成品。

## 7. Agent 检索规则（按任务取素材）

| 任务 | 筛选条件（大类/子类 + 角色 + 权限） |
|---|---|
| 锁模特身份 | **只用 🟢 AI Muse 身份卡**（模特库，角色=身份）；真人/网图脸 🟡 不做身份锚点，只用于"建新 Muse" |
| 群像/多人 | 调用多个 🟢 Muse 身份卡；没有合适的就先按 🟡 类型参考生成新 Muse |

## 9. 无库时降级（技能可移植关键）

- 技能**不写死**任何库 ID、飞书链接、本地路径，只说"从素材库按 X 条件检索"。
- 检测不到库或库为空时：请用户本次提供素材，或直接走纯提示词流程；流程不中断。
- 每条素材的可用性最终以"投喂权限"为准：**参考层一律可用（无红线）**；**公开交付**（参赛/商用/公开发布）只用 🟢 作锚点、🟡 必须已转化、🔴 不复现；练习/个人/内部全 🟢。

## 10. 如何自建 / 迁移这个库

1. 取 `assets/asset-library-template.csv`（空表头+少量示例行），导入飞书多维表格 / Airtable / Notion / Excel。
2. 按大类建立筛选视图；按第 3 节设置单选/多选下拉，投喂权限四个选项逐字一致。
3. 图、视频、纹理放云盘（或本地），表里存链接或封面；批量大文件不要塞附件。
4. **先建锚点**：固定 AI Muse 身份卡 + 数字样衣三视图（🟢），这是第一批也是最高优先级。
5. 其余按"养库原则"（第 6 节）项目驱动，**不预建通用百科/防崩图册**。
6. 权限与上传：
   - 🟢 历史/传统/自建/通用材质可存图、可垫图；
   - 🟡 个人库可存过程图（方便发散），但必须带**来源链接**、标 🟡，且**不随技能/GitHub 发布、不发给外部协作者**；
   - 🔴 品牌老花/Logo/注册印花**只存来源链接、不传标志图**。
7. 每个成品归档时回填素材 ID、提示词、以及 🟡 过程参考的转化说明，形成闭环。
