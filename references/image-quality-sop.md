# 生图总调度：四步管线 · 三路径 · 21 项路由 · 人体比例统一口径

这是出图的**总入口与调度台**。任何一件衣服/一个系列要出图，先确定在管线哪一步、走哪条路径、用哪套人体；具体提示词公式分散在各图种文件，本篇只做顺序、验收门、路由与边界，不重复公式。

- 板面尺寸/字体/网格/命名/两语境三路径总约定，见 `design-boards.md` 全局板面底座。
- 锚点清单、变化白名单、失败诊断、返工分流，见 `consistency-lock.md`（本篇只引用，不复制）。
- 图种提示词公式：平铺/挂拍/人台→`image-garment.md`；真人 Lookbook/Editorial→`image-editorial.md`；细节/工艺/面料微距→`image-detail-fabric.md`；视频→`video-brief.md`/`video-film-types.md`。

## 〇、先分清两套顺序：创作顺序 vs 出图顺序

**编号 01–21 是交付物目录，不是创作先后。**

- **创作顺序（从无到有，完整结构见 `design-boards.md` 开篇）**：调研 01 → 灵感 02 → 服装三要素（**款式·廓形 06 / 色彩 03 / 面料 04** 并行迭代）→ 纹样/工艺花型 05 → **效果图 08（先）→ 定款 → 款式图 07（后）** → 系列 09 / 细节 11 / 配饰 10 → 工程 12–16。
- **本篇四步管线，是"设计定稿之后"把已定稿的款做成商品图/模特大片的渲染顺序**：先锁样衣、再上模特。此时效果图与款式图都已存在，所以步骤①能拿款式图/平铺当锁定参考。
- 别把"做设计"（效果图在前）与"出商品图"（样衣先锁）混成一条线；前者是发散收敛，后者是稳定复刻。

## 一、四步管线（顺序不可跳级）

先有"衣服本身"，再让它"上人身"，最后补镜头。跳步直接出模特大片 = 衣服每一张都在变，是最常见的返工根因。

| 步 | 产物 | 锁什么 | 参考图 | 主文件 |
|---|---|---|---|---|
| ① 锁数字样衣 | 无模特款式图/平铺正背 + 面料纹理 + 色卡 | 结构、版型、色位、织纹 | 图1=服装 | `image-garment.md`、`fashion-illustration-spec.md` 07 |
| ② 成衣定妆 | 人台/幽灵模特成衣图 | 把①的色位/闭合件/织纹在立体成衣上锁死 | 图1=①的成衣 | `image-garment.md` |
| ③ 上模特 | 真人/模特上身成组图 | 衣不动；只变动作/场景/光源 | 图1成衣·图2模特·图3面料场景 | `image-editorial.md` |
| ④ 补镜头 | 细节/工艺/面料微距 | 补"值这个价"的证据 | 对应部位 | `image-detail-fabric.md` |

**语境开关**：企业保真语境每一步都要"与实物可核对"（色号/结构/闭合件/织纹），AI 图不可冒充实物；赛事表达语境允许②③④氛围化、风格化，但①的结构仍须自洽（见 `aigc-competition.md`）。

### 步骤① 锁数字样衣

先把"衣服"这件**无生命体**定下来，不带人、不带场景：

- 无模特平面款式图（正+背，必要时侧）；或平铺正/背图（白底、光线均匀、褶皱可控、无遮挡）。
- 面料纹理单独一张（材质四要素：纹理/光泽/厚度/垂感，见 `image-detail-fabric.md`）。
- 色卡单独锁（精确色走排板工具/TCX，AI 不直出精确色，见 `design-boards.md` 03）。

**验收门（全过才进②）**
- [ ] 正/背齐全，领型/肩线/袖长/门襟/下摆可辨；对称处左右对称。
- [ ] 廓形/松量/腰线位置明确；衣长/裙长/袖长/裤长有落点。
- [ ] 主色**及颜色位置**逐处写明（拼接/滚边/内衬各自位置），不是只有"红色"。
- [ ] 闭合件数量与位置明确（纽扣几颗、拉链多长、腰带/扣件）。
- [ ] 印花/格纹的**位置与尺度**明确，不是满图随机。
- [ ] 织纹肌理可见、面料四要素写全。
- [ ] 需进工厂的款式图：AI 直出过 07.5 约束清单即可用；合同级另用 Illustrator 描摹成矢量（见 `fashion-illustration-spec.md` 07/07.5）。

### 步骤② 成衣定妆

把平面的①在立体上"挂"起来，先用**人台/幽灵模特**（不含真人五官），确认成衣立体状态：

- 人台/幽灵（ghost mannequin）正背；锁色位、闭合件、织纹、省道与立体褶皱。
- 这一步仍不追求氛围，只追求"这就是那件衣服"。

**验收门（全过才进③）**
- [ ] 色位与①一致，拼接/滚边位置没有随立体起伏漂移。
- [ ] 闭合件数量/位置/开合方向与①一致（纽扣不增减、拉链不偏）。
- [ ] 织纹在立体拉伸处没有被"织成另一种花"。
- [ ] 廓形/松量/长度与①一致，立体褶皱属于该面料应有垂感。
- [ ] 无多余配饰、无未指定的层次（没加帽子/外套/腰带/包）。
- [ ] 电商主图用途：无人台残留（Amazon 主图禁任何人台，见 `portfolio-board.md` 21）。

### 步骤③ 上模特

衣服与模特、场景**三参考分离**，只允许在白名单内变化：

- **图1=成衣**（锁结构/版型/颜色位置/长度/闭合件/图案/织纹/配饰鞋履/面料质地）。
- **图2=模特**（锁五官/发型/肤色/身形比例），脸与服装不用同一张图管；**大片/场景片锁脸用面部特写母版（母版_04）或面部四宫格整张（母版_02），不用全身母版管脸**（人脸像素太小=没锁）。
- **图3=面料场景**（可选；面料质感 + 场景/光线/色调）。
- **参考图优先级**：**服装图 + 脸部图必须准确、绝对保住**；场景图可舍弃/用文字描述/允许虚化模糊（镜头聚焦人物、场景虚化是正常摄影语言）——场景与服装/脸抢参考名额时牺牲场景。
- **人脸双锁**：大片提示词同时写**特写脸部图**（图片锚）+ **身份卡文字锚**（五官/发型/发色/肤色/标志特征，"与 @图片2 完全一致、不随光影改变五官结构"）；机位与脸部参考角度对齐；反复漂时先出中近景定脸再扩全景（完整协议见 `image-editorial.md` 通用要求 6）。
- **场景三情况路由**：① 无场景图 → 纯文字描述；② 有纯环境场景图 → 三图全保（图3 必须无人无强主体）；③ 有人物的场景图 → 底图编辑换人协议（走 `image_edit` 主体替换）。先选情况再定参考图组合（见 `image-editorial.md` 通用要求 7）。
- **变化白名单只有三项：动作、场景、光源**（详见 `consistency-lock.md`）；其余一切（服装锚点、模特身份）写成显式禁令。
- 成组出图：固定同一模特、同一场景光调、同机位系列，生成不同姿态/场景。

**验收门（全过才进④）**
- [ ] 服装与图1逐处一致：结构/配色/长度/闭合件/图案位置/织纹/配饰。
- [ ] 模特与图2一致：五官、发型、肤色、身形比例（无母版直出按 1:9 + 裆 55%；有母版以母版为准；插画档 9–10，见第五节）。
- [ ] 变化仅发生在动作/场景/光源；没有自行加配件、换色、改长度。
- [ ] 手部：复杂姿势易多指，让手自然垂下/出画或简化。
- [ ] 系列图：同色调/同光调/同比例，跨套可辨为同一系列。
- [ ] 图内无品牌名/长文字（文字一律后期排版，见 `portfolio-board.md` 17）。

### 步骤④ 补镜头

在已经锁定的成衣/模特上补**局部证据镜头**：拉链、套结、针距、纽扣、袖口下摆、织纹、纱线、对花、面料微距。

- 用 `image-detail-fabric.md` 微距公式与面料-光位表；不露脸、不强调身体。
- 工艺特写用途分叉：**展示/提案/效果 → AI 出超真实工艺图**（提示词写死缝型名/针距/部位/视角，见 `fashion-illustration-spec.md` 07.5）；**工艺核验/合规证据 → 必须实拍或矢量**，AI 图不能当核验（见 `fashion-illustration-spec.md` 11）。

**验收门**
- [ ] 每处细节与①②的成衣一致（拉链款式/纽扣数量/缝线结构不矛盾）。
- [ ] 光位与面料匹配（织纹/绒面/缎面高光走向正确，见光位表）。
- [ ] 光圈 f/8 级细节清晰，没有糊成一片、过度锐化、塑料感。
- [ ] 没有虚构的缝线结构、不存在的花纹。
- [ ] 工艺核验件标注为实拍/矢量，未用 AI 图冒充。

## 二、不达标分流（统一走 `consistency-lock.md`）

四步任何一屏不过验收门，按 `consistency-lock.md` 的**失败诊断表 + 返工规则**处理，核心三句（细节不在此重复）：

1. **锚点级问题 → 整图重出**：动了结构/版型/廓形/长度/闭合件、颜色位置/整体配色、图案/纹样/印花、配饰鞋履、面料质地反光、模特身份/整张脸/比例、大姿势/光调/场景氛围——整图重出，不打补丁。
2. **非锚点小瑕疵 → 局部圈选/蒙版重绘**：仅限手部多指、面部小瑕疵、背景杂物、单颗纽扣/拉链头、小范围 hex 级换色、局部光影等。
3. **同一处局部改 2 次仍不自然 → 换素材重出**（补背面图/换更清晰模特图/加姿态参考），不继续磨措辞。一次只改一处。

> 返工前先定位"唯一一处该改的地方"，再决定整图重出还是局部圈选；视频用时间戳+框选，规则同样见 `consistency-lock.md`。

## 三、三条产出路径（每件交付物都要先选路径）

| 路径 | 工具 | 最擅长 | 短板 |
|---|---|---|---|
| **A · AI 生图** | Seedream 文生图/图生图 | 氛围、插画、大片、材质渲染、风格迁移、成组延展 | hex 精确取色、图内文字、纽扣/缝线计数、矢量精度、量产一致性、严格对称 |
| **B · 排板拼贴** | PS / InDesign / Canva / 飞书 | 多页栅格、图文层级、印前规格（300dpi/CMYK/出血）、合规控制、精确色卡赋值 | 无原创视觉产出 |
| **C · 矢量/专业软件** | Illustrator / 打版 CAD / CLO / Style3D / 金昌 | 款式图精度、对称、可缩放、规格标注；无缝检验、丝印分色、纸样、3D 仿真 | 无氛围/无写实质感 |

**选路原则**：
- 企业/商业语境：**B 为主 + C 出技术稿 + A 仅辅助**；颜色/面料/版型以实物为准，平台合规。
- 赛事/院校语境：**A + C 混合 + B 排板**；守原创、匿名、征稿方尺寸/页数/dpi。
- 生产技术文件（款式图/纸样/Tech Pack/BOM/3D）：**C 为唯一可靠路径**，AI 图只能当沟通示意，不能当生产依据。

## 五、人体比例统一口径（一套数字，两条路径）

出图前必查（第一个是路径）：**有没有 Muse？** 有 Muse 就继承，没有就统一写死，不玩多口径。

| 路径 | 头身比 | 裆到脚底 | 怎么用 |
|---|---|---|---|
| **无 Muse 直出**（纯文字/无固定模特，写实/照片向） | **1:9** | **55%** | 提示词统一写这两组数字，不写区间、不写 1:8 |
| **有 Muse / Muse 着装真实效果图** | 继承 Muse 母版 | 继承 | 以母版为人体锚，提示词不写头身比数字 |
| 时装画插画档（装饰/前卫/概念，仅插画风格） | 9–10 | 腿颈拉长 | 只有明确"插画/风格化"时才用；写实/照片向一律 1:9 |

判定口径：最终画面"像照片"→ 一律 **1:9 + 裆 55%**（无母版时写死）；"插画/时装画风格"→ 9–10 头。同一张图内不混用；不得把插画人体喂给写实图当模特参考。

**出图前提醒**：无 Muse 时，在效果图/大片/视频之前**先提醒用户是否建立 Muse**（流程见 `ai-model-muse.md` 开工提醒）；不建 → 按上表"无 Muse 直出"直接出图。

### 五·附 1 源感锁定 Source-Look Lock（治"AI 塑料感"）

写实风格最稳的写法：**命名采集源 + 拥抱其签名瑕疵**——瑕疵词汇本身就是风格，别反着修。假装 UGC 却太干净 = 假两次。

| 想要什么源感 | 锁定写法（瑕疵=风格） |
|---|---|
| 手机实拍/UGC | 竖屏手持、轻微握持晃动、自动曝光漂移、环境音 |
| 直播/信息流 | 固定摄像头取景、平顶补光、轻度压缩感、实时字幕节奏感 |
| 胶片/复古 | 颗粒、门缝漏光、高光光晕、年代对比（Portra 400 暖 / 400H 冷） |
| 监控/行车记录仪 | 锁定高角度、时间戳烧录感、低光噪、对事件无镜头反应 |
| 商业棚拍 | 受控反光、干净背景、抛光细节、零手持晃动 |

配 `image-editorial.md` 胶片质感段使用：要"真实感"就选一个源感锁定，不要堆"电影感/氛围感"空词。

#### 真人皮肤纹理关键词（治"磨皮假脸"，大片/真人上身时并入图2模特提示词）

**核心必写（稳定底座，每张不变）**：真实人类皮肤肌理——皮肤纹理的"风格锚点"，写实大片必写，跨图/跨视频保持不变。

**按需选用（控制写法，不全堆）**：轻微毛孔、鼻翼泛红、眼下淡淡青黑、脸颊自然红血丝、细微泪沟、少量淡淡雀斑、唇周暗沉、皮肤轻微油脂反光（T 区微微出油）。
不要写：无瑕肌肤、零毛孔、完美嫩肤。

> **防漂移（写前必读）**：皮肤瑕疵是**身份锚点的一部分**（与五官/发型/肤色同级，见 `consistency-lock.md` 模特锚点），写法三限——
> ① **每图只选 1–2 个瑕疵词**（选多=换皮肤），选定后写进 Muse 身份卡，同一 Muse/系列内逐张一致、不逐图换词；
> ② **只写"轻微/淡淡/少量"限幅词**（"毛孔"→"轻微毛孔"、"青黑"→"淡淡青黑"），让模型收敛而不放大；
> ③ **跨图/跨视频复用同一模特时，皮肤细节以 Muse 身份卡为准**，不在此处新增或删除特征；"真实皮肤肌理"作稳定底座，其余按①②限量选用。

#### 神态动态关键词（拒绝僵硬模板脸，大片/视频共用）

正面写（打破标准微笑与僵硬站姿）：放空呆滞眼神、半垂眼皮、嘴唇微张、轻微咬唇、眼神轻微涣散、脸部肌肉松弛、动态模糊发丝、风吹拉扯皮肤的轻微形变、肩颈不刻意挺直（轻微含肩更真人）。
不要写：标准微笑、笔直对称站立、表情僵硬、眼神空洞对镜。

> **防漂移（写前必读）**：神态动态**最容易造成跨图/跨视频人物漂移**，写法三限——
> ① **每镜只选 1–2 个神态词**（多选=表情在换人），写"哪一刻哪个神态"而不是堆一串；
> ② **幅度可执行、不写死**：用"轻微/淡淡/一点点"这类可收敛的限幅词（"轻微含肩"≠"驼背"），并和动作/场景绑定（"风吹发丝时眼皮半垂"），不让神态脱离环境；
> ③ **同一 Muse/系列内神态词逐张一致**：表情是短时状态，但提示词若不锁，跨图就是"换了张脸"——系列定稿前把神态词写进该图提示词即可，跨图复用仍以 Muse 身份卡为准；视频内神态由镜头节奏带动，按 `video-brief.md` 表演锚点（感受词+物理锚点，单镜内最多 2 个）控制，不做无依据的自由发挥。

### 五·附 2 中文 Slop Traps 替词表（空泛词 → 可执行替词）

提示词里出现这些"套话"时，把它翻译成可见/可听的具体指令：

| 套话 | 可执行替词（服装场景版） |
|---|---|
| 高级感 | 指明要展示的工艺/材质：`侧光扫过缎面，高光沿褶皱连续流动` |
| 大片感 | 写明人物与空间的比例关系：`人物占画面 1/3，身后纵深 20 米` |
| 质感 | 指明哪个物体、哪种表面：`近处梭织面料露出可见织纹与缝线` |
| 震撼 | 指明造成冲击的对比/动作/揭示：`转身瞬间下摆甩出完整弧线` |
| 唯美 | 明确构图/色彩/光的行为，不强制柔光低饱和 |
| 氛围感 | 先明确哪种氛围（静谧/肃穆/浪漫），再选声画细节 |
| 史诗级 | 写主体与环境的比例：`人物立于门洞中央，门框占满画幅高度` |
| 超高清/8K | 当作交付分辨率要求，不当输出保证（`image-quality-sop` 不承诺） |
| 杰作/顶级品质 | 明确本图验收项（锚点是否全对、光位是否匹配面料） |

有用风格词保留（极简静奢、黑白电影感可留）；意图不清时才拆成可见/可听指令，别一刀切删光。

## 六、多参考图写法约定（图1/图2/图3）

- **读图 → 回读锚点 → 确认 → 才进提示词**：读完任何参考图，先把提取的锚点清单用文字列给用户扫一眼（**按 `consistency-lock.md` 锚点清单逐项**：结构 / 版型廓形 / 颜色及色位 / 长度 / 闭合件 / 图案·纹样·印花 / 配饰鞋履 / 面料质地 / 模特身份），用户说"对"再写进提示词——LLM 读图是压缩感知，回读确认是廉价的纠错点，**禁止读完图不核对就直接生成**。
- 每张参考图都要写明"**抽取什么 + 生成什么**"；多图时逐张标注对应关系，模型才不会串。
- 图1=服装（只取版型/图案/颜色/面料质感）；图2=模特（只取五官/肤色/身形比例）；图3=场景与光线（只取背景/光向/色调）。
- 步骤①②只有图1；步骤③才引入图2/图3；④回到图1局部。
- 具体多参考提示词模板（平铺转人台/上身、换装换背景、Lookbook 大片）见 `image-garment.md`、`image-editorial.md`；锚点禁区句式见 `consistency-lock.md`。
- 负面表述：首选正向改写（如用"sharp, in-focus"替代"不要模糊"）；工具支持负面栏时再填清单（水印/文字/多余手指/畸变/模糊/过曝/拼接痕迹/重复纽扣/扭曲五官/杂乱背景）；**Seedance 视频无负向字段，负向写法可能被当作要包含的内容**。

## 七、开工前 60 秒：先定四件事

第一张图生成前，逐项定死，填不齐不裸开图。**生成前先给"出图前预览工单"确认（先 1 张定调小样、选定再批量），图回来按本篇验收门分诊并给改写提示词**——协作与项目流程见 `project-workflow.md` 第六、七节。

1. **在哪一步**：是①锁样衣、②成衣定妆、③上模特、还是④补镜头？有没有上一步的产物可垫？（缺上一步产物 → 先补，不跳级。）
2. **走哪条路径**：A 生图 / B 排板 / C 矢量·专业？（查第四节路由表；技术稿/生产件默认 C。）
3. **人体口径**：无 Muse 直出写实/照片向统一 **1:9 + 裆 55%**；有 Muse 继承母版比例；插画档 9–10（查第五节）。
4. **哪个语境**：企业保真（颜色/面料/版型以实物为准、可复现）还是赛事表达（概念/叙事/视觉完成度、守征稿尺寸与匿名）？
5. **出几件、什么规格**：用途/渠道、数量、画幅比例、dpi/色彩模式、是否进 PDF/打印；命名与板面按 `design-boards.md` 底座。

### 四步各步高频卡点（一句话速查）

| 步 | 最常翻车点 | 一句话纠偏 |
|---|---|---|
| ① | 只给正面、没写颜色位置 → ②③色位乱漂 | 补背面 + 逐处写"什么色在什么位置" |
| ① | 直接要 AI 出工艺单级款式图，对称/计数错 | 过 07.5 约束清单直出（正背分开/对称后处理/计数锁定）；合同级 Illustrator 收口 |
| ② | 立体上织纹/图案被"拉伸成另一种花" | 禁区加"织纹与图案随成衣保持一致" |
| ② | 自己加了未指定的层次/配饰 | 补"不加任何未经指定的配件" |
| ③ | 一张图同时管脸和服装 → 脸/衣互相串 | 拆图1（衣）与图2（模特）独立参考 |
| ③ | 除了动作还变了配色/长度/版型 | 只留动作/场景/光源三项白名单，其余写禁令 |
| ③ | 手部多指、姿势复杂 | 让手自然垂下/出画，或简化姿势 |
| ④ | 用 AI 图当工艺核验证据 | 工艺核验须实拍/矢量；AI 超真实展示图仅可提案/展示 |
| 全程 | 图内塞品牌名/长文字/数字 | 一律后期排版，不进 AI |
| 全程 | 同处局部改 2 次仍不自然还在磨 | 换素材重出（补背面/换清晰模特/加姿态） |

### 四步调度骨架（每步提示词必须填满的槽位）

每步提示词都按此骨架填槽；具体公式再去对应图种文件，槽位缺项就是模型自由发挥处。

```
[步骤① 数字样衣]
主体=服装无模特（款式图/平铺 正+背）；
结构=领型/肩线/袖长/门襟/下摆；廓形/松量/腰线；
颜色=主色 + 每色所在位置；闭合件=种类/数量/位置；
图案=位置/尺度；面料=材质四要素；白底/均匀光/无场景。

[步骤② 成衣定妆]
主体=人台/幽灵 正+背；
锁=色位/闭合件/织纹/省道与应有垂感；
禁令=不增减配饰、不改变长度与廓形；
要求=这就是参考图1那件成衣。

[步骤③ 上模特]
参考图1=成衣（锁服装锚点）；参考图2=模特（锁五官/身形比例）；
参考图3=场景光线（锁背景/光向/色调）；
允许变化=仅动作/场景/光源；人体=无母版直出写实 **1:9 + 裆 55%**；有母版以母版为锚、提示词不写头身比数字；插画档 9–10（比例写进提示词）。
禁令=不改色/不换长度/不加配件。

[步骤④ 补镜头]
主体=指定部位（拉链/套结/针距/纽扣/织纹/纱线）；
光位=按面料-光位表；微距 f/8；不露脸/不强调身体；
工艺核验=实拍/矢量，AI 仅作氛围。
```
