# 生图 · 服装本体（无模特）

适合：电商详情、订货会、款式建档、内部沟通。优点是版型、颜色、工艺最准确，不受模特和场景干扰。

## 通用提示词五要素（所有生图模块都按这个骨架写）

每条服装提示词都写全五块，缺一不可：

1. **主体**：服装品类、廓形、颜色及颜色位置、结构、闭合件、辅料（锁锚点，见 `consistency-lock.md`）。
2. **风格**：风格词、质感取向、胶片/镜头气质（如"商业 lookbook""编辑大片""Kodak Portra 400"）；不写品牌名、设计师名。
3. **材质**：材质四要素（纹理/光泽/厚度/垂感），面料微距写法见 `image-detail-fabric.md`。
4. **构图**：景别、角度、焦段、布光、背景、人物姿势、画幅比例。
5. **参数**：生成工具、比例、负面提示词；图生图时点明 `图1/图2/图3` 各管什么。

顺序可以按"主体 → 风格 → 材质 → 构图 → 参数"组织；先锁主体，再给风格和材质，最后构图与负面。

## 四种形式

| 形式 | 用途 | 特征 |
|---|---|---|
| 平铺 flat-lay | 电商主图、搭配图 | 俯视、造型摆布、质感背景 |
| 挂拍 / 幽灵模特 | 要立体又不想露脸 | 挂点或隐形人台，有立体轮廓 |
| 人台 dress form | 展现立体剪裁、廓形 | 无头人台，中性 |
| 技术款式图 flat sketch | 生产、内部沟通、工艺 | 正面/背面线稿，无光影 |

## 平铺公式

```
俯视平铺（top-down flat-lay）：一件[服装]整齐摆放于[质感背景]，搭配 1–2 件[配饰]；
柔和均匀的顶部日光，自然柔和阴影；50mm、f/8、正上方拍摄；
干净极简造型，中性低饱和色；可见织物织纹与缝线细节；1:1。
```

要点：

- 一个方向的柔光，让阴影朝同一个方向（像柔光箱/窗光）
- 明确要求"可见织纹与缝线"，否则模型会糊掉质感
- 背景与配饰只留一两件，别抢服装
- 避免极小的文字和品牌标志（AI 常糊）

## 挂拍 / 幽灵模特公式

```
挂拍 / 幽灵模特：[服装]穿在隐形人体上，呈现自然立体轮廓；
无缝浅色背景；柔和均匀棚光，左右各一柔光箱；
所有接缝、门襟、口袋、下摆清晰；f/8 全片清晰；[比例]。
```

## 技术款式图公式

```
服装平面款式图（fashion flat sketch）：[服装]正面与背面，对称、无透视、无光影、
纯白背景；清晰画出领口、肩线、袖型、门襟、口袋、缝线、纽扣、拉链；
标准工业制图风格，线条均匀，可用于生产。
```

## 无模特时锚点最好锁

没有脸和身体干扰，服装本体图最容易做到一致。务必写全：

- 正面 + 背面
- 颜色及颜色位置（拼接、滚边、内衬）
- 面料纹理与反光
- 接缝、纽扣、口袋、拉链、配饰
- 版型与轮廓（oversized / tailored / relaxed / structured / fitted / cropped）

负面：不要衣架外露（除非是挂拍）、不要模特身体、不要多余道具、不要文字水印。

## 一组出多图

电商按"多角度一组"出：正面、背面、侧面、细节各一张，比例与光照统一。这是提高转化的标准格式。

## 图生图素材分工

以图生图时点名：`图1` 只提供服装结构与颜色（人台/裁体），`图2` 若为背景则只提供背景质感与光位，不参考其中人物。
