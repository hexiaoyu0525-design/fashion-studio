# 视频 · 九种影片类型

先定类型，它决定叙事、时长、镜头密度，最后才进入 `video-brief.md` 写备料包。

## 一张表先判

| 类型 | 核心目的 | 时长 | 叙事 |
|---|---|---|---|
| 品牌宣传片 | 讲"你是谁"，不是卖什么 | 1–5 分钟 | 价值 / 理念 |
| 系列宣发片 campaign | 绑定某季/某波/某单品 | 15–60 秒 | 明确卖点 |
| 时尚短片 / 时装电影 | 服装为主体的艺术表达 | 1–5 分钟 | 弱 / 中 / 艺术 |
| 秀场影片 | 秀场记录、数字替代走秀 | 全程或 1–3 分钟 | 无 |
| BTS 幕后花絮 | 真实感、建立信任 | 15–45 秒 | 无，跟拍 |
| Webisode | 系列化人物/故事，养受众 | 每集 1–3 分钟，连续 | 连续剧式 |
| Moodfilm | 纯氛围、情绪、视觉 | 15–45 秒 | 无 |
| Techfilm | 面料/工艺/功能性证明 | 20–60 秒 | 讲解式 |
| AR / 虚拟时装短片 | 数字时装、虚拟模特、未来感 | 15–60 秒 | 概念 |

## 各类型打法

### 1. 品牌宣传片 Brand film
- 讲品牌价值观、创始人理念、品牌气质，层次最高
- 电影感、有制作价值、情绪连接，可慢热
- 不绑具体单品，靠品牌肖像、空间、匠人、生活方式
- 它回答"你是谁"，系列宣发回答"你在卖什么"，别混

### 2. 系列宣发片 Campaign / product story
- 绑定某季、某波段、某单品，有明确目的和受众
- 结构紧凑、强视觉、有记忆点；可"hero 片 + 社媒切片"
- 服装是主角：用五镜结构完整展示造型

### 3. 时尚短片 / 时装电影 Fashion film
- 时装、电影、广告三种语言的杂交：产品是时装，执行是电影，目的是营销
- 三种叙事：无叙事（杂志编辑动起来）、传统叙事（时尚作为渴望符号）、有机叙事
- 服装主导画面，可做系列作品，不必像广告
- 编辑大片语法：固定机位、单硬主光、克制双色、保持住的姿势

### 4. 秀场影片 Runway
- 真实走秀记录，或数字秀场（替代实体走秀）
- 固定 T 台机位 + 侧面机位 + 起终点特写；节奏跟音乐与步伐
- 重点：每件衣服的完整廓形、动态、面料流动；同一运镜贯穿全场
- 数字秀场要注意造型连续性与多模特时的服装归属

### 5. BTS 幕后花絮
- 后台、妆造、走位、最后调整、大幕拉开前的安静与忙乱
- 真实、抓拍、近景、剪辑利落；不旁白、不解释，让氛围说话
- 快但不糙，"展示过程但不拆穿魔术"
- 成本低、产出快，社媒日常主力

### 6. Webisode 网络系列短剧
- 以人物（设计师、主理人、KOL、虚拟形象）为主角的连续剧式短内容
- 每集一个小故事/场景，服装在剧情里自然出场（"day in the life"）
- 强在人物连续性和追更，要锁同一主角身份与服装归属
- 适合持续运营、养社群，不是一次性宣发

### 7. Moodfilm 氛围片
- 纯氛围、情绪、视觉，几乎无叙事
- 最慢、最留白，靠光影、面料动态、空镜、音乐、配色
- 可以没有一句卖点，只为调性
- 提示词里场景/光源/材质描述重于动作

### 8. Techfilm 技术片
- 证明面料、工艺、功能：防水、透气、3D 针织、无缝、保暖
- 微距 + 测试动作 + 数据/字幕；镜头跟着"功能证据"走
- 把微距视觉做视频版：光扫过面料、拉链拉合、水泼在面料上
- 理性、可信，区别于 moodfilm 的感性

### 9. AR / 虚拟时装短片
- 数字服装、虚拟模特、AR 试穿、虚拟走秀，未来感与话题性
- 允许超现实材质、流动光效、重力变化；但服装结构锚点仍要锁（数字衣也要像这件衣服）
- 可自由发挥，但要统一"数字材质"规则（金属、发光、粒子要一致）
- 适合社媒传播、跨界、数字藏品语境

## 选类型的三个问题

1. 这条片子解决什么？（品牌认知 / 上新 / 卖点 / 调性 / 真实感 / 话题）
2. 投放在哪？（官网 / 发布会 / 信息流 / 抖音小红书 / 订货会）
3. 服装是主角还是配角？（campaign 是主角，brand film 是载体）

选定后进 `video-brief.md`。类型决定"一句话简报"里的基调和镜头密度。
