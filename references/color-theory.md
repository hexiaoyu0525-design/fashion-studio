# 色彩理论与服装配色工具箱 Color Theory for Fashion

> 本文件聚焦服装整体配色；纹样层面的配色方法论见 `pattern-texture-skill` 的 `references/color-pattern.md`（下称 **PTS**，本文件其余处同）。

> **本文件内容均为设计建议（可按需调整）**：没有绝对的“高级/廉价”，也没有绝对的“对/错”——先想清楚你想要的是什么风格，再判断这些规则适不适用。一切以你的需求为准。

> **什么时候用我**：
> - 客户/赛题给了一个感觉词（"要高级""要秋冬感""要显瘦""要多巴胺"），需要把它翻译成一套可执行的配色方案时；
> - 已经有几个候选色，纠结"这几个色放一起到底成不成立、为什么成、怎么调"时；
> - 要从潘通年度色 / WGSN 季度色里提取一个属于自己系列的色彩板，而不是照搬时；
> - 模特画像有肤色/体态约束（黄皮/黑皮/梨形/小个子），需要定向选色时。
>
> **和其他文件的关系**：
> - `design-language-dictionary.md` 第五节是**速查表**——给色彩词直接方向；我是它的**系统展开**——讲清楚为什么、怎么操作、踩什么坑。
> - `design-boards.md` 03 节是**板面操作规范**——色板怎么拼、色卡怎么落；我是它的**配色方法依据**——色板里到底该放哪几个色、按什么关系放。
> - PTS 的 `references/color-rules.md` 色彩构成体系是**纹样层面**的——图案里的颜色怎么配；我是**服装整体穿着层面**的——人穿在身上、上下内外、整体造型的配色。
> - 精确 hex / Pantone TCX 落值仍走 `design-boards.md` 03 的企业色卡流程，本文件不承诺色值。

## 一、色彩三要素：每个要素在服装里的独立作用

大多数人配色只看"色相"（红还是蓝），但当你想要静奢/老钱/极简这类风格时，调性往往来自**明度**和**纯度**的控制；波普/街头/多巴胺风则反过来玩色相。三要素不是并列的概念，它们在服装里各自干不同的事——怎么用，看你要什么风格。

### 1.1 色相（Hue）：这是什么颜色

- **定义**：色环上的位置，红/橙/黄/绿/蓝/紫 + 中间过渡色。
- **在服装里干什么**：定调性、定情绪、定品牌记忆点。色相是"远看就知道是什么风格"的东西。
- **操作要点**：
  - 一般来说，一个系列**主色相收敛在 1 个、邻近扩展 2–3 色**（见后文配色法）会更和谐；但民族风/波普/孟菲斯/波西米亚这类风格本来就要多色并置，看你要什么效果。
  - 色相本身没有"廉价"一说：色相越纯、越接近"玩具色"，越需要靠面料质感压；反过来说，波普/街头/童装/多巴胺风就是要这种纯玩具色，那就是对的。
  - 色相定了之后，**如果要保持系列统一感，尽量不要中途换**——改色相等于换系列；想调"调性"（从静奢变活泼），优先调明度/纯度，不要换色相。

### 1.2 明度（Value）：这颜色有多亮

- **定义**：从黑（0）到白（10）的亮度刻度。
- **在服装里干什么**：**明度对"显高级/显干净/显瘦/显高"的影响通常最大**。它是服装配色里权重很高的一个要素——具体用"拉开"还是"统一"，取决于你想要立体戏剧感还是整体顺色感。
- **关键规律**：
  - **明度拉开 = 立体、有层次、对比强**。一组配色里如果明度全部挤在中间（都是灰扑扑的中间调），再美也容易糊——这一条在你想要"立体、戏剧、有层次"时尤其成立；但同色系极简/莫兰迪/侘寂风本来就是要明度统一、要"糊成一片"的柔焦感，那就是对的。
  - **明度统一 = 整体、显高、纵向拉长**。全身同明度不同色（如全身米色系），视觉上拉长纵向——这是静奢/老钱/顺色穿搭的核心逻辑；但波普/街头/拼贴风就反着来，要横向切割和色块对比。
  - **上浅下深 = 视觉上稳定、显腿长**；上深下浅 = 活泼、视觉重心偏上（想要显高时参考，想要俏皮活泼时无所谓）。
  - **深色 + 纵向延伸色（同色鞋/裤/袜）= 显瘦显长的常用操作**，比靠"黑色显瘦"一个颜色硬扛有效；如果你就是想要膨胀感/娃娃廓形/Coquette 甜系，这条反过来用也可以。
- **操作要点**：
  - 配色方案先在脑子里**画一条明度轴**：主色落在哪一档、辅色落在哪一档、点缀落在哪一档。想要层次时三档拉开（深/中/浅）= 成立；三档挤在一起 = 糊——但想要莫兰迪柔焦感时，挤在一起本身就是目标。
  - **9 级明度参考**（经验参考，不是硬标准）：0 黑、1 炭、2 深灰、3 中深灰、4 中灰、5 中浅灰、6 浅灰、7 米白、8 象牙白、9 纯白。服装主色常用 1–7 档，8–9 档多做内搭/衬衫。

### 1.3 纯度（Saturation / Chroma）：这颜色有多艳

- **定义**：颜色的鲜艳程度，从灰（0）到纯光谱色（10）。
- **在服装里干什么**：**纯度主要影响"年轻/成熟、街头/安静、吵闹/克制"这一组气质**。没有绝对的"高饱和=廉价、低饱和=高级"——
  - 想要静奢/老钱/莫兰迪/侘寂时，降纯度（加灰调）就是对的；
  - 想要波普/街头/多巴胺/民族风/童装/节日礼服时，高饱和就是对的。
- **关键规律**：
  - **纯度越高 → 越年轻、越街头、越多巴胺、视觉冲击越强**；纯度越低（加灰调）→ 越成熟、越安静、越莫兰迪、越内敛。具体往哪边调，看你要什么气质。
  - **"高级感"的常见做法 = 把高纯度色加灰调**——这是静奢风的玩法。克莱因蓝很刺激，但灰蓝（雾霾蓝）就内敛；同一个色相，纯度从 9 降到 3，气质完全反转。反过来说，想要克莱因蓝那种冲击感，就该保留高纯度。
  - **一组配色里纯度有主次通常更耐看**：大面积低纯度 + 小面积高纯度 = 经典耐看的配比（灰底 + 一个亮色点睛）；大面积高纯度 + 小面积低纯度 = 视觉上偏吵；全部高纯度 = 满屏冲击（波普/多巴胺/音乐节就是要这个）；全部低纯度 = 安静灰调（莫兰迪就是要这个）。
- **操作要点**：
  - 想"显内敛/显安静/静奢" → 把主色纯度**降两档**（高→中，中→低）。
  - 想"显年轻活力/多巴胺/出片" → 把点缀色纯度**拉满**，但只给 5–10% 面积（经验参考，不是硬标准）。
  - **莫兰迪的本质不是"颜色"，是"所有颜色都加了同一层灰"**——这是它和谐的根本原因。想要波西米亚混搭感时，就别加这层灰。

### 1.4 三要素决策口诀

> 下表是"当你想要 XX 效果时，通常调哪个要素"的参考路径，不是唯一解。波普/街头/先锋风会反着用，看你要什么风格。

| 我想要的效果 | 一般调哪个要素 | 怎么调（经验参考） |
|---|---|---|
| 显内敛、显干净（静奢风时） | 明度 | 拉开三档（深/中/浅） |
| 显年轻、显活力（多巴胺时） | 纯度 | 主色降，点缀色拉满 |
| 显高、显整体（顺色穿搭时） | 明度 | 全身同明度 |
| 显瘦、显长（通勤/日常时） | 明度 | 深色 + 纵向延伸 |
| 改风格、改情绪 | 色相 | 换主色相 |
| 显成熟、显安静（秋冬/通勤时） | 纯度 | 整体降纯度 |
| 觉得太吵、太乱（日常穿时） | 纯度 | 把高纯度色加灰 |

## 二、五种色彩对比：强弱级数 + 服装表现 + 适用风格

> 速查表见 `design-language-dictionary.md` 五·附②（伊登七对比）。本节展开**强弱分级**和**在服装上的具体用法**。

### 2.1 色相对比

- **本质**：两个颜色在色环上隔多远。
- **强弱级数**（按色环夹角）：

| 级数 | 夹角 | 关系 | 服装表现 |
|---|---|---|---|
| 极弱 | 0° | 同色相 | 单色/顺色，最安全 |
| 弱 | 30° 内 | 邻近 | 自然和谐，日常 |
| 中 | 60–90° | 中距 | 有变化但不冲 |
| 强 | 120–150° | 远距 | 撞色，需控面积 |
| 极强 | 180° | 互补 | 最强冲击，只做点缀 |

- **服装上的表现**：弱对比→日常通勤/静奢/侘寂；中对比→休闲/学院/复古；强对比→街头/运动/多巴胺；极强对比（互补色）→**在你想要内敛日常感时，不要 50/50 对半撞，通常一大一小更耐看**；但波普/艺术系列/品牌视觉本来就要对半撞，那就是它的语言。
- **踩坑提示**：两个高纯度强对比直接 50/50 放一起，在想要"日常高级"时容易像童装；想保留强冲击就降其中一个的纯度。反过来，波普/童装/多巴胺风就是要这种强高饱和对比，那是对的。

### 2.2 明度对比

- **本质**：两个颜色的明暗差。
- **强弱级数**：

| 级数 | 明度差 | 效果 |
|---|---|---|
| 短调 | 差 1–2 档 | 柔和、朦胧、同色系 |
| 中调 | 差 3–5 档 | 稳定、经典、耐看 |
| 长调 | 差 6–9 档 | 强烈、戏剧、黑白式 |

- **服装上的表现**：短调→同色系深浅叠穿（米白+燕麦+驼），在静奢/极简风里很出效果；中调→绝大多数成衣安全区（藏青+白+卡其）；长调→黑+白/藏青+米白，经典对比款，要靠面料质感撑。
- **核心结论（带风格前提）**：在你想要"立体、有层次、经典对比"时，明度拉不开（全挤中间）、色相再和谐也容易糊——先调明度对比，再谈色相。但莫兰迪/侘寂/同色系极简本来就是要明度统一的柔焦感，"糊"恰恰是它要的效果。

### 2.3 纯度对比

- **本质**：鲜艳与灰浊的差。
- **强弱级数**：

| 级数 | 纯度差 | 效果 |
|---|---|---|
| 弱 | 都是中低纯度 | 莫兰迪、灰调、安静 |
| 中 | 一灰一艳 | 灰底+亮色点睛，最常用 |
| 强 | 纯光谱色+纯灰 | 最戏剧、最有张力 |

- **服装上的表现**：灰调底+一个高纯度点缀=在静奢/老钱/通勤风里很出效果（全身灰蓝/灰粉/奶白，加一只克莱因蓝手袋）；反过来（高纯度底+灰点缀）在想要日常内敛感时偏吵，在波普/街头风里反而是对的。
- **踩坑提示**：在你想要"耐看、安静"时，全部高纯度会很冲，全部低纯度会闷——通常需要纯度差来制造主次。但波普/多巴胺本来就要全高饱和，莫兰迪本来就要全低饱和，那是风格选择。

### 2.4 冷暖对比

- **本质**：暖色系（红橙黄）vs 冷色系（蓝绿紫）的对抗。
- **服装上的表现**：全暖→秋冬/大地/节日（驼+焦糖+奶+赭石）；全冷→春夏/科技/职场（藏青+雾蓝+银+白）；冷暖对撞→张力最强，日常风里常见面积 7:3 或反过来（经验参考，不是硬标准），波普/拼贴/先锋风可以对半。
- **季节暗示**：暖调→秋冬/节日/食欲/亲密；冷调→春夏/职场/距离/专业——这是大众心理联想，不是物理定律。
- **踩坑提示**：在你想要"调性统一"时，一身衣服里**冷暖摇摆不定**（一半暖一半冷又没有主次）容易显乱。通常定一个主调，另一个做点缀；但波西米亚/拼贴/民族风本来就是冷暖混搭，那是它的语言。

### 2.5 补色对比

- **本质**：色环 180° 相对的色对（红-绿、蓝-橙、黄-紫）。
- **服装上的表现**：视觉冲击最强、最容易视觉疲劳。**当你想要日常/内敛/高级感时，常见用法**：一个做大面（70% 左右，降纯度），一个做小面（10–15%，拉纯度点睛）（经验参考，不是硬标准）。但秀场/波普/节日/品牌视觉本来就要强补色对撞，那是对的。

| 补色对 | 日常/内敛风常见打开方式 | 备注 |
|---|---|---|
| 红↔绿 | 酒红（深降纯度）+ 墨绿（降纯度）+ 金点缀=节日高级；想要节日/圣诞/民俗感时可保留正红+鲜绿 | 后者在日常通勤会偏跳，但在节日主题里是对的 |
| 蓝↔橙 | 藏青/雾蓝（降纯度）+ 焦糖/南瓜橙（小面积）=秋冬经典；想要活力街头感时可用宝蓝+亮橙 | 后者在街头风里是对的 |
| 黄↔紫 | 芥末黄（降纯度）+ 薰衣草紫（小面积）=复古高级；想要先锋/蒸汽波感时可用明黄+鲜紫 | 后者在先锋风里是对的 |

### 2.6 五种对比怎么组合用

| 我想要的风格 | 主用哪种对比 | 辅助哪种 |
|---|---|---|
| 高级、静奢、老钱 | 明度对比（拉开三档） | 纯度对比（整体降纯度） |
| 莫兰迪、温柔 | 纯度对比（全低纯度） | 邻近色相对比 |
| 街头、多巴胺、年轻 | 纯度对比（点缀拉满） | 色相对比（强/极强） |
| 经典、通勤、永恒 | 明度对比（中/长调） | 无彩色 + 一个主色相 |
| 秋冬、温暖、大地 | 冷暖对比（全暖） | 纯度对比（中低） |
| 春夏、清爽、科技 | 冷暖对比（全冷） | 明度对比（高明度） |
| 暗黑、哥特、神秘 | 明度对比（低明度） | 纯度对比（低纯度 + 一个高纯度点缀） |

## 三、色彩调和：四种调和方法的操作步骤

> PTS 的四种调和是**纹样层面**的结论。本节是**服装整体造型**的操作步骤。

调和 = 让一组颜色"看起来像一家人"的方法。冲突的配色不是不能用，是要用对调和方法让它和谐。

### 3.1 同一色相调和（单色 / Monochromatic）

- **做法**：同一个色相，只变明度和纯度。
- **操作步骤（推荐流程，可按自己习惯调整）**：选一个主色相 → 拉 3–5 个明度/纯度梯度（深→中→浅）→ 服装按梯度分配（最深在外套/下装，中间在主单品，浅在内搭）→ 鞋包呼应其中一档。
- **效果**：在静奢/老钱/极简风里，通常显得最安全、最显高、最易穿；想要活泼跳脱时这个方法会偏闷。
- **适用**：静奢、老钱、极简、职场、小个子想要显高的搭配。
- **踩坑提示**：全部同明度在你想要层次时会显闷——通常需要拉开明度梯度（深/中/浅三档）；但侘寂/柔焦风本来就要"糊成一片"的同明度，那是对的。

### 3.2 类似色相调和（邻近色 / Analogous）

- **做法**：色环上相邻 2–3 个色相（夹角 30–60°，经验参考，不是硬标准）。
- **操作步骤（推荐流程，可按自己习惯调整）**：选起始色相，顺时针/逆时针取相邻 1–2 个（如橄榄绿→黄绿→芥末黄）→ 定一个主色（约 60%）、一个辅色（约 25%）、一个点缀（约 10%）（经验参考，不是硬标准）→ **想要和谐感时统一纯度**（都加灰调，不要一个艳一个灰）→ 中间用无彩色过渡留白。
- **效果**：在波西米亚/自然风/文艺风里通常显得自然、和谐、有变化不单调。
- **适用**：波西米亚、自然风、秋冬大地、文艺。
- **踩坑提示**：三个色相都高纯度在想要和谐时会偏花哨；**想要和谐时统一纯度通常是关键**。反过来，波西米亚/拼贴风本来就要纯度参差，那是对的。

### 3.3 对比色相调和（远距色 / 但不是互补）

- **做法**：色环上距离较远（90–150°，经验参考）的两个/三个色相，靠**中性色过渡**让它们和谐。
- **操作步骤（推荐流程，可按自己习惯调整）**：选两个对比色相（如蓝+橙）→ **想要日常耐看时各自降纯度一档**（不要直接用纯光谱色）→ 中间用无彩色（米白/灰/黑）做过渡层（上身穿 A，中间夹白衬衫，下身穿 B）→ 面积约 7:3 或 6:3:1（经验参考，不是硬标准）。
- **效果**：在你想要"有张力但不刺眼"时，比互补色柔和。
- **适用**：高级时装、街头、想撞色又怕太冲。
- **踩坑提示**：直接两个高纯度对比色贴在一起，在日常风里会偏俗；**想要耐看时中性色过渡层通常很有用**。但先锋/波普风本来就要硬碰硬，那是对的。

### 3.4 互补色相调和（Complementary）

- **做法**：色环 180° 相对的色对。
- **操作步骤（推荐流程，可按自己习惯调整）**：选一个主补色对（如蓝+橙）→ **当你想要日常耐看时，主色降纯度、做大面积**（雾霾蓝外套约 60%）→ **补色拉纯度、做小面积点缀**（焦糖橙手袋/内搭边约 10%）→ 中间用无彩色填充（米白/灰约 30%）。日常风里通常避免两个补色 50/50 对撞；但秀场/波普/品牌视觉本来就要对半撞，那是对的。
- **效果**：在你想要出片/记忆点时，最强刺激、最有记忆点。
- **适用**：秀场、街头、多巴胺、品牌视觉、想"出片"的场合。
- **踩坑提示**：日常风里两个补色面积对半会偏跳、两个补色都高纯度会偏吵；**补救方法**：把其中一个加黑/加白/加灰，降低纯度或改变明度。

### 3.5 无彩色调和（黑白灰 + 一个点缀）

- **做法**：黑/白/灰/米/驼做基底，只加一个有彩色点睛。
- **操作步骤（推荐流程，可按自己习惯调整）**：全身约 90% 用无彩色或中性色 → 选**一个**有彩色，给约 5–10% 面积（包/鞋/围巾/口红/耳饰）（经验参考，不是硬标准）→ 这个有彩色**可以拉纯度**（因为面积小，通常不会吵）。
- **效果**：在你想要稳妥、百搭时，最不容易翻车。
- **适用**：职场、初学者、商务、任何不敢确定的时候。
- **踩坑提示**：日常风里点缀色超过 2 个通常会乱；想要视觉焦点明确时**通常只加一个**。但波普/拼贴风本来就要多点色，那是对的。

## 四、色彩情感与九调：调性定位速查

### 4.1 主要色相的情绪与文化联想

> 速查见 `design-language-dictionary.md` 第五节和 `board-dictionaries.md` 9.1②。这里补充**文化关联**和**使用边界**（什么情况下不能用）。

| 色相 | 核心情绪 | 文化/场景联想 | 服装使用边界 |
|---|---|---|---|
| 红 | 热烈、力量、警示、喜庆 | 中国节庆/婚礼、革命、性感、危险 | 全身正红只做礼服/节庆；日常用酒红/砖红降纯度 |
| 橙 | 活力、温暖、食欲、丰收 | 运动、外卖、万圣节、秋日 | 全身橙很挑人；做点缀（鞋/包）最安全 |
| 黄 | 乐观、明亮、警示、幼稚 | 快餐、出租车、婴儿、柠檬 | 明黄显黑显黄皮；日常用芥末黄/姜黄降纯度 |
| 绿 | 自然、生机、平静、军旅 | 环保、军队、医院、生长 | 正绿挑人；日常用墨绿/橄榄/鼠尾草绿 |
| 蓝 | 冷静、信赖、专业、深邃 | 职场、牛仔、科技、企业 | 最安全的色相；藏青/雾蓝/牛仔蓝是万能基底 |
| 紫 | 神秘、高贵、梦幻、前卫 | 皇室、LGBT、蒸汽波、宗教 | 紫显黑，黄皮慎选亮紫；日常用灰紫/薰衣草 |
| 粉 | 柔美、少女、浪漫、Coquette | 甜、芭比、春天、女权 | 灰粉/裸粉比亮粉高级；亮粉只做少女/Coquette |
| 棕/驼 | 温暖、复古、可靠、大地 | 学院、美式、咖啡、秋 | 最安全的暖中性色；全身驼=老钱 |
| 黑 | 庄重、酷、正式、哀悼 | 西装、葬礼、哥特、极简 | 万能色；但全身黑+黄皮=显憔悴 |
| 白 | 纯净、清新、简约、新娘 | 婚礼、医护、极简、夏天 | 白显膨胀；纯白挑肤色，象牙白/米白更安全 |
| 灰 | 中立、高级、克制、雾感 | 职场、极简、工业、侘寂 | 万能调和色；灰让任何颜色变高级 |

### 4.2 九调（明度 × 纯度）氛围分类

> PTS 的九调表是**纹样**视角。这里是**服装系列**视角的调性选择。

| | 低明度（深） | 中明度（中） | 高明度（浅） |
|---|---|---|---|
| **高纯度（艳）** | 深艳调：厚重浓烈、节日、礼服、国风重彩 | 中艳调：鲜明活力、波普、多巴胺、运动 | 浅艳调：明亮轻快、春夏、少女、童装 |
| **中纯度** | 中深调：沉稳典雅、秋冬、通勤、学院 | 中中调：舒适日常、基础款、胶囊衣橱 | 中浅调：清新柔和、春夏、田园、通勤 |
| **低纯度（灰）** | 灰深调：暗黑高级、哥特、Noir、高定 | 灰中调：莫兰迪、极简、静奢、知性 | 灰浅调：温柔奶油、奶茶、仙气、少女感 |

**怎么用九调定位一个系列**（推荐流程，可按自己习惯调整）：
1. 先定**明度**：这个系列是深（秋冬/暗黑/厚重）、中（日常/通勤）、还是浅（春夏/轻盈）？
2. 再定**纯度**：这个系列是艳（多巴胺/街头）、中（基础/舒适）、还是灰（内敛/莫兰迪）？
3. 交叉点就是这个系列的调性定位。
4. **想要系列感强时，通常一个系列聚焦一个调性**，不要在同一系列里同时出现"深艳调"和"灰浅调"——那读起来像两个系列。但拼贴/混搭/概念系列本来就要调性对撞，那是它的语言。

## 五、配色方法体系（重点）：八种方法的比例、场景与踩坑

> 这是本文件的核心。速查表见 `design-language-dictionary.md` 五·附①。本节展开**每种方法的具体操作比例、适用场景、常见错误**。
>
> **关于下面所有百分比/角度/面积数字**：都是经验参考，不是硬标准。60-30-10 是经典配比，但波普可以 5:5、极简可以 9:1、先锋可以完全打破——一切看你要什么风格。

### 5.1 同类色配色（Monochromatic）

| 维度 | 内容 |
|---|---|
| 色环关系 | 同一色相，靠明度/纯度变化 |
| 配色比例 | 深 60% / 中 30% / 浅 10%（外套/主单品/内搭） |
| 视觉效果 | 最安全、最显高、最显贵、最极简 |
| 适用场景 | 静奢、老钱、极简、职场、小个子、胶囊衣橱 |
| 典型示例 | 全身驼色系（深驼大衣 + 驼色毛衣 + 米白裤）；全身藏青系（藏青西装 + 中蓝衬衫 + 浅蓝牛仔） |
| **容易踩的坑** | ① 三档明度拉不开 = 闷；② 全部同明度 = 没层次；③ 没有一个点睛色 = 平淡 |
| 补救方法 | 加一个**不同色相但低纯度**的小点缀（如驼色系里加一只灰蓝包） |

### 5.2 邻近色配色（Analogous）

| 维度 | 内容 |
|---|---|
| 色环关系 | 相邻 2–3 色（30–60°） |
| 配色比例 | 主色 60% / 辅色 25% / 点缀 10% / 无彩色 5% |
| 视觉效果 | 自然、和谐、有变化不单调 |
| 适用场景 | 波西米亚、自然风、秋冬大地、文艺、复古 |
| 典型示例 | 橄榄绿 + 芥末黄 + 卡其（暖邻近）；雾蓝 + 灰绿 + 薰衣草（冷邻近） |
| **容易踩的坑** | ① 三个色纯度不一致（一个艳一个灰）= 乱；② 没有主色 = 平均用力没重点；③ 选了距离太远的色（>60°）= 不是邻近色了 |
| 补救方法 | 把三个色统一加一层灰调（统一纯度），定一个主色 |

### 5.3 对比色配色（Contrast / 远距但非互补）

| 维度 | 内容 |
|---|---|
| 色环关系 | 距离 90–150° 的色对 |
| 配色比例 | A 色 60% / 中性过渡 25% / B 色 15% |
| 视觉效果 | 有张力、有活力、比互补柔和 |
| 适用场景 | 街头、休闲、想撞色又怕太冲 |
| 典型示例 | 藏青 + 焦糖（蓝橙远距）；墨绿 + 砖红（红绿远距） |
| **容易踩的坑** | ① 两个高纯度直接贴 = 俗；② 没有中性色过渡 = 硬；③ 面积对半 = 抢 |
| 补救方法 | 中间夹一件白/米/灰做过渡层；把其中一个降纯度 |

### 5.4 互补色配色（Complementary）

| 维度 | 内容 |
|---|---|
| 色环关系 | 180° 相对（红-绿、蓝-橙、黄-紫） |
| 配色比例 | 主色 70%（降纯度）/ 中性色 20% / 补色 10%（拉纯度点缀） |
| 视觉效果 | 最强冲击、最出片；日常穿容易偏跳，秀场/街头/多巴胺里是对的 |
| 适用场景 | 秀场、街头、多巴胺、品牌视觉、节日 |
| 典型示例 | 雾霾蓝大衣 + 焦糖橙包；酒红裙 + 墨绿外套 + 金饰 |
| **容易踩的坑** | ① 两个补色 50/50 = 俗；② 两个都高纯度 = 吵；③ 日常穿全互补 = 像节日装饰 |
| 补救方法 | 主色降纯度做大面积，补色拉纯度做小点缀，中间夹中性色 |

### 5.5 三色配色（Triadic）

| 维度 | 内容 |
|---|---|
| 色环关系 | 色环均分 120° 三色（如红-黄-蓝） |
| 配色比例 | 主色 60% / 辅色 25% / 第三色 10% / 中性 5% |
| 视觉效果 | 平衡、有活力、热闹、艺术感 |
| 适用场景 | 复古、装饰艺术、波普、童装、艺术系列 |
| 典型示例 | 藏青 + 焦糖 + 芥末黄（复古三色）；墨绿 + 砖红 + 金（Art Deco） |
| **容易踩的坑** | ① 三个色面积平均 = 没重点；② 三个都高纯度 = 花；③ 没有主色 = 乱 |
| 补救方法 | 定一个主色占 60%，另两个一个降纯度、一个做小面积点缀 |

### 5.6 分裂互补（Split-Complementary）

| 维度 | 内容 |
|---|---|
| 色环关系 | 基色 + 其补色两侧的邻色（如蓝 + 黄橙 + 红橙） |
| 配色比例 | 基色 65% / 邻色1 20% / 邻色2 10% / 中性 5% |
| 视觉效果 | 强对比但比纯互补柔和、高级时装感 |
| 适用场景 | 高级时装、暗黑情绪、想撞色又要高级感 |
| 典型示例 | 蓝主 + 黄橙 + 红橙辅；绿主 + 红紫 + 黄紫辅 |
| **容易踩的坑** | ① 两个邻色都拉纯度 = 太冲；② 基色没拉开明度 = 糊 |
| 补救方法 | 基色拉开明度，两个邻色统一降纯度 |

### 5.7 无彩色 + 强调色（Neutral + Accent）

| 维度 | 内容 |
|---|---|
| 色环关系 | 黑/白/灰/米/驼基底 + 一个有彩色 |
| 配色比例 | 无彩色 90% / 强调色 10% |
| 视觉效果 | 最安全、最百搭、最不容易翻车 |
| 适用场景 | 职场、初学者、商务、任何不敢确定的时候 |
| 典型示例 | 全身黑/白/灰 + 一只克莱因蓝包；全身驼/米 + 一只酒红唇色/围巾 |
| **容易踩的坑** | ① 强调色超过 2 个 = 乱；② 强调色面积太大 = 抢；③ 全身无彩色没点缀 = 闷 |
| 补救方法 | 永远只加**一个**强调色，面积控制在 10% 以内（包/鞋/围巾/配饰） |

### 5.8 中性色 + 中性色（全大地/全黑白灰）

| 维度 | 内容 |
|---|---|
| 色环关系 | 全部无彩色或暖中性色（驼/咖/米/燕麦/可可） |
| 配色比例 | 靠明度梯度拉开（深棕 60% / 中驼 25% / 浅米 15%） |
| 视觉效果 | 最显贵、最静奢、最老钱、最不挑人 |
| 适用场景 | 老钱、静奢、秋冬、商务、高定、侘寂 |
| 典型示例 | 深棕大衣 + 驼色针织 + 米白裤 + 可可鞋；黑西装 + 灰衬衫 + 黑裤 |
| **容易踩的坑** | ① 全部同明度 = 像睡衣；② 没有材质对比 = 闷；③ 全棕 + 黄皮 = 显黄 |
| 补救方法 | 拉开明度梯度（深/中/浅），用材质对比（羊毛+丝绸+皮革）增加层次 |

### 5.9 八种方法怎么选

| 我的需求 | 选哪种 |
|---|---|
| 第一次做配色、怕翻车 | 无彩色 + 强调色（5.7） |
| 想显高级、显贵、静奢 | 同类色（5.1）或全中性（5.8） |
| 想日常、自然、不费力 | 邻近色（5.2） |
| 想撞色、出片、有记忆点 | 互补色（5.4）或分裂互补（5.6） |
| 想活泼、艺术、复古 | 三色配色（5.5） |
| 想有张力但不要太冲 | 对比色（5.3） |

## 六、服装色彩的特殊考量

### 6.1 视觉修正：不同色块在人体部位的面积分配

配色不只是"选哪几个色"，更是"**哪个色放上身、哪个色放下身、哪个色放中间**"。同一个颜色，放上身和放下身，视觉效果完全不同。

#### 6.1.1 基本规律

| 部位 | 用什么色 | 视觉效果 |
|---|---|---|
| 上衣（上身） | 浅色 / 高明度 | 显上半身轻、显脸亮、显高 |
| 上衣（上身） | 深色 / 低明度 | 显上半身重、显压个子、显成熟 |
| 下装（下身） | 深色 / 低明度 | 显腿细、显腿长、稳定 |
| 下装（下身） | 浅色 / 高明度 | 显腿粗、显膨胀、显活泼 |
| 内搭 | 浅色 / 白 | 拉长脸型、提亮整体、过渡 |
| 外套 | 深色 | 收缩、显瘦、压场 |
| 鞋包 | 与下装同色 | 延长腿部线条、显高 |
| 鞋包 | 与上衣同色 | 上下呼应、整体 |

#### 6.1.2 不同体态的配色策略

| 体态问题 | 配色方案 | 原理 |
|---|---|---|
| 整体显瘦 | 全身深色 + 纵向同色（裤鞋同色）+ 内搭浅色 | 深色收缩，纵向延伸拉长 |
| 显腿长 | 上浅下深 + 裤鞋同色 + 高腰线 | 下半身深色收缩，同色鞋裤延伸 |
| 显高（小个子） | 全身同色系（顺色）+ 高腰线 + 同色鞋裤 | 无横向切割，纵向线条连续 |
| 上半身胖（肩宽/背厚） | 上衣深色 / 下装浅色 + V 领 | 上身收缩，下身浅色平衡 |
| 下半身胖（梨形/胯宽） | 上衣浅色 / 下装深色 + A 字廓形 | 上身扩张，下身收缩 |
| 显脸白/亮 | 内搭/领子用浅色（白/米）靠近脸 | 浅色反光提亮肤色 |
| 显成熟/稳重 | 全身低明度 + 低纯度 | 深色 + 灰调 = 成熟 |

#### 6.1.3 色块切割的常见注意事项（当你想要显高显瘦时）

> 下面这些是"想要显高显瘦、纵向拉长"时的注意事项；如果你就是想要俏皮/比例感/横向切割的设计感，反过来用也完全可以。

- **想要显腿长时，避免在腰部用强烈对比色切割**（如上黑下白，正好在腰部分界）——视觉上容易显腿短、显五五分。
- **想要显高时，避免全身多个横向色带**（上衣红 + 腰封黑 + 裙子白 + 鞋黑）——视觉上容易切碎、显矮。但高街/复古风本来就要横切，那是对的。
- **想要显瘦时，避免上下都用膨胀色**（上浅下浅）——整体视觉上偏膨胀。
- **想要活泼时，避免上下都用收缩色**（上深下深）——视觉上偏沉闷；如果你就是想要暗黑/哥特/全黑酷感，那是对的。

### 6.2 肤色适配：冷皮 / 暖皮 / 中性皮

> 速查见 `design-language-dictionary.md` 五·附④。本节展开**怎么判断肤色 + 具体适合/回避的色相矩阵**。

#### 6.2.1 怎么判断自己/模特是冷皮还是暖皮

| 测试方法 | 暖皮 | 冷皮 | 中性皮 |
|---|---|---|---|
| 手腕血管颜色 | 偏绿/橄榄 | 偏蓝/紫 | 蓝绿都有 |
| 金银首饰 | 金饰好看 | 银饰好看 | 都可以 |
| 白纸对比法 | 脸偏黄/偏暖 | 脸偏粉/偏蓝 | 不明显 |
| 阳光下容易晒成 | 棕/小麦色 | 红/晒伤 | 先红后棕 |

#### 6.2.2 肤色 × 色相适配矩阵

| 色相 | 暖皮（黄/小麦/棕） | 冷皮（粉/苍白/橄榄） | 中性皮 |
|---|---|---|---|
| 橙 | ✅ 非常适合（南瓜/焦糖/赤陶） | ⚠️ 避开亮橙，可用灰橙 | ✅ |
| 黄 | ✅ 适合芥末/姜黄 | ❌ 避开明黄（显黄），可用灰黄 | ✅ 中黄 |
| 红 | ✅ 适合砖红/橘红/朱砂 | ✅ 适合玫红/酒红/蓝调红 | ✅ 正红 |
| 绿 | ✅ 适合橄榄/军绿/芥末绿 | ✅ 适合墨绿/松石绿/薄荷 | ✅ |
| 蓝 | ✅ 适合藏青/驼蓝 | ✅ 适合宝蓝/雾蓝/天蓝 | ✅ |
| 紫 | ⚠️ 避开亮紫（显黄），可用灰紫 | ✅ 非常适合薰衣草/紫罗兰 | ✅ |
| 粉 | ✅ 适合珊瑚/蜜桃/橘粉 | ✅ 适合玫瑰粉/樱花粉/冷粉 | ✅ |
| 棕/驼 | ✅ 非常适合（全身驼） | ⚠️ 避开太黄的驼，可用灰棕 | ✅ |
| 黑 | ⚠️ 全身黑显憔悴，加白内搭 | ✅ 非常适合 | ✅ |
| 白 | ✅ 象牙白/米白 | ✅ 纯白/冷白 | ✅ |
| 灰 | ✅ 暖灰/驼灰 | ✅ 冷灰/蓝灰 | ✅ |

#### 6.2.3 通用原则

- **靠近脸的颜色（领子/内搭/围巾）选对色相**，因为它直接映在脸上。
- **远离脸的颜色（裤子/裙子）容错率高**，可以随便玩。
- **不确定时，选中性色（黑白灰驼米）+ 远离脸的位置用彩色**——最安全。

### 6.3 季节适配：春夏秋冬 × 色彩调性

| 季节 | 明度 | 纯度 | 冷暖 | 典型配色 |
|---|---|---|---|---|
| 春 | 高明度 | 中高纯度 | 暖中带粉 | 樱花粉、鹅黄、嫩绿、浅蓝、米白 |
| 夏 | 高明度 | 高纯度 | 冷 | 白、天蓝、薄荷、柠檬黄、珊瑚 |
| 秋 | 中低明度 | 中纯度 | 全暖 | 焦糖、驼、芥末、赭石、橄榄、深红 |
| 冬 | 低明度 | 中低纯度 | 冷/深 | 藏青、炭灰、酒红、墨绿、黑、灰白 |

**季节×面料×色彩的联动**：
- 同样是蓝色：夏天用**高明度、冷调、薄面料**（天蓝 + 丝绸/棉麻）；冬天用**低明度、暖调、厚面料**（藏青 + 羊毛/呢子）。
- 同样是棕色：夏天用**浅驼 + 薄料**；冬天用**深棕 + 厚料**。

### 6.4 场合适配：五档场合的配色上限

| 场合 | 配色上限 | 纯度 | 明度 | 典型配色 |
|---|---|---|---|---|
| 职场/商务 | ≤3 色，无彩色 + 一个主色 | 中低 | 中 | 藏青 + 白 + 驼；黑 + 灰 + 白 |
| 日常/休闲 | ≤3 色，可邻近色 | 中 | 中高 | 牛仔蓝 + 白 + 卡其；橄榄 + 米 + 棕 |
| 约会/社交 | 可 3–4 色，可粉色/暖色 | 中 | 中高 | 灰粉 + 米白 + 玫瑰金；驼 + 奶茶 + 焦糖 |
| 婚礼/正式 | 同色系 + 光泽料 + 小撞色 | 中低 | 中高 | 酒红 + 米白 + 金；藏青 + 银 + 象牙白 |
| 秀场/赛事 | 可破三色，可强对比 | 高 | 任意 | 互补撞色、多色艺术表达、强对比 |

## 七、潘通 / WGSN 流行色体系应用

> 这是现有 FS 文件几乎空白的板块。机构流行色不是"直接抄"，是"**读它的逻辑，提取自己的配色**"。

### 7.1 潘通年度色 / 季度色怎么读

- **潘通年度色（Pantone Color of the Year）**：每年 12 月发布一个代表色，是一种**文化情绪信号**，不是让你全身穿这个色。
  - 例：2024 桃色 Fuzz、2025 摩卡慕斯 Mocha Mousse。
  - **正确读法**：这个色代表"今年的情绪关键词"——桃色 = 柔软/亲密/治愈；摩卡 = 温暖/踏实/复古。你要提取的是**情绪**，不是这个色本身。
- **潘通流行色趋势报告（Fashion Color Trend Report）**：每季（春夏/秋冬）发布 10 个左右的流行色，分两组：核心色（经典常青）+ 时尚色（本季新趋势）。
- **WGSN 季度色卡**：商业机构，提前 2 年预测，给品牌做生产参考。通常给 **5 个关键色 + 5 个基础色**，带配色比例建议（70-20-10）。

### 7.2 怎么从机构趋势里提取自己的配色（不照搬）

**不推荐的做法**：直接把潘通年度色涂满整个系列——在想要"有自己语言"时，容易像快时尚跟风；但如果你就是要做一个"年度色主题胶囊"，那也是一种明确的选择。

**推荐做法（四步提取法，可按自己习惯调整）**：

1. **读情绪，不读色值**：
   - 潘通说今年是"桃色 Fuzz"——情绪是**柔软、亲密、温柔、反力量感**。
   - 你要提取的是"今年大家想要柔软感"这个信号，不是桃色本身。
2. **从色卡选 1–2 个最契合你系列的色**：
   - 不要全用 10 个流行色。选 1–2 个做主色/辅色，剩下用自己的经典色压。
   - 例：你的系列是秋冬大衣——从当季色卡里选"摩卡慕斯"做辅色，主色还是你的经典藏青/驼。
3. **降纯度/改明度，变成"你的版本"**：
   - 机构色通常是标准纯度，你要做自己的调性调整。
   - 例：流行色是亮桃色——你做灰调桃色（加 30% 灰），变成"莫兰迪版桃色"，就是你的。
4. **用机构色做点缀，不做主角**：
   - 流行色给 10–15% 面积（包/围巾/内搭边），70% 还是你的经典中性色。
   - 这样既跟趋势，又不跟风。

### 7.3 流行色 × 经典色的配比公式

| 配比 | 用法 |
|---|---|
| 经典中性色 70% + 本季流行色 20% + 经典点缀 10% | 商业成衣最安全，跟趋势又不老气 |
| 经典中性色 50% + 本季流行色 35% + 对比色 15% | 时尚系列，趋势感强但有自己语言 |
| 本季流行色 60% + 中性 30% + 点缀 10% | 潮流/年轻线，大胆用趋势 |

### 7.4 怎么看 WGSN 色卡的配色逻辑

WGSN 每季会给：
- **5 个关键色（Key Colors）**：本季要主推的趋势色。
- **5 个基础色（Core Colors）**：常年卖的中性色。
- **配色建议**：哪几个色搭一起、比例多少。

**你的提取方法**：
1. 不要把 5 个关键色全用上——选 2–3 个和你系列气质合的。
2. 基础色直接用（黑白灰驼米藏青，这些永远是安全的）。
3. 关键色**降纯度一档**变成你的版本。
4. 按 70-20-10 分配：基础色 70%，关键色 20%，点睛 10%。

### 7.5 常见趋势机构的区别

| 机构 | 发布节奏 | 用途 | 怎么用 |
|---|---|---|---|
| 潘通年度色 | 每年 1 个 | 文化情绪信号 | 提取情绪，不抄色 |
| 潘通季度色卡 | 每季 10 色 | 成衣色彩参考 | 选 1–2 色做辅/点缀 |
| WGSN | 提前 2 年，每季 5+5 | 商业品牌生产参考 | 提取配色逻辑，降纯度改明度 |
| 流行织 趋势 | 国内机构 | 国内市场参考 | 类似 WGSN，国内本土化 |

## 八、配色决策流程：从"我要什么感觉"到"具体怎么配"

当客户/赛题给你一个模糊需求（"要高级""要秋冬""要显瘦"），可以按下面这个推荐流程走一遍——**它是参考路径，不是必须遵守的步骤，熟了之后可以按自己习惯跳步或调换顺序**。

### 第 1 步：定调性（明度 × 纯度 × 冷暖）

问自己三个问题：
1. 这个系列是**深 / 中 / 浅**？（明度）
2. 这个系列是**艳 / 中 / 灰**？（纯度）
3. 这个系列是**暖 / 冷 / 中性**？（冷暖）

→ 三个答案交叉 = 调性定位（查九调表）。

### 第 2 步：定主色相

- 这个系列的情绪关键词是什么？（热烈？冷静？自然？未来？）
- 从色相情感表里选**一个主色相**。
- 主色相定了，**不要中途换**。

### 第 3 步：定配色方法

- 我的需求是安全 / 高级 / 撞色 / 活泼？
- 从八种配色方法里选一种（查 5.9 速查）。

### 第 4 步：定面积比例

- 日常风里常见参考：主色约 60–70% / 辅色约 20–25% / 点缀约 5–10%（经验参考，不是硬标准；波普/先锋可以完全打破）。
- 主色放哪个部位？辅色放哪个部位？点缀放哪里？（查 6.1 视觉修正表）

### 第 5 步：定对比强度

- 我要高级感 → 拉开明度对比 + 降纯度。
- 我要年轻感 → 点缀拉纯度 + 强色相对比。
- 我要日常感 → 邻近色 + 统一纯度。

### 第 6 步：检查特殊约束

- 模特肤色是什么？（查 6.2 肤色矩阵，避雷）
- 什么季节穿？（查 6.3 季节表）
- 什么场合？（查 6.4 场合表，定配色上限）

### 第 7 步：自检三个"是不是"（针对日常/耐看风）

> 这三个问题是"想要和谐、有主次、耐看"时的自检；如果你要的是波普/拼贴/先锋风，这三条反过来成立。

- ✅ 明度有没有拉开三档？（想要层次但没拉开 → 容易糊；想要莫兰迪柔焦感时糊是对的）
- ✅ 纯度有没有主次？（想要耐看但全部一样 → 容易闷或吵；想要波普全高饱和时吵是对的）
- ✅ 面积有没有主次？（想要重点但平均用力 → 容易没焦点；想要三色均衡/国旗配色时平均是对的）

三个都符合你想要的风格 = 配色成立。

### 第 8 步：落色板

- 概念色彩板走 `design-boards.md` 03 节流程。
- 精确色值（TCX/TPG/hex）走企业色卡流程，人工落值。
