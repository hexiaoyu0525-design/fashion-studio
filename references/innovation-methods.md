## 0. 什么时候用我

`design-ideation.md` 管的是**灵感流程**：简报怎么写、参考怎么拆、形色质意怎么翻、系列语言怎么锁、怎么发散收敛。它回答"**从一个点子走到一件衣服，路上每一步怎么走**"。

本文件管的是**方法库**：当你的目标不是"做一件好看的日常衣服"，而是——

- 参加设计比赛（要评委记住、要有"为什么这样设计"的说辞）；
- 做概念系列 / 毕业系列 / 艺术表达（要有立场、要反常规）；
- 给品牌做差异化 capsule（要一眼看出"这是谁家的、为什么是这个季度的"）；
- 用户说"我要先锋一点 / 实验一点 / 不像成衣"——

时，翻开这里。它是一张**菜单**：告诉你服装创新一共有哪些路数可走、每条路长什么样、难不难、什么风格、怎么和结构/面料/系列搭配。不是教材，是点菜工具。

> 分工一句话：`design-ideation.md` 告诉你"怎么把灵感一步步做出来"；本文件告诉你"**在灵感变成衣服的每一步，有哪些不常规的做法可以选**"。两者配合：先用 ideation 把流程走通，卡在哪一步要"突破常规"时，来这里挑方法。
>
> 工艺落地细节（立裁怎么别针、纸样怎么转印、七族再造手法目录）不在本文：工艺表见 `technical-production-spec.md`，面料再造目录见 `material-lab.md`，本文只做**设计决策层**的选择。

## 1. 创新思维转化四法（把灵感变成设计动作）

`design-ideation.md` 第 4 节给了形/色/质/意四维拆解的通用流程。下面四法是它的**进阶版**——当四维拆解出来的结果"还是太常规、像普通成衣"时，用下面哪一种方式把灵感**推离舒适区**。

### 1.1 传统元素现代化转译（提取 → 抽象 → 重构 → 落地）

做新中式、做非遗转译、做"把某个朝代/器物/建筑穿在身上"的系列，常见的两种翻车方向（当你想要"当代设计感"时）：① 直接把纹样印上去（贴图，不是设计）；② 把形制原样照搬（戏服，不是当代服装）。**推荐做法是下面四步走**（可按自己习惯调整，不是必须）：

| 步骤 | 做什么 | 反例（别这么做） | 正例（这么做） |
|---|---|---|---|
| ① 提取 | 从传统对象里只抽**形式语言**：一根线、一个比例、一种关系，不抽图案本身 | 把冰裂纹整张印花印满裙子 | 只抽"裂纹从一个点发散、断续、有粗细变化"这条**线的逻辑** |
| ② 抽象 | 把形式语言提纯到几何级：去掉装饰细节，只剩最本质的形/线/节奏 | 保留青花瓷的完整山水人物 | 提纯成：青色+白色的面积关系、一笔重笔一笔枯笔的笔触节奏 |
| ③ 重构 | 把抽象后的语言**嫁接到当代服装结构**上：它出现在分割线？领口褶皱？门襟？包袋五金？ | 整件做成交领右衽的古装 | 裂纹逻辑变成西装前片的不对称分割线，青色只在滚边出现 10% |
| ④ 落地 | 校验三件事：当代人穿出门像话吗？工艺能做吗？拿掉文化标签它还成立吗？ | 宽袍大袖只能拍大片不能穿 | 用现代比例收短、用现代面料（羊毛/科技布）换掉绸缎，廓形落到当代 H/O |

**转译强度自检**（当你想要"当代东方感"而非"古装/贴图"时）：做完问"这件衣服放在当代街头，路人看得出来出处吗？"——
- 完全看不出来 = 抽象过头，文化关联丢了（如果你就是要纯当代抽象，无所谓）；
- 一眼看出是"某朝代古装" = 偏戏服感（如果你就是要做戏服/舞台装/复原款，那是对的）；
- 说不清出处但"有一种东方的味道" = 在当代转译这个目标下是常见的好结果。

**传统题材的三个安全取法**（对应 ideation 参考分寸尺）：
- **取比例不取形制**：宋器的收腰放量比例 → 当代服装廓形，不做宋制衣裳；
- **取工艺不取纹样**：苏绣的针法密度 → 局部工艺焦点，不绣整幅牡丹；
- **取意境不取符号**：园林的"留白/借景" → 服装的虚实关系（透与不透、露与遮），不做月亮门造型。

### 1.2 跨领域灵感迁移（从服装之外借造型语言）

服装本身的造型语言已经被几百年用尽了，真正的新意往往来自**别的领域**。迁移不是"画个建筑印花"，而是借那个领域的**造型逻辑**。

| 灵感来源 | 借什么过来 | 变成服装的什么 | 常见错位（别这么做） |
|---|---|---|---|
| 建筑 | 结构方式（承重墙/悬挑/拱/体块咬合）、材料对比（玻璃×钢×混凝土） | 廓形的体块感、硬挺结构件与软垂部分的对比、外露"骨架" | 直接把建筑照片印在衣服上 |
| 雕塑 | 体量关系（正负形/扭转/团块/单体感）、静态中的张力 | 肩/袖/裙的雕塑体积，身体被材料包裹后的形态 | 做成立体雕塑摆件不像衣服 |
| 自然 | 生长逻辑（叶脉放射/花瓣层叠/贝壳螺旋）、材质（蜂窝/羽毛/树皮） | 褶皱的放射逻辑、层叠的顺序、表面肌理 | 把花朵动物图案直接印花 |
| 科技/工业 | 结构暴露逻辑（机械管线/接缝/卡扣）、材料（橡胶/透明/工业尼龙） | 外露缝线、机能扣件、透明材质叠加 | 做成工服/防护服样式照搬 |
| 音乐/舞蹈 | 节奏（强弱拍/休止符）、动势（爆发/绵长/顿挫） | 系列款之间的节奏安排、一件衣服上松紧长短的对比 | 衣服上印音符 |

**迁移操作法**：选定一个跨域对象 → 不看它的"样子"，看它"**为什么是这个形状**"（受力？生长？功能？美学？）→ 把那个"为什么"翻译成服装的对应逻辑。例：贝壳螺旋 = "从一个起点层层包裹、每一层比上一层大一点、有固定旋转角度" → 服装上就是**从肩部锚点开始的螺旋缠绕裁片**，而不是印一个贝壳。

### 1.3 解构重组（把已有服装拆开重装）

最省力也最容易出"新意"的路：拿一件**已经成立的常规衣服**（白衬衫/T恤/西装/牛仔裤/大衣），故意违反它的使用方式。这是低成本高辨识度的创新，赛事和 capsule 常用。

四种基本拆法（可叠加）：

| 拆法 | 动作 | 效果 |
|---|---|---|
| **里外翻转** | 把衣服的内里当外面：缝份外露、包边露出来、衬里面料朝外、标签挂外面 | 未完成感、手工感、反精致 |
| **错位重组** | 裁片重新拼时位置挪一挪：门襟缝到侧面、领接到腰、袖窿开在后背 | 结构意外、穿着方式被改写 |
| **上下颠倒/左右换位** | 下摆当领口、后片当前片、两只袖子一长一短、前后衣片不等长 | 不对称、不规则、实验感 |
| **增减构件** | 去掉常规服装"本该有"的东西（没有领子/没有扣子/没有侧缝），加上"本不该有"的（多一个袖子/多一层内衬外露/肩带从腋下走） | 反常规、概念性 |

> 解构不是"乱剪一刀"。反面教材见 ideation 负面词库里的"无意义的破洞与解构、到处镂空"。**当你要的是"有说法的解构"（赛事/品牌 capsule 需要讲设计理由时），通常每一处反常都要有理由**（为什么门襟在侧面？因为要展示穿着者从侧面进入这个动作），评委追问"为什么"时答得上来。但如果你要的就是"无意义解构/邋遢街头/反设计"美学，那乱剪本身就是风格。

### 1.4 概念驱动法（从一个词推导出全套设计）

反过来做：先有一个**概念词/一句立场**，再让造型、色彩、面料全部服从它。适合毕业系列、赛事、有命题的合作。

操作链：

```
一个概念词（如"边界的消解"）
  → 拆成 3–4 个视觉解释（什么叫边界？衣服和身体的边界？内外的边界？性别边界？场合边界？）
  → 每个解释选一个设计动作（内外边界消解 = 透明材质叠穿；性别边界消解 = 雌雄同体廓形）
  → 全系列所有款都在"从不同角度回答同一个问题"
```

**概念词常见来源**：一个社会观察（工作与生活边界消失）、一个哲学命题（遮蔽与暴露）、一种材料行为（面料自己会站立）、一种身体状态（静止 vs 运动中的服装）。
**避坑提示（当你要做赛事/毕业系列、需要讲概念时）**：概念词如果只是形容词堆砌（"高级""未来感""东方美学"），比较空；更扎实的概念通常是**一个可被多角度回答的问题**，例如"衣服能不能反过来穿？""当面料不需要人穿着也能保持形状？"——如果你做的是商业胶囊不需要强概念叙事，形容词方向也能用。

## 2. 创新结构设计

结构是衣服的骨架。成衣结构追求"合身、隐形、合理"；创新结构追求"**让人多看一眼骨架**"。

### 2.1 解构主义设计语言（deconstruction）

不是某个设计师的专属风格，而是一套可调用的结构语言，核心是**暴露本应被隐藏的东西、打破本应被遵守的规矩**：

- **暴露结构**：缝线、缝份、包边、衬里、里布、省道、扣眼、别针——成衣里藏起来的全露出来当装饰；
- **未完成感**：毛边、散口、未收边、半成品状态、样衣状态直接穿出门；
- **反常规穿着**：一件衣服可以正穿反穿、两穿、当裙子当上衣、左右脚不同鞋（服装层面）；
- **层级打乱**：内衣外穿、睡衣外穿、正装和运动装结构混接。

> 使用分寸（当你要做商业系列/有正常款衬托时）：解构语言用在**一个系列的 2–3 个款**做亮点通常更有力；全套都解构时，解构就不再是对比点，而变成整个系列的语言——这在纯先锋/解构品牌里是对的，在商业系列里容易没重点。解构款旁边配"正常款"衬托，对比出解构的意义；如果你做的就是全解构品牌，无所谓。

### 2.2 不对称与不规则剪裁（asymmetry）

| 类型 | 做法 | 视觉效果 | 适用 |
|---|---|---|---|
| 左右不对称 | 前后中线两边不一样：一袖长一袖短、单侧开衩、单肩 | 动态感、个性、不刻板 | 礼服、晚装、概念款 |
| 前后不对称 | 前短后长、后片有抽褶前片无、背面是设计重点 | 背面惊喜、行走时的变化 | 连衣裙、风衣、大衣 |
| 斜裁（bias） | 布料斜四十五度裁，利用斜向垂性 | 贴身流动、沿身体曲线螺旋、浪漫 | 礼服、吊带裙、垂坠款 |
| 局部不对称 | 整体对称，只在一个细节破掉（单侧口袋、单侧蝴蝶结） | 小而精的记忆点，不挑人 | 商业品牌差异化、通勤款 |

**不对称不是"做坏了的对称"**：好的不对称是**有意的平衡**——左边重了什么，右边用别的东西找补（视觉均衡，不是镜像复制）。AI 出图常见"左右不对称（非设计）"——那是模型手滑，要在提示词里写成"有意的不对称设计、单肩、单侧结构"，和 bug 区分。

### 2.3 立体剪裁 vs 平面剪裁的创意选择

| | 平面剪裁（flat pattern） | 立体剪裁（draping） |
|---|---|---|
| 逻辑 | 布是平面几何块，通过省道/分割贴合身体 | 布直接在人台上捏、别、绕，跟着材料脾气走 |
| 擅长 | 结构清晰的合体款、西装、衬衫、量产 | 流动的褶皱、雕塑体积、垂坠造型、不规则 |
| 创意产出 | **结构创新**：分割线游戏、新省道位置、块面组合 | **形态创新**：褶皱、缠绕、包裹、体积 |
| 适合的风格 | 建筑感、几何、理性、未来感 | 浪漫、感性、雕塑、艺术感 |

> 实操提示（工艺细节见 `technical-production-spec.md` 创意立体造型制版节）：想做"褶皱/垂坠/雕塑感"系列，从立裁入手；想做"分割线/几何块/结构重组"系列，从平面纸样游戏入手。两者可以混用——立裁出造型、平面补结构。

### 2.4 模块化设计（可拆解 / 可变形 / 一衣多穿）

把衣服当成**可以重新组合的单元**，而不是一件固定的东西：

- **可拆解**：外套拆成马甲+袖子两件；裙子的一片可以卸下来当围巾；
- **可变形**：一件大衣通过系带/扣子/暗扣在长与短、宽与收、穿与披之间切换；
- **一衣多穿**：正反两面不同材质不同色；一件连衣裙多种穿法（露肩/挂脖/正常）。

创新价值：① 叙事上回应"可持续/胶囊衣橱"概念；② 商业上一个款卖多次理由；③ 系列里天然产生"变化维度"（同一件的不同穿法 = 不同 look）。适合：概念可持续系列、旅行胶囊品牌、赛事"创新穿着方式"命题。

## 3. 创意立体造型手法库（核心速查表）

这是本文件最常用的一节。每种手法：**视觉特征 → 适用部位 → 工艺难度 → 风格定位 → AI 提示词锚点**。（工艺落地步骤见 `technical-production-spec.md`，本表只管设计选型。）

| 手法 | 视觉特征 | 适用部位 | 工艺难度 | 风格定位 | 提示词锚点 |
|---|---|---|---|---|---|
| **抽褶/碎褶** gathering | 布被收拢后形成细密均匀的褶，量感集中在收束点 | 领口、袖口、腰、肩、裙身 | ★☆☆ | 浪漫、柔、仙女感（日常商务风里过量容易显甜腻，看风格） | 密致抽褶、收褶荷叶量、肩线碎褶 |
| **压褶/百褶** pleating | 固定方向的规律褶（细褶/太阳褶/工字褶），褶线锋利、面料被定型 | 整裙、整袖、前片拼接条 | ★★☆ | 未来感、秩序感、动态展开（走路时褶会动） | 定型百褶、锋利压褶、放射太阳褶 |
| **缠绕** wrapping | 布在身体上绕圈裹缠，形成斜向层叠与交叠边 | 躯干、腰、裙 | ★★☆ | 围裹感、东方感、包裹身体 | 裹身缠绕、斜向叠片、交叠门襟 |
| **垂坠/悬垂** draping | 布从一个锚点（肩/胸/腰）自由垂落形成自然褶浪，重力驱动 | 肩胸、裙侧、领口 | ★★☆ | 希腊式、流动、慵懒高级 | 自然垂坠褶浪、肩点锚定悬垂 |
| **斜裁螺旋** bias twist | 斜向裁片沿身体螺旋缠绕，贴身且有扭转动线 | 整件裙、礼裙 | ★★★ | 流体、性感优雅、贴身曲线 | 斜裁螺旋裙、扭转贴合 |
| **折叠/折纸感** origami fold | 布料折成硬挺块面，有清晰棱线，像纸一样翻折 | 肩袖结构、裙摆、局部 | ★★★ | 建筑感、几何、艺术先锋 | 折纸块面、锋利折痕、几何折叠结构 |
| **膨胀/充体积** volume | 身体外被撑起夸张体积（泡袖/O型裙/气球感），内部有支撑 | 袖、肩、裙廓形、整件 | ★★★ | 夸张、戏剧性、雕塑感 | 夸张膨胀廓形、泡芙体积、内部支撑的圆润造型 |
| **填充/立裁塑形** padding | 局部填充出立体形状（胸垫结构、肩部垫高、臀部衬） | 肩、胸、臀、袖 | ★★☆ | 结构化身体、超现实身体感 | 内部填充立体造型、肩部垫高结构 |
| **荷叶边/层叠** ruffles & layering | 布料边缘卷曲成波浪状，或多层布片叠加 | 领口、袖、裙边、斜向条带 | ★☆☆ | 浪漫、少女、繁复（通勤风里过量会偏甜，Coquette/浪漫风里就是对的） | 层叠荷叶边、斜向波浪层 |
| **堆叠/堆叠褶** draping stack | 布在一个点堆积出丰厚褶皱团 | 肩、腰侧、裙腰 | ★★☆ | 雕塑感、厚重、戏剧性 | 局部堆积褶皱、腰侧布团造型 |
| **披挂/悬片** cape panel | 一片布从肩颈披下、不贴身，形成可动的外层片 | 肩背、外套 | ★☆☆ | 披风感、仪式感、东方 | 披挂外层片、肩背悬垂长片 |
| **结构外露/内衬外翻** exposed construction | 缝份、里布、衬、骨架暴露在外 | 整件、局部 | ★☆☆ | 解构、未完成、实验 | 缝份外露、里布外翻、毛边未收 |

**选型三问**（拿不准用哪个手法时，参考路径）：
1. **这个造型要"动"还是要"静"？** 动（走路有变化）→ 垂坠/百褶/悬片；静（雕塑体量）→ 折叠/膨胀/填充。
2. **要"柔"还是要"硬"？** 柔 → 抽褶/垂坠/荷叶；硬 → 折纸/折叠/填充。
3. **这个系列已经用了几个手法？** 一般来说一个系列聚焦 **2–3 种**主力手法（可以贯穿）会更统一（经验参考，不是硬标准）；其余款只重复不堆新。手法堆太多在你想要"系列聚焦"时容易像杂货摊——但波西米亚/拼贴/复古市集风本来就要丰富杂糅，那是对的。

> **AI 分界**：这些手法 AI 出**效果意象**很稳（写锚点即可），但"这褶立不立得住、会不会塌"必须人台/实物小样验证——尤其膨胀、填充、折叠，没有内部支撑 AI 画的体积现实中会垮。

## 4. 创意面料与再造（设计决策层）

面料**再造的完整手法目录**（七族手法、综合法、AI 创意面料、可持续材料）在 `material-lab.md`，本文不重复。这里只管三个**决策问题**。

### 4.1 什么时候该动面料（而不是选一块好料就行）

先回答：**不改造行不行？** 大多数成衣设计，选对面料就够了。只有三种情况值得再造：

| 触发条件 | 为什么需要再造 |
|---|---|
| 系列需要一个**独有的材料动作**（ideation 第 5 节"全系列在面料上做同一件事"） | 市面面料找不到你要的那个质感，必须自己造一块 |
| 概念需要**材料行为本身讲故事**（如"纸一样易破的衣服""会随身体改变形态的面料"） | 材料就是概念，不是配角 |
| 需要**单一来源的辨识度**：这块再造面料 = 品牌/系列的指纹 | 别人买不到、抄不走 |

反过来，**什么时候别再造**：企业订单要量产、成本敏感、交期紧——再造面料打样贵、不稳定，用现成面料把结构做对更重要。

### 4.2 混合材质对比作为设计策略

不改造任何一块布，把**两种性格相反的布拼在一起**，本身就是在静奢/高级时装/设计师品牌风里很常用的"调性杠杆"（与 ideation 6·5 ④材质冲突呼应）；如果你走的是全棉/全亚麻/统一质感的侘寂风，这条反过来用。

| 对比轴 | A 面 | B 面 | 效果 |
|---|---|---|---|
| 硬 × 软 | 皮革/挺括西装料 | 真丝/雪纺 | 边界被打破，刚柔并济 |
| 亮 × 哑 | 缎面/金属涂层 | 哑光羊毛/棉 | 光泽成为隐形分割线 |
| 厚 × 薄 | 粗花呢/毛呢 | 薄纱/透明网 | 体积与穿透的矛盾 |
| 天然 × 合成 | 亚麻/真丝 | 塑料感/科技面料 | 温度感与未来感碰撞 |
| 旧 × 新 | 做旧/ vintage 布 | 崭新亮面 | 时间层次、复古未来 |

**设计决策**：混合材质拼在哪里最出效果？——**当你想要"克制有重点"时，沿着结构线拼**（分割线两侧换料），让材质对比和结构线重合；日常风里一处对比就够，全身拼三种以上在你想要克制时会偏乱——但拼贴/复古拼布/拼色风本来就要多种材质拼，那是对的。

### 4.3 非常规材料的叙事用法

纸、塑料、金属、硅胶、3D 打印件、回收物……非常规材料的价值不在"新奇"，而在**它自带一个必须被说出来的故事**：

- **纸**：脆弱、一次性、反对"衣服耐穿"的常识 → 概念：快时尚批判；
- **塑料/回收塑料瓶织成的布**：环保叙事闭环（见 material-lab 第 3 节）；
- **3D 打印 / 硅胶**：精确、不可能手工做出的形状 → 概念：数字身体、未来皮肤；
- **金属 / 硬质材料**：身体被防护/被束缚 → 概念： armor、保护与禁锢。

> 边界提醒：非常规材料**几乎不可量产、穿着性差、易损**，天然属于赛事/概念/艺术系列。商业品牌最多用"点缀件"（一个金属肩饰、一颗 3D 打印纽扣），不用来做整件。

## 5. 系列化设计方法（从 1 个 idea 到 8–12 套）

`design-ideation.md` 第 5 节定了系列四条锁死（母题/材料动作/比例故事/记忆点）。本节解决它往下一层的问题：**锁死之后，怎么变出不重复的 N 套？**

### 5.1 一致性语言怎么"锁得不死板"

系列感 ≠ 8 套长得一样。真正的系列感是：**同一个语言在不同款上反复变奏**。锁死的应该是"语法"，不是"造型"：

- 同一个**母题**反复出现，但每次出现的位置/大小/方向不同（这一季的"裂纹分割线"在 1 号是前中缝、在 3 号是肩线、在 6 号是裙侧开衩）；
- 同一个**材料动作**贯穿，但面积比例变（每款都有压褶，有的压整件、有的只压一条袖）；
- 同一个**比例关系**保持，但松紧度渐变（全系列都高腰线，但裙长从膝盖到脚踝变化）。

### 5.2 变化维度（8–12 套 look 的变法清单）

一个 idea 展开成系列时，沿下面的维度系统变化，**每个维度扫一遍，不会重复**：

| 变化维度 | 怎么变 | 举例（同一母题） |
|---|---|---|
| 廓形 | H/A/O/X/T 轮着用，不要全套一个廓形 | 同母题：2 件 H、2 件 X、2 件 O、1 件斗篷、1 件 T |
| 色彩 | 主色不变，辅色/点缀色在款间轮换；有的款素、有的款有印花焦点 | 主色全系列统一，点缀色按 look 分配 |
| 材质 | 同一结构语言换面料性格（硬版/软版、亮版/哑版） | 西装料版 + 雪纺版 = 两个 look |
| 长短/松紧 | 长度梯度：短款 → 及膝 → 及踝 → 拖地 | 系列里有 2–3 个不同长度档位 |
| 穿着层次 | 有的单穿干净、有的叠穿两层、有的内外反差 | 叠穿款提供厚度节奏 |
| 性别模糊 | 同一廓形做男装版/女装版/中性版 | 拓宽系列叙事 |
| 场合梯度 | 从日装 → 晚装的过渡，有的日常可穿、有的偏礼服 | 兼顾买手可穿性和秀场高潮 |

**常见反例（当你想要"系列有节奏、有梯度"时）**：8 套全是连衣裙、全是长裙、全是黑白灰 = 在你想要节奏时会显得像一个款的配色表；但如果你做的就是"全连衣裙系列/全黑白极简胶囊"，那是明确的风格选择。

### 5.3 系列节奏（开场 / 高潮 / 收尾怎么排）

一场发布一个系列，look 顺序就是叙事节奏：

- **开场 2–3 套**：定调。廓形清晰、克制、能一眼说出"这季是什么"，不放大招；
- **中段**：展开变化维度，日装/基本款在这里铺开；
- **高潮 2–3 套（约在 2/3 处）**：全系列最先锋、最戏剧、最有记忆点的款放这里（最夸张的体积/最强烈的材质碰撞/最概念的结构），媒体照片从这里出；
- **收尾 1–2 套**：呼应开场但升一级，留下余韵（通常是最完整/最优雅的那件）。

> 一个常见误区（当你做发布排顺序时）：把最炸的款放在第 1 个出场——开场就用尽，后面容易是下坡。但如果你要的就是"开场即高潮、一上来就抓住眼球"的快闪/短视频发布，那也可以。

### 5.4 从 1 个 idea 展开到 8–12 套的具体操作

```
第 1 步：先画 3 张"母题款"（把核心母题最纯粹地各做一个方向）
第 2 步：从 3 张里选 1 个最强的当系列主力骨架
第 3 步：沿 5.2 变化维度表逐个维度变 → 每个维度产 1–2 个变体
        （廓形变一下 = 1 套；材质软硬版 = 2 套；长短梯度 = 2–3 套）
第 4 步：补 1–2 个"高潮款"（在主力骨架上把造型手法推到最极端，见第 3 节手法库选一个最戏剧的）
第 5 步：凑齐 8–12 套后，按 5.3 节奏排顺序，自检（针对想要"系列感强"的场景）：
        - 母题在每套都出现了吗？（想要系列统一但没出现 = 脱节；做胶囊混搭时不要求每套都有母题）
        - 有没有 2 套长得太像？（像 = 想要丰富变化时可考虑合并或再变一个维度）
        - 系列里"最安静的款"和"最炸的款"之间有梯度吗？（想要叙事节奏时，没有梯度 = 平铺；做全极简胶囊时无所谓）
```

## 6. 创新设计决策流程（本文件总入口）

接到一个"要创新/要先锋/要参赛"的任务时，可以按下面这个推荐顺序过一遍，逐层选方法——**它是参考路径，不是必须遵守的步骤，熟了之后可以按自己习惯跳步或调换顺序**：

```
① 先定灵感类型（在 design-ideation 已走完灵感流程后，问：这个灵感的"不常规"从哪里来？）
   ├─ 来自传统/文化题材？  → 走 1.1 传统元素四步转译
   ├─ 来自服装之外？       → 走 1.2 跨领域迁移
   ├─ 来自对现有衣服的反叛？ → 走 1.3 解构重组
   └─ 来自一个概念/立场？   → 走 1.4 概念驱动法

② 再定创新落在哪一层（一次主攻 1–2 层，别全上）：
   ├─ 结构层？ → 第 2 节（解构语言/不对称/立裁vs平面/模块化）
   ├─ 造型层？ → 第 3 节手法库选 1–2 个主力手法（柔还是硬？动还是静？）
   └─ 面料层？ → 第 4 节（该不该再造？材质对比怎么拼？非常规材料叙事是什么？）

③ 然后配系列（第 5 节）：
   锁一个母题贯穿 → 沿变化维度扫出 8–12 套 → 按开场/高潮/收尾排节奏

④ 最后过两道自检（针对赛事/品牌差异化这类"要讲设计理由"的场景）：
   - 解构/先锋款旁边有"正常款"衬托吗？（全先锋 = 在商业系列里容易无对比；纯先锋品牌无所谓）
   - 评委问"为什么这样设计"时，每一个反常处理都答得上理由吗？（答不上 = 在需要叙事的赛事里容易被追问；如果你做的就是"无理由美学/反设计"，那也是一种立场）
```

> 一句话总结本文件（带风格前提）：**当你要做赛事/品牌差异化/有说法的先锋系列时，创新不是堆怪东西，是选对方法、守住母题、让每一个反常都有理由**——如果你做的就是"无意义解构/反设计/邋遢街头"美学，那"没理由"本身就是风格。
