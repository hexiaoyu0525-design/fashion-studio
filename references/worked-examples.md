## 一、企业任务样例

企业一句话："帮我们做今年秋冬的新品。"

**补齐后的 brief：**
- 目标：秋冬上新 + 双十一订货会
- 季节波段：秋冬，分 3 波（9 月、10 月、11 月）
- 受众：28–35 岁都市通勤女性，客单价 800–1500
- 渠道：天猫旗舰店 + 小红书 + 订货会
- 交付物：每波段一组图 + 一条 15 秒上新片，整季一条品牌片
- 预算与时间：[由企业定]

**落到交付物矩阵（第一波）：**
- 款式/平铺/挂拍图：每款 4 张（正/背/侧/细节）→ image-garment
- Lookbook 系列图：8–12 张整季基调 → image-editorial
- 细节微距：每款 1–2 张卖点图 → image-detail-fabric
- 上新片 15 秒（竖屏 9:16，campaign）→ video-brief
- 整季品牌片 60 秒（横屏 16:9）→ video-film-types 品牌宣传片

## 二、生图样例

### 平铺（电商主图）

```
俯视平铺：一件驼色羊毛双面呢大衣整齐摆放在浅米色亚麻背景上，
旁边搭配一双棕色乐福鞋与一枚简约皮质卡包；
柔和均匀的顶部日光，自然柔和阴影，所有阴影朝同一方向；
50mm、f/8、正上方拍摄；可见羊毛织纹、门襟缝线与纽扣；
干净极简，中性低饱和色；1:1。
不要衣架、不要模特身体、不要文字水印、不要多余道具。
```

### 影棚 Lookbook（模特）

```
模特穿着驼色羊毛双面呢大衣，站直正对镜头，纯白无缝背景；
两个大柔光箱均匀棚光，无硬阴影；f/8 让整件衣服从头到脚清晰，
每条接缝、翻领、口袋都可见；头身比 1:9（无母版直出统一值），裆到脚底占身高 55%，
；五官、发型与肤色保持一致；
中性、专业、商业 lookbook 摄影，Kodak Portra 400 质感；3:4。
不改变大衣颜色与结构，不加帽子、包、腰带，不要塑料 CG，不要比例失真。
```

### 面料微距（工艺卖点）

```
微距特写：驼色羊毛双面呢的手工撬边接缝，100mm 微距 f/8，
方向性侧柔光让光扫过表面，清晰显露织纹、纱线与隐形式缝线；
浅景深，焦外柔和，纯聚焦材质与做工，不出现脸、不强调身体；
深驼色，铺满画面，高端纺织品质感摄影；1:1。
不要塑料感、不要错误针距、不要虚构缝线、不要过度锐化。
```

## 三、视频样例

### 竖屏电商 15 秒（campaign）

```
素材映射：@图片1 提供这件驼色羊毛大衣的结构、版型、配色与闭合件位置，不提供人物特征。
@图片2 只提供人物身份：五官、发型与身形比例，不提供服装与背景。
@图片3 只用于第 4 拍的袖口与前襟构造验证，不参与其余镜头。
@图片4 只提供窗边环境的空间与色调，不参考其中的人物。
@音频1 提供旋律与氛围。

一句话简报：模特穿着这件驼色羊毛大衣，在室内窗边自然光下，从静立整理衣领走到转身停步；
电商展示片，中性纪实质感，固定机位为主，浅景深。

0–3 秒：中景全长，固定机位，平视腰部高度。模特静立，抬手整理衣领；
领口、肩线、下摆、手、脚全部在画面内，不被裁切。
3–6 秒：固定机位，高度不变。模特做四分之一转身，展示侧面轮廓与背部结构；
大衣形态保持稳定，下摆不甩动。
6–9 秒：侧面跟拍。模特向前走两步，下摆自然摆动，展示羊毛垂坠与重量；
跟拍距离与速度稳定，模特不走出布光区。
9–12 秒：切到稳定特写。手指抚过袖口与前襟，主光沿表面移动，让缝合线与织纹清晰可读。
12–15 秒：回到中景正面，机位与前两镜同高。模特停住，大衣自然垂落，画面稳定。

全局约束：服装的结构、版型、配色、长度与闭合件位置始终与 @图片1 一致，
不随镜头变形、不改色、不改变长度、不增减任何配饰、不加任何未经指定的新配件。
人物的五官、发型与身形比例始终与 @图片2 一致；头身比 1:9（无母版直出统一值），裆到脚底占身高 55%，
。全片保持同一套布光逻辑与白平衡、浅景深。
变化只发生在动作、场景与光源三处。无字幕、无旁白，只保留布料声与室内环境底噪。
不要黑白、插画、玩具感渲染或塑料 CG，不生成运动路径、坐标轴或摄影机辅助线。
```

### 横屏 Moodfilm / 时装电影 30 秒

```
素材映射：@图片1 与 @图片2 分别提供这条真丝长裙的正面与背面：结构、版型、
准确配色及颜色位置、面料纹理与反光、接缝与配饰，不提供人物特征。
@图片3 只提供人物身份：五官、发型与身形比例，不提供服装与场景。
@视频1 只参考运镜与剪辑节奏，不复制其人物、服装与场景。

一句话简报：模特穿着真丝长裙，在深灰无缝背景影棚里，从静立到一次缓慢转身再回到静立；
编辑大片，单一硬主光，克制的米金与深灰双色，固定机位，浅景深，氛围重于叙事。

0–5 秒：中景全长，固定机位。模特静立，裙摆落地自然铺开；单一硬主光从左上 45 度打来，
右侧用旗板压住多余反光，深灰无缝背景；轮廓光在肩与发际形成细边；全片保持此光位。
5–10 秒：机位不动。模特小幅摆胯，真丝随动作荡开、下摆形成连续褶浪，再缓慢回落。
10–16 秒：切特写，机位固定。主光扫过前襟，绒面反光与褶皱层次逐层显出；
手指轻抚腰侧接缝，缝合线清晰可读。
16–24 秒：回到中景全长，机位与前两镜同高。模特缓慢完整转身，
先转出侧面再转到背面，交代背部开合结构与裙摆动态；节奏均匀不加速。
24–30 秒：转回正面停住，真丝缓缓落定，画面稳定，留下放一句短品牌名的余地。

全局约束：裙装结构、版型、配色及颜色位置、长度与接缝始终与 @图片1、@图片2 一致，
不随镜头变形、不改色、不改变长度、不增减配饰、不加任何未经指定的新配件。
人物五官、发型与身形比例始终与 @图片3 一致；头身比 1:9（无母版直出统一值），裆到脚底占身高 55%，
。全片只有一处主光位、一套白平衡和同一片无缝背景，不改变光位与色温。
变化只发生在动作、场景与光源三处。无字幕、无旁白，只保留布料摩擦声与室内底噪。
不要黑白、插画、故事板线稿、玩具感渲染或塑料 CG，不生成运动路径、坐标轴或摄影机辅助线。
```

## 弱写法 → 强写法

| 弱写法 | 强写法 |
|---|---|
| 让画面有高级感 | 单一硬主光从左上 45 度打来，深灰无缝背景，米金与深灰两色 |
| 展示裙子的质感 | 主光扫过前襟，真丝绒面反光与褶皱层次逐层显出 |
| 模特优雅地走动 | 向前走两步，下摆随步幅摆动，停步后缓慢垂下 |
| 情绪到位 | 眼眶微红，嘴角下压，呼吸变快 |
| 参考这个视频的风格 | @视频1 只参考运镜与剪辑节奏，不复制其人物、服装与场景 |
| 拍出面料高级感 | 羊毛，走动时整体摆荡、停步后缓缓垂下 |
| 工艺看起来很好 | 100mm 微距 f/8，方向性侧柔光显露织纹与隐形式缝线 |

## 企业 AI 素材开发全流程范例（东方美学品牌 · 非遗新系列）

> 通用虚拟示例，用于演示"设计前期（不含制版成衣）"的完整交付；品牌与数据均为示例。

**背景**：某东方美学品牌要做 2027 春夏"非遗新生"系列，设计前期由 AI 完成素材开发，最终交付 4 件东西。

### 四项交付物

| 交付物 | 数量/规格 | 关键要求 |
|---|---|---|
| ① AI 提示词库 | ≥20 条 | 五要素齐全，含 ≥5 条传统纹样；固定风格词 + 配色词 + 负面提示词 |
| ② 面料与纹样素材集 | ≥6 面料 + ≥6 纹样 | 高清图 + 生成参数记录；纹样无缝循环 |
| ③ 系列概念方案 PDF | 五板整合 | 灵感/配色/面料/图案/效果图，系列化五要素贯穿 |
| ④ AI 素材版权自查报告 | 四板块 | 风险清单/规避措施/合规声明/原创性证明 |

### 三个子系列（按调性分，文化母题只取公共元素）

| 子系列 | 调性 | 色彩 | 面料 | 纹样 |
|---|---|---|---|---|
| 白瓷 | 月白清雅 | 月白/米白/青白 | 桑蚕丝、棉麻 | 暗纹刻花 |
| 靛染 | 植物染浓色 | 靛蓝/赭石/藤黄/黛绿 | 植物染真丝 | 团窠、联珠、缠枝 |
| 水墨 | 做旧素色 | 墨黑/竹青/石灰 | 亚麻做旧 | 水墨晕染 |

### 分阶段推进（每阶段产出 + 验收）

1. **主题定位**：约 100 字主题定位 + 关键词；验收=能一句话说清"这季讲什么"。
2. **提示词库**：按五要素写 ≥20 条；传统纹样三步法（提取文化元素→保留构图→注入现代风格配色）；负面提示词不写品牌名/艺术家名；验收=固定风格词与配色词跨条复用。
3. **面料肌理**：≥2 个工具对比，每款记录提示词/参数/工具/评分；材质四要素写全；验收=可复现、无塑料感。
4. **印花纹样**：生成无缝循环（seamless/tileable/repeating），每款附文化说明（名称/寓意/重构思路）；验收=四方连续无接缝、母题可溯源。
5. **垫图/重绘/风格迁移**：做微调前后对比，每款填版权初审表（工具/提示词摘要/风险高中低/规避）；统一命名 `组别_素材类型_编号_v版本`。
6. **五板整合**：把素材整合成五板 PDF，检查系列化五要素与排版规范；图标字体查授权。
7. **版权自查报告**：四板块齐全、签字日期；无报告不提交。
8. **评审会汇报**：5 分钟汇报 + 3 分钟答辩，分角色（设计总监/企划/AI/合规）。

### 三级随件文字示范（图随文走）

- **L1 单素材**（贴在每张面料图后）：
  > 靛染-缠枝纹真丝-03 | 即梦 Seedream；正向"植物染真丝，缠枝纹，靛蓝主色，哑光柔光，中等厚度，垂感随步荡开"，无缝循环；无参考图；文化说明：缠枝纹寓意生生不息，重构为四方连续现代印花；风险：低。
- **L2 板块**（贴在图案板后）：
  > 图案板以靛染子系列的团窠、联珠、缠枝三纹构成，与配色板的靛蓝/赭石呼应，纹样在连衣裙、衬衫、半裙上做同体系延展，保证系列图案延续。
- **L3 项目**（汇报开场，约 100 字）：
  > "非遗新生"以传统染织纹样为母题，用 AI 把白瓷、靛染、水墨三种东方色调做成可生产的春夏通勤女装。所有廓形现实可制版，AI 只承担素材与效果图，造型、配色与版式由团队主导，全套素材可商用、可追溯。

### 评分对照（示例，四项权重）

提示词库 20% · 面料纹样素材集 30% · 系列概念方案 30% · 版权自查报告 20%。

## 参赛样例：AIGC 数字女装（以沙河杯 / Style3D 规格为蓝本）

**读题结论（先写死）**：4 套系列女装；企划 A3 横版 300dpi JPG + PDF；走秀 MP4 4K/16:9/60fps/60–90 秒；不做实物；无个人/院校标识。

**9 项企划逐项产出**：

1. 作品标题：《潮生》
2. 灵感板：岭南骑楼窗格、海边潮间带、晨雾灰调（贴 8–12 张参考图）
3. 色彩方案：主色雾蓝灰 Pantone 15-4502，辅助米白，点缀深青
4. 面料说明：数字真丝缎（垂坠、随动褶皱）+ 数字欧根纱（半透明层叠），无弹力
5. 标准款式图：每套正背面，标注 H 型/收腰、门襟、开衩、缝位
6. 虚拟效果图：4 套正/背/侧完整着装
7. 细节图：窗格暗纹提花、盘扣、袖口拼接
8. 设计理念：把岭南"潮起潮落"的节奏做成可量产的通勤女装（思路 + 文化 + 商业）
9. AI 创作说明：工具链（生图/虚拟走秀/3D）、流程、关键提示词、自主设计与 AI 辅助分界

**200 字概念（节选示范）**：
> 《潮生》以潮间带一天之内的光色变化为灵感：退潮时海面是雾蓝灰，清晨第一层光是米白。系列用 4 套通勤女装讲同一节奏——垂坠真丝缎对应平静的水面，层叠欧根纱对应被风掀起的浪。所有廓形都可现实制版生产，没有物理上无法成型的结构。它为需要在通勤与轻社交之间转换的女性设计。

**虚拟走秀视频备料**：套用 `video-brief.md` 四段式，虚拟模特依次走完 4 套，重点呈现廓形、面料垂坠、动态褶皱；材质规则全片统一；配乐贴合；无标识。

**提交前自查**：套数/尺寸/dpi/时长/帧率/比例是否逐项符合；3D 工程文件是否随附；AI 创作说明是否诚实披露工具与提示词；画面是否去标识；原创承诺书、报名表、命名是否齐。

## 高定系列端到端走一遍（含项目画布 / 审美基准 / 出图工单 / 成本档）

> 演示 `project-workflow.md` 的运行层，不是新领域知识。虚拟系列《瓷骨》，4 套高定球裙/鱼尾礼服，定位国际秀场级繁复（结构、珠绣、多层纱）。通用示例，无品牌。

### 0. 开工：建项目画布 + 快速启动

- 说"做个新系列，4 套高定礼服"，模式默认**协作**，语境按需=高定秀场（精致度档=高定，见 `category-guide.md`）。
- 复制 `assets/project-template.md` 为 `00_项目画布_瓷骨.md`；先盘点已有素材（一张瓷瓶参考图、一段秀场走秀动态视频），其余标"未定"。

### 1. 审美基准板（一次对齐，出对比图）

你没有明确方向，我给 3 个方向各 1 张 contact sheet（只变气质/色调，廓形先不锁）：
- A 冷白青瓷·克制留白；B 月白与香槟金·繁复珠绣；C 墨色窑变·结构主义。
- 你选 **A 的廓形气质 + B 的珠绣材质**（杂交）→ 收敛为"冷白青瓷底 + 局部香槟金细珠"，写进宪法风格 DNA。
- 参考分寸：瓷瓶/宋器取形取质（🟢）；**秀场图全绿**（🟢 可看/学/拆/垫、学布光、节奏与廓形语言，可作长期参考）；**拿秀场款当改造基底是行业常态**（改结构/面料/色彩即改造）；品牌老花/Logo 🔴 慎喂、不进终稿。

### 2. 设计宪法（锁定，节选）

| 维度 | 锁定 |
|---|---|
| 主题/母题 | 《瓷骨》；母题=冰裂纹分割线 + 瓷釉开片光泽 |
| 色 | 月白主、青白辅、香槟金点缀（领口/分割线珠绣）；60-30-10 |
| 面料 | 真丝缎（裙身）+ 欧根纱/硬网纱（罩层撑体积）+ 水溶蕾丝；材质四要素入卡 |
| 廓形·结构 | 1 球裙（crinoline）、2 鱼尾（corset 鱼骨）、1 鞘式斜裁；内置胸衣、骨架画面不外露 |
| 纹样/工艺 | 冰裂纹珠绣 + 立体花；珠绣交工厂须 .DST（AI 只给意象） |
| 人体 | 插画档 **9–10 头身**（效果图）；写实/照片向成片 1:9（无母版直出统一值），二者不混用 |
| 禁忌 | 不塌陷裙摆、不外露骨架、不廉价亮片、蕾丝不每张变 |

### 3. 发散与设计（先设计，后渲染）

## 品牌/设计师参照样例（点名品牌 · 无参考图）

场景：前期灵感 / 效果图阶段，用户没给参考图，只点名品牌或设计师做参照。核心是"**线索先翻译、确认后再出图**"，品牌名不进提示词。

### 样例 A：字典里有 → 翻译 + 对比小图

> 用户："帮我做一件 Margiela 感觉的外套，参考这个设计师"
>
> Agent（不开图，先翻译 + 补参数）：
> "我查了大师字典（design-language-dictionary 六·5）：Margiela → **解构重组 + 外露缝线 + 匿名极简**。你要的是这个方向吗？
> 再定 3 个点：① 用途（参赛 / 商用 / 练习？）② 品类细项（大衣还是夹克）③ 季节。
> 我先出 3 个方向对比小图：① 偏解构（破坏感浓）　② 偏静奢（线条干净）　③ 平衡版。"
>
> 用户："②，但袖子要①的错位感"
>
> Agent："锁定 **静奢极简 + 精准比例 + 错位袖缝** 进设计宪法。正式出图。"（提示词写锚点，不写品牌名）

### 样例 B：字典里没有 → 自己搜集 + 拆解（或按用户要求直接采用）

> 用户："参考一下 Lemaire，就想要那种松弛感"
>
> Agent："字典里没有 Lemaire，我查一下它的资料再拆（不直接出图）。
> ——（联网搜集：品牌理念'面料优先、日常奢简'、当季秀场关键词）——
> 按 3·7 七维拆解：**松弛知识分子 / 面料优先 / 慵懒克制廓形 / 大地色系 / 无 logo**。
> 你要的是这个吗？我出 3 个方向对比小图（偏 Lemaire / 偏极简 / 平衡）。"

- **直接挪过来**：用户明确说"就要那个感觉，直接按它做"——即以该品牌的风格语言为**基准语言**直接采用（拆解出的锚点整体采用，不再降量转译）；练习/内部交付全 🟢 可用；**公开交付**（参赛/商用/公开发布）仍按 `copyright-compliance.md` 转化到不可指认。
- **资料与字典的关系**：内置字典（六·5/六·6）是快查；**字典没有或想更贴近当季，可自己搜集**（联网查品牌设计理念/秀场/作品）→ 3·7 拆解 → 翻译成锚点。搜集到的品牌资料标 🟡 入调研板，来源可溯。
- **多条红线照旧**：品牌名/设计师名只用于内部理解与对话确认，**不进提示词、不进公开交付成片**；老花/Logo 慎喂垫图、公开交付不复现。
