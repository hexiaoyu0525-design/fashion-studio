# 设计表达：平面款式图 · 时装效果图 · 系列 Line-up · 细节图（07–09 · 11）

设计落地的四种图：**07 平面款式图**（无人体，给工厂看结构）、**08 时装效果图**（含人体，给人看感觉）、**09 系列 Line-up**（看整体系列）、**11 细节图**（放大工艺与材质）。板面尺寸/字体/网格统一见 `design-boards.md` 全局板面底座；材质微距与光位写法见 `image-detail-fabric.md`。

> **不同品类各有结构、面料、工艺与 AI 翻车点**（针织/牛仔/男装/童装/内衣泳装/羽绒户外/婚纱礼服高定/皮革等），出图前先查 `category-guide.md`；本篇讲四种图的通用画法。

> **顺序提示（编号 ≠ 创作先后）**：本篇按 07→08 排列只是"按图种归类"，**真实创作顺序是 08 效果图在前、07 款式图在后**——先用效果图把设计提案定下来，**定款之后**才画无人体的款式图给打版/工厂做技术翻译。前期三要素（款式·色彩·面料）与完整顺序见 `design-boards.md` 开篇；定稿后出商品图的渲染顺序见 `image-quality-sop.md`。

> **默认出图模型：Seedream 5.0 Pro**——写实渲染档（类摄影，企业订货/高定展示）属成品档、系列 Line-up 要跨图一致性，统一 Pro；时装画/装饰/前卫等媒介质感类不强制（Flash 也能出），但 Pro 不可用时统一降级 5.0 Flash/标准版（与 `SKILL.md` 生成工具默认档一致）。

**贯穿全篇的人体比例统一口径（一套数字，两条路径，详见 `image-quality-sop.md` 第五节）**：
- **无母版直出（写实/照片向）**：头身比 **1:9**、裆到脚底 **55%**，提示词写死这两组数字——本文件所有"真实人物穿着/实穿图/照片向"输出都用它。
- **有 Muse / Muse 着装真实效果图**：以 Muse 母版为人体比例基准继承、提示词不写数字（走 `image-editorial.md` 场景3）。
- **插画/时装画风格档**：9–10 头身，只用于本文件 08/09/11 明确"插画/风格化"时。
- 写实/照片向与插画档不混用；同一张图内只用一个口径。

## 07 ｜ 平面款式图 / 技术款式图 Flat Sketch　【语境：企业；赛事多要求】

无人体、正投影、无透视、无光影的服装结构图。企业订货场景它是**合同级文件**（绑 tech pack，工厂报价打样依据）；赛事场景只是叙事辅助。

### 生成前强制硬约束（必做，禁止跳过）

1. **款式图默认输出纯线稿**：所有AI直出的平面款式图，默认是纯黑色线条勾勒、**无任何填充色块、纯白背景**，禁止自动加面料色、材质渲染，只有用户明确要求带色款式图时才加填充。

2. **先判断品类结构再拆分**：生成款式图前先确认服装是分体套装还是连体款：
   - **分体套装**：拆成外套/上衣、内搭、下装（裤/裙），每个部件单独展示正视图+背视图
   - **连体款**（连体裤/连衣裙/连体衣）：不拆分，整体展示正视图+背视图
   - **禁止默认所有款式都按上下两件拆分**

3. **服装结构必须以纯白底原图为唯一锚点**：生成任何款式图前，必须先读取用户指定路径下的纯白底原图，逐处核对结构（领型、袖型、拼接位置、廓形、特殊设计），**禁止凭文件夹名称、旧路径素材、或之前的印象脑补设计细节**，避免出现串结构、错画设计元素的问题。

4. **提示词模板强制前置写死**：生成款式图时，提示词最开头必须写死"纯黑色线稿，无填充色块，纯白背景，无人体，正交投影"，并先明确该款是分体/连体结构，再写对应的拆分/整体要求，禁止省略这些强制项。

5. **线宽规范保持**：外轮廓粗黑线、内部结构细黑线、明线用细虚线，和工业打版规范一致。

---

### 放什么 / 不放什么

- 必放：**正视图 + 背视图（最低配置）**，必要时侧视/局部；轮廓线；内部结构线（分割线、公主线、省道、褶裥、拼接线）；明线（虚线）；闭合件（拉链长度、纽扣数量/间距、扣眼方向）；口袋；罗纹/贴边/滚边；**纱向线（grainline 箭头）**、对折线（点划线）、折边（双点划线）；部位代号；引出线 + 测量箭头 + 规格表；拼色边界配 Pantone。
- **不放**：人体头手脚腿脖子、五官发型、立体褶皱光影、3/4 透视、情绪背景（仅 presentation flat 可加极轻明暗）。

### 线宽三套口径（显式声明选用哪套，不伪装唯一）

| 口径 | 外轮廓 | 内部结构 | 明线 |
|---|---|---|---|
| 通用工业口径 | **1pt** | 0.5–0.75pt | 虚线/点线，段长 2–3mm、浅灰，间距 3–6mm |
| 制图线宽系列 d=0.25/0.35/0.5/0.7/1/1.4/2mm，优先 0.5 与 0.7，粗:中:细=4:2:1 | 粗 | 中 | 细 |
| 另一口径【经验值】 | 2.0pt | 内部细节 ≥0.5pt | — |

- 结构制图比例 1:2/1:5；款式图本身不受制图比例限制（可放大细节）。纱向线 2pt 箭头+标注。
- **门襟叠压方向（画错=工艺逻辑错误）**：女装右压左、男装左压右；**女装牛仔例外**（左压右）。
- 前门襟拉链约 7"（≈18cm）；最后扣位与下摆距离要更大；正装/晚装（盲缝）下摆不画虚线，休闲（牛仔/运动/泳装）画虚线。
- 输出 **矢量 .AI/.EPS/PDF**；位图放大锯齿会让缝纫工误读。
- 线条符号分类可参考 **FZ/T 80009-2004《服装制图》**（粗实线=裁片外轮廓、细实线=基础/尺寸线、虚线=下层轮廓与明线、点划线=对折/连折线、双点划线=折边/贴边）——**该标准号为行业转述，落地前核标准原文**。

### AI 直出款式图：可用，须严格约束（默认路径）

AI 直出款式图**完全可用**，前提是过「07.5 AI 直出约束清单」：正背分开出、对称靠提示 + 镜像后处理、计数锁定并逐项验收、工艺逻辑按行业规则写死、比例走**真实比例正交（无人体、to-scale）**。约束过完、验收通过的款式图可直接进流程；关键款/合同级款式图仍可用 Illustrator 收口做 to-scale 标注与 callout（可选，不再一刀切）。

> **比例注意**：款式图是**无人体、正投影、真实比例（to-scale，可测量）**的技术图纸，对应真实号型数据；**9–10 头身时装画比例只用于 08 效果图 / 09 Line-up / 11 人物态**，严禁把拉长人体套进款式图。

```
【主体】无人体、无头手腿的服装平摊视图，正视图+背视图并排
【品类与廓形】<女装衬衫>，<H 型直筒廓形>，<落肩>，<长袖>，<方领>
【结构】可见领型轮廓、门襟、口袋位置、下摆造型；线条干净闭合
【风格】时装设计手稿，平涂+细线，白底，无阴影，无透视；作人工描摹用结构参考
【参考】图1=廓形与部件位置；图2=领型/门襟细节；图3=配色与面料感觉（仅取色）
【禁止】不要人体、模特、五官、褶皱光影、透视、背景、文字水印、纽扣数量错误
```

工作流：Seedream 出 3–5 张氛围底图 → 选形 → Illustrator 单边绘制+镜像合并 → 分层（轮廓/内部/明线/闭合件）→ 补纱向、对折线、代号、callout、规格表 → 导 PDF+AI/EPS。

### 验收门

正+背齐全；0 人体部件；中线镜像一致；线宽 轮廓>结构>明线 同类一致；明线用虚线且带间距；闭合件数量/方向对、门襟叠压正确；有 grainline；callout 带参数；有规格表与公差；矢量 300dpi 无锯齿；同系列线宽/符号/字号统一。

### 07.5 AI 直出约束清单（款式图 · 工艺特写共用模板）

AI 直出"生产向"图纸不是碰运气，按这份清单出图，过完验收即可用。每项都要写进提示词或后处理，缺一项就回退重出：

| 约束项 | 写法 / 做法 |
|---|---|
| ① 视图 | 正视图 + 背视图**分开两张出**，不要并排挤在一张里（易互相污染）；必要时单独出侧视/局部 |
| ② 对称 | 提示词写"左右对称、中线居中、镜像一致"；出图后取中线做**镜像后处理**（PS 半幅复制翻转）锁死对称 |
| ③ 计数 | 闭合件数量写死并逐项验收：纽扣几颗/间距、拉链长度、扣眼方向、口袋数量与位置；验收数错即重出 |
| ④ 工艺逻辑 | 按行业规则写进提示词：门襟叠压（女装右压左、男装左压右、女装牛仔例外）、省道指向 BP、拉链与门襟关系、下摆明线（正装盲缝不画虚线、休闲画虚线） |
| ⑤ 比例 | **真实比例、to-scale、无人体**（见上「比例注意」）；写"正交投影、无透视、无人体、白底"；产出后可用参考图1 锁真实号型比例 |
| ⑥ 线条 | 线宽口径三选一（见 07 线宽表）；明线用虚线、浅灰；勾线干净闭合 |
| ⑦ 后期可编辑 | 位图出图后如需 callout/规格表/纱向/公差：导出矢量路径（Illustrator 镜像合并 + 分层），或由 Agent 按图补标注 |
| ⑧ 验收门 | 复用 07「验收门」全项：0 人体、中线镜像一致、闭合件数量/方向对、门襟叠压正确、有 grainline、可标注 |

**工艺特写**（11 节细节图同样适用）：提示词写死 缝型名称 + 针距数值 + 部位 + 视角（如"平缝 0.6cm 针距，袖窿内侧特写，微距"）；展示/提案用途直接可用，**工艺核验与合规证据仍须实拍或矢量**。

## 08 ｜ 时装效果图 / 时装画 Fashion Illustration（含 6A 人体比例专题）　【语境：两者，赛事更重】

唯一含人体的交付物：传达氛围、廓形、色彩、面料动态。**不承担精确工艺信息**（工艺交给 07 与规格表）。

**效果图一律用全身图**：从头到脚完整、全廓形可见；作换装/实穿参考时尤其避免半身、坐姿、裁切与裙摆遮挡，否则衣长与版型会被误读而反复漂移。

### 先分清：写实大片 vs 时装效果图（两种完全不同的表达形式）

| 维度 | 写实摄影大片 | 时装效果图/时装画 |
|---|---|---|
| 核心目的 | 展示真实穿着效果、商业感 | 展示设计方案、创意感 |
| 人体比例 | **1:9（无母版直出统一值），裆到脚底 55%**；有 Muse 则继承母版 | 插画档 9–10 头身（拉长比例） |
| 风格特点 | 高细节、真实比例、面料质感真实、光影讲究 | 线稿+淡彩/马克笔，廓形优先、脸手简化 |
| 适用场景 | 企业订货、campaign提案、商业展示 | 赛事效果图、院校作业、系列设计提案 |
| 人脸处理 | 完整五官、真实皮肤 | 留白或极简、简化处理 |

> **重要**：无母版直出写实/照片向统一 **1:9 + 裆 55%**；插画档才用 9–10 头。出图前先判断：用户要的是写实摄影感还是插画感？无 Muse 时先提醒是否建立（不建则按 1:9 直出）。

### 先问画风再出图（不要上来就生成；出效果图前必问用户）

**出效果图前，先向用户确认画风档，不替用户默认选择**（用户没指定时一律先问）：

| 画风档 | 头身 | 一句话特征 |
|---|---|---|
| ① 写实渲染（类摄影/照片向） | **1:9（无母版直出统一值，裆 55%）** | 高细节、真实比例、面料质感真 |
| ② 标准时装画 | 9–10（插画档） | 线稿+淡彩、廓形优先、脸手简化 |
| ③ 装饰/风格化 | 9–10 | 夸张比例、平涂装饰、强个人风格 |
| ④ 前卫/概念 | 9–10（前卫可至上限，不破 10） | 抽象、拼贴、解构人体 |

用户不确定时按 **08-附 ④ 画风×语境对应表** 给推荐，但**最终由用户选定**；确认画风档后再选媒介技法（十六种：水彩 / 马克笔 / 彩铅 / 钢笔线稿 / 平涂装饰 / 数字插画 / 拼贴 / 水墨工笔 / 混合媒介 / 色粉 / 炭笔 / 素描铅笔 / 二次元动漫 / 油画·油彩 / 水粉·丙烯 / 版画·木刻），再写提示词。

### 双向转换流程（风格效果图 ↔ 人物实穿图）

效果图不是一次性的，可以在两种风格之间互相转换，按用户需求选择方向：

#### 方向1：风格效果图 → 人物实穿图（白底PNG，即成衣定稿）

**什么时候用**：设计提案阶段用了风格效果图（水彩/马克笔/时装画），后续需要真实的人物实穿图做展示/生产参考，也就是文件夹里的"成衣定稿"

**步骤**：
1. 以风格效果图为参考图1（锁服装结构、廓形、颜色位置）
2. 写prompt：将图1的服装转换为真实人物穿着，白底PNG背景，无母版直出写实/照片向统一 **1:9 头身比、裆到脚底 55%**（有 Muse 则继承母版比例）
3. 生成后检查：服装结构/颜色/廓形是否和风格效果图一致
4. 输出：白底PNG透明底，只保留人物和服装

**提示词模板**：
```
将参考图1中的服装转换为真实人物穿着效果，纯白背景PNG，
头身比 1:9、裆到脚底占身高 55%（无母版直出统一值；有 Muse 则继承母版比例），
服装结构、颜色、廓形、特殊设计完全按参考图1，
面料质感真实，光影均匀，影棚柔光，
从头到脚完整显示，正面站姿。
不要改变服装结构、不要加多余配饰、不要改变颜色。
```

#### 方向2：人物实穿图 → 风格效果图

**什么时候用**：一开始直接生成了真实实穿图，后续需要转换成艺术风格的效果图做提案/展示

**步骤**：
1. 以人物实穿图为参考图1（锁服装结构、廓形、颜色位置）
2. 写prompt：将图1的服装转换为XX风格的时装画——画风从下方 **08-附 全档选**（② 媒介技法十六种 + ②·2 绘画流派），锚定"媒介 + 流派调性"两个词
3. 生成后检查：服装结构/颜色/廓形是否和实穿图一致
4. 输出：风格化效果图，默认纯白素底；仅赛事按赛题可加氛围背景

**提示词模板**：
```
将参考图1中的服装转换为[画风从 08-附 ② 媒介十六种 / ②·2 绘画流派选，例：油画·油彩 / 水彩 / 浮世绘平面套色 / 印象派光色]风格的时装画，
插画档 9–10 头身，头部小而窄，四肢修长，
服装结构、颜色、廓形、特殊设计完全按参考图1，
线条干净流畅，[媒介质感描述]，
柔和侧光+大面积留白，竖构图3:4。
负面：写实照片、真实人体比例、改变服装结构、改变颜色。
```

> **注意**：两个方向转换时，服装锚点（结构/颜色位置/廓形/特殊设计等，完整锚点清单见 `consistency-lock.md`）必须保持不变，只改变风格和人体比例。转换前后都要核对服装细节是否一致。

### 版式

- 版式：单人 A4、展示 A3；人物 3:4/2:3 竖构图（3:4→1536×2048、2:3→1365×2048、9:16→1152×2048）；图 85–95%；头顶留白 ≥1 头长、脚下 ≥0.3 头长；企业订货纯白素底、克制夸张，赛事按赛题可加氛围背景。
- 必放：人体+着装、廓形剪影、面料质感与悬垂、动态走姿、配饰鞋、简化的脸与手、系列色板呼应。
- 说明文字：设计说明 80–200 字（灵感/廓形/面料/人群各 1 句，赛事可至 300）；英文 collection statement ≤200 词。

### 画法关键数值（手绘 croquis 用 9 头身，自顶向下第 X 头长：头顶=0）

下颌 1.0 · 肩线 1.5 · 胸 2.0 · 腰 3.0（与肘齐平）· 臀 4.0 · 裆 4.25 · 指尖 5.0 · 膝 6.0 · 踝 8.0–8.5 · 脚底 9.0；头宽约 2/3 头长、女肩宽 2 头宽、腰宽 1 头长、臀宽 1.5 头长；单脚重心、肩臀线反向（contrapposto）。

### AI 能力边界

Seedream 强在媒介质感（线稿/水彩/马克笔/平涂/数字时装画/水墨/油画/水粉/版画）、面料悬垂光泽、风格化配色、多参考一致性；**默认回弹写实比例**——写实/照片向直出统一写 **1:9 + 裆 55%**；插画档 9–10 头须风格词 + 负面词强约束；手部、五官、走姿解剖、跨图一致性是弱项。Seedream 最多挂 **10–14 张参考图**（不同平台口径 10/14）。

### 6A.1 统一口径

| 路径 | 头身 | 裆到脚底 | 用在哪 |
|---|---|---|---|
| **无母版直出（写实/照片向）** | **1:9** | **55%** | 本文件所有写实/照片向输出（实穿图、写实档效果图）；提示词写死这两组数字 |
| **有 Muse / Muse 着装真实效果图** | 继承母版 | 继承 | 以母版为比例锚、提示词不写数字（`image-editorial.md` 场景3） |

写实/照片向与插画档**同一张图内不混用**；系列/群像统一一个口径。

### 6A.2 手绘 croquis 参考（人工画法；AI 提示词不写这些数字）

9 头身 croquis 自顶向下（头顶=0）：下颌 1.0 · 肩线 1.5 · 胸 2.0 · 腰 3.0 · 臀 4.0 · 裆 4.25 · 指尖 5.0 · 膝 6.0 · 踝 8.0–8.5 · 脚底 9.0；拉长几乎全部加在腿与颈、躯干基本写实；单脚重心、肩臀线反向（contrapposto）。男装同头身：肩更宽、腰线更低；童装随年龄约 4–7.5 头（头大、颈短、腹部前凸）。

### 6A.3 提示词骨架

**写实/照片向直出（无母版）**：
```
写实/照片向，头身比 1:9、裆到脚底占身高 55%，
<正面站姿/走姿/3/4 侧身>，五官完整、真实皮肤，面料质感真实、光影自然，
类摄影渲染，竖构图 3:4，人物居中。
负面：插画、卡通、7头身、短腿、矮挫、大头、解剖错误、水印文字。
```

**插画/时装画档（9–10 头）**：
```
时装画风格，9–10 头身（head-to-body ratio 1:9~1:10），
头部小而窄、颈部细长、肩窄腰细、四肢极度修长、小腿略长于大腿，整体拉长剪影，
<站/走/回眸>，肩线与臀线反向倾斜，重心在单腿。
媒介：<水彩/马克笔/平涂/数字时装画/油画/版画>，线条干净流畅，非写实摄影。
服装：<连衣裙/套装>，<廓形>，面料<真丝垂坠/硬挺羊毛/薄纱飘逸>。
柔和侧光+大面积留白，衣褶按重力方向；竖构图 3:4，人物居中，纯白底。
```

**负面词（封死回弹，固定模板逐张复用）**：
```
写实照片, 摄影, 影棚布光, 真实人体比例, 7头身, 8头身, 时装画拉长比例, 插画式身高, 短腿, 大头, 多肢, 多手,
六指, 手指畸形, 手脚变形, 五官扭曲, 面部特写, 解剖错误, 站立不稳, 合成感, 水印, 文字, logo, 低清
```

### 6A.4 防结构错工作流

- **写实/照片向**：比例 1:9 + 裆 55% 写 prompt 前段 + 负面词封死；不另做 croquis；有 Muse 以母版为锚、提示词不写数字。
- **插画档**：先出/手绘简笔人形 croquis（9–10 头身）锁比例姿态 → 用该 croquis 作参考图1 图生图着衣（参考图2=服装款型、参考图3=面料/配色）→ 逐张复用同一参考图1 与同一张脸部参考（系列内脸/身材/高度一致）→ 手部单独处理 → 单张单人物、一次只改一个变量。

### 6A.5 头手脚简化惯例（手绘）

- **头**：蛋形轮廓、帽向留白/常不画五官；若画用三庭五眼、鼻宽=1 眼长、嘴略宽于 1 眼长、耳长=1 庭。
- **五官**：眼=一条上睑线+一小段瞳孔；鼻只画一侧鼻梁线；嘴上唇"M"下唇"W"。
- **手**：**合并中指与无名指**（保两指宽度）；**中节与末节合并为一段**并与基节等长（三节按两节画）；指锥形、关节微弯。
- **脚/鞋**：正侧视近似三角形；踝内高外低；鞋跟向脚心靠拢、跟底与掌底同水平线；鞋底画双线表厚度。
- 头发：轮廓/分组/线描三选一，用走向线表达不逐根堆砌。儿童五官集中在头部 1/2 以下。

### 08 验收门

口径用对（写实/照片向 1:9+55%、插画档 9–10，未混用、未回弹矮挫/7 头）；插画档落位符合 6A.2 手绘参考；重心平衡、肩髋反向；每手 5 指无并指多指；脸完整（写实）/简化留白（插画）；衣褶按重力、压点（肩/胸/臀）合理；系列脸型/身材/高度一致；头顶留白 ≥1 头长；企业版纯白素底、赛事版可氛围/夸张。

## 09 ｜ 系列效果图 / Line-up / Collection　【语境：两者，赛事核心】

全套造型走秀式排列，检验"是否成为一个系列"（色板节奏、廓形演进、品类覆盖）。

### 套数口径

| 场景 | 套数 |
|---|---|
| 教学 croquis lineup | **10–18 张/系列** |
| 高校毕业系列 | **6 套**（如 six-outfit range） |
| 赛事 | **3–8**：REDRESS/Talons 3 体、TFDA 5 体、International Youth 4–6、ITS 5–8（具体以当年赛题为准） |
| 商业款图 lineup | 8–12 套横排，按 range architecture 定；开发周期 4–7 个月 |

### 版式（商业 vs 赛事）

- 商业款图：A3/A2 横版，一板一排走秀式等距横排、**统一脚底基线**、左→右动线、正面为主穿插 1–2 侧/背、纯白素底克制。
- 赛事系列：A2/A1（A1=594×841mm/9933×7016px@300），可单排/双排/错落、叙事化构图。
- 人物间距约 0.3–0.6 个人物宽、负空间均匀；编号 01… 10–14pt、系列名 24–36pt；头顶高度误差 <2% 板高。
- 系列说明 150–400 字（灵感+系列逻辑+人群+商业/可持续定位），英文 ≤200 词。

### AI 边界与主路径（硬）

**Line-up 不要一次文生图直出**（多人物同框必串脸/串肢体、不守网格、控不住套数）。主路径 **A 逐套单张 → B 人工排板**：
```
矢量 croquis 模板（9 头身，统一姿态）→ 复制 N 份（N=目标套数）
→ 每份图生图着衣：图1=该份 croquis；图2=该款服装；图3=同一位模特脸部
→ 统一 3:4、统一纯白背景、统一光质的后缀提示词
→ 人工排板：统一脚底基线 + 等距列 + 同高缩放（对齐头顶线）+ 编号 + 款号 + 页脚
```
单套提示词：`9 头身比例与图1完全一致；与图3同一模特（脸型/发型/身高一致）；图2 的造型 <款式+面料+配色>；正面站立双臂自然下垂重心居中；竖构图 3:4 纯白背景柔和均匀光无投影；不要背景道具、不要多个模特、不要改变比例`。负面：`多个人物, 不同比例, 不同身高, 写实照片, 换脸, 服装变化, 不一致光源, 不同色温`。

### 验收门

套数符合场景；全系列同一 croquis 比例、未混用口径；脚底同基线、头顶等高；等距负空间均匀；编号连续不压人；色板色相/明度有递进无跳变；品类覆盖（上装/下装/外套/连身）无缺口无重复；商业版纯白素底克制、赛事版可氛围化。

## 11 ｜ 细节图 Detail Drawing　【语境：两者】

放大设计亮点与工艺，证明"值这个价、做得出来"。赛事作品集加分页，评审最看重完成度的一环；企业与款式图/tech pack 绑定。

- **两类特写分开**：**工艺特写**（怎么做：线迹、缝型、结构、五金、尺寸）与**面料特写**（什么材质：纹理、光泽、厚度、垂坠、色彩）。
- 每款 **2–4 个**部位（复杂款可至 6，即 3–8 区间）；母图上用细线方/圆框（1pt）标 a/b/c，小图注明"a 处放大"；**必须标放大倍率**（工艺 2×–5×、面料宏拍 5×–10×），否则无尺度。
- 小图 3–6cm 见方拼入主图版面，等大等距、间距 ≥3mm；版面配比 主图 60% + 小图 25% + 标注 15%。
- **指示线**：直线/折线+箭头，线宽细于轮廓（0.25–0.5pt），文字 9–11pt 无衬线、单条 ≤20 字；关键尺寸（领高/袋宽/罗纹宽/扣距）以 mm/cm 标注；**同一数字在细节图、款式图、tech pack 三处必须一致**。
- 面料特写单一方向光（硬光刻纹理/柔光显垂坠，二选一）；面料-光位表见 `image-detail-fabric.md`。

### AI 边界（展示 / 核验分叉）

AI 强于面料/材质微距与工艺特写，**约束后 AI 可出超真实工艺展示图**——提示词写死缝型名称、针距数值、部位、视角（模板见 07.5 约束清单⑦⑧）：**展示/提案/效果用途完全可用，默认追求真实**。只有**工艺核验与合规证据**（确认缝线/针距/做工是否成立、或作为质量证据提交）仍须实拍或矢量；不得把 AI 生成的"缝线"当真实工艺写入合规说明。指示线/局部框/倍率标注：AI 底图出完由 Agent 或排板工具补标注（数字与 tech pack/款式图一致）。
```
【主体】面料微距特写，无人体，无背景杂物
【材质】<羊毛华达呢 320g/m²，2/2 斜纹>，可见织物肌理与厚度
【构图】正交平铺/45°斜视，画面填满，浅景深
【光影】单一方向硬光（或柔光），突出纹理起伏（二选一）
【参考】图1=该服装面料与配色；图2=该面料近景质感（只取纹理光泽）
【风格】商业面料目录级，真实物理，高解析；不出现缝纫结构
【禁止】不要人体、模特、文字、水印、多重光源、塑料感、过度磨皮、失真纹理、假皮革
```
工艺特写：人工 Illustrator 绘制（可参照 AI 底图）+ 标尺寸；面料特写：Seedream 图生图；最后核对所有数字与 tech pack/款式图一致。

### 验收门

母图有局部框、小图 a/b/c 对应；每小图标倍率；有 callout 且线宽细于轮廓；工艺/面料两类分开可辨；数量 2–4（复杂 ≤6）；关键尺寸 mm/cm；三处数字一致；面料特写单一光质；小图等大等距不压母图；无假皮革/塑料感。
