# 面料全品类知识库：识别 · 命名 · 渲染 · 动态

一句话：把一匹布"叫对名字、说清手感、写准渲染、给出动态"，AI 才会把这块料画成这块料，而不是糊成一块塑料。

分界（只引用不重复）：材质四要素、微距公式、面料-光位表见 `image-detail-fabric.md`；面料卡八字段、小样尺寸、D65 对色见 `design-boards.md` 04；面料词 → 四要素速查见 `design-language-dictionary.md` 第四节（本篇是其深化版，不照抄）；每种料的**结构·廓形·工艺·翻车点**见 `category-guide.md`（本篇每料只用一行点名"常见品类"）；硬数值见 `quick-reference.md`，克重/缩率/3D 面料参数见 `technical-production-spec.md`。

**每块料按九字段写**：规范成分 · 手感与克重 · 垂感/挺括 · 光泽 · 缩水与特性 · 常见品类 · 布光与渲染 · AI 翻车点/负面词 · 视频动态。缺一项，模型就在那一项自由发挥。

**三条命名基本原则**

1. **用规范纤维名**：聚酯纤维（不写"涤纶"）、锦纶（俗称"尼龙"）、氨纶（俗称"莱卡/Lycra"）、腈纶、粘胶纤维（俗称"人棉"）、莫代尔纤维、莱赛尔纤维、铜氨纤维、醋酯纤维、棉、亚麻、苎麻、绵羊毛、山羊绒、桑蚕丝。**现行 GB/T 29862-2013；新版 GB/T 29862-2026《纺织品 纤维含量标识技术规范》2026-07-02 发布、2027-08-01 全部代替 2013 版，实施前仍按 2013 版**；含量【通识】：单种纤维 ≥5% 须标，<5% 可并入"其他纤维"，以实测报告为准，技能不给数值。
2. **品牌名不是纤维名**：莱卡 Lycra（氨纶品牌）、天丝 Tencel（莱赛尔品牌）、新雪丽 Thinsulate（保暖絮片品牌）——标注回到规范名，可另注品牌。
3. **品牌名不进提示词与喂图**（失实 + 版权，见 `copyright-compliance.md`）：写"聚酯纤维面料""氨纶弹力针织"。

安全与维护只引标准号：**GB 18401-2010**（A 婴幼儿 ≤36 月甲醛 ≤20 mg/kg、B ≤75、C ≤300）；婴童 **GB 31701-2015**；维护符号 **GB/T 8685-2008**；链路见 `portfolio-board.md` 19。

### 1.2 组织决定手感骨架

**梭织三原组织**：平纹（交织点最密 → 平整挺实；府绸/塔夫绸/欧根纱/雪纺）、斜纹（浮线长 → 柔软垂、易磨光；卡其/牛仔/华达呢）、缎纹（浮线最长 → 最光滑有光、易勾丝；缎面/里布/晚装）。**针织**：纬编（汗布/罗纹/珠地/毛圈，弹软贴身）、经编（网眼布/蕾丝底布/泳装布，尺寸稳定）。**非织造**（絮片/衬）无织纹。识料四步：看组织（经纬交织=梭织、V 形线圈=针织、无织纹=非织造）→ 看光泽透光 → 试垂（下坠=垂、成角=挺）→ 回写九字段（四要素见 `image-detail-fabric.md`）。

- **布光**：侧逆光出经纬浮雕；针织棉用柔光显线圈。
- **AI 能做/做不了**：能做平整哑光、竹节不匀、水洗泛白；做不了真实缩率，常把丝光棉画成塑料光、把针织线圈在拉伸处画乱。
- **动态**：小幅摆动、回位快。

```
棉府绸衬衫料，平纹细密，哑光均匀，微挺不塌；侧逆光扫出经纬微浮雕，可见纱线细节，纯色<白/浅蓝>；面料微距 100mm f/8，柔和漫射光，布面平整
```
```
塑料反光, 丝绸高光, 蜡光涂层, 针织线圈(画成针织), 织纹不合理, 过度磨皮
```

```
```
均匀条纹(竹节画成规则条), 化纤光泽, 丝滑高光, 织纹刻板, 涂层感
```

## 四 丝系（桑蚕丝与仿真丝）

桑蚕丝厚度惯用**姆米 momme**：**1 姆米 ≈ 4.3 g/m²【经验值】**。

| 织物 | 规范成分 | 手感 · 克重 | 垂感/挺括 | 光泽 | 缩水/特性 | 常见品类 |
|---|---|---|---|---|---|---|
| 双绉 crepe de chine | 桑蚕丝（可混聚酯纤维） | 微砂感、软 · 16–22 姆米 ≈ 70–95 GSM | 垂坠好 | 柔光低反 | 缩 3–5%，湿强下降 | 连衣裙/衬衫 |
| 乔其纱 georgette | 桑蚕丝/聚酯纤维 | 轻薄起绉 · 8–12 姆米 ≈ 35–50 | 飘逸 | 哑光微透 | 易勾丝 | 裙/叠层 |
| 雪纺 chiffon | 桑蚕丝/聚酯纤维 | 极薄通透 · 6–10 姆米 ≈ 26–43 | 极飘 | 亚光微透 | 易勾丝、须锁边 | 裙/披肩 |
| 缎 satin | 桑蚕丝/醋酯纤维/聚酯纤维 | 光滑重坠 · 16–30 姆米 | 垂坠强 | 高光柔亮 | 易勾丝、留水渍印 | 礼服/吊带 |

| 欧根纱 organza | 桑蚕丝/锦纶/聚酯纤维 | 硬挺网格 · 20–50 | 撑开不垂 | 微光 | 易勾、边缘易散 | 蓬裙/造型外层 |
| 蕾丝 lace | 锦纶/棉/聚酯纤维（经编或刺绣底） | 视花型 · 30–150 | 随底布 | 哑/微光 | 易勾、须加衬 | 礼服/内搭 |

- **布光**：缎面用可调角度柔光加旗板控高光走向；雪纺逆光显透；欧根纱硬光显轮廓。
- **AI 能做/做不了**：能做连续褶浪、缎面高光流动、薄纱叠层加深、蕾丝孔洞；做不了蕾丝花纹的规律性与接版（给的是随机网眼，不能无缝对花），薄纱叠层极易糊成均匀灰。

```
真丝缎面料，平纹缎面，柔亮高光随布面起伏流动，垂坠连续褶浪；单向柔光侧扫，高光窄带不炸，深色保留暗部结构；面料特写 100mm f/8，无塑料感
```
```
高光炸开成白块, 塑料膜感, 纱糊成均匀灰, 蕾丝网眼随机噪点, 贴图接缝
```

- **布光**：主灯侧移、少补光，织纹与毛流方向才看得见；花纱要显杂色颗粒。
- **AI 能做/做不了**：能做花纱杂色、绒面毛流、粗纺颗粒；做不了"哑而润"的微光泽（易压成全哑或反成高光），花纱规律易变成随机噪点。
- **动态**：呢料回位利落、褶痕缓慢展开；羊绒随体轻垂。

```
精纺羊毛呢，细密斜纹，哑光微润，手感挺括；主灯侧移侧光扫出织纹与毛流方向，花纱带自然杂色颗粒；面料微距 100mm f/8，深色保留暗部细节
```
```
全哑死黑, 塑料高光, 随机噪点(花纱画成脏点), 绒毛过度锐化, 织纹消失
```

```
```
棉质感(不垂不软), 真丝高光, 塑料反光, 褶皱僵硬, 织纹刻板
```

```
聚酯纤维弹力面料，平纹紧密，哑光柔顺，轻微弹性，无塑料反光；大面积柔光加反光板，高光被压成柔面，<黑/藏青>；面料微距 100mm f/8
```
```
廉价塑料感, 点状硬高光, 塑料板反光, 涤纶亮光, 织纹网格化
```

## 十三 物理与生产基础

### 13.1 克重与厚薄

- 单位 **g/m²（GSM）**；**1 姆米 ≈ 4.3 g/m²【经验值】**（真丝）；**1 oz/yd² ≈ 33.9 g/m²【经验值】**（牛仔）。
- 厚薄与克重【经验值】：<100 极薄（雪纺/欧根纱/里布）；100–200 薄—中（衬衫/连衣裙）；200–350 中厚（裤料/外套/针织）；350–600 厚（大衣呢/重磅牛仔/毛衫）；>600 特厚（双面呢/皮草）。

### 13.2 门幅与用量

- 门幅单位 cm【经验值】：梭织常见 **110–150**（144/150 主流）；弹力布 130–160；针织 150–180；牛仔 140–150；皮革按张（平方英尺 sq ft）计。
- 用量：`用量(m) ≈ 净耗面积 ÷ 有效门幅 ×(1+损耗率)`，损耗率 3%–8%（条格对花、厚料更高），公式与实例同 `technical-production-spec.md` 15。

### 13.3 对色 · 缩率 · 成分标注

- 对色 **D65 标准光源**，色差容差 **±0.5ΔE**；色卡用 **Pantone TCX（棉布）/ TPG（纸面）**，两者不混用（`design-boards.md` 03）。
- 缩率【经验值】：棉梭织 2–5%、亚麻 3–8%、粘胶纤维 4–8%、绵羊毛 2–5%、牛仔洗水 3–8%、针织棉 5–8%、聚酯纤维热缩 1–3%；**打版前须先测缩水率并预放量**（`technical-production-spec.md` 13）。
- 成分标注按现行 **GB/T 29862-2013** 用规范名（新版 **GB/T 29862-2026** 已发布、2027-08-01 实施后全部代替 2013 版，实施前仍按 2013）；维护符号 **GB/T 8685-2008**；安全类别 **GB 18401-2010**、婴童 **GB 31701-2015**；**合规判定必须人工完成，AI 不能代判**（`portfolio-board.md` 19）。

## 十五 自检与验收门

### 15.1 看到一块料，如何描述（四步）

规范成分名 + 组织（写"粘胶纤维，平纹"，不写"人棉"）→ 四要素（纹理/光泽/厚度/垂感）→ 手感克重区间（标【经验值】）→ 光位（见 `image-detail-fabric.md` 光位表）。

### 15.2 验证 AI 没画错面料（六查）

- [ ] **织纹对**：平纹不画成斜纹、斜纹不画成缎纹、梭织不画成针织线圈；
- [ ] **光泽对**：哑/柔光/高光与面料匹配（棉不出现塑料高光、缎面不塌成哑布）；
- [ ] **厚度与垂感对**：挺括料不软塌、薄透料不厚重；
- [ ] **透明与叠层对**：薄纱叠层处密度加深，而不是均匀灰；
- [ ] **反光有方向**：金属/缎面高光随布料起伏，不是整片死白；
- [ ] **无非法花纹**：没有把织纹画成不存在的提花或图案。
任一不过 → 按 `consistency-lock.md` 分流（锚点级整图重出 / 非锚点局部重绘）。
