# 视频 · 四段式备料包

> 类型已定（`video-film-types.md`）。把素材整理成照抄进**默认平台（即梦）**就能用的四段式；换平台（入口/槽位/时长/负向）见 `tool-adapter.md`。

## 导演流水线总览（先想清楚，再备料）

时装片从立项到成片是一条完整的导演流水线，本文档的章节顺序就是这条流水线；**四段式只是其中的备料环节，不是全部**：

| 阶段 | 干什么 | 章节 |
|---|---|---|
| ① 定类型 | 九类影片选一：类型决定时长、镜头密度与叙事方式 | `video-film-types.md` |
| ② 五问定片 | 类型/开场3秒/推进/收束/每镜功能——"这条片为什么成立" | 本文档「先当导演」 |
| ③ 视觉系统分层 + 服装出现形态 | 主表演/服装全貌/面料证据/场景/声音五层；每件衣服的全部出现形态列全，漏掉的就是该补的镜头 | 同前 |
| ④ 定风格档 + 导演声音 | 20 档联动静态大片；导演声音六型整片一只手，不逐镜换腔 | 本文档「风格档/导演声音」 |
| ⑤ 镜头表 + 动作 + 运镜 + 切点 + 时间轴 | 多镜/多人必填镜头表；动作五要素；运镜四选一；结束档案 6 型；节奏密度三档 | 本文档各节 |
| ⑥ 四段式备料包 | 素材映射/一句话简报/镜头顺序/全局约束——照抄进生成平台 | 本文档「四段式」 |
| ⑦ 生成与锚点 | 定妆锚点图→派生镜头→空镜独立；Hold/React 双模式；链深 ≤2 硬 3 | 本文档「视频锚点依赖链」 |
| ⑧ 声音与后期包装 | 配乐/音效/旁白/字幕/花字/封面——成片最后一道工序，决定能不能直接发 | 本文档「声音与后期包装」 |
| ⑨ 验收门 | 音乐可商用、曲型匹配、卡点不抢服装、字幕无错字且在安全区、规格正确 | 本文档「输出与验收」 |

**边界**：本流水线覆盖**用户自建 / 原创**的时装片（从零规划、或从自己的素材/参考出发）——**原创 ≠ 无参考**：图片参考（服装/模特/细节/场景图）与视频参考（秀场片/时装电影/竞品大片）随时可传；视频参考走「对标拆解」**只借功能关系**（铺垫/揭示/卡点/收束），不抄秒数/机位/场景/模特/服装。**复刻 / 改编他人爆款视频是另一套独立方法论**，走可选协作 `video-remix-studio`（见 README「可选配套」），两套体系不混合、不互相承接。

## 先当导演，再写备料（每次生成前必过）

> 视频不是"提示词写好、模型碰运气"。无论**文生视频、图生视频、有无参考视频**，进四段式之前先过这套导演逻辑，把"这条片为什么成立"想明白，再让模型执行——**先当导演想清楚，而不是让模型替你想**。有参考时用它拆参考，无参考时用它规划新片，同一套逻辑、两种用法。

### 五问定片（动笔前先答）

1. **类型**：九类影片（`video-film-types.md`）里的哪一类？类型决定时长、镜头密度与叙事方式。
2. **开场 3 秒凭什么抓人**：第一个镜头给观众什么——造型全貌的冲击、面料动态的悬念、还是场景与人的关系？前 3 秒必须有"继续看下去的理由"。
3. **中间怎么推进**：节奏曲线怎么走——慢板留白在哪、动态揭示在哪、特写证据在哪；不平均用力，更不为凑时长硬拖。
4. **结尾怎么收束**：收在哪、怎么呼应开场；产品名/系列名的落位在哪。
5. **每镜承载什么功能**：每个镜头是"主表演"还是"证据"还是"氛围"——它为什么存在、删掉会怎样。

### 视觉系统分层（时尚片版本）

| 层 | 时尚片里的职责 |
|---|---|
| 主表演 A-roll | 模特对镜/走秀的完整造型——结构、廓形、面料垂坠是主角 |
| 服装全貌 | 全长、正/侧/背、转身时的整体轮廓与摆量 |
| 面料/工艺证据 | 特写：肌理、反光、缝线、闭合件、流苏摆动（微距逻辑见 `image-detail-fabric.md`） |
| 场景/氛围 | 秀场、影棚、古建筑、山野——空间与光位（布光见本文档「布光与面料」） |
| 声音 | 配乐/环境音/服装音效；声音与包装章节在文末，不让模型自动造音乐 |

### 服装出现形态清单（每件衣服的"全部出现形态"）

生成前把服装在片中的**每个出现形态**列全，逐形态覆盖——漏掉的形态就是该补的镜头：

- 全长全身（正/侧/背）、四分之一转身、走秀动态
- 面料特写、工艺细节、闭合件、内里/结构
- 人台/平铺/挂拍（如需展示版型）、镜中倒影、B-roll 里的局部
- 多人/群像中的位置与服装归属（谁穿哪件，跨镜头不乱）

### 视频锚点依赖链（图生视频核心）

**生成通道决策（先选，再写备料）**：
- **主通道 = 关键帧图生视频**（`image_to_video`）：所有含人物/服装的镜头必须走这条——先有"长什么样"（锚点图/关键帧），再有"怎么动"（文字增量）；纯文字锁不住结构/色位/身份。
- **文生视频**（`text_to_video`）仅限：空镜/B-roll、无主体的氛围镜头、声场概念。有主体却走文生 = 必漂。
- 多镜成片 = 每镜独立图生视频 + 切点拼接，不用一段文生长片。

图片四步管线延伸到视频，**保持依赖链浅**：

1. **先出 1 张"服装+模特+场景"定妆锚点图**（四步管线的③上模特），作为全片视觉权威。**锚点图出图按 `image-editorial.md` 通用要求 6（人脸双锁）+ 通用要求 7（场景三情况路由）执行**：无场景图→纯文字描述；纯环境场景图→三图全保；**有人物的场景图→先走换人协议产出"换人定妆图"（场景原图当壳 + Muse 脸 + 着装图），再以它为视频锚点——视频不直接吃有人物的场景原图，避免成片中人物身份与场景原人串脸**。
2. **反打/侧面/特写等所有镜头都从锚点图派生**：`image_edit` 时点名"图1 负责什么不变（服装结构/颜色及位置/身份/比例/光调）、新机位改变什么"。
3. **空镜/B-roll 独立生成**（`text_to_video` 或独立图），不与锚点绑定。
4. **不造"只为喂下一张"的中间图**；同造型跨镜头复用同一批锚点，除非切点本身是设计好的连续帧。

### 图生视频双模式：Hold / React（动笔前先选）

| 模式 | 适用 | 写法 |
|---|---|---|
| **Hold**（图即瞬间） | 定妆展示、静态造型"活起来" | 分布 3–4 个自然微动作（眨眼/呼吸/发丝/缓慢视线），其余**双重锁定**：`她保持坐姿在窗边；她不站起、不转身、不离开画面`。机位不动或至多一个慢推 |
| **React**（有事发生） | 面料动态、风起、灯光变化 | 把一个情绪展开为子节拍并**给足 2 秒以上落地时间**（"她听到声音、眼睛睁大、两到三秒内脸色变化"）——仓促情绪=glitch |

- 锚点图定妆展示 = Hold 起手；风起裙摆/揭示构造等动态镜头 = React。
- 关键句：`the clip begins exactly at this moment`——图是片中瞬间而非开场帧时，显式锚定起点。

### 有参考视频时：对标拆解（继承功能，不抄秒数）

用户给一条参考（秀场片、时装电影、竞品大片）说"要这个感觉"：

1. **先通读一遍**抓整片模型：前 3 秒给什么、中间凭什么留住人、高潮收在哪、整体什么情绪与节奏——一句话写出"它为什么成立"。
2. **再时间码级分层**：抽帧对齐转场/音乐/步伐/静帧，逐段写"客观看到什么"与"它为什么有效"分开，不混在一起。
3. **只继承功能关系**：铺垫/揭示/卡点/收束这些"关系"可以借鉴；秒数、机位、场景、模特、服装一概不抄——换成你自己的造型与内容。
4. **无参考时**：同一套五问 + 分层直接规划新片——类型标准与时尚语言就是你的"参考"。

## 四段式

| 段 | 回答什么 | 必填 |
|---|---|---|
| ① 素材映射 | 每件素材管什么、不许管什么 | 是 |
| ② 一句话简报 | 这条片子是什么（类型+主体+动作+风格） | 是 |
| ③ 镜头顺序 | 逐拍怎么演 | 是 |
| ④ 全局约束 | 什么不许变 | 是 |

## 素材映射

- 按上传顺序编号：`@图片1`、`@视频1`、`@音频1`（英文 `<IMG1>/<VID1>/<AUD1>`）
- 每件素材回答：属于谁/什么？参考什么？只用一部分时写清什么不能继承
- 不依赖图片里的文字，不用模糊指代

| 类别 | 控制什么 | 不许控制什么 |
|---|---|---|
| 服装图 | 结构、版型、颜色及位置、长度、闭合件、图案/印花位置、配饰鞋履、面料 | 五官、场景 |
| 模特图 | 五官、身形比例、发型 | 服装、背景 |
| 细节图 | 指定部位构造 | 整体构图 |
| 场景图 | 空间、光位、色调（须纯环境图：无人、无强主体） | 人物、服装；**有人物的场景图不走素材映射，先经换人协议出"换人定妆锚点图"再进视频（见 `image-editorial.md` 通用要求 7）** |
| 参考视频 | 运镜、节奏、转场、动作顺序 | 其人物、服装、场景 |
| 配乐 | 声音；说明旋律还是节奏 | 画面 |

**服装单独参考（最重要）**：颈部以下/人台/裁切身体，不引入另一张脸；参考须含正背面、颜色及颜色位置、面料纹理与反光、接缝/纽扣/口袋/拉链、版型轮廓、鞋履。

数量边界：图片≤30 张、单张≤4K，**1–8 主体最可靠**；视频≤10 段共 30 秒（主体参考 5–10 秒好）；音频≤10 段共 30 秒；故事板<15 格用线稿。

### 增量原则（有参考时文字只写增量）

参考图/视频**已承载的状态，prose 不重复描述**；只写参考承载不了的增量——当前动作、位置变化、音频相位、排除项。

- 文字与像素一致 = 浪费预算；文字与像素不一致 = 漂移指令。
- 例：锚点图已显示服装全貌 → 四段式里不再写服装外观，只写"保持 @图片1 服装不变 + 本镜动作"。
- 例外：跨镜位置/朝向变化属于增量，必须写（见锁行）。

## 先定风格档（与静态大片 20 档联动）

视频是"动起来的大片"：风格档直接复用 `image-editorial.md` 的大片风格二十档（极简高级/黑白电影/年代复古/千禧 Coquette/超现实/AI 原生不可能/童话幻想/暗黑/街头都市/波西米亚/魅惑/浪漫/自然环境/国风东方/动感运动/赛博科技机能/学院知识分子/度假奢华/蒸汽波/西部牛仔），每档补"动态·运镜·节奏"三件套；"编辑大片/商业广告"是影像基调选项（下面两行），不是风格档本身。**用户点名品牌/设计师做参照时，先按 `design-ideation.md` 3·8 拆成锚点语言，再落到风格档/镜头/场景/妆造，锚点贯穿全片。用户没给参考时，选档走 `image-editorial.md` 六（推荐三通道 + 对比小图拍板），同一档位 + 动态三件套。**

- **编辑大片**：固定机位、单硬主光、克制双色、每镜一个保持住的姿势（5–8 秒）
- **商业广告**：可推近/跟拍/小弧线、柔光、更短更多切
- 出现运镜或柔和补光，就是商业片，不是编辑大片

### 导演声音六型（风格档之上的"导演手"维度）

风格档决定"长什么样"，导演声音决定"怎么被看见"。整片先定一个声音，镜头/光/表演全部听它的——全片一只手，不逐镜换腔。服装片两型最常用（表内加粗）。

| 声音 | 相机 | 光 | 色彩 | 节奏 | 适合 |
|---|---|---|---|---|---|
| Observational naturalist | 不可见、动机化、少动/微手持 | 可用/动机软光 | 柔和真实 | 长镜晚切 | 纪实、真实瞬间 |
| Composed classicist | 刻意、平衡、有度 | 动机化但塑形 | 受控和谐 | 从容卡拍 | 高定、premium、年代 |
| Kinetic visceral | 手持能量、跟拍、近景 | 硬高反差 | 冲、去饱和糙感 | 快速敲击 | 运动、hype |
| **Expressive stylist** | 设计感运镜、大胆构图 | 戏剧化、动机但推满 | 饱和、签名色板 | 音乐性 | **时尚片、音乐视频、幻想** |
| Intimate minimalist | 近镜、小动 | 单一柔源 | 暖或克制 | 慢、少切 | 私人、情感、孤独 |
| **Graphic formalist** | 锁定/精确、几何构图 | 硬、成形 | 限定刻意 | 精确、deadpan | **高定、runway、设计向品牌** |

高定/秀场示例多用 Graphic formalist（锁定机位、几何构图、硬成形光、精确节奏）；时尚片通用 Expressive stylist（设计感运镜+戏剧化光+签名色板）。

| 蒸汽波 | 复古摆动、慢动作、失真感 | 滑轨缓推、渐变光效 | 复古卡点、粉紫氛围 | 蒸汽波、粉紫霓虹、复古动态 |
| 西部牛仔 | 大步走、骑马动势、尘土 | 跟拍、低角度 | 粗粝节奏、西部感 | 西部牛仔、荒漠、粗粝动态 |

**人体比例（统一口径）**：**用户什么都没有（无 Muse/无着装图）→ 视频模特一律头身比 1:9、裆到脚底占身高 55%**（写死）；**有 Muse / Muse 着装图 → 以这些图为基准制作**（首帧锚定比例，提示词不写数字）；**用到其他角度时，参考 Muse 其他角度图片着装后再制作**。动画/时装电影向（明确插画风格）可 9–10 头（`fashion-illustration-spec.md` 6A）；群像片全部人物统一一个口径，不混用。视频首帧锁比例、镜头机位贯穿一致；比例差先调组合参数，仍差按锚点重出。

## 镜头表（多镜/多人前必填的硬门）

任何**多镜或多模特**片子，进四段式前先填镜头表，逐格想清楚再写 prose——模型不记事，但表会替你记事。单镜短片可跳过，群像片必须全填。

| 列 | 填什么 |
|---|---|
| 镜头 | 编号 |
| 机位 | 相对固定地标在哪侧 + 景别（wide/medium/close） |
| 入镜者 | 每人位置/朝向；背景组一次描述 |
| 视线 | 谁看什么；反应镜头机位在"被反应物"一侧 |
| 动作 | 本镜唯一主动作；反应=感受词+物理锚点（见动作库） |
| 他人 | 每人一行持续空闲业务（呼吸/眨眼/目光漂移，不许静止冻结） |
| 光 | 光源+色温（与首镜同词复述，见锁行） |
| 末帧 | 本镜结束时画面停在哪（必须机位可见；选型见「切点与构图」的结束档案） |

**纸面渲染**：填完逐行朗读，任何"未注明/大概"都是免费找到的错。服装片场景简单可精简为 4 列（机位侧/主体朝向/主动作/末帧），群像必须 8 列全填。

## 15 秒五镜结构

| 时间 | 镜 | 干什么 | 硬要求 |
|---|---|---|---|
| 0–3s | 建立造型 | 全长帧，模特稳定下来 | 领口、下摆、手、脚不被裁切 |
| 3–6s | 展示侧面 | 固定机位，四分之一转身 | 保持同一机位高度 |
| 6–9s | 揭示动态 | 侧面跟拍走位，或固定机位 | 让下摆自然摆动 |
| 9–12s | 展示构造 | 稳定特写：肩带、缝线、闭合件 | 让光扫过表面直到细节可读 |
| 12–15s | 干净收尾 | 中景正面，衣服稳定 | 留出放一句短产品名的余地 |

跨镜保持一致：服装、白平衡、站位标记、布光。先比对中性的开场与结尾两帧，再做创意调色。

### 锁行（每镜结尾加一行，同词复述）

全局约束管全片不变项；**锁行管每镜会变的位置/朝向/机位**——模型跨切不记事，逐镜复述才兜得住。模板（接你的全局约束，逐镜重复）：

```
同一光位：仅一处主光，暖白。模特：长发，穿 @图片1 服装（结构/色位/长度不变），
站位于场景中央偏左，面朝镜头偏右 30°。机位在她正面偏右。
```

关键：**同词复述**，不是"同上"；光、身份、位置、机位朝向四项每镜重写一遍。

## 动作库

| 动作 | 展示什么 |
|---|---|
| 整理衣领 / 抚平前襟 | 领型、肩线、面料手感 |
| 四分之一转身 | 侧面轮廓、背部结构、缝线 |
| 两步走 | 下摆摆动、裤装垂坠、面料重量 |
| 抬手 / 插袋 | 袖窿余量、袖长、口袋位置 |
| 坐下 / 起立 | 抗皱回弹、裙装堆叠 |
| 小幅摆胯 / 拨发 | 主体与服装的动态关系 |
| 止步回望 | 收尾定格，完整廓形 |

**道具写手**（服装特写/闭合件/手持物）：写手怎么拿、倾斜、去向——不写结果动词，写过程。例：`翻腕把杯口朝下放` 优于 `把杯子放下`；`指尖捻住拉链头，拉到 1/3 停住` 优于 `拉拉链`。

**避免高速动作**（奔跑、跳跃、大幅旋转）。给动作定五要素：起点标记、终点标记、节奏、转身点、视线。

### 表演锚点（表情/情绪写法：感受词 + 一个物理锚点）

模型渲染不了"情绪名词"（清冷/高级/紧绷），但渲染得了具体行为。写表演 = 感受词打头 + **一个可执行物理锚点**；禁习语（"目光如刀"），禁纯肌肉列表（"嘴角下压"会读成噘嘴）。

| 感受 | 物理锚点（可执行） |
|---|---|
| 清冷/疏离 | 眼神不追镜头，嘴角无弧度，下颌微抬 |
| 松弛/高级 | 肩线放平，重心单腿，视线自然游移 |
| 克制/紧绷 | 喉结微动，指尖轻按面料，呼吸可见 |
| 沉浸/享受 | 闭眼微仰，裙摆被风吹起时匀速转身 |
| 惊讶/被吸引 | 视线先到、头后到；眨眼后目光停在目标上 |
| 不舍/收束 | 手在面料上滑到边停住，不看镜头 |

微表情物理锚（单镜内最多 2 个）：一次眨眼、喉结动、嘴角上挑并保持半秒、指尖轻压。

> 静态大片同一套表见 `image-editorial.md`（图片只定格"瞬间"）；两处同源，改动须同步。

## 运镜四选一

每段只选一个，写明服务什么：

| 运镜 | 用途 | 风险 |
|---|---|---|
| 固定机位 | 正/侧/背视图，或稳定画面内转身 | 无聊，靠动作补 |
| 缓慢推近 | 从整体看到领口/闭合件 | 两端查焦点，细节出画前停 |
| 侧面跟拍 | 平行走位，展示下摆动态 | 保持距离速度，别走出布光区 |
| 小幅弧线 | 揭示体积或叠穿 | 反光变、背景乱、手臂挡廓形 |

出现漂移、广角拉伸、防抖掰弯背景，就简化运镜。

## 切点与构图

- 同造型拍 wide/medium/detail 三级，切点才有落处
- 在可重复的动作上切（如转身开始）
- 切点前后保持屏幕方向一致
- 横竖版分别排练构图——居中 16:9 不会保护 9:16 的手、下摆和文字

### 结束档案 6 型（末帧选型：下一段是"接"还是"立"）

每镜末帧按下一段的意图选，不随便停：

| 型 | 用在哪 |
|---|---|
| Resolve（收束） | 本镜节拍完成，干净结束 |
| Extension anchor（延展锚） | 末帧留开放动作给下一镜续接 |
| Loop seam（循环缝） | 首尾无缝循环（产品循环 gif 类） |
| Hero hold（主体定格） | 主表演定格展示 |
| Edit point（剪辑点） | 停在可切处（如转身开始） |
| Reveal（揭示） | 末帧揭示新信息，钩下一段 |

### 多段续拍交接（时装电影/双段 campaign 专用）

续写下一段前，先记录上一段**实际成片（或尾帧）**的：开场状态 / 实际结束状态 / 未闭合动作 / 机位相位 / 服装位置与状态 / 光相位。下一段从"实际结束状态"开场，**不从计划开场**；接受态覆盖计划态；被否的片段不得作为下一段起点。

- **场景=重锚单元**：同一地点+时间包络内才可无缝续写；场景边界=有意切，从权威锚点图重开。
- **链深上限 ≤2 硬 3**：连续吃输出片段的生成不得超过 3 次，超了必须回锚点图重锚——**按计划重锚，不等漂移可见**。首帧锁比例、镜头贯穿一致。

## 群像 / 多模特视频（秀场、群像大片专用）

多人同框是视频最易串脸/串衣的场景。规则（与 `ai-model-muse.md` 第七节图片向多人同理，视频更严）：

1. **每个模特先有身份卡 + 标准 6 件模卡资产包**（`ai-model-muse.md`）；视频用的定妆锚点图按人分别生成（一人一张），不共用。
2. **服装归属写进锚点**：谁穿哪件跨镜头不乱——每件服装指定穿它的人，素材映射里逐件写"LOOK 编号 × 模特编号"。
3. **站位与运动路径**：群像镜头先定站位（谁在左/中/右、谁先动），运动路径与交错点写清，避免穿模与遮挡抢戏。
4. **群像防串脸**：提示词点名"图1=模特A（发色/服装主色块/站位最左）、图2=模特B（…）"，用可区分标签锁人（同 `consistency-lock.md`）。
5. **统一比例与地面**：所有人同一比例（无母版同一 1:9+裆 55%；有母版以母版为准；或同一插画头身），同一地面透视，否则"不是一个世界"。
6. **主次分配**：每个镜头只给 1 个主表演，其余为站位/氛围，避免多人同时大动作互相干扰。
7. **三人动作层级（群像稳定器）**：画面里每个可见人物取**且只取**一个层级——
   - **① 持续微动作（默认）**：呼吸、眨眼、轻微肩动、发丝、目光漂移——非焦点所有人用这层，连续无空隙；
   - **② 单个聚焦反应**：只有主表演者有一个带时间窗的小反应（`嘴角上挑并保持半秒注视`）；
   - 人-道具物理（举杯、递物）多人同框最易崩：保持接触简单或移出画面。

## 布光与面料

起手大面积柔光前侧 + 对侧反光板，让脸、领口、下摆在整条路径可读，需要分离背景加轮廓光。面料与光位的精确对应见 `image-detail-fabric.md` 的面料-光位表。

### 光即情绪五杠杆（布光前先定"光在说什么"）

光不是亮度是意义。每个主光源在进四段式前过这五问：

| 杠杆 | 怎么调 | 读出来是什么 |
|---|---|---|
| 光比 | key:fill 低比高调 | 低比=安全/开放/商业；高比=私密/威胁/戏剧 |
| 主光方向/高度 | 正面/侧面/逆光/底光/顶光 | 正面讨好、侧面揭示肌理、逆光孤立、底光不安、顶光审判 |
| 色温 | 暖/冷/冷暖并置 | 暖=亲密/记忆；冷=距离/夜；并置=内在分裂 |
| 动机 | 每个光源必须有来处（窗/灯/屏/太阳） | 无动机的"美光"=塑料感 |
| 光随转折变 | 云过、灯开、门缝光束 | 剧情翻转时光一起翻 |

起手光位方案确定后，用这五问验证一遍：光有没有动机、够不够让面料/轮廓可读、情绪对不对——比堆"氛围感"三个字可靠。

## 时间轴写法

- 时间范围连续：`0–3、3–7、7–15 秒`，不留空档
- 精确："第 5 秒甩镜向左，用划像接自然叠化"；相对："按下快门后定格一秒"
- **密度是硬约束**：太少模型自由发挥，太多动作被省略、剪辑慌乱
- 先写主要动作，细节留给少数记忆点
- 常见术语可直接用：大远景/中景/特写/推近/拉远/横摇/俯仰/低角度/俯拍/一镜到底/航拍/FPV/滑动变焦
- 不常见术语靠画面描述，例如："从第 4 秒开始变焦：前景杯子逐渐失焦，背景人物从模糊变清晰，焦点过渡平滑，机位不变。"

### 转场库（按需选，AI 适用性注明）

| 转场 | 效果 | AI 适用性 |
|---|---|---|
| 硬切 | 干脆、节奏感 | ✅ 最可靠 |
| 叠化 | 柔和、时间流逝 | ✅ 可靠（时长 0.3–0.8s 最佳） |
| 划像 | 复古、编辑感 | ◐ 偶发不齐，可后期补 |
| 甩镜/快速横摇 | 动感、衔接动作 | ◐ 容易糊，慎用 |
| 匹配剪辑 | 形状/动作衔接，高级 | ◐ 依赖两镜构图，先排 wide/medium/detail |
| 动画转场（粒子/图形） | 花字/数字感 | ✗ 后期做，AI 不直出 |

### 节奏密度三档（按时长给镜头数）【经验值】

| 时长 | 镜头数 | 平均镜头时长 | 说明 |
|---|---|---|---|
| 15 秒 | 4–6 | 2.5–3.5s | 五镜结构（见上） |
| 30 秒 | 8–12 | 2.5–3.5s | 双段：建立+推进+收束 |
| 60 秒 | 14–20 | 3–4s | 时装电影：留白+长镜可更多 |

- 高定/时装电影取上限（更少更长），campaign/社媒取下限（更多更短）。

## 白模（3D 预演）

只在严格锁运镜和空间关系时用。白模负责镜头顺序、机位、构图、主体路径、节奏，不负责材质与外观。

- 写明控制范围：`@视频1 只用于镜头顺序、机位、构图、主体路径与节奏，不复制材质与人物外观。`
- 时间到画面映射：`0–3 秒对应 @图片2；3–5 秒对应 @图片3……`
- 收尾：`严格保持 @视频1 的镜头结构，不新增镜头。`
- **必须加负面**：`不要生成运动路径、坐标轴或摄影机辅助线。`
- 白模用简单几何体，去掉路径、坐标轴、视锥
- 重渲染固定句式：`完全重渲染 @视频1，严格保留其动作路径、运镜、时间与构图。`

## 声音与后期包装（成片交付前）

Seedance 等图生视频模型**主要出画面**：配乐、音效、旁白、字幕、花字、封面一般在后期（剪辑/云平台）加，不指望模型自动生成音乐。声音与包装是成片最后一道工序，决定"高级感"和"能不能直接发"。

### 先定要不要声音（按影片类型）

| 类型 | 音乐 | 旁白/字幕 |
|---|---|---|
| 高定时装电影 / Moodfilm / 编辑大片 | 氛围器乐或**纯环境音**，弱鼓点、敢留白 | 通常无旁白、无花字（`consistency-lock.md` 的"无字幕无 BGM"即用此类） |
| 品牌宣传片 Brand film | 递进式配乐，可主题旋律 | 可加 1–2 句品牌主张/旁白 |
| 系列宣发 Campaign | 有明确鼓点、跟剪辑 | 结尾落产品名/系列名 |
| 秀场影片 | 稳定 BPM，跟步伐 | 可有品牌/系列标题，无口播 |
| Techfilm | 干净、少人声 | 数据/功能字幕为主 |
| BTS | 现场同期声为主 | 偶尔小标题，保持真实 |

### 配乐 BGM（版权是底线）

- **只用可商用音乐**：平台/剪辑工具自带的版权曲库（如即梦、剪映等云曲库），或订阅式授权曲库；**不直接用流行歌曲、明星曲目、未授权音乐**——下架与侵权风险，商用尤其致命。
- 选曲与类型匹配：高定/时装电影=器乐/氛围/古典/极简电子，慢板、留白；campaign=有节奏鼓点；秀场=稳定 BPM 跟步点；机能/户外=电子/工业节奏；垂坠慢料用长音，硬挺结构用利落节拍。
- **卡点**：切点落在鼓点/重拍或可重复动作上；走秀类常取 **100–120 BPM【经验值】**，高定慢片少切、跟呼吸。别为卡点硬塞动作。
- 同系列多切片统一一套音乐风格/版头，形成听觉识别。

### 音效 SFX（点到为止，提升质感）

- 环境底噪：风声、空间感、海浪、室内氛围（先铺一层，画面才有"空气"）。
- 服装相关：丝绸摩擦、裙摆摆动、脚步声、拉链/扣合、面料抖开——正是 Techfilm 与细节镜头的"高级感"来源。
- 转场音：whoosh、低频冲击等克制使用；**不堆满音效**，每段留 1–2 个记忆点。

### 旁白 / 配音

- 品牌片需要旁白时，文案走 `text-content.md`（品牌主张/主题概念）；人声或 AI 配音均可，AI 合成人声按平台要求标注。
- 旁白节奏给画面留白，不要从头说到尾；人声与 BGM 做音量平衡（人声清晰、BGM 垫底）。

### 字幕 · 花字 · 封面（全部后期排，不进 AI）

- 图内文字一律后期叠加，不让视频模型生成文字（会糊、会错）。
- 字体全案统一、≤2 个字族；中英双语；高对比描边/半透明底条保证可读。
